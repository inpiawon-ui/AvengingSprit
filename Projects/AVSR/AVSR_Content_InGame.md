## 2. 진행 단위

```
CHAPTER(3) > STAGE(30/챕터) > ROOM(6/스테이지)
```

룸 입장 → 오토어택 교전 → [호스트 사망] 고스트 복귀 → 재빙의
→ 전멸 → 룸 클리어 → 다음 룸 → (6번째 룸) **보스** → 스테이지 클리어

- 1~5 룸: 잡몹 4~7기 (룸이 깊을수록 증가)

- 클리어 = 골드 + 고스트 EXP 지급 후 로비 복귀. **실패는 진행도를 올리지 않는다**

## 3. 코어 규칙

| # | 규칙 | 구현 |
|---|------|------|
| 0 | **멈춰야 쏜다** — 이동 중에는 공격하지 않는다. **궁수의 전설의 기본 규칙** | `TickPlayer` |
| 1 | **빙의** — 고스트가 적에게 접근하면 `POSSESS` 활성. 누르면 그 적의 몸을 뺏는다 | `BattleDirector.TryPossess` |
| 2 | **오토어택** — 정지 상태에서 사거리 안 최근접 적에게 자동 발사 | `TickPlayer` |
| 3 | **투사체** — 기본 공격은 탄이 날아가 맞아야 피해가 들어간다. **유도하지 않는다** | `Projectile` |
| 4 | **상실** — 호스트 HP 0 → 그 자리에서 고스트로 복귀. 고스트 HP 0 → 스테이지 실패 | `LoseHost` / `Finish(false)` |
| 5 | **얼티밋** — 시간으로 자동 충전. 발동 시 화면 전체 광역 | `TryUltimate` |
| 6 | **버프 3택1** — 룸 클리어마다 런 한정 빌드를 쌓는다 | `OnRoomCleared` / `ChooseBuff` |
| 7 | **보스 패턴** — 페이즈 3단계 · 패턴 5종. 예고 후 발동 | `BossBrain` / `TickBoss` |

### 왜 "멈춰야 쏜다" 가 최상위 규칙인가

플레이 스타일 정본은 **궁수의 전설**이다. 그 게임이 성립하는 이유는 **이동과 공격이 배타적**이라
매 순간 *자리를 옮길까 / 딜을 넣을까* 를 고르게 만들기 때문이다.
움직이면서도 쏘게 하면 조이스틱은 그냥 산책이 되고 적 탄을 피할 이유도 사라진다.

같은 이유로 **투사체는 유도하지 않는다.** 전탄 명중이 보장되면 위치 선정이 의미를 잃는다.

멈춘 뒤 `AttackResumeSeconds`(0.12초) 의 준비 시간을 둔다. 없으면 톡톡 끊어 눌러도
손해가 없어 "멈춤의 대가" 자체가 사라진다.

**고스트는 공격할 수 없다.** 핵심 동사(`빙의한다 · 싸운다 · 잃는다 · 다시 빙의한다`)를 강제하기 위함이다.
대신 고스트는 **받는 피해가 22%** 로 줄고 이동이 가장 빠르다 — 빙의할 틈을 만들기 위한 수치다.

## 4. 화면 요소 (요소 이름 = 프리팹 GameObject 이름 = 클라 바인딩 키)

| 그룹 | 요소 | 표시 데이터 |
|------|------|-------------|
| `TopHudGroup` | `GhostHudIcon` · `GhostLabel` · `GhostHpBarBg/Fill` · `GhostHpText` | 고스트 체력 |
| | `HostPortraitFrame` · `HostPortraitImage` · `HostLabel` · `HostHpBarBg/Fill` · `HostHpText` · `HostNameText` | 빙의 중인 호스트. 미빙의 시 숨김 |
| | `BossGroup`(`BossLabel` · `BossHpBarBg/Fill` · `BossHpText`) | 보스 룸에서만 표시 |
| | `GoldIcon`/`GoldText` · `GemIcon`/`GemText` · `PauseButton` · `StageText` | 재화 · 일시정지 · `ROOM n / 6` |
| `RoomField` | `RoomFloor` · `UnitLayer` · `ShotLayer`(런타임 생성) | 전투 필드 |
| `ControlGroup` | `DPadBase` + `DPadKnob` | 이동. **플로팅 패드** — 아래 참조 |
| | `UltimateButton` + `UltimateCooldown` | 충전 완료 시 발동 가능 |
| | `PossessButton` | 빙의 가능 대상이 있을 때만 활성 |

> `ULTIMATE` · `POSSESS` 글자는 **버튼 스프라이트에 이미 들어 있다**(목업 크롭). 별도 TMP 라벨을 얹지 않는다.

### 가상 패드는 플로팅이다

화면 아무 곳이나 누르면 **패드가 그 자리로 따라오고**, 손을 떼면 원래 자리로 돌아간다.
한손 세로 조작에서 엄지가 닿는 위치는 매번 다르다 — 고정 패드는 손을 옮기게 만든다.

| 동작 | 결과 |
|------|------|
| 화면(HUD 제외) 터치 | 패드 중심이 그 지점으로 이동. **이동 입력은 0** |
| 드래그 | 중심 대비 방향이 이동 입력. 패드 폭의 30% 에서 최대 속도 |
| 손 뗌 | 패드·노브 원위치, 이동 입력 0 |

- 누른 순간 입력이 0 이어야 **"멈춰야 쏜다"** 가 유지된다. 탭만으로 사격이 끊기면 안 된다.
- **데드존 18%** — 미세한 흔들림이 이동으로 잡히면 사격이 영영 재개되지 않는다.
- 전체 화면 입력판(`TouchCatcher`)은 버튼보다 **아래**에 둔다.
  `ULTIMATE` · `POSSESS` · `PAUSE` 가 터치를 먼저 가져간다.
- 장식 이미지(바닥·HP 바)의 레이캐스트는 전부 끈다. 하나라도 켜져 있으면 그 위에서 패드가 죽는다.

## 5. 호스트별 공격 차등

**"어떤 몸을 뺏었는가가 빌드를 결정한다"** 가 한 줄 컨셉이므로, 12종이 실제로 다르게 싸워야 한다.
`HostTable` 의 `역할` 문구를 그대로 교전 수치로 옮겼다.

| 호스트 | 역할 | 방식 | 사거리 | DPS(전탄) | 특수 |
|--------|------|------|-------:|----------:|------|
| 아마조네스 | 고속 근거리 | `Melee` | 95 | 73 | — |
| 람보 | 중화기 사수 | `Rapid` | 210 | 73 | 발당 피해 최저·연사 최고 |
| 마법사 | 마법 원거리 | `Pierce` | 273 | 81 | 관통 |
| 닌자 | 밸런스 어쌔신 | `Spread` 3발 16° | 189 | 123 | — |
| 마피아 | 확산 사수 | `Spread` 5발 34° | 147 | 130 | 넓게 퍼져 원거리 명중률 낮음 |
| 히트맨 | 정밀 저격 | `Snipe` | 357 | 90 | 탄속 1.6배 |
| 요가마스터 | 부양 서포트 | `Pulse` | 116 | 32 | **사거리 안 전원 동시 타격** |
| 드래곤 | 헤비 탱크 | `Spread` 3발 12° | 105 | 109 | HP 최고(95) |
| 로봇 | 테크 밸런스 | `Pierce` | 231 | 60 | 관통 |
| 설녀 | 얼음 컨트롤 | `Single` | 221 | 48 | **둔화 45% / 1.6초** |
| 슬러거 | 탄환 반사 | `Melee` | 126 | 87 | **사거리 안 적 탄 소거** |
| 흡혈귀 | 흡혈 전투 | `Melee` | 105 | 88 | **피해의 35% 회복** |

- `DPS(전탄)` = 모든 탄이 맞았을 때의 상한. 확산은 거리가 멀수록 실제 DPS 가 급락한다.
- **적도 같은 프로파일을 쓴다** — 방마다 등장 조합이 달라 교전 양상이 바뀐다.
- 수치는 `GameConfig` 기본값 × `HostTable` 배율이다. 밸런스는 배율만 고쳐 조정한다.

> 드래곤은 초기값에서 DPS 204 로 1위였다. "헤비 탱크"는 맷집이 정체성이므로 간격을 늦춰 109 로 내렸다.

## 6. 로그라이크 버프 3택1

룸을 클리어할 때마다 12종 중 서로 다른 3개를 뽑아 제시하고, 하나를 고를 때까지 전투가 멈춘다.
**런 한정**이다 — 스테이지를 나가면 사라진다 (`RunBuffs.Clear()` on boot).

| 키 | 이름 | 효과 | 중복 |
|----|------|------|:---:|
| `atk_up` | 공격력 강화 | 피해량 +25% | ○ |
| `aspd_up` | 연사 강화 | 발사 간격 −18% | ○ |
| `range_up` | 사거리 강화 | 사거리 +25% | ○ |
| `move_up` | 질주 | 이동 속도 +18% | ○ |
| `ghost_hp` | 영혼 강화 | 고스트 최대 체력 +40 (즉시 회복) | ○ |
| `heal` | 응급 회복 | 호스트 체력 40% 회복 (즉발) | ○ |
| `multishot` | 다중 사격 | 탄 +1 발 | ○ |
| `pierce` | 관통탄 | 탄이 적을 관통한다 | ✗ |
| `lifesteal` | 흡혈 | 피해의 15% 회복 | ○ |
| `slow` | 서리 | 명중 시 둔화 25% | ○ |
| `ult_charge` | 얼티밋 충전 | 충전 속도 +30% | ○ |
| `shot_speed` | 탄속 강화 | 탄속 +30% | ○ |

- 중복 불가(`pierce`)는 한 번 고르면 제외 목록에 들어가 다시 뽑히지 않는다.
- **버프는 유닛 스탯을 덮어쓰지 않고 발사 시점에 곱한다.** 빙의로 몸이 계속 바뀌는
  게임이라 스탯에 새기면 호스트가 바뀔 때마다 다시 입혀야 하고 원본 수치를 잃기 쉽다.
- 적에게는 적용하지 않는다. 플레이어 전용 강화다.

## 7. 보스 패턴

잡몹은 "접근 후 사거리 안이면 공격" 한 줄이면 되지만, 보스는 **여러 행동을 각자의
쿨다운으로 돌리고 체력이 깎이면 레퍼토리가 늘어난다.**

### 페이즈

| 페이즈 | 조건 | 변화 |
|:---:|------|------|
| 1 | 시작 | 기본 패턴만 |
| 2 | 체력 **60%** 이하 | 패턴 추가 + 쿨다운 단축 |
| 3 | 체력 **30%** 이하 | 패턴 추가 + 쿨다운 추가 단축 |

쿨다운은 페이즈마다 `PhaseCooldownMul` 을 곱한다 (0.72~0.80). 체력이 줄수록 압박이 커진다.

### 패턴 5종

| 패턴 | 동작 | 의도 |
|------|------|------|
| `Volley` | 플레이어 방향 부채꼴 탄막 | 정면을 비우게 만든다 |
| `Ring` | 사방 360° 탄막 | **붙어 있으면 피할 수 없다** — 거리를 벌리게 만든다 |
| `Charge` | 플레이어를 향해 돌진, 접촉 피해 | 멈춰서 딜하는 자세를 깬다 |
| `Summon` | 잡몹 소환 | 보스만 노리다 둘러싸이게 만든다 |
| `AimedBurst` | 조준 연사 | 이동 중 처벌 |

### 챕터 보스 3체

| 챕터 | 보스 | 성격 | 패턴 (시작 페이즈) |
|:---:|------|------|--------------------|
| 1 | `MAD DOCTOR` | 소환형 | Volley(1) · Summon(1) · AimedBurst(2) · Ring(3) |
| 2 | `IRON CLAW` | 돌진형 · 이동 1.3배 | Charge(1) · AimedBurst(1) · Volley(2) · **Charge 강화(3)** |
| 3 | `OVERLORD` | 탄막형 · HP 1.55배 | Ring(1) · Volley(1) · Summon(2) · **Ring 16발(3)** |

- **모든 패턴은 0.45초 예고 후 발동한다.** 유닛이 노랗게 번쩍인다.
  피할 시간을 주지 않으면 패턴이 아니라 사고다.
- 보스 탄은 잡몹과 **색을 나눈다**(적색). 화면이 탄으로 덮이면 무엇을 피해야 할지 안 보인다.
- 소환은 방 유닛 상한(14)을 넘지 않는다. 무한 소환으로 화면이 잠기는 것을 막는다.

> 보스 이름 3종은 아직 `[TBD]` 다 — 목업이 CH3 `MAD DOCTOR` 만 노출했고 챕터 서사가
> 미기획이다. 현재 값은 로비 챕터 카드와 맞춰둔 임시 문구다.

## 8. 적 배치와 어그로

필드는 **720 × 900**(캔버스 px)이다. 이 절의 수치는 그 크기를 전제로 한다.

### 배치

| | 값 | 이유 |
|---|---|---|
| 적 배치 띠 | 필드 높이 **6% ~ 44%** (y −54 ~ −396) | 위쪽에 넓게 흩는다 |
| 가로 범위 | 필드 폭 **10% ~ 90%** · 행마다 ±7% 어긋남 | 격자로 딱 맞으면 대형처럼 보인다 |
| 플레이어 시작 | 필드 높이 **80%** (y −720) | 가장 가까운 적과 **324px** — 탐지 거리보다 멀다 |

### 어그로

```
탐지 거리 300  ·  분리 거리 82
```

- 탐지 거리 **밖이면 제자리에서 기다린다.** 플레이어가 들어가야 달려든다.
- 한 번 인지하면 **꺼지지 않는다.** 멀어졌다고 잊으면 적이 왔다 갔다 하며 어그로가 끊긴 것처럼 보인다.
- **맞으면 거리와 무관하게 인지한다.** 히트맨 사거리(357)가 탐지 거리(300)보다 길어,
  이게 없으면 저격당하고도 가만히 있는 그림이 된다.
- 보스가 소환한 잡몹은 처음부터 인지 상태다.

### 분리

전부 같은 목표로 달려가면 사거리가 비슷한 개체끼리 같은 지점에 겹쳐 **한 마리처럼 보인다.**
82px 안의 개체끼리만 반대로 밀어 덩어리를 푼다(이동 속도의 55%).

> 시작 위치 80% · 배치 띠 44% · 탐지 300 은 서로 묶여 있다.
> 하나를 바꾸면 첫 프레임부터 적이 달려들거나, 반대로 다가가도 반응하지 않게 된다.

## 9. 수치

모든 전투 수치는 `GameConfig` SO 한 곳에서 관리한다 (`04_scenes.md` 규약 — 스크립트 하드코딩 금지).
에셋 `Assets/BundleResource/TableData/GameConfig.asset` · 주소 `TableData/GameConfig`.

호스트 테이블의 스탯은 **0~100 표시 스케일**이다. 전투 수치는 `GameConfig` 계수로 환산한다 —
표시값을 건드리지 않고 밸런스만 조정하기 위함이다.
