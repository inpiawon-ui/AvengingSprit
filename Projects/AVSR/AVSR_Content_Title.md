## 1. 목적 (플레이어 경험)

앱을 켠 직후 **"1991년 그 게임이다"** 를 3초 안에 각인시키는 브랜드 관문. 기능은 하나 — **탭해서 로비로 들어간다.**
`[도출: 1차 범위 3콘텐츠 중 가장 단순한 화면. 타이틀에 선택지를 늘리면 원작 아케이드의
"화면 하나 · 프롬프트 하나" 정서가 깨진다. 확정 #1(원작 감성 최우선) 적용.]`

## 3. 기능·규칙 (동작)

### 3-1. 부팅 → 타이틀 → 로비 흐름

```
BootScene   모듈 등록 → Addressable 카탈로그 → 마스터 테이블 → UserData 로드/신규 생성
            └ 완료 시점에 "게임 시작 가능" 상태가 보장된다
   ↓ LoadAsync(SceneNames.Title, LoadingStyle.None)
TitleScene  로고 노출 → TAP TO START 점멸 → (백그라운드) label_lobby 사전 로드
   ↓ 탭 → LoadAsync(SceneNames.Lobby, LoadingStyle.Overlay)
LobbyScene
```

- **로딩은 부트에서 끝낸다.** 타이틀 진입 시 필수 데이터는 이미 준비 완료다.
  `[도출: 확정 #4(로컬 우선 저장) — 로컬 로드는 빨라 타이틀을 로딩 대기실로 쓸 이유가 없다.
  타이틀이 데이터 준비를 겸하면 "탭했는데 안 넘어가는" 구간이 생겨 첫인상을 해친다.]`
- 대기 중 **`label_lobby` 사전 로드**(선택적 최적화, 실패해도 진행 차단 없음). `[근거: 02_addressables.md — 사전 로드는 라벨, 런타임 로드는 주소]`
- 탭 시점에 미완이면 **`LoadingStyle.Overlay`** 로 덮어 대기. `[도출: 로딩 씬을 추가하면 씬이 하나 늘어난다. 1개월 범위(확정 #23)에서 비용 대비 이득 없음.]`

### 3-2. 입력 규칙

- 유효 입력은 **화면 전체 탭 1종**뿐. 스와이프·롱프레스·백버튼은 무시. 첫 탭 후 `TouchArea` 즉시 비활성(중복 전환 차단).
- **`TAP TO START` 채택 — `START` 버튼 위젯이 아니다.**
  `[도출: 원작 아케이드는 프레임 버튼이 아니라 점멸 프롬프트(PUSH START BUTTON)로 시작을 유도했다.
  프레임 버튼을 두면 로비 CTA(`CONTINUE` 골드 프레임)와 같은 언어가 되어 타이틀이 로비의 축소판으로 읽힌다.
  확정 #1에 따라 원작 방식(점멸 프롬프트 + 전면 탭)을 택한다.]`

### 3-3. 첫 실행 vs 재실행 — **분기 없다**

`[도출: 신규 유저 판정(세이브 유무 → saveVersion 부여)은 Boot의 UserData 초기화 책임이다.
튜토리얼·호스트 선택 직행은 1차 범위 밖이며, 필요해지면 **로비 진입 후 로비가 분기**한다.
타이틀에 분기를 넣으면 "브랜드 각인" 단일 책임이 깨진다.]`

### 3-4. 어테랙트 모드 · 데모 플레이 — **넣지 않는다**

`[도출: 어테랙트 모드는 코인 투입을 유도하는 캐비닛 장치다. 이미 설치·실행한 모바일 유저에게는 유도 대상이 없고,
확정 #3(1차 범위에 전투 없음)이라 보여줄 데모 자체가 존재하지 않는다. 스캔라인·CRT 필터도 배제 — 확정 #16(후처리 최소).
원작 감성은 §5의 정적 연출로 확보한다.]`

- **BGM**: 원작 타이틀 테마 어레인지, 루프, 로비 진입 시 크로스페이드. `[TBD — 이유: 원작 음원 사용 범위가 IP 확인 대기(확정 #25)에 종속]`

## 6. 의존 · 연결

| 구분 | 대상 |
|------|------|
| 선행 | **Boot** — 모듈 등록·테이블·UserData 준비 완료가 타이틀 진입 전제 |
| 후행 | **로비(HUB)** — 유일한 출구 |
| 공통 | `ISceneManager` · `IEventBus` · `IResourceManager`(라벨 사전 로드) |
| 무관 | 재화·진행도·호스트 데이터 — 타이틀은 **유저 데이터를 읽지도 쓰지도 않는다** |

### 발행 / 구독 이벤트

> 규약: `IEventBus` 경유. `C# event`·`Action` 직접 선언 금지. `IEvent` 는 `public struct`(`readonly` 금지).
> 씬 전환은 `ISceneManager.LoadAsync(SceneLoadRequest)` — `UnityEngine.SceneManagement` 직접 호출 금지.
> 씬 이름은 `Game.Module.Common.SceneNames` 상수(`Boot`/`Title`/`Lobby`/`InGame`)만 사용.

| 방향 | 이벤트 | 정의 위치 | 시점 · 처리 |
|------|--------|-----------|------------|
| 구독 | `OnSceneLoaded` | 프레임워크 내장 | `NextScene == SceneNames.Title` 일 때 타이틀 초기화 + `label_lobby` 사전 로드 시작 |
| 발행 | `TitleStartRequestedEvent` | `Game.Module.Events` | `TouchArea` 탭 시 UI가 발행. `TitleModule` 이 수신해 로비 로드 |

```csharp
// Assets/Scripts/Module/Events/ — 필드 없는 신호 이벤트
public struct TitleStartRequestedEvent : IEvent { }
```

- `TitleModule` 은 `Register()` 에서 인스턴스 등록만, **구독은 `Initialize()`**. 토큰(`IDisposable`)은 필드 저장 후 `Dispose()` 에서 해제.
- 로비 전환: `LoadAsync(new SceneLoadRequest { SceneName = SceneNames.Lobby, LoadingStyle = LoadingStyle.Overlay })`
