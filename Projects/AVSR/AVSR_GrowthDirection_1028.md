## 0-1. 모든 요리에 공통으로 까는 밑간 — 「보이는 가위바위보」

상성 ±30% 는 숫자라 화면에서 안 읽힌다. 대신 **적의 모양이 답을 알려 주게** 한다(잡몹 · 엘리트에 다섯 유형).

| 적 유형 | 화면에 보이는 것 | 이기는 스킬 컨셉군 | 왜 이기는지가 보인다 |
|---|---|---|---|
| **방패병** | 앞에 방패 — 정면 탄이 튕긴다 | 돌격 난무 · 설치 | 뒤로 돌아 들어가거나 발밑에서 터진다 |
| **떼** | 작은 놈 여럿이 몰려온다 | 제압 · 탄막 | 끌어모아 한 번에 / 쏟아부어 쓸어낸다 |
| **탄막 사수** | 화면을 덮는 적 탄 | 수호 · 반격 | 막고 되받아친다 — 적 탄이 많을수록 내가 세진다 |
| **날쌘 놈** | 빠르게 파고든다 | 설치 · 소환 | 함정에 걸리고, 분신 · 해골에 시선이 끌린다 |
| **거대한 놈** | 크고 단단하다 | 단일 강타 | 표식 · 급소 · 처형으로 한 놈을 녹인다 |

- 기존 파워 · 무기 · 마법은 **챕터 색 · 보너스 숫자**로 남기거나 이것으로 갈아 끼운다(결정 사항 2).
- 방마다 유형 2~3개를 섞어 내면 「이 방엔 무엇이 필요하지?」가 매 방 생긴다. 어떤 요리에서도 이 질문이 맛의 바탕이 된다.

## 요리 1 — 「사령 군단」 빼앗고, 버리고, 부린다 ★ 추천

**한 줄 맛**: 유령은 복수하는 망령이다. 빼앗았던 몸은 버려지지 않고 **내 망령 부하**가 되어 따라다니며 자기 스킬을 쓴다.
판이 갈수록 화면에 **내가 모은 군단**이 늘어나고, 그 조합이 그 판의 빌드다.

### 한 판 장면
1. 1번 방 — 갱스터를 빼앗는다(입은 몸 = 평타 · 이동 · 필살기).
2. 4번 방 — 떼가 몰려온다. 사슬 닌자를 경직시켜 갈아탄다. **떠난 갱스터는 쓰러지지 않고 반투명한 망령 부하**가 되어 내 옆에서 「일제 표식」을 자동으로 쓴다.
3. 이제 사슬 닌자가 떼를 묶고, 망령 갱스터가 표식을 찍고, 표식 붙은 적은 처형된다 — **두 몸의 스킬이 한 화면에서 같이 돈다.**
4. 12번 방 — 설녀로 갈아탄다. 망령 부하 둘(갱스터 · 사슬 닌자) + 입은 몸 설녀. 묶고 · 얼리고 · 표식 찍고 · 처형.
5. 부하 칸은 3칸. 가득 차면 새로 빼앗을 때 **누구를 놓아줄지** 고른다(놓아준 망령은 혼불로 터지며 마지막 한 방).

### 재료가 이 맛 하나를 위해 하는 일
| 재료 | 이 요리에서의 역할 |
|---|---|
| 빙의 | **영입**이다. 빙의할수록 군단이 커진다 — 빙의가 가장 큰 이득이자 판단(누구를 데려갈지) |
| 액티브 | 입은 몸은 버튼으로, **망령 부하는 자동으로** 쓴다 — 한 화면에 스킬 2~4가지가 같이 보인다 |
| 패시브 | 입은 몸만 켜진다(입을 몸을 고르는 이유) |
| 필살기 | 빙의할 때 찬다(지금 그대로) + **부하 전원이 필살기에 합세**(분신 · 해골이 같이 덤빈다) |
| 가위바위보 | 적 유형에 맞는 부하를 데리고 있으면 이긴다 — 「이 방엔 반격형이 필요해」로 빙의 대상이 정해진다 |
| 군단 시너지 | 같은 컨셉군 둘 = 그 스킬 강화 · 서로 다른 셋 = 「삼각 진형」 보너스 — 레벨업 카드에 군단 카드를 더한다 |
| 유령 육성 | **유령 = 사령술사.** 스탯은 유령에게(체력 · 공격 · 속도) + **사령구 장비**(낫 · 등불 · 망토 · 사슬 · 반지 · 부적 6칸, 궁수의 전설 장비 자리) |
| 호스트 육성 | 성급 = **망령이 되었을 때의 세기** + 스킬 레벨. ★3 이상 호스트는 판 시작에 **계약 망령 1칸**으로 처음부터 데려갈 수 있다 |
| 상점 · 소환 | 조각 = 군단의 품질. 사령구 장비 = 새 수집축 |

### 무엇을 키우나 — 방향이 뚜렷한가
- **사령술사(유령)와 그 장비**가 한 줄 육성(궁수의 전설의 영웅 + 장비).
- 호스트는 「군단 후보」로 모은다 — 컨셉군 7개마다 주력 하나씩이 자연스러운 목표.
- 원작 테마와 가장 잘 맞는다: 영매(강령) · 사신(망자 군단)이 이미 이 맛의 원형이다.

### 위험 · 비용
- 화면이 다시 복잡해질 수 있다 → 부하는 반투명 · 단색 윤곽으로 그리고 스킬 이펙트는 작게(인게임 심플화 시안과 같이 간다).
- 부하 AI(따라다니기 · 자동 시전) 새로 필요. 스킬 69가지는 그대로 재사용.

## 요리 2 — 「영혼 합주」 세 몸을 겹쳐 입는다

**한 줄 맛**: 유령은 호스트 셋을 **장비처럼 겹쳐 입는다**. 액티브를 누르면 세 몸의 스킬이 **정한 순서대로 이어서** 터진다.
순서가 바뀌면 결과가 바뀐다 — 「묶고 → 태우고 → 날린다」 같은 **연계 한 곡**을 짜는 게임.

### 한 판 장면
1. 출전 전 합주 편성: 1번 사슬 닌자(사슬 결박) → 2번 드라군(화염 지대) → 3번 슬러거(풀스윙).
2. 입은 몸은 1번(평타 · 이동 · 패시브). 액티브를 누르면 사슬이 적을 묶고, 0.5초 뒤 발밑에 불바다, 0.5초 뒤 회오리가 묶인 적을 쓸어 날린다.
3. 판 안에서 적 호스트를 빼앗으면 **편성 한 칸을 그 몸으로 바꿀 수 있다** — 「이 방은 탄막이 많다, 3번을 전탄 반사로」.
4. 순서 반응(연계 효과)은 이름이 붙는다: 「묶고 태우기」 · 「얼려서 깨기」 · 「표식 난사」 · 「반사 폭풍」… 처음 터뜨리면 **연계 도감**에 기록.

### 재료가 하는 일
| 재료 | 역할 |
|---|---|
| 액티브 | 한 곡의 음표 셋. 컨셉군끼리 정해진 반응(제압 → 설치 = 모아 태움, 설치(빙결) → 단일 = 파쇄 등) |
| 빙의 | 판 안에서 **편성을 고쳐 쓰는** 수단 — 방마다 적 유형에 맞춰 곡을 바꾼다 |
| 패시브 | 1번(입은 몸)만. 2 · 3번은 스킬만 빌려준다 |
| 필살기 | 세 몸 필살기가 한 컷에 이어 나오는 「합주 필살기」(빙의 때 충전) |
| 가위바위보 | 곡의 **마지막 음**이 적 유형을 맞히면 연계가 2배 |
| 유령 육성 | 유령 스탯 + **펫 하나**(합주 박자를 당기거나 연계 반경을 키움) |
| 호스트 육성 | 성급 = 그 몸 스킬 레벨 + **편성 몇 번 자리에 설 수 있는지**(★1 = 3번 자리만 · ★5 = 2번 · ★7 = 1번) |

### 무엇을 키우나
- 「내 곡 하나」를 정하고 **세 명**을 키운다 — 23명보다 훨씬 좁고 뚜렷하다. 적 유형이 바뀌는 챕터에서 두 번째 곡을 짠다.
- 맛: 퍼즐 · 조합 발견. 데미지보다 「이 순서로 하면 이렇게 된다」가 재미.
- 위험: 연계 반응표(7 × 7 컨셉군) 설계 · 밸런스가 크다. 스킬 시간이 겹쳐 화면이 바빠질 수 있다.

## 요리 3 — 「빙의 릴레이」 갈아탈 때 터진다

**한 줄 맛**: 몸을 갈아타는 순간이 가장 화려한 기술이다. 떠나는 몸은 **이탈기**를 남기고, 들어가는 몸은 **진입기**로 등장한다.
두 기술이 겹쳐 **릴레이 콤보**가 된다 — 빠르게 몸을 바꿔 타며 춤추듯 싸우는 액션.

### 한 판 장면
1. 수류탄 코만도로 싸우다 적 드라군을 경직시킨다.
2. 빙의 버튼 — 떠나는 코만도가 그 자리에 **융단 폭격을 남기고 터지고**, 유령이 날아가 드라군에 들어가며 **진입 화염 폭발**.
3. 두 폭발이 겹치면 「폭염 릴레이」(이름 있는 콤보) — 크게 · 화려하게.
4. 몸은 오래 입을수록 **영혼 부담**이 쌓여 약해진다(체력이 서서히 타 들어감) → 자연스럽게 계속 갈아타게 된다.
5. 상성: 적 속성에 유리한 몸으로 들어가면 진입기 2배 — 「누구에게 들어갈까」가 매 순간 판단.

### 재료가 하는 일
| 재료 | 역할 |
|---|---|
| 빙의 | 게임의 중심 동작. 경직 게이지 = 다음 몸 「찜」 |
| 액티브 | 몸 안에서는 평소대로 + **이탈기**(그 액티브의 남기는 판: 폭탄 · 장판 · 분신 · 포탑) |
| 필살기 | **진입기**(빙의 때 이미 차는 지금 규칙을 「들어가는 순간 짧은 필살기」로) |
| 패시브 | 갈아탈 때 **하나씩 들고 간다**(최대 2칸) — 릴레이가 이어질수록 빌드가 쌓인다 |
| 유령 육성 | 유령 스탯 + **영혼 짐승(펫)** — 빙의 사거리 · 경직 속도 · 빙의 직후 무적 등 「갈아타기 능력」 |
| 호스트 육성 | 성급 = 이탈기 · 진입기 세기, ★ 높은 호스트끼리 릴레이하면 콤보 단계가 오른다 |
| 콤보 도감 | 이름 있는 릴레이 30~40종 발견 · 보상 — 「아직 안 해 본 조합」이 수집 동기 |

### 무엇을 키우나
- 한 명이 아니라 **잘 이어지는 짝(2~3명)**을 키운다 — 「코만도 → 드라군」 짝, 「사슬 닌자 → 슬러거」 짝.
- 맛: 액션 쾌감 · 「빙의 게임」 정체성은 네 요리 중 가장 강하다.
- 위험: 조작이 바빠진다(모바일 한 손). 영혼 부담 수치가 어긋나면 「쉴 틈이 없다」가 된다. 10-04 「갈아타기는 판단이어야」와 부딪히지 않게 비용을 다시 맞춰야 한다.

## 요리 4 — 「영혼 덱」 내 호스트들이 레벨업 카드가 된다

**한 줄 맛**: 궁수의 전설의 레벨업 카드(3장 중 1장)를 **내가 모은 호스트들의 스킬 조각**으로 채운다.
입은 몸에 다른 호스트의 힘을 **이식**해 가며, 판마다 다른 혼종 빌드를 만든다.

### 한 판 장면
1. 출전 전 **영혼 덱 8명** 편성(유령 레벨로 칸이 는다): 갱스터 · 설녀 · 사슬 닌자 · 로봇 · 슬러거 · 청룡 · 드라군 · 영매.
2. 레벨업 카드에 공통 카드와 함께 덱 호스트 카드가 섞여 나온다: 「설녀의 서릿발 — 평타 30% 빙결」 · 「갱스터의 표식 — 적중 시 표식」 · 「로봇의 포탑 — 10초마다 포탑」.
3. 입은 몸이 아마존이어도 서릿발 + 표식 + 포탑을 달고 싸운다 — **몸 + 이식된 힘 = 혼종**.
4. 같은 호스트 카드를 3장 모으면 **강림** — 그 호스트 필살기를 내 버튼으로 쓴다.
5. 판 안에서 적 호스트를 빼앗으면 그 몸의 카드가 **이번 판 덱에 추가**된다.

### 재료가 하는 일
| 재료 | 역할 |
|---|---|
| 레벨업 카드 | 맛의 중심. 공통 36장 + 호스트 카드(23명 × 3장 = 패시브 · 액티브 조각 · 강림) |
| 빙의 | 입는 몸(평타 성격) 바꾸기 + 그 몸 카드를 덱에 넣기 |
| 덱 시너지 | 덱 안 컨셉군 조합 세트(제압 2 + 설치 2 = 「덫의 사냥꾼」 세트 보너스) |
| 가위바위보 | 덱을 챕터 적 유형에 맞춰 짠다(출전 화면에 「이 챕터: 떼 · 탄막」) |
| 유령 육성 | 유령 스탯 + **장비 6칸**(궁수의 전설과 가장 비슷한 자리) |
| 호스트 육성 | 성급 = 그 호스트 카드 **등급**(★1 커먼판 → ★5 에픽판 → ★9 전설판)과 등장 확률 |

### 무엇을 키우나
- 「내 덱 컨셉」(예: 빙결 덱 · 소환 덱)을 정하고 **그 8명**을 키운다 — 카드 게임처럼 방향이 분명하다.
- 맛: 로그라이트 빌드 깊이. 궁수의 전설 유저가 가장 빨리 이해한다.
- 위험: 화면 볼거리는 요리 1 · 3보다 약하다(몸 하나에 효과가 붙는 방식). 카드 69장 추가 설계 · 문구 · 아이콘이 크다.
