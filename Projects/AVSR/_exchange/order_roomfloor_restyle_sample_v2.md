> 일단 이쁘지가 않아... 먼가 원작 느낌도 안살고... 내가 스샷 준것만도 못해..

> 스샷 준건 먼가 요새 느낌을 잘 살렸는데, **하나의 이미지로 완벽한데.**

- 반려된 1차: `Projects/AVSR/_exchange/in/rejected_roomfloor_env_junkyard_v1.png` — **이 방향으로 가지 마라.**
  지금 쓰는 회색 콘크리트 바닥을 조금 밝게 다시 그린 것에 그쳤다

  "한 장으로 완성된 그림"을 **우리 무대로** 만들어 달라는 것이다

**색 · 조명 · 재질 · 화풍 · 무엇을 어디에 그릴지 — 디자인은 전부 그쪽이 정한다.**
예시에서 무엇이 좋은지도 그쪽이 직접 보고 판단해 달라. 아래는 게임이 돌아가는 데 필요한 규격뿐이다.

## 이번 무대 — CH1 「쓰레기 집적장」

- 원작 STAGE 1 — "I discovered the map in the pile of garbage." 쓰레기 더미에서 지도를 찾은 곳
- 게임: **AVENGING SPIRIT: RE:BORN** — 1991 Jaleco 아케이드 리메이크. 주인공은 **유령**이고 적의 몸에 **빙의**해 싸운다.
  방 단위 로그라이크, 세로 모바일, 위에서 내려다보는 시점
- 원작 느낌이 살아야 한다. 동시에 요즘 게임처럼 보여야 한다
- 이 한 장이 통과하면 같은 화풍으로 나머지 무대(미사일 기지 · 밤의 거리 · 공중기지 옥상 · 연구소 · 정유소 · 보스 아레나)를 이어 받는다

## 캔버스 — 한 장에 두 구역

```
 x 0                                    720
 y 0     ┌────────────────────────────────┐
         │ ▒ 맨 위 약 56 px 는 구름 층에 가린다 │
         │      ┌─ 출구 문 x 252~468 ─┐      │  문 그림(216×180)은 게임이 따로 얹는다
 y 180   │                                │  ← 위 180 px: 적·장애물이 안 놓인다
         │                                │
         │         방 (전투가 벌어진다)        │
         │    10 m × 16 m · 72 px = 1 m    │
         │  좌·우 24 px 안쪽은 전부 걸어 다닌다 │
         │                                │
         │           ● 플레이어 시작  약 y 1030
 y 1128  │ ─ ─ ─ 캐릭터는 이 아래로 못 간다 ─ ─ ─│
 y 1152  ├────────────────────────────────┤  ← 여기서 내가 잘라 두 장으로 쓴다
         │                                │
         │     방 아래 영역 (아무도 안 걷는다)   │  조이스틱 · 스킬 버튼이 이 위에 뜬다
         │                                │
 y 1692  └────────────────────────────────┘
```

**두 구역이 한 장면으로 자연스럽게 이어져야 한다.** 따로 그린 두 장을 붙인 것처럼 보이면 안 된다.

## 꼭 지킬 것

| 항목 | 값 | 이유 |
|---|---|---|
| 파일 | `roomfloor_env_junkyard_full.png` | |
| 크기 | **720 × 1692 px 정확히** | 위 1152 = 방 전체, 아래 540 = 방 아래 영역. 다른 크기면 늘어나 찌그러진다 |
| 형식 | PNG, **완전 불투명**(알파·마젠타 없음) | |
| 시점 | 위에서 내려다본 방. 바닥 칸은 위아래 어디서나 같은 크기(원근으로 좁아지지 않게) | 유닛·장애물이 72 px 격자에 놓인다 |
| 좌우 벽 | **얇게.** 방 구역(y 0~1152)에서 서 있는 벽·담장은 **좌우 끝 24 px 안에만** | 24 px 안쪽까지 캐릭터가 걸어 다닌다. 두꺼우면 벽 위를 걷는 것처럼 보인다 |
