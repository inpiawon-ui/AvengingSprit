# 인게임 UI 「몸 없음(유령 상태)」 검수
1) ○ 정상 상태성 — `NO HOST`·빈 실루엣·안내문·잠금 UI가 한 세트라 빈 칸이나 누락 화면으로 보이지 않는다.
2) ○ 상단 안정성 — 좌·중·우 패널의 외곽 위치와 크기가 D2와 같고, 호스트 패널 안의 내용만 교체되어 빙의 전환 시 출렁임이 없다.
3) △ 다음 행동 — 우하단 `POSSESS`와 상단 “빙의할 몸을 찾으세요”는 잘 보이나, 어느 적이 빙의 대상인지 버튼과 화면 속 대상의 연결은 즉시 확정하기 어렵다.
4) ○ 잠긴 상성 배지·ACTIVE — 저채도 처리와 자물쇠가 명확하고 `NO HOST` 맥락과 붙어 있어 고장보다 “현재 해당 없음”으로 읽힌다.
5) ○ 그림 흠 — 주요 영문·한글·수치가 판독 가능하며 눈에 띄는 겹침이나 화면 밖 잘림은 없다.
고칠 점 — 빙의 가능한 적에 `POSSESS`와 같은 보라/청록 계열 표식 또는 짧은 대상 하이라이트를 붙여 행동-대상 연결을 강화할 것.
