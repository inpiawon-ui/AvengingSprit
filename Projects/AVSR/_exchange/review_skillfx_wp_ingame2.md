# 무기 활성 스킬 인게임 2차 검수

검수 기준: 컷인 뒤 스킬 구간을 0.05초 간격 확대 캡처로 확인했다. 적 몸의 파란 얼음 조각, 노란 별, 흰 수리검, 몸 둘레의 큰 흰 원은 공통 연출로 보고 스킬 판정에서 제외했다.

## 아마존 — 도약 강타

- **판정: 통과**
- **손볼 것:** 없음. 발밑 펄스 `168×56px / 55% / 0.33초`, 바닥 갈라짐 `128×64px / 50%`, 착지 파편 `1회 / 35%`를 유지.
- **한 줄 평:** 착지점이 먼저 읽히고 갈라짐과 1회성 파편이 짧게 마무리되어, 이전의 반복 잔상 없이 타격 축이 또렷하다.

## 난사

- **판정: 통과**
- **손볼 것:** 없음. 세 갈래 조준선 `가운데→좌→우 / 0.03초 간격 / 45% / 각 0.10초`, 피격 코어 `38px / 85% / 0.12초 / 피격당 1회`를 유지.
- **한 줄 평:** 세 방향의 발사 순서가 짧지만 분리되어 보이고, 맞은 자리 코어도 공통 얼음·별 타격 속에서 필요한 순간만 힘을 준다.

## 방벽

- **판정: 통과**
- **손볼 것:** 없음. 방벽 생성 전 예전 쉴드 거품은 계속 `0회`로 유지.
- **한 줄 평:** 준비 구간에서 곧바로 구조물이 서므로 개인 쉴드로 오독되지 않고, 방벽 스킬의 목적이 즉시 읽힌다.

- **판정: 통과**
- **손볼 것:** 없음. 현재의 화면 안 보정 위치를 유지하고, 기존 기준인 원본과 같은 크기·애니메이션, 생성 `45%`, 유지 `38~48%`, 지속 `4.73초`를 유지.
- **한 줄 평:** 분신이 HUD 아래에 숨지 않고 전투 공간 안에서 계속 확인되며, 반투명한 푸른 복제로 원본과도 충분히 구별된다.
