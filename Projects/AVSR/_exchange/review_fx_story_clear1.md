# 판정: 수정 필요

검수 기준은 `mock_fxstory_clear_v2.png`의 3컷과 `clear_vs_mock.png`의 재현 0.25 / 2.00 / 4.05 / 4.55초다. 창의 큰 배치, 보상·상자·경고·OK의 정보 순서와 글자 가독성은 대체로 맞지만, 핵심 연출의 크기·시점·합성 순서가 시안과 다르다. 특히 1컷 금빛 방사광, 2컷 코인/상자 최대 상태, 3컷의 누름 기점, 4컷의 플레이어 적용광이 아직 시안대로 이어지지 않는다.

## 1컷 — 등장 (재현 0.25초)

### 시안과 다른 점

- 시안은 결과창 중앙 뒤에서 금빛 방사광이 화면 높이의 대부분까지 뻗으며 등장한다. 재현은 `clear_title_burst`가 제목판 크기 안에 가까운 `520 x 360`으로 작고, 중심도 `(360, 368)`로 높아 불투명한 창 뒤에 거의 묻힌다. 등장 컷의 주 동작이 보이지 않는다.
- 시안의 방사광은 결과창 뒤에만 있고 글자·버튼 위를 덮지 않는다. `back=True` 방향은 맞다.
- 좌우 청록 장식이 등장 직후부터 강하게 반복된다. 시안에서 이 단계의 주색은 금색이며 청록은 프레임 자체의 보조광 정도다. 현재 `clear_edge_bolt` 두 줄은 너무 일찍, 너무 오래 눈에 띈다.
- 결과 제목이 재현본에서는 순백 단색으로 보여 시안의 따뜻한 금백색 제목보다 차갑다. 제목 크기와 외곽선은 현재 규칙(`result_title` 44, 최소 36, 진한 외곽선)을 유지해도 되지만 글자색은 맞춰야 한다.

### `layers_clear()`에서 바꿀 값

- `clear_title_burst`: 중심 `(360, 560)`, 크기 `980 x 980`, 프레임 간격 `0.08`, `t0=0.00`, `t1=0.72`, `loop=False`, `alpha=0.88`, `fade=0.10`, `add=True`, `back=True`.
- 왼쪽 `clear_edge_bolt`: 중심 `(50, 640)`, 크기 `64 x 360`, 프레임 간격 `0.14`, `t0=0.45`, `t1=0`(대기 지속), `alpha=0.34`, `add=True`, `back=False`.
- 오른쪽 `clear_edge_bolt`: 중심 `(670, 640)`, 크기 `64 x 360`, 프레임 간격 `0.14`, `t0=0.52`, `t1=0`, `alpha=0.34`, `add=True`, `back=False`, `flip=True`.
- 창 전체를 물들이는 별도 색면은 추가하지 않는다.

### 창·글자

- `popup_c_layout.py`의 `ResultTitleText` 위치/크기 `420 x 74`, 역할 `result_title`은 유지한다.
- `ResultTitleText`의 `color='#FFFFFF'`만 `#FFF3D0`으로 바꾼다. 가짜 Bold, 추가 Glow, 별도 번짐은 넣지 않는다. 나머지 본문·값·OK 글자는 현재 칸 밖으로 나가거나 연출에 가려지지 않아 유지한다.

## 2컷 — 최대/대기 (재현 2.00초)

### 시안과 다른 점

- 시안 2컷의 핵심인 골드 칸 위 코인 낙하와 상자 아래 청백색 착지 고리가 2.00초 재현에는 없다. 현재 코인은 `0.35~0.95초`, 상자 고리는 `0.70~1.10초`에 끝나므로 비교 시점 전에 사라진다.
- 시안의 코인 덩어리는 골드 아이콘 위에서 아래로 떨어지며 칸 안에 머문다. 현재 좌표 `(240, 548)`와 `260 x 160`은 범위가 넓어 값 글자 쪽까지 침범할 여지가 있다.
- 시안의 상자 고리는 상자 발밑에 납작하게 놓인다. 현재 중심 `(240, 766)`, `260 x 120`은 세로가 두껍다.
- 좌우 청록 상승광은 시안보다 밝고 빠르다. 대기 장식은 더 느리고 은은해야 한다.

### `layers_clear()`에서 바꿀 값

- `clear_coin_rain`: 중심 `(236, 560)`, 크기 `220 x 150`, 프레임 간격 `0.12`, `t0=1.35`, `t1=2.35`, `loop=False`, `alpha=0.82`, `fade=0.12`, `add=True`, `back=False`.
- `clear_chest_land`: 중심 `(238, 783)`, 크기 `230 x 84`, 프레임 간격 `0.10`, `t0=1.55`, `t1=2.40`, `loop=False`, `alpha=0.72`, `fade=0.12`, `add=True`, `back=False`.
- 좌우 `clear_soul_rise`: 중심은 각각 `(38, 640)`, `(682, 640)`, 크기 `52 x 330`, 프레임 간격 `0.18`, `t0=1.15`/`1.27`, `t1=0`, `alpha=0.32`, `add=True`, `back=False`; 오른쪽만 `flip=True`.
- 코인과 상자 연출은 글자 뒤로 보내지 않는다. 대신 위 크기와 좌표로 아이콘 열 안에 제한하여 `골드 획득`, `+1,240`, `은빛 상자`를 가리지 않는다.

### 재발주

- `clear_chest_land`는 재발주가 필요하다. 현재 부품의 먼지 가장자리에 선명한 녹색 매트가 남아 시안의 청백색 고리와 다르다. 사양: 투명 RGBA, 4프레임, 별/십자 반짝이 없음, 고리는 청록 `#42EAF2`~백색, 먼지는 중성 회백색, 녹색 픽셀과 검은 테두리 0, 원근은 가로:세로 약 `2.7:1`, 상자 중심 아래가 비어 있는 타원형.

## 3컷 — 선택/수락/누름 (재현 4.05초)

### 시안과 다른 점

- 시안은 OK를 누른 순간 버튼 테두리가 짧게 밝아지고, 반응의 시작점이 버튼 중앙이다. 현재 `clear_ok_glow`는 `phase='open'`, `t0=1.0`, 무한 반복이라 누르기 전부터 켜져 있다. 선택 반응이라는 인과가 맞지 않는다.
- 현재 OK 발광은 `320 x 117`, `alpha=0.6` 가산 합성으로 노란 면 전체를 하얗게 태운다. 시안은 테두리 중심의 짧은 펄스이며 `OK` 글자는 또렷하게 남는다.
- 좌우 상승광의 주황 점과 작은 십자형 하이라이트는 시안의 청백색 원혼 입자와 다르고, PD의 별/십자 반짝이 금지에도 걸린다.
- 창은 선택 후 0.35초인 4.15초에 닫히는 현재 타이밍이 맞다. 이 값은 바꾸지 않는다.

### `layers_clear()`에서 바꿀 값

- `clear_ok_glow`: 좌표를 노드 기준 `(0, 0)`으로 바꾸고 `atNode='ResultOkButton'`; 크기 `304 x 96`, 프레임 간격 `0.09`, `t0=0.00`, `t1=0.35`, `loop=False`, `alpha=0.32`, `fade=0.06`, `phase='accept'`, `add=True`, `back=False`.
- 누름 연출은 이 한 층만 사용한다. 버튼 밖 전면 플래시, 화면 전체 색면, 제목 재점화는 추가하지 않는다.
- `clear_soul_rise`는 2컷에 적은 저알파 대기값을 유지하고, 수락 순간 알파를 올리지 않는다. 따라서 버튼과 경고 글자를 가리지 않는다.

### 재발주

- `clear_soul_rise`는 재발주가 필요하다. 사양: 투명 RGBA 4프레임, 둥근 청록/백색 원혼 입자만 사용, 주황 입자 제거, 별 모양·십자 모양·렌즈 플레어 제거, 한 줄의 입자 수 6~9개, 가장 밝은 입자도 불투명도 70% 이하, 위로 느리게 흘러 프레임 가장자리에서 소멸.

## 4컷 — 창 닫힘 뒤 플레이어 「능력치 적용」 빛 (재현 4.55초)

### 시안/요청과 다른 점

- `layers_clear()`에는 `ui_powerup` 층이 없다. 따라서 4.15초에 창이 닫힌 뒤 4.55초 재현은 어두워진 게임 화면만 남고 플레이어 몸에 적용광이 깃들지 않는다.
- “클리어는 없음”은 클리어 전용 이벤트색 곱이 없다는 뜻으로 적용한다. 제단 청록·상점 호박처럼 별도 대표색을 만들지 말고, 공통 `ui_powerup` 원색(흰색 곱)을 사용한다.
- 적용광은 실제 플레이어 몸에서만 나와야 하며 화면 전체 또는 닫힌 창 위치에 잔광을 남기면 안 된다.

### `layers_clear()`에 추가할 값

- 마지막 층으로 다음 값을 추가한다: `L('ui_powerup', 0, -40, 230, 280, 0.07, 0.35, 0.95, loop=False, tint=(255, 255, 255), alpha=1.0, fade=0.08, phase='accept', fromAvatar=True, add=True, back=False)`.
- 이 설정은 선택 후 `0.35초`(절대 4.15초)에 시작하여 `0.95초`까지 재생한다. 4.55초에는 플레이어 몸 중심에 보이고, 클리어 고유색은 곱하지 않는다.
- 공통 `ui_powerup` 부품에 별/십자 모양이 들어 있다면 부품을 재발주한다. 사양: 몸 중심의 타원형 코어 + 위로 감기는 얇은 광띠 + 작은 원형 입자, 투명 RGBA 4프레임, 별/십자/전면 섬광 없음. 부품 자체는 백색·저채도 청백색으로 두어 다른 이벤트에서 색 곱이 깨끗하게 먹게 한다.
