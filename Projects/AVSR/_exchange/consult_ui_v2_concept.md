## 게임
「Avenging Spirit RE:BORN」 — 1991 아케이드 「Avenging Spirit」(자레코) 리메이크. 유령이 적의 몸(호스트 23명)에 빙의해 싸우는 로그라이트(챕터 · 방). 도트 픽셀 아트 캐릭터. 세로 720 × 1280, 일본 출시(한 · 일 · 영).
메타: 호스트 수집(가챠 = 조각 소환) · 성급 1~10성(은별 1~4 · 5성마다 큰 금별) · 등급 R/SR/SSR · 스킬 셋(필살기 · 액티브 · 패시브) · 상점 · 시즌 패스 · 추가 모드(탑 · 밤).

- 모든 화면이 「밤 배관 · 네온 도시」 배경 위에 청록 네온 테두리 칸을 빽빽하게 쌓은 한 가지 문법 — 칸 · 테두리 · 빛이 정보보다 시끄럽다.
- 소환은 버튼을 누르면 같은 화면 위에 결과가 뜰 뿐, 장면 전환 · 연출 흐름이 없다.

## 묻는 것 (그림은 그리지 말 것 — 답 파일만)
1. **디자인 컨셉 3~4개** — 서로 확실히 다른 방향으로. 각 컨셉마다:
   - 이름 · 한 줄 요지 · 실제 게임 레퍼런스 2~3개(예: Clash Royale/Brawl Stars 식 굵은 캐주얼, Archero 2 · Survivor.io 식 캐릭터 진열 중심, Dead Cells/Hades 식 다크 일러스트, Octopath/Sea of Stars 식 HD-2D 도트, 유령 테마 반투명 등 — 네가 아는 것 중 이 게임에 맞는 것)
   - 색(바탕 · 판 · 강조 3~5개) · 글꼴 느낌(굵기 · 외곽선) · 판 모양(테두리 두께 · 모서리 · 그림자/뎁스) · 배경을 어떻게 다룰지(지금 배관 배경을 계속 깔지, 흐리게/어둡게, 단색)
   - 도트 캐릭터와 어떻게 어울리나, 이 게임(유령 · 복수 · 아케이드 리메이크)과 맞는 이유
2. **공통 레이아웃 원칙** — 「큼직하게 · 정리 · 뎁스」:
   - 최소 글자 크기(720 폭 기준 본문 · 숫자 · 제목), 터치 칸 최소 크기, 한 화면에 보일 정보 수 상한
   - 뎁스 구조(예: 홈 → 전체 화면 페이지 → 아래에서 올라오는 시트 → 팝업), 무엇을 어느 층으로 내릴지(지금 한 화면에 다 넣은 육성 · 출전 화면을 어떻게 나눌지)
   - 위 막대 · 아래 바(지금 4칸 HOST · PLAY · SUMMON · SHOP)를 어떻게 바꿀지
3. **가챠(소환) 흐름** — 장면 전환이 있는 단계 흐름(예: 소환 화면 → 버튼 → 전환(포털 · 화면 전환) → 연출 → 결과(1회 / 10회) → 다시/닫기). 단계마다 무엇이 보이고 몇 초인지, 등급별(R/SR/SSR) 강약 · 건너뛰기.
4. **시안 발주 목록** — 컨셉마다 그릴 화면: 홈(로비) · 호스트 육성 · 소환 화면 · 소환 연출 흐름(한 장에 4~6컷 스토리보드). 각 장에 꼭 들어갈 요소와 글자 크기 · 칸 배치를 짧게.
