# 판정: 수정 필요 — 필수 수정 2건

승인 시안 `mock_fxstory_room_shop_v1.png`, 정지 비교판 `room_shop_vs_mock.png`, 동작본 `room_shop.gif`를 기준으로 검수했다.

1회차 반영 방향은 대체로 맞다. 대기 장식은 앞층·가산에서 실제로 보이고, 떠 있는 금화와 네 등불의 배치, 접근 시 눈 점등, 사용 후 상점 오브젝트 암전, 접촉 0.35초 뒤 실제 상점 창 표시가 모두 의도대로 읽힌다. 실제 상점 창에서도 이펙트가 제목·상품명·설명·가격·`나가다` 버튼을 가리지 않는다. 별/십자 반짝이와 화면 전체 틴트도 없다.

다만 아래 두 차이는 사소한 수치 다듬기 범위를 넘는다. 대기 혼불은 시안보다 밝아 상인 원화를 덮고, 작동 금화 고리는 시안보다 작고 탁해 3컷의 핵심 반응이 약하다. 이 두 층만 수정하면 된다.

부품 원화 다섯 종은 시안의 형태와 맞는다. **재발주 없음.**

## 1컷 — 대기(0.0~1.6초)

### 시안과 다른 점

- 현재 `room_shop_soul_flame`은 시안보다 명도가 높아 해골 얼굴, 모자 아래, 몸통 중앙이 한 덩어리의 흰 노랑 불빛으로 뭉친다. 시안은 혼불 윤곽이 분명히 보이면서도 상인의 얼굴과 옷 디테일이 계속 읽힌다.
- 혼불의 위치와 크기는 시안 범위에 들어오므로 다시 뒤로 보내거나 덮기 합성으로 바꾸지 않는다. 1회차처럼 `back=True`, `add=False`, `alpha=.28`로 되돌리면 물건 뒤에 숨어 대기 장식이 사라진다는 이번 회차 조건과 충돌한다.
- 떠 있는 금화는 좌우에 보이고, 네 등불도 기존 등불 자리에서 은은하게 순차 점등된다. 이들은 시안보다 밝지 않으므로 더 낮추지 않는다.

## 3컷 — 접촉/작동(2.8~3.8초)

### 시안과 다른 점

- 현재 `room_shop_coin_ring`은 발밑에 낮고 작은 주황 고리로 모여 있다. 시안은 상점의 좌우 폭보다 넓고, 하체 중간부터 발밑까지 감싸는 밝은 금색 타원으로 한 번 확산된다. 지금 상태는 작동 컷의 주효과가 시안보다 약하다.
- 고리의 덮기 합성 때문에 금색 광선이 탁하게 보인다. 시안의 밝기를 맞추려면 가산으로 돌리되, 과노출을 피하도록 알파를 `0.58`로 제한한다.
- 사용 직후 오브젝트가 어두워지는 것과 0.35초 뒤 실제 `ShopPanel`이 열리는 것은 이번 회차 요구와 맞는다. 실제 창은 고리보다 나중에 앞에 합성되므로 제목·상품·설명·가격·버튼을 가리지 않는다.
- 방 접촉 고리는 상점 물건 선택 반응이 아니다. 실제 구매 반응은 기존 팝업 층의 `atNode='ShopItem{slot}'` 기점을 유지해야 하며, `layers_room_shop()`에 `atNode`를 추가하지 않는다.
