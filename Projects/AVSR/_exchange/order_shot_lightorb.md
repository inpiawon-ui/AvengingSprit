> ⚠ **그리기 스크립트로 만들지 마라.** `ImageDraw` 의 `arc`·`polygon`·`ellipse`·`rectangle`
> 로 도형을 조립하는 방식은 불합격 사유다. 손으로 그린 픽셀아트여야 한다.
> **매끈한 정원·완전 대칭·그라데이션 채우기가 보이면 불합격이다.**

## 왜 다시 그리나 — 지금 그림이 원작과 다르다

- 지금 매지션(라이트)은 `Assets/BaseResource/InGameMainUI/shot_beam_1.png` — **주황 총알 모양 막대**를 쏜다
- 원작 매지션(라이트)의 마법탄은 **동그란 빛 구슬**이다. 작은 점 → 커지는 구슬 → 크고 흰 구슬로 날아간다

- 이번 발주는 **날아가는 구슬**만이다. 오른쪽 고리(맞는 순간)는 그리지 않는다
- 원작의 **납작한 알약 모양**(가운데 가로로 긴 것)은 쓰지 않는다 — 우리 게임에서는 총알로 읽힌다

## 무엇을 그리나

- 크고 **흰 속**에 **옅은 노랑 → 주황 테**가 감싸고, 가장 바깥이 **검붉은 가는 윤곽**인 빛 구슬
- 네 칸이 이어져 **은은하게 일렁인다** — 테 두께가 칸마다 1 px 정도씩 들고 나고, 속의 밝은 면 자리가 조금 옮겨 간다
- 테 바깥에 **작은 빛 알갱이 1~3개**가 칸마다 다른 자리에 붙었다 떨어진다 (원작의 작은 구슬들처럼)
- 구슬은 방향이 없다 — 둥글어서 어느 쪽으로 날아가도 같게 보인다. 꼬리를 그리지 마라

## 규격

| 항목 | 값 |
|---|---|
| 파일 | `shot_lightorb_sheet.png` |
| 크기 | **256 × 64** (64×64 × 4칸, 가로로 왼쪽부터) |
| 구슬 지름 | 칸 안에서 **약 36~40 px**, 중심은 각 칸 한가운데 |
| 배경 | 마젠타 `#FF00FF` 한 색 (투명은 내가 뚫는다). 그림 안쪽에 마젠타를 쓰지 마라 |
| 경계 | 칸 경계 열에 그림이 **0 px**. 칸 안쪽에 최소 4 px 여백 |
| 화풍 | 픽셀아트, 안티에일리어싱 없이 또렷하게. 원작처럼 **색 띠가 계단으로** 나뉜다 |

## 팔레트 (원작 시트 실측값)

| 쓰임 | 색 |
|---|---|
| 속 (가장 밝은 곳) | `#F7F7F7` |
| 속 바깥 · 옅은 노랑 | `#F7F773` |
| 테 · 노란 주황 | `#F7AD00` |
| 테 바깥 · 주황 | `#D67300` |
| 윤곽 (가는 선) | `#941000` |

이 다섯 색 밖의 색을 넓게 쓰지 마라.

## 검수 기준

1. 시트 크기가 정확히 256 × 64
2. 배경 마젠타 한 색, 칸 경계 침범 0 px
3. 원작 앵커와 나란히 놓았을 때 **같은 구슬로 읽힌다** — 흰 속 · 노랑/주황 테 · 검붉은 윤곽
4. 총알·막대·알약 모양이 아니다 · 꼬리가 없다
5. 도형이 아니다 — 매끈한 원·완전 대칭이 없다
6. 네 번째 칸에서 첫 칸으로 끊김 없이 이어진다
