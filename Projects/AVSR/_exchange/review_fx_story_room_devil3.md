# 판정: 통과

검수 대상: `mock_fxstory_room_devil_v1.png`, `room_devil_vs_mock.png`, `room_devil.gif`  
검수 기준: PD 통과 시안의 3단계(등장 → 최대/접근 → 선택·수락·구매), 2회차 필수 수정 `chain_release v2`, 시안 밝기 우선. 좌표는 720×1280 화면에서 제단 중심 상대값이다.

2회차의 유일한 필수 수정이었던 `room_devil_chain_release` 재발주가 제대로 반영됐다. 사슬은 더 이상 좌우 대칭 U자나 하트형 고리를 만들지 않고, 제단 좌우 구속점에서 서로 다른 길이와 굴곡으로 바깥·위쪽을 향해 풀린다. 등장·접근·작동의 단계 구분, 대기 장식의 밝기, 작동 연기, 사용 후 감광과 실제 거래 창 표시도 유지됐다.

글자·버튼을 가리는 효과, 별/십자 반짝이, 화면 전체 착색은 없다. 작동 반응은 플레이어가 닿아 선택이 일어난 때에만 시작한다. PD에게 최종본으로 제시할 수 없을 만큼 시안과 다른 부분은 남지 않았다.

## 1컷 — 등장 / 멀리 대기 (1.00초)

### 시안과 다른 점

필수 수정 차이 없음. 뿔 위의 작은 불씨, 제단 뒤쪽의 좁은 붉은 연기, 몸통 안쪽 원혼 일렁임이 시안과 같은 위치와 역할로 보인다. 대기 장식은 은은하며 제단 외곽을 삼키거나 화면 전체를 붉게 물들이지 않는다. 시안보다 밝지 않으므로 추가 감광하지 않는다.

### `layers_room_devil()`에서 바꿀 값

없음. 아래 현행값을 유지한다.

- `room_devil_fire_smoke`: 좌표 `(0,-92)`, 크기 `270×270`, 알파 `0.30`, 시작 `0.00`, 끝 `0`(대기 지속), 프레임 간격 `0.18`, 덮기(`add=False`), `back=True`.
- `room_devil_core_glow`: 좌표 `(0,-2)`, 크기 `104×208`, 알파 `0.48`, 시작 `0.00`, 끝 `0`(대기 지속), 프레임 간격 `0.16`, 가산(`add=True`), `back=False`.
- 좌/우 `room_devil_horn_fire`: 좌표 `(-80,-146)` / `(80,-146)`, 크기 `34×68`, 알파 `0.66`, 시작 `0.10` / `0.17`, 끝 `0`(대기 지속), 프레임 간격 `0.14`, 가산(`add=True`), `back=False`.

## 2컷 — 최대 / 플레이어 접근 중 (2.00초)

### 시안과 다른 점

필수 수정 차이 없음. 플레이어가 240 안으로 들어온 뒤 얼굴 중심의 눈 점멸이 추가돼 1컷보다 반응이 커지지만, 대기층은 그대로 이어져 시안의 “떠 있는 동안 은은히”가 유지된다. 점멸은 제단 내부에 한정되고 HUD·퀘스트 글자·화면 전체를 침범하지 않는다.

### `layers_room_devil()`에서 바꿀 값

없음. 아래 현행값을 유지한다.

- `room_devil_eye_flash`: 좌표 `(0,-48)`, 크기 `54×54`, 알파 `0.62`, 시작 `0.00`, 끝 `0`(`near` 동안 지속), 프레임 간격 `0.12`, 가산(`add=True`), `phase='near'`, `back=False`.
- 1컷의 `fire_smoke`, `core_glow`, 좌/우 `horn_fire` 값도 그대로 유지한다. 시안 밝기와 맞으므로 알파를 낮추지 않는다.

## 3컷 — 선택/수락/구매, 닿아서 작동 (3.05초)

### 시안과 다른 점

필수 수정 차이 없음.

- `smoke_ring`은 제단 뒤에서 좌우로 퍼져 시안의 넓은 붉은 연기 고리를 만들며, 중앙 오브젝트와 전경 캐릭터를 과도하게 덮지 않는다.
- `chain_release v2`는 중앙을 비운 채 제단 양옆 구속점에서 출발한다. 좌우 사슬의 길이·굽음·끝 방향이 서로 다르고, 두 끝 모두 바깥·위쪽으로 풀려 시안의 사슬 해방 동세와 일치한다. 직전 회차의 대칭 U자/하트형 문제는 해소됐다.
- 두 작동층은 접촉 시에만 한 번 재생되고 짧게 끝난다. 대기 중에는 나오지 않으며 별/십자 입자나 전 화면 틴트도 없다.

### `layers_room_devil()`에서 바꿀 값

없음. 아래 현행값을 유지한다.

- `room_devil_smoke_ring`: 좌표 `(0,52)`, 크기 `360×150`, 알파 `0.48`, 시작 `0.00`, 끝 `0.54`, 프레임 간격 `0.09`, 덮기(`add=False`), `back=True`, `loop=False`, `phase='accept'`.
- `room_devil_chain_release`: 좌표 `(0,6)`, 크기 `410×205`, 알파 `0.90`, 시작 `0.00`, 끝 `0.42`, 프레임 간격 `0.07`, 덮기(`add=False`), `back=False`, `loop=False`, `phase='accept'`.

`chain_release v2` 부품 그림 자체도 시안과 같은 용도로 성립하므로 **재발주 없음**이다. 좌표·크기·알파를 다시 조정하면 현재 맞아 있는 구속점 출발 위치와 사슬 두께가 오히려 어긋난다.

## 실제 거래 창 확인

접촉 후 작동 연출이 끝나고 큰 `EventPanel`이 열리는 순서가 유지된다. 사용한 제단은 어두워지고 작동층은 창 아래에서 종료되므로 `EventTitleText`, `EventBodyText`, 보상·비용, 수락·거절 버튼을 가리지 않는다. 창의 틀·칸·글자는 `popup_c_layout.py`와 `consult_popup_typography.md`의 기존 확정 구성을 유지하며, 이번 연출 때문에 생긴 겹침이나 가독성 저하는 없다.

## Claude가 바로 적용할 변경 목록

1. 적용할 변경 없음. 현재 `layers_room_devil()`의 일곱 레이어 좌표·크기·알파·시작/끝·프레임 간격·가산/덮기·`back` 값을 모두 유지한다.
2. `room_devil_chain_release v2` 여섯 프레임을 현 상태로 유지한다. 재발주하거나 좌우 반전 복사형으로 되돌리지 않는다.
3. 대기층 밝기를 더 낮추지 않는다. 현재 밝기가 시안과 맞고, PD 기준의 은은한 대기 장식을 충족한다.
4. 접촉 시 작동 → 작동층 종료 → 실제 거래 창 표시, 사용 후 제단 감광의 현재 순서를 유지한다.
