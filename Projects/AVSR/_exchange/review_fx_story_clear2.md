# 판정: 수정 필요

검수 기준은 `mock_fxstory_clear_v2.png`의 3컷과 `clear_vs_mock.png`의 재현 0.25 / 2.00 / 4.05 / 4.55초다. 창 배치, 글자, 좌우 청록 대기광, OK 대기/누름 반응, 닫힘 뒤 처리 방향은 이번 회차 기준에 맞는다. 다만 등장 방사광과 2컷의 코인·상자 효과가 비교 시점 전에 프레임 재생을 끝내 실제 재현 컷에서 사라지고, 원혼 입자가 시안과 다른 화면 양끝에서 올라온다. 아래 항목만 이번 회차에서 고친다.

## 1컷 — 등장 (재현 0.25초)

### 시안과 다른 점

- 시안은 0.25초에도 결과창 뒤의 금빛 방사광이 최대에 가까운 굵기와 밝기로 남아 있다. 재현은 `clear_title_burst`가 4프레임 비반복인데 프레임 간격이 `0.08`이라 0.24초에 마지막 프레임까지 소진된다. 그래서 0.25초 컷에는 가는 붉은 잔선만 남아 시안의 첫인상보다 현저히 약하다.
- 중심 `(360,560)`, 크기 `980 x 980`, `alpha=0.88`, 가산·뒤 배치는 맞다. 크기나 알파를 더 올릴 문제가 아니라 프레임 진행이 너무 빠른 문제다.
- 좌우 `clear_edge_bolt`는 글자와 버튼을 가리지 않고, 등장광보다 늦게 켜지는 현재 값이면 유지 가능하다.

### `layers_clear()`에서 바꿀 값

- `clear_title_burst`: 중심 `(360,560)`, 크기 `980 x 980`, **프레임 간격 `0.08 → 0.18`**, `t0=0.00`, `t1=0.72`, `loop=False`, `alpha=0.88`, `fade=0.10`, `add=True`, `back=True`.
- `clear_edge_bolt` 두 줄은 현재 값 유지: `(50,640)` / `(670,640)`, `64 x 360`, 프레임 간격 `0.14`, `t0=0.45` / `0.52`, `t1=0`, `alpha=0.34`, `add=True`, `back=False`, 오른쪽만 `flip=True`.

### 재발주

- 없음. `clear_title_burst` 부품은 금빛 중심 방사와 투명 여백이 시안 방향에 맞고, 재생 속도만 바로잡으면 된다.

## 2컷 — 최대·대기 (재현 2.00초)

### 시안과 다른 점

- 시안 2컷에는 골드 칸의 코인 낙하와 상자 발밑의 청백색 착지 고리가 동시에 보인다. 재현 2.00초에는 둘 다 보이지 않는다.
- 원인은 위치·밝기가 아니라 비반복 4프레임의 실제 재생 길이다. `clear_coin_rain`은 `t0=1.35`, `step=0.12`라 약 1.83초에 끝나고, `clear_chest_land`는 `t0=1.55`, `step=0.10`이라 약 1.95초에 끝난다. `t1`을 각각 2.35/2.40으로 써도 비반복 프레임이 먼저 소진되면 그 뒤에는 그려지지 않는다.
- 재발주된 `clear_chest_land`는 녹색 매트가 없어졌고, 청백색 타원 고리와 중성 회백색 먼지로 시안에 맞는다. 부품 재발주는 더 필요 없다.
- 재발주된 `clear_soul_rise`도 둥근 청백색 입자만 남아 별/십자 및 주황 입자 문제는 해결됐다. 그러나 현재 `(38,640)`, `(682,640)` 배치는 화면 양끝에 붙어 대부분 잘리며, 시안 3컷의 중앙 원혼 주위에서 올라오는 입자와 위치가 다르다.
- 코인·상자 효과의 현재 알파는 시안보다 과하지 않고 글자도 가리지 않는다. 요청대로 더 낮추지 않는다.

### `layers_clear()`에서 바꿀 값

- `clear_coin_rain`: 중심 `(236,560)`, 크기 `220 x 150`, **프레임 간격 `0.12 → 0.18`**, **`t0=1.35 → 1.55`**, `t1=2.35`, `loop=False`, `alpha=0.82`, `fade=0.12`, `add=True`, `back=False`.
- `clear_chest_land`: 중심 `(238,783)`, 크기 `230 x 84`, **프레임 간격 `0.10 → 0.18`**, **`t0=1.55 → 1.65`**, `t1=2.40`, `loop=False`, `alpha=0.72`, `fade=0.12`, `add=True`, `back=False`.
- 왼쪽 `clear_soul_rise`: **중심 `(250,300)`**, 크기 `52 x 330`, 프레임 간격 `0.18`, `t0=1.15`, `t1=0`, `alpha=0.32`, `add=True`, **`back=True`**.
- 오른쪽 `clear_soul_rise`: **중심 `(470,300)`**, 크기 `52 x 330`, 프레임 간격 `0.18`, `t0=1.27`, `t1=0`, `alpha=0.32`, `add=True`, **`back=True`**, `flip=True`.
- 원혼 입자를 뒤로 보내는 이유는 중앙 원혼 주위의 빈 배경에서는 보이되, 제목·보상 글자·OK 위로 지나가지 않게 하기 위해서다.

### 재발주

- 없음. `clear_chest_land`, `clear_soul_rise` 두 재발주본 모두 부품 자체는 통과다. 이번 차이는 합성 시간과 좌표·앞뒤 순서로 해결한다.

## 3컷 — 선택/수락/구매, 누를 때만 (재현 4.05초)

- 시안 3컷의 원혼 입자 위치 차이는 2컷 항목의 `clear_soul_rise` 좌표·`back` 수정으로 함께 해결한다.
