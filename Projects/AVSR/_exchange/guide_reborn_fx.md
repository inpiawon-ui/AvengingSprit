## 목표 모습
판 · 버튼은 매끈한 남색(Neon Cabinet) — 그 위에 **도트 모양 빛(빛살 · 반짝 별 · 문양) + 부드러운 번짐 · 떠오르는 빛 알갱이**를 겹친다.
묶음에 온 연출 시트(점 · 원 · 막대 코드 그림)는 기준이 아니다 — 「단순 원 · 선만으로 된 연출」은 실패.

## 등급 계단 — 상자(은 < 금 < 백금), 각성(6 < 10)
| 원칙 | 내용 |
|---|---|
| 바닥 | 가장 낮은 등급(은 · 6성)도 확실히 연출 — 시안 수준 |
| 크기 | 등급이 올라도 빛 · 후광 크기는 같다 |
| 힘 | 위로 갈수록 알갱이 수를 조금 늘리고 겹을 하나씩 더한다 |
| 색 | 은 `#AAB6C6` · 금 `#FFC93D` · 백금 흰금 + 은은한 무지개 / 6성 시안 `#3EE6FF` · 10성 금 |
| 남김 | 최상위(백금 · 10성)만의 겹을 하나 남긴다 |

| 상자 | 머묾(뚜껑 닫힘 · 떨림) | 힘주는 순간(뚜껑 열림) |
|---|---|---|
| 은 | 은빛 번짐 + 작은 알갱이 | 뚜껑 열림 + 빛살 솟음 + 내용물(금화 · 조각) 튐 |
| 금 | + 알갱이 촘촘 · 반짝 별 | + 반짝 별 함께 터짐 |
| 백금 | + 위로 흘러오르는 빛 알갱이 | + 0.5초 뒤 두 번째 반짝임 |
