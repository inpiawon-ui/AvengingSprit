# 발주 — 능력치 아이콘 「방어력」 한 장 (28 × 28)

로비 호스트 선택 화면의 능력치 칸 아이콘이다. 방어력이 새 스탯으로 생겼는데 아이콘만 없다.
이미 여섯 장이 있고(**체력 · 공격력 · 이동속도 · 치명타 · 사거리 · 공격속도**)
같은 눈높이의 일곱 번째 한 장을 만든다.

## 이미 있는 여섯 장의 화풍 (실측)

`Assets/BaseResource/HostSelectPanel/staticon_{hp,atk,spd,crit,rng,rate}.png` — 전부 **28 × 28**.

- **아주 굵은 픽셀**이다. 28 칸 안에 큰 덩어리 하나만 넣는다. 잔 디테일이 없다
- 물체 하나만 그린다 — 하트 · 검 · 날개 달린 부츠 · 붉은 폭발 · 파란 조준 표시 · 노란 겹화살표
- **짙은 남색 외곽선**으로 전체를 감싼다 (`#00012C` · `#00004D` 계열)
- 안쪽은 밝은 면 · 바탕 · 그늘 세 톤이면 충분하다
- 안티에일리어싱 없음. 반투명 픽셀 없음(알파는 0 또는 255)

## 이번 한 장 — 방패

**정면을 보는 방패 하나**를 그린다. 「받는 피해를 깎는다」가 한눈에 읽혀야 한다.

- 위가 넓고 아래로 좁아지는 방패꼴. 28 칸 안에서 세로로 거의 꽉 차게 (약 24 px)
- 한가운데 세로 이음선이나 작은 징 하나로 금속감을 준다. 그 이상은 넣지 마라
- 검·주먹·십자가 같은 다른 물체를 얹지 마라 — 방패만
- 여섯 장 중 **파란 계열(이동속도 · 사거리)과 구분되게 회색 강철**로 간다

| 쓰임 | 색 |
|---|---|
| 외곽선 | `#00012C` |
| 강철 밝은 면 | `#E6ECF5` |
| 강철 바탕 | `#9AA8BC` |
| 강철 그늘 | `#5A6678` |
| 징 · 이음선 | `#F6C246` |

## 규격

| 항목 | 값 |
|---|---|
| 파일 | `staticon_def.png` · **28 × 28** |
| 배경 | 마젠타 `#FF00FF` 한 색 (투명은 내가 뚫는다). 그림 안쪽에 마젠타를 쓰지 마라 |
| 그림 여백 | 사방 2 px 안쪽까지만. 가장자리 열에 그림이 닿지 않는다 |

## 검수 기준

1. 28 × 28, 배경은 마젠타 한 색
2. 가장자리 1 px 테두리에 그림 0 px
3. 위 다섯 색 밖의 색이 크게 섞이지 않았다
4. 6배로 키워 봤을 때 **방패**로 읽힌다
