# 결과창 금화 · 상자 유령 빛 문법 상의 답

## 1. 결과창에 적용할 문법

| 항목 | 결론 | 조정안 | 이유 |
|---|---|---|---|
| 유령 빛의 재료·색 문법 | 유지 | `UIAdditiveLight`의 고리와 `UISilhouette`의 단색 테두리, `ghostmote`만 등급색으로 사용 | 승인 화면에서 이미 통과한 부드러운 가산광과 도트 알갱이라 새 장식 그림보다 현재 게임과 잘 맞는다. |
| 상자 착지 고리 | 유지 | 상자 뒤 바닥에 한 번 열고, 착지 강조 뒤 약하게 남겼다가 0.30초 안에 제거 | 140×108 칸에서는 원형 폭발보다 낮은 타원이 접지와 획득 순간을 가장 적은 면적으로 설명한다. |
| 상자 실루엣 테두리 | 수정 | 1.04~1.05배의 얇은 등급색 테두리를 상자 바로 뒤에 두고 느리게 숨쉬기 | 제안한 1.06~1.08배는 140×96 상자 외곽 전체가 굵게 빛나 원화의 톱니 아우라를 다시 만드는 쪽에 가깝다. |
| 상자 뒤 광막 | 삭제 | 세로 광막 두 장과 빛심 모두 사용하지 않음 | 108 px 높이 안에서는 광막의 사다리꼴·가장자리·점선 마디가 읽힐 공간이 없고, 위 칸 및 오른쪽 글자와 경쟁한다. |
| 상자 알갱이 | 수정 | 상자 위쪽에서 작은 `ghostmote` 한 알씩 드물게 아래로 흘리고 아이콘 영역에서 자르기 | 승인된 입자 질감은 살리되 여러 알이 계속 내리면 작은 칸에서 눈보라처럼 보인다. |
| 금화 더미 테두리 | 수정 | 금색 실루엣을 1.025~1.035배로 아주 약하게 숨쉬기 | 금화의 울퉁불퉁한 외곽을 크게 복제하면 코인 사이가 메워져 덩어리 아우라로 보인다. |
| 금화 반짝임 | 추가 | 더미의 위쪽 절반에서 작은 `ghostmote` 한 알을 짧게 점멸하고 거의 이동시키지 않음 | 테두리만으로는 “선택되어 빛난다”는 지속 상태는 되지만, PD가 말한 순간적인 반짝임까지 전달되지는 않는다. |
| 빛의 깊이·클립 | 유지 | 고리·테두리는 물건 뒤, 알갱이는 물건 앞이며 금화 150×106·상자 140×108 아이콘 영역 밖은 클립 | 물건 형태는 선명하게 남기고 오른쪽 보상명·금액을 가리지 않아야 한다. |

## 2. 권장 숫자

유령 빛의 인게임 수치를 기계적으로 같은 비율로 줄이지 않고, 실제 결과창의 금화 150×106 및 상자 140×108(그림 140×96) 칸에서 한 번에 읽히는 값으로 환산했다.

| 대상 | 항목 | 권장값 | 이유 |
|---|---|---:|---|
| 상자 고리 | 크기 | 104×18 px | 유령 빛 94×24의 납작한 접지감은 남기되 상자 폭과 칸 높이에 맞춘다. |
| 상자 고리 | 색·최대 알파 | 등급색, 0.42 | 가산 고리의 흰 심이 상자 밑면을 태우지 않으면서 착지 순간은 읽히는 상한이다. |
| 상자 고리 | 시간 | 0→최대 0.10초, 0.12초 유지, 0.18초 소거 | 상자의 0.40초 낙하 뒤 접지만 찍고 반복 장식으로 남기지 않는다. |
| 상자 테두리 | 배율 | 1.04↔1.05 | 140×96 그림에서 바깥으로 약 3~4 px만 보여 얇은 윤곽으로 남는다. |
| 상자 테두리 | 색·알파 | 등급색, 0.18↔0.30 | 유령 빛의 0.9는 전장 포커스용이라 작은 보상 칸에서는 과포화된다. |
| 상자 테두리 | 숨쉬기 | 2.0초 왕복 | 0.72초 전장 신호보다 느려 결과창의 머묾 장식으로 조급하지 않다. |
| 상자 알갱이 | 크기 | 7~9 px | 유령 빛 12 px를 줄여도 `ghostmote`의 십자 실루엣은 알아볼 수 있다. |
| 상자 알갱이 | 간격·동시 수 | 0.85~1.20초, 최대 1개 | 작은 칸에서 별 무리 대신 드문 빛 한 알로 보이게 한다. |
| 상자 알갱이 | 속도·수명 | 아래로 24~32 px/s, 0.55~0.75초 | 유령 빛 82 px/s·0.95초를 그대로 쓰면 108 px 칸을 급하게 관통한다. |
| 상자 알갱이 | 알파·영역 | 최대 0.38, 상자 중심 기준 x ±42 px·상단 12~34 px | 상자 표면과 오른쪽 글자를 피하면서 위에서 내려오는 문법만 남긴다. |
| 금화 테두리 | 배율 | 1.025↔1.035 | 코인 사이의 작은 음영과 개별 외곽을 메우지 않는 범위다. |
| 금화 테두리 | 색·알파 | `#FFC04A`, 0.08↔0.14 | 금화 원화 자체가 밝아 테두리는 형태 분리만 돕는 수준이면 충분하다. |
| 금화 테두리 | 숨쉬기 | 2.4초 왕복 | 금액 집계가 끝난 뒤에도 눈에 띄지 않게 살아 있는 정도다. |
| 금화 반짝임 | 크기·알파 | 6~8 px, 최대 0.38 | 원화보다 작은 한 점으로 두어 새 별 장식이 아니라 표면 반사로 읽힌다. |
| 금화 반짝임 | 간격·수명 | 1.25~1.80초마다 1개, 0.24~0.34초 | 동시에 하나만 짧게 켜져 “반짝임”은 생기고 눈보라는 생기지 않는다. |
| 금화 반짝임 | 이동·영역 | 이동 0~8 px, 더미 위쪽 55% 안 | 유령 빛 알갱이의 모양만 빌리고 낙하 운동은 줄여 금화 표면의 반사로 보이게 한다. |

## 3. 금화 더미의 「반짝이는 연출」

**결론: 수정 + 추가 — 테두리는 유지하되, 테두리만으로 끝내지 않고 작은 `ghostmote` 점멸 한 알을 더한다.** 테두리는 더미를 배경에서 분리하고 은은한 생동감은 주지만, 전체 외곽이 같이 밝아졌다 어두워질 뿐이라 “한 지점이 반짝였다”는 사건은 약하다. 위쪽 동전 면에서 1.25~1.80초마다 6~8 px 한 알을 0.24~0.34초만 켜면 승인된 유령 빛 재료 안에서 PD 요청을 충족하며, 별 테두리나 방사광으로 돌아가지 않는다.

## 4. 착지 먼지 대신 고리

**결론: 유지 — 착지 먼지는 삭제하고 고리로 대신하는 것이 맞다.** 실제 녹화의 상자는 0.40초 낙하 자체가 충격을 이미 설명하고, 좁은 칸의 먼지는 상자 밑면을 가리거나 오른쪽 글자 쪽으로 번지기 쉽다. 104×18 px 고리를 상자 뒤에서 0.40초 동안 한 번 여는 편이 접지·등급·획득 시점을 동시에 말하며 유령 빛 문법에도 일관된다.
