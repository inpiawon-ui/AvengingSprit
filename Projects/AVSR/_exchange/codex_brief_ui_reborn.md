## 2. 방향 한 줄
1990년대 밤거리 오락실 캐비닛 — 무광 검정 · 짙은 남색 판 + 어두운 놋쇠 + 가로등 호박빛 + 비 젖은 반사광. 유령 · 선택 = 시안, 주요 행동 = 코인 노랑(화면당 하나), 위험 = 빨강, 상승 · 완료 = 초록.
- **누를 수 있는 것 = 앞면 + 아래 두께**(누르면 두께만큼 내려간 모습). 판(누를 수 없음)은 두께 없음.
- 네온관(시안 빛 선)은 **히어로 판(화면의 주인공 1~2개)** 위 테두리에만.
- 금지: 사이버펑크 · SF · 크롬 · 홀로그램 · 분홍 UI · 파이프 · 리벳 · 양피지 · 금테 장식 · 판 전체 발광 · 글자(배지 BEST · NEW 만 예외).

## 3. 개발 제약 (꼭 지킨다)
- **9-slice 로 늘려 쓴다** — 모서리 4곳만 모양이 있고, 네 변은 어디를 잘라도 같은 띠, 가운데는 무늬 없는 면(늘려도 안 깨지게). 가운데에 그림 · 문양 금지.
- **투명 바탕 PNG** — 판 바깥은 완전 투명. 바깥 그림자 · 빛은 4 px 이내(9-slice 테두리 칸이 커진다).
- 상태(기본 · 누름 · 비활성 …)는 **한 장 안에 칸을 나눠 같이** 그린다 — 따로 그리면 칸마다 모양이 달라진다. 상태끼리 크기 · 모서리 · 테두리 폭이 같아야 한다.
- 각 부품은 자기 칸 가운데, 칸 밖으로 넘치지 않게. 칸 사이 경계선 · 눈금 · 글자 · 번호를 그리지 않는다.
- 크기는 1080 폭 화면 기준 px(게임은 720 폭으로 줄여 쓴다 — 줄이는 것은 우리가 한다).
