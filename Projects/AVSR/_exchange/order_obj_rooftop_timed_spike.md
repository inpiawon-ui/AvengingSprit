## 왜

인게임 배경을 새 화풍으로 바꿨고, 그 위에 놓이는 장애물도 새로 받는다.
**쓰레기 집적장 블록 샘플이 통과**했다 — 모든 장애물의 기준이다. 사장님 요청 그대로:

> 좀 **심플하면서 잘 보이는** 걸로 부탁해

배경은 일부러 조용하게 죽여 놓았다 — **그 위에서 장애물과 캐릭터가 살아야 한다.**
**색 · 재질 · 형태 · 화풍 — 디자인은 전부 그쪽이 정한다.** 아래는 게임이 쓰는 규격뿐이다.

## 이번 물건 — CH4 「밤의 공중기지 옥상 설비」의 가시 함정

- 무대: 밤의 공중기지 옥상 설비 (원작 STAGE 4). 게임: AVENGING SPIRIT: RE:BORN — 유령이 빙의해 싸우는 방 단위 로그라이크
- **바닥에 박힌 함정판.** 때가 되면 가시가 올라와 밟은 캐릭터가 아프다. 바닥에 눕는다(솟지 않는다)
- **세 프레임을 한 장에 나란히** 그린다 — 따로 그리면 프레임마다 판 모양이 달라진다

```
 ┌── 144 ──┬── 144 ──┬── 144 ──┐
 │ 1 닫힘   │ 2 반쯤   │ 3 다 올라옴│   144 높이
 └─────────┴─────────┴─────────┘
```

## 규격 (꼭 지킬 것)

| 항목 | 값 |
|---|---|
| 파일 | `obj_rooftop_timed_spike_sheet.png` |
| 크기 | **432 × 144 px 정확히** — 144 × 144 칸 셋. 내가 세로로 144 씩 잘라 쓴다 |
| 형식 | PNG **투명 배경**(알파). 판 밖은 완전히 투명 |
| 세 칸 | **판(바닥 틀)은 세 칸이 픽셀까지 똑같다.** 가시만 1 없음 → 2 반쯤 → 3 끝까지 |
| 발자국 | 144 × 144 (2 × 2 칸) — 판이 칸을 꽉 채운다 |
| 시점 | 새 배경과 같은 시점 |
- 게임은 이 그림을 **70 %로 줄여서** 그린다. 가시가 올라온 상태가 한눈에 위험해 보여야 한다
