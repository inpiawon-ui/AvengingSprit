# 상시 루프 장식 1차 검수

검수 대상: `fx_ambient`의 8개 GIF/6컷 스트립, 팝업 원본 4종, `Tools/fx_ambient.py`.

## 판정 기준과 좌표 기준

- 아래 좌표와 크기는 모두 합성 코드가 쓰는 **720×1280 원본 화면 좌표**다. GIF/스트립(360×640)에서 보이는 좌표의 2배다.
- 한 화면의 움직임은 성격이 다른 계통 3~4개까지만 남긴다. 같은 계통의 좌우 복제는 1개로 센다.
- 제목 반사광처럼 간헐적인 장식도 루프 안에서 반복되므로, 버튼·가격·선택지에 쓰면 선택 유도 신호로 읽힌다. 정보 영역에는 쓰지 않는다.
- 별/십자 반짝이와 화면 전체 틴트는 추가하지 않는다.

## 1. 레벨업 (`levelup`)

### 관찰

- 살아 있다는 인지는 가장 확실하다. 반대로 금색 관로 5개, 좌우 유리관 기포/유령, 문장 호흡, 제목 반사광, 카드 3장의 반사광, 하단 불씨가 동시에 움직여 **가장 정신없는 화면**이다.
- 상단·좌우 관로의 흐름광은 관 중심을 대체로 잘 타지만 `size=44`, `alpha=1.0`이라 광점이 관 두께보다 크다. 특히 양옆 수직관은 유리관의 기포/유령과 겹쳐 한 덩어리의 번쩍임으로 보인다.
- 카드 상단 반사광은 `RARE/COMMON` 칩과 카드 이름 부근을 훑는다. 글자를 순간적으로 희게 만들어 가독성을 해치며, 순차 재생 때문에 카드 선택 유도로도 읽힌다.
- 하단 불씨는 프레임 아래 배경까지 넓게 올라와 약하지는 않지만, 관로/유리관 장식과 주제가 겹치지 않는다.

### `fx_ambient.py` 수정값

- 관로 `Flow` 5개 공통: `size=44 → 30`, `alpha=1.0 → 0.55`, `speed=110 → 72`. 상단 좌·우 경로는 `n=2 → 1`; 중앙 수직관과 하단 좌·우는 `n=1` 유지. 현재 경로 좌표는 틀 그림과 맞으므로 유지한다.
- 좌우 유리관 `Rising`: 박스 `(42,344,38,132)`, `(667,344,38,132)` 유지. `per_sec=5 → 3`, `speed=(25,45) → (20,32)`, `size=(3,5) → (2,4)`, `alpha=1.0 → 0.60`, 색 `(255,230,150) → (235,200,115)`.
- 좌우 `TubeGhost`: 박스 유지, `size=46 → 34`, `alpha=0.95 → 0.55`, `n=1` 유지. 유령은 관 밖으로 넘치지 않게 크기만 줄인다.
- 문장 `Breath`: 중심 `(360,301)` 유지, `size=150 → 128`, `alpha=0.7 → 0.45`. 두 번 호흡하는 현재 주기는 유지한다.
- 제목 `Sheen`: 제목 박스 `(191,388,349,80)` 유지, `dur=0.7 → 0.9`, `alpha=0.5 → 0.28`, `width=46 → 30`, 색 `GOLD → (255,235,185)`.
- 하단 `Rising`: 박스 `(55,786,610,260) → (75,846,570,150)`, `per_sec=4 → 2`, `speed=(30,50) → (22,34)`, `size=(3,5) → (2,4)`, `alpha=0.7 → 0.40`.
- **삭제:** `BuffCard0~2`에 추가한 `Sheen` 3개 전부. 카드 글자 가림과 선택 유도 오해를 동시에 없앤다.

### 더하면 좋은 장식

- 추가하지 않는 편이 좋다. 이미 축소 후에도 관로 흐름·유리관 내부·문장 호흡·제목 반사광의 4계통이 남는다.

## 2. 회복의 제단 팝업 (`altar`)

### 관찰

- 좌우 긴 유리관의 기포와 유령은 위치가 정확하고 화면 정체성과 잘 맞는다. 다만 현재 기포 `per_sec=7`과 유령 좌우 합계 4마리가 동시에 올라가 유리관이 끓는 듯하다.
- 선택지 오른쪽의 `ring_pulse`가 차례로 켜지며 선택 가능한 버튼 표시처럼 보인다. 상시 장식 취지보다 인터랙션 신호가 강하고, 우측 아이콘 및 설명 끝부분과 겹친다.
- 하단 곡선 `Flow`는 실제 프레임 하단 관로보다 안쪽/위쪽을 가로질러, 6컷에서 청록 광점이 선택지 아래 빈 면을 떠다니는 것처럼 보인다.
- 제목 반사광과 문장 호흡은 보이나 세기가 다소 강해, 유리관과 합쳐졌을 때 움직임 계통이 많다.

### `fx_ambient.py` 수정값

- 좌우 유리관 `Rising`: 박스 `(91,510,34,330)`, `(595,510,34,330)` 유지. `per_sec=7 → 4`, `speed=(40,70) → (28,46)`, `size=(3,6) → (2,4)`, `wobble=5 → 3`, `alpha=1.0 → 0.65`, 색 `(190,255,255) → (155,225,235)`.
- `TubeGhost`: `n=2 → 1`, `size=40 → 34`, `alpha=0.6 → 0.48`; 박스와 좌우 위상은 유지.
- 문장 `Breath`: 중심 `(360,438)`, `size=120 → 106`, `alpha=0.7 → 0.42`.
- 제목 `Sheen`: 박스 `(203,481,314,48)` 유지, `dur=0.7 → 0.9`, `alpha=0.5 → 0.25`, `width=46 → 26`.
- 하단 `Flow`: 경로를 `[(125,870),(225,902),(495,902),(595,870)]`로 내려 실제 하단 호스/관을 따른다. `n=2 → 1`, `size=44 → 28`, `speed=90 → 64`, `alpha=1.0 → 0.50`.
- 하단 배경 `Rising`: 박스 `(85,870,550,120) → (105,892,510,76)`, `per_sec=3 → 2`, `speed=(20,35) → (16,25)`, `size=(3,4) → (2,3)`, `alpha=0.6 → 0.35`.
- **삭제:** `ShrineChoice0~2`의 `LoopFx('ring_pulse', ...)` 3개 전부.

### 더하면 좋은 장식

- 선택지와 무관한 프레임 상단 좌우 작은 저장조에 아주 약한 액면 밝기 변화 1계통을 넣을 수 있다. 새 클래스를 만들지 않고 `Breath` 2개를 `(157,476)`, `(563,476)`, `size=34`, `alpha=0.16`, `CYAN`으로 두되, 전체 계통 수를 지키려면 하단 불씨는 삭제한다.

## 3. 악마 거래 팝업 (`devil`)

### 관찰

- 붉은 관로 흐름과 하단 연기는 화면 성격을 잘 살린다. 그러나 좌우 상단 `energy_arc`는 특정 시점에만 튀어나오는 번개라 PD가 배제한 ‘한 방’에 가장 가깝다.
- 하단 연기 3개와 불씨가 프레임 밖 바닥까지 크게 번져 팝업보다 배경이 더 움직인다. 화면 전체를 붉게 물들이지는 않지만 하단 밀도가 과하다.
- 수락 버튼의 큰 `Breath(size=300)`는 버튼을 계속 권하는 신호가 되고, 버튼 글자/테두리 대비를 주기적으로 바꾼다.
- 좌우 세로 `Flow`의 x=`75`, `645`는 실제 붉은 세로관 중심과 거의 맞지만 `size=44`, `alpha=1.0`이라 프레임 밖으로 번진다.

### `fx_ambient.py` 수정값

- 좌우 세로 `Flow`: 경로 `[(75,522),(75,892)]`, `[(645,522),(645,892)]` 유지. `n=2 → 1`, `size=44 → 28`, `speed=100 → 62`, `alpha=1.0 → 0.48`, 색 `(255,90,70) → (225,75,62)`.
- 문장 `Breath`: 중심 `(360,417)`, `size=140 → 118`, `alpha=0.7 → 0.42`.
- 제목 `Sheen`: 박스 `(236,484,248,55)` 유지, `dur=0.7 → 0.9`, `alpha=0.45 → 0.24`, `width=46 → 26`, 색 `(255,150,130) → (240,165,150)`.
- 연기: 중앙 `LoopFx` 1개는 삭제. 좌우 중심을 `(200,912)`, `(520,912)`로 프레임 안쪽/위쪽으로 옮기고 `size=230 → 160`, `step=0.16 → 0.20`, `alpha=0.45 → 0.25`, 색 `RED → (175,55,50)`.
- 불씨 `Rising`: 박스 `(90,792,540,200) → (125,820,470,130)`, `per_sec=7 → 3`, `speed=(40,80) → (28,48)`, `size=(3,6) → (2,4)`, `alpha=1.0 → 0.55`, 색 `(255,120,60) → (225,95,55)`.
- **삭제:** 좌우 `energy_arc` 2개, 수락 버튼 `Breath` 1개. 번개성 단발과 인터랙션 오해를 없앤다.

### 더하면 좋은 장식

- 프레임 하단의 매달린 붉은 천/뿔 장식에 1~2px 정도의 느린 상하 흔들림은 어울린다. 다만 현재 합성 구조에서는 패널 일부 분리가 필요하므로 이번 값 수정 범위에서는 추가하지 않는다.

## 4. 상점 팝업 (`shop`)

### 관찰

- 상단·하단 관로 흐름과 좌우 유리관 내부가 틀 위치를 잘 따른다. 색도 원본과 일치한다.
- 가격 6곳의 반사광이 순서대로 지나가면서 가격 숫자를 직접 덮는다. 가독성 저하가 있고 할인/구매 가능 알림처럼 읽힌다.
- 좌우 관 유령 4마리, 기포, 상·하 관로, 문장, 제목, 가격 반사광, 하단 불씨까지 동시 사용되어 레벨업 다음으로 복잡하다.
- 하단 불씨는 ‘상점’보다 화로처럼 보이며, 하단 관로 광점과 겹쳐 프레임 아래가 과하게 밝다.

### `fx_ambient.py` 수정값

- 좌우 유리관 `TubeGhost`: 박스 `(29,545,34,300)`, `(657,545,34,300)` 유지. `n=2 → 1`, `size=44 → 34`, `alpha=0.75 → 0.48`.

- 하단 `Flow`: 경로를 `[(105,886),(235,900),(485,900),(615,886)]`로 낮춰 실제 하단 관에 붙인다. `n=2 → 1`, `size=44 → 28`, `speed=100 → 64`, `alpha=1.0 → 0.45`.
- 문장 `Breath`: 중심 `(360,435)`, `size=120 → 104`, `alpha=0.7 → 0.40`.

- 상단 자물쇠 문장 아래의 작은 계기/볼트에 1~2px 범위의 느린 밝기 변화 1개는 가능하다. 문장 `Breath`만으로 충분히 살아 보이면 추가하지 않는다.

## 5. 챕터 클리어 (`clear`)

### 관찰

- 좌우 세로 관의 금색 흐름, 문장 호흡, 제목 반사광은 틀과 잘 맞는다. 좌우 청록 기포도 관 옆 공간에 있어 위치 어긋남은 없다.
- 보물상자 아래 납작한 `ring_pulse`와 OK 버튼의 큰 `Breath`는 보상 수령/버튼 입력을 재촉하는 신호다. 상시 배경 장식으로는 부적합하다.
- 금화 영역 불씨는 글자 `골드 획득`과 수치 가까이 올라와 순간적으로 숫자 외곽을 건드린다.
- 금색 관로와 청록 기포가 좌우에서 동시에 강해, 중앙 문장까지 합치면 화면이 지나치게 밝다.

### `fx_ambient.py` 수정값

- 좌우 `Flow`: 경로 x=`70`, `590`은 관 중심과 맞으므로 유지. `n=2 → 1`, `size=44 → 28`, `speed=100 → 64`, `alpha=1.0 → 0.48`, 색 `GOLD → (235,190,75)`.
- 좌우 청록 `Rising`: 박스 `(30,382,60,560)`, `(570,382,60,560)` 유지. `per_sec=3 → 2`, `speed=(30,50) → (22,36)`, `size=(3,5) → (2,4)`, `wobble=6 → 3`, `alpha=1.0 → 0.45`, 색 `ICE → (125,195,220)`.
- 문장 `Breath`: 중심 `(330,362)`, `size=150 → 125`, `alpha=0.7 → 0.42`.
- 제목 `Sheen`: 박스 `(130,432,400,60)` 유지, `dur=0.7 → 0.9`, `alpha=0.5 → 0.25`, `width=46 → 28`.
- 금화 `Rising`: 박스 `(130,590,140,70) → (145,608,110,42)`, `per_sec=4 → 2`, `speed=(20,35) → (15,24)`, `size=(3,5) → (2,3)`, `alpha=1.0 → 0.42`.
- **삭제:** 보물상자 `LoopFx('ring_pulse', ...)`, OK 버튼 `Breath`.

### 더하면 좋은 장식

- 보물상자 자체를 덮지 않는 범위에서 잠금쇠의 밝기만 `alpha 0.10~0.18`로 천천히 호흡시키는 장식 1개는 가능하다. 현재 `ring_pulse`의 대체이며, 별/십자 광택은 쓰지 않는다.

## 6. 회복실 오브젝트 (`room_heal`)

### 관찰

- 유리관 내부 유령/액체 호흡, 상승 기포, 바닥 링, 상단 표식 흔들림이 모두 분명해 ‘살아 있음’은 충분하다.

- 바닥 링 `size=270`은 실제 링 이미지(230×86)보다 커서 광륜이 받침 밖으로 번진다. 위치 중심은 맞다.

## 8. 상점 방 오브젝트 (`room_shop`)

### 관찰

- 네 램프의 호흡, 중앙 문장 호흡, 불씨, 바닥 링, 표식이 모두 움직인다. 다른 방 오브젝트보다 작은 점멸원이 많아 장식 수가 과하다.
- 코드에서 각 램프에 `phase`를 넣지만 `Breath.draw()`는 `phase`를 읽지 않는다. 따라서 네 램프가 완전히 동시에 밝아져 한 번에 번쩍이는 인상이 난다.
- 상승 금색 입자는 상점 오브젝트 전면 전체를 통과하며 얼굴/몸통 디테일을 가릴 수 있다. 6컷에서는 약하지만 GIF에서 수가 누적된다.

### `fx_ambient.py` 수정값

- 바닥 `ring_pulse`: `size=270 → 230`, `alpha=0.55 → 0.28`, `step=0.2 → 0.24`, `squash=0.36 → 0.34`.
- 중앙 `Breath`: 중심 `(cx,py+100)` 유지, `size=110 → 92`, `alpha=0.4 → 0.24`.
- 불씨 `Rising`: 박스 `(cx-110,py+20,220,200) → (cx-82,py+55,164,145)`, `per_sec=4 → 2`, `speed=(25,40) → (18,30)`, `size=(4,6) → (2,4)`, `wobble=6 → 3`, `alpha=1.0 → 0.42`, 색 `GOLD → (235,180,75)`.
- 네 램프 `Breath`: `size=46 → 36`, `alpha=0.55 → 0.24`. 동시 점멸을 피하려면 `Breath`에 phase를 새로 구현하지 말고, **대각선 두 개만 남긴다**: `(cx-95,py+95)`, `(cx+95,py+175)`. 나머지 두 개 삭제.
- 표식 `Bob`: `amp=6 → 3`, 왕복 `2회 → 1회`.

### 더하면 좋은 장식

- 없음. 램프를 줄여도 링·중앙 호흡·불씨·램프·표식 중 네 계통이 보인다. 더 추가하면 다시 과밀해진다.

## Claude 즉시 적용용 변경 목록

1. 공통 기본값을 일괄 변경하지 말고 위 화면별 생성 인자에서 조정한다. 다른 미리보기에 파급시키지 않는다.
2. `levelup`: 카드 `Sheen` 3개 삭제. 모든 `Flow`를 `size 28~30 / alpha 0.45~0.55 / speed 64~72`로 축소하고 상단 좌우 `n=1`. 유리관 유령 `34/0.55`, 기포 `3/s`, 하단 불씨 영역 축소.
3. `altar`: 선택지 `ring_pulse` 3개 삭제. 유리관 유령 좌우 각 1, 기포 `4/s`. 하단 `Flow`를 y=`870~902` 관로로 이동하고 1개만 운행.
4. `devil`: `energy_arc` 2개와 수락 버튼 `Breath` 삭제. 중앙 연기 삭제, 좌우 연기 `size 160 / alpha .25`; 세로관 `Flow n=1 / size 28 / alpha .48`; 불씨 `3/s`.
5. `shop`: 가격 `Sheen` 6개 삭제. 유리관 유령 좌우 각 1, 기포 `3/s`; 상·하 관로 `Flow n=1 / size 28`; 하단 관로 경로를 y=`886~900`으로 내림.
6. `clear`: 보물상자 `ring_pulse`와 OK 버튼 `Breath` 삭제. 좌우 관로 `Flow n=1 / size 28 / alpha .48`; 청록 기포 `2/s / alpha .45`; 금화 입자 박스를 `(145,608,110,42)`로 축소.
7. `room_heal`: 링 `230/.32`, 연기 `105/.22`, 내부 호흡 `105/.28`, 기포 `4/s`; 표식 흔들림 `amp=3`, 1루프 1왕복.
8. `room_devil`: `energy_arc` 2개 삭제. 링 `230/.30`, 연기 `125·115/.24·.22`, 불씨 `3/s`; 표식 `amp=3`, 1왕복.
9. `room_shop`: 링 `230/.28`, 불씨 `2/s`, 램프는 대각선 2개만 `size=36 / alpha=.24`; 표식 `amp=3`, 1왕복.
10. 모든 팝업 제목 `Sheen`은 `dur=.9`, `alpha=.24~.28`, `width=26~30`으로 통일한다. 카드·선택지·가격·버튼에는 `Sheen/Breath/ring_pulse`를 두지 않는다.
11. 수정 후 동일한 3.2초/25fps로 다시 뽑아 확인할 항목: 루프 접점 끊김 없음, 글자 위 광점 없음, 관로 이탈 없음, 한 화면 동시 움직임 4계통 이하, 별/십자 반짝이 및 전체 화면 틴트 없음.
