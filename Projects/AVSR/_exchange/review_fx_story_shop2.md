# 판정: 수정 후 통과 — 필수 1건

검수 기준: `mock_fxstory_shop_v1.png`, `shop_vs_mock.png`, `shop.gif`, `layers_shop()`, `popup_c_layout.py`, `consult_popup_typography.md`.

1회차 변경 목록과 재발주 3종은 대부분 시안대로 반영됐다. 등장 순서, 구매 반응의 두 갈래, 선택 뒤 0.35초 유지, 창이 닫힌 뒤 플레이어 몸의 능력치 적용 빛은 통과다. 창·칸·글자의 배치도 이번 회차에서 다시 고칠 차이가 없다. 별/십자 반짝이, 화면 전체 착색, 글자·버튼을 막는 면광도 없다.

남은 필수 차이는 **2.00초 대기 컷의 여섯 상품 칸 테두리 호흡이 시안보다 지나치게 약한 것** 하나다. 사소한 위치·수치 차이는 통과로 남긴다.

## 1컷 — 등장 (0.25초)

### 시안과 다른 점

- 중앙 등불 점등 뒤 좌우 관, 상단 배관으로 시선이 퍼지는 순서가 시안과 맞는다.
- 중앙 광륜은 제목을 덮지 않는 160×160 범위이며, 좌우 관도 글자 영역 바깥에서 보인다.
- 재현 쪽 좌우 관의 호박색이 시안보다 약간 또렷하지만 시안보다 과도하게 밝거나 화면을 물들이는 정도는 아니다. 필수 수정으로 보지 않는다.

### `layers_shop()`에서 바꿀 값

- 없음.
- `shop_lamp_glow`: `(360,435)`, `160×160`, 프레임 간격 `0.10`, `t0=0.00`, `t1=0`, `alpha=0.72`, 가산, `back=True`, `untilAccept=True` 유지.
- 좌우 `shop_tube_ghost`: `(46,695)` / `(674,695)`, `44×300`, 프레임 간격 `0.14`, `t0=0.16/0.22`, `t1=0`, `alpha=0.68`, 가산, `back=False`, 오른쪽만 `flip=True`, `untilAccept=True` 유지.
- 좌우 `shop_pipe_flow`: `(205,463)` / `(515,463)`, `200×36`, 프레임 간격 `0.10`, `0.22~0.82` / `0.28~0.88`, `loop=False`, `alpha=0.50`, 가산, `back=True` 유지.

## 2컷 — 최대/대기 (2.00초)

### 시안과 다른 점

- 시안은 여섯 칸 모두의 바깥 테두리에 호박색 호흡이 분명히 남아, 칸 내부 글자를 건드리지 않으면서 “떠 있는 동안의 은은한 장식”으로 읽힌다.
- 재현은 `shop_cell_rim`의 위치·크기·투명 내부는 맞지만 `alpha=0.26` 때문에 2.00초 컷에서 기본 금속 테두리와 거의 구분되지 않는다. “은은함”의 범위를 넘어 장식이 사라진 상태다.
- 한 번 지나가는 `shop_cell_sheen`은 글자 뒤에 있어 가독성을 해치지 않는다. 중앙 등불과 좌우 관의 대기 밝기도 시안 범위다.

### `layers_shop()`에서 바꿀 값

- 여섯 `shop_cell_rim`만 `alpha: 0.26 → 0.48`로 올린다.
- 나머지는 그대로 유지한다: 중심 `cen(c)`, 크기 `c[2]+12 × c[3]+12`(현재 282×103), 프레임 간격 `0.16`, `t0=0.72+0.07*i`, `t1=0`, `loop=True`, `fade=0.16`, 가산, `back=False`, `untilAccept=True`.

적용값:

```python
L('shop_cell_rim', *cen(c), c[2] + 12, c[3] + 12,
  0.16, 0.72 + 0.07 * i, alpha=0.48, fade=0.16,
  untilAccept=True)
```

`back=True`로 보내지 않는다. 불투명한 칸 뒤로 숨으면 테두리 호흡이 다시 사라진다. 새 부품은 내부가 완전히 투명하므로 전면 가산이어도 상품명·가격·설명을 가리지 않는다.

### 재발주 여부

- 재발주 없음. 새 `shop_cell_rim`은 투명한 내부와 가는 외곽선만 가진 부품이라 형상은 시안에 맞는다. 이번 차이는 부품이 아니라 합성 알파다.

## 3컷 — 선택/수락/구매 (4.05초, 선택 뒤 0~0.35초)

### 시안과 다른 점

- 없음. 선택 칸 가운데에서 반응이 시작하고, `shop_coin_to_gold`가 HUD 골드 쪽으로 뻗으며 `shop_item_arc`가 반대쪽 원호로 아이콘을 올려 두 갈래가 분리되어 읽힌다.
- 선택 칸의 짧은 `shop_coin_burst`도 눌림 확인 역할에 머물며 상품 글자를 계속 가리지 않는다.
- 세 구매층이 모두 `t1≤0.34`에 끝나므로 0.35초 뒤 창이 닫힐 때 잔상이 남지 않는다.

### `layers_shop()`에서 바꿀 값

- 없음.
- `shop_coin_burst`: 선택 칸 중심, `130×130`, 프레임 간격 `0.07`, `0.00~0.28`, `alpha=0.72`, 가산, `back=False` 유지.
- `shop_coin_to_gold`: 선택 칸 중심→`(75,152)`, 높이 `18`, 프레임 간격 `0.05`, `0.02~0.32`, `alpha=0.90`, 가산, `back=False`, `beam=True` 유지.
- `shop_item_arc`: 선택 칸 기준 `(0,-175)`, `250×390`, 프레임 간격 `0.06`, `0.03~0.34`, `alpha=0.92`, 가산, `back=False`, `beam=False` 유지.

### 재발주 여부

- 재발주 없음.
- 새 `shop_coin_to_gold`는 별/십자 없이 원형 도트가 꼬리 방향으로 작아져 빔 합성에 적합하다.
- 새 `shop_item_arc`는 아이콘 비율이 유지되고 사각 파편과 굽은 꼬리만 있어 시안의 원호 이동과 맞는다.

## 4컷 — 창 닫힘 뒤 능력치 적용 빛 (4.55초)

### 시안/추가 조건과 다른 점

- 없음. 창이 선택 뒤 0.35초에 닫힌 다음 플레이어 몸 중심에 상점색 빛이 붙는다.
- 180×220 안에서 끝나 화면 전체를 물들이지 않으며, 다른 세 창과 같은 크기·합성 규칙이다. 가산 합성이라 0.4초 뒤에도 이벤트색이 읽힌다.

### `layers_shop()`에서 바꿀 값

- 없음. `powerup('shop')`의 몸 기준 `(0,-10)`, `180×220`, 프레임 간격 `0.07`, `0.35~0.95`, `alpha=0.95`, 가산, `back=False`, `tint=(255,174,32)`, `fromAvatar=True` 유지.

## Claude가 바로 적용할 변경 목록

1. `layers_shop()`의 여섯 `shop_cell_rim`에서 `alpha=0.26`만 `alpha=0.48`로 변경한다.
2. 좌표, 크기, 프레임 간격, 시작/끝, 가산/덮기, `back`, 나머지 모든 상점 FX 값은 유지한다.
3. 재발주 3종(`coin_to_gold`, `item_arc`, `cell_rim`)은 다시 발주하지 않는다.
4. 변경 뒤 2.00초 한 컷만 확인한다. 여섯 칸의 호박색 외곽 호흡이 보이되 상품명·가격·설명 내부에는 빛이 들어오지 않으면 최종 통과다.
