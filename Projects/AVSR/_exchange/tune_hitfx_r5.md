# 전체 통과

# 피격 FX 수치 조정표 r5

기준 시안: `in/mock_hitfx_v7.png`  
현재 비교: `ref/hitfx_ingame/compare_r4.png`의 맨 위 시안과 0.035 / 0.075 / 0.125초 게임 캡처(2배)  
r4까지 적용된 값을 현재 값으로 본다. 넷째 적의 노란 시험판 외형은 판정에서 제외한다. 표에 없는 함수·재질 수치는 r4를 유지한다.

## 1. 경우별 판정

측정은 비교 이미지의 2배 표시를 원본 720×1280 기준으로 환산했다. 블룸과 숫자 겹침을 포함한 오차는 약 `±3 px`다.

| 경우 | 판정 | r4 결과 측정 및 근거 | 남은 판단 |
|---|---|---|---|
| 보통 | **통과** | 0.035초 흰 중심이 약 `21~24 px`, 바깥 잔광이 약 `32~36 px`. 0.075초에는 흰 파편 3개 이상이 분리되고 0.125초에는 작은 잔광만 남는다. 시안의 크기와 소멸 순서 범위다. | 변경 없음. |
| 치명 | **통과** | 0.035초 방사광의 안쪽 끝이 중심 밖 약 `3~7 px`에서 시작한다. 서로 맞물려 있던 십자·별 매듭이 사라졌고, 0.075초에도 끊긴 방사광 5개 이상이 독립적으로 읽힌다. 바깥 도달 반경은 시안과 약 `±4 px` 범위다. | 변경 없음. 숫자 겹침은 FX가 아니라 별도 숫자 시스템에서 처리한다. |
| 유리 | **통과 + 다듬을 점** | 0.035~0.075초 원뿔 길이는 약 `74~85 px`, 중심의 밝은 심은 약 `7~10 px`로 시안 범위다. 0.125초에 독립 주황 불티가 `4~6개` 읽혀 공격 종류는 즉시 구분된다. 다만 시안의 `9~11개`보다 적고, 보이는 불티도 약 `8~11 px`로 작고 연하다. | 원뿔은 고정. 주황 불티만 약간 키우고 번짐을 줄여 진한 주황 몸과 노랑 심을 살린다. |
| 불리 | **통과 + 다듬을 점** | 0.035초 접촉점에 약 `48~55 × 9~12 px`의 얇은 은백색 면이 보이며 쏜 쪽의 은빛 낱알과 분리된다. 0.075초에는 충돌면 잔광과 `-dir` 파편, 0.125초에는 파편과 긴 꼬리만 남아 “막힘”의 문법은 성립한다. 시안 목표 폭 `54 px`의 하한에는 닿지만 첫 박자 대비가 조금 약하다. | 앞·뒤 면의 시작 크기와 알파만 소폭 올린다. 방패·돔·반사체는 추가하지 않는다. |

네 경우 모두 형태, 방향, 색, 소멸 순서가 서로 구분되므로 **전체 통과**다. r5는 재설계가 아니라 최종 가독성 다듬기다.

## 2. 남은 수치표

### HxTap — 보통

**변경 없음. r4 유지.**

### HxCrit — 치명

**변경 없음. r4 유지.** 방사광 생성 반경 `10~16 px`, 접선 흔들림 `-3~+3 px`, 길이×폭 `40~52 × 5`, 생성 시각 `0 / 0.006 / 0.012 / 0.018초` 순환을 그대로 둔다.

### HxPierce — 유리

원뿔, 바깥 번짐, 몸 관통 빛기둥은 전부 r4 값으로 고정한다. 아래 주황 불티만 바꾼다.

| 계층 | 항목 | 지금 값(r4) | 새 값(r5) |
|---|---|---:|---:|
| 큰 둥근 불티 | 개수 | `9` | `11` |
| 큰 둥근 불티 | 반각 / 속도 | `38° / 195~330` | `42° / 205~345` |
| 큰 둥근 불티 | 크기 | `13×11` | `15×13` |
| 큰 둥근 불티 | 생성 위치, 진행축 / 접선축 | `6~20 / -8~+8 px` | `8~22 / -11~+11 px` |
| 작은 둥근 불티 | 개수 / 크기 | `3 / 10×10` | `3 / 11×11` |
| 작은 둥근 불티 | 반각 / 속도 | `42° / 185~320` | `46° / 195~335` |
| 경량 둥근 불티 | 개수 / 크기 | `2 / 10×8` | `2 / 11×9` |
| 경량 둥근 불티 | 반각 / 속도 | `46° / 210~350` | `50° / 220~365` |
| 모든 주황 불티 | 생성 시각 | `0 / 0.008 / 0.016 / 0.024초` 순환 | 동일 |

총 생성수는 `14 → 16개`다. 한 프레임의 가시 목표는 `7~10개`로 잡는다. 좌우 합계 4개 이상이 원뿔 가장자리보다 접선축으로 `8 px` 이상 밖에서 보여야 한다. 수명은 늘리지 않는다. 잔상이 아니라 각각의 낱알로 읽혀야 한다.

### HxDeflect — 불리

| 계층 | 항목 | 지금 값(r4) | 새 값(r5) |
|---|---|---:|---:|
| 뒤 은빛면 | 시작→끝 크기 | `66×11 → 82×14` | `72×12 → 86×15` |
| 뒤 은빛면 | 알파 / 수명 | `0.46 / 0.105` | `0.52 / 0.105` |
| 앞 흰빛면 | 시작→끝 크기 | `58×7 → 76×10` | `64×8 → 80×11` |
| 앞 흰빛면 | 알파 / 수명 | `0.90 / 0.09` | `0.96 / 0.09` |
| 면 위치 | 접촉점에서 `-dir` 쪽 | `1 px` | `1 px` |
| 대·소 은빛 불티 / 긴 빛꼬리 | 전체 | r4 값 | 동일 |
| 맞은 탄 반사 / 방패 / 반고리 / 돔 | 생성 여부 | 생성하지 않음 | **계속 생성하지 않음** |

면의 끝 크기와 수명은 거의 고정하고 첫 프레임의 면적과 대비만 올린다. 0.035초 화면상 합성 윤곽 목표는 `54~62 × 10~14 px`다.

## 3. 재질값

표에 없는 재질은 r4 값을 그대로 유지한다.

| 재질 | 속성 | 지금 값(r4) | 새 값(r5) |
|---|---|---:|---:|
| `HxDotSolid_Orange` | `_DstBlend / _RingWhite / _CoreWhite` | `1 / 0.58 / 0.92` | `1 / 0.48 / 1.00` |
| `HxDotSolid_Orange` | `_RingWidth / _RingGlow` | `0.48 / 0.30` | `0.56 / 0.20` |
| `_hxPlaneMat` | `_DstBlend / _RingWhite / _CoreWhite` | `10 / 0.30 / 0.62` | `10 / 0.34 / 0.68` |
| `_hxPlaneMat` | `Body / CoreWidth / CoreBoost` | `0.90 / 0.20 / 0.68` | `0.94 / 0.20 / 0.74` |
| `_hxPlaneBackMat` | `_DstBlend / _RingWhite / _CoreWhite` | `10 / 0.18 / 0.42` | `10 / 0.22 / 0.48` |
| `_hxPlaneBackMat` | `Body / CoreWidth / CoreBoost` | `0.72 / 0.15 / 0.46` | `0.78 / 0.15 / 0.52` |

`HxDotSolid_Orange`는 더하기 합성을 유지하되 `_RingGlow`를 낮춰 흐린 살구색 번짐을 줄인다. 넓어진 주황 몸 안에 더 작은 노랑·흰 심이 박혀 보여야 한다. 유리 원뿔 재질 `_hxConeMat`, `_hxConeGlowMat`, `_hxBeamMat`은 r4에서 이미 통과했으므로 변경하지 않는다.

## 4. 숫자 시스템 별도 적용

FX 판정과 분리한다. r4 결과에서 숫자가 적 머리와 FX 중심을 가리므로 **r2 4절 제안을 그대로 적용한다.**

| 항목 | 지금 | r5 적용값 |
|---|---:|---:|
| 숫자 생성 기준 Y | 적 머리/FX와 겹치는 현재 위치 | 현재 위치에서 화면 위쪽 `+18 px` |
| 보통 숫자 시작 배율→안착 배율 | `1.00 → 1.00`로 간주 | `0.92 → 1.00`, `0.06초` |
| 치명 숫자 첫 튐 배율→안착 배율 | 약 `1.35 → 1.00` | `1.12 → 1.00`, `0.08초` |
| 같은 프레임 다중 숫자 X 간격 | 겹침 | 중심 기준 좌우 교대 `18 px`, 최대 `±36 px` |

숫자 이동 뒤 FX 중심과 적 얼굴이 함께 드러나야 한다. 숫자 색·폰트·최종 크기는 바꾸지 않는다.

## 5. 점검표

| 시각 | 보통 | 치명 | 유리 | 불리 |
|---|---|---|---|---|
| 0.035초 | 중심 `20~25 px`, 몸통을 완전히 가리지 않음 | 중심 가장자리와 방사광 안쪽 끝 사이 `2~7 px`; 중심 매듭 없음 | 폭 `18~22 px` 주황 원뿔 안에 노랑·흰 심 `7~10 px`; 독립 불티 5개 이상 | 접촉점에 `54~62×10~14 px` 납작한 은백색 면이 독립적으로 보임 |
| 0.075초 | 흰 파편 3개 이상 | 끊긴 방사광 5개 이상; 십자·별·마름모 없음 | 원뿔 길이 `70~86 px`; 심·몸·외곽 3단과 독립 불티 7개 이상 | 충돌면 잔광과 `-dir` 은빛 불티가 분리되어 보임 |
| 0.125초 | 작은 잔광만 남음 | 금빛 낱알 8개 이상; 닫힌 선 윤곽 없음 | 둥근 주황 불티 `7~10개`; 원뿔보다 좌우로 넓은 낱알 4개 이상 | 면은 사라지고 은빛 낱알 5개 이상과 긴 꼬리 2~3개만 남음 |
| 색 확인 | 무채색 흰색 | 금빛 낱알 + 흰 중심 | **진한 주황 몸 + 노랑·흰 심**, 연분홍·살구색 덩어리 아님 | 은백색 충돌면 + 은빛 낱알 |
| 숫자 | FX와 적 얼굴을 가리지 않음 | 첫 튐이 FX 중심을 덮지 않음 | 적 머리 위로 `18 px` 이동 | 적 머리 위로 `18 px` 이동 |
| 금지 형태 | 별·고리 과장 없음 | 중심 십자·별·마름모·닫힌 다각형 없음 | 흐린 연기 덩어리·단색 주황 면·화살촉 없음 | 방패·반고리·돔·화살촉·새 투사체 없음 |

최종 기준은 원본 720×1280에서 네 경우가 각각 `중심 형태 1개 + 방향성 파편`으로 즉시 구분되고, 숫자가 그 중심 형태와 적 얼굴을 가리지 않는 것이다. r5 확인에서 유리 불티가 `7개` 이상, 불리 첫 면이 목표 하한에 들면 추가 조정 없이 종료한다.
