# 재발주 — 로비 UI 크롬 (9장)

지난 판본은 불합격이다. 1 px 윤곽에 2색 단색으로 나와 게임 UI 가 아니라 도형처럼 보였다.
원인은 발주서였다 — 팔레트와 화풍을 내가 시시콜콜 지정했다.
**이번엔 그리는 방식을 지정하지 않는다. 기준 그림을 보고 네가 판단해서 그려라.**

## 기준 그림

```
Projects/AVSR/Reference/Mockups/parts/
```

승인된 목업에서 그 부위만 잘라 낸 **실물**이다. 아홉 장 전부 열어 보고,
**나란히 놓았을 때 같은 게임의 UI 로 읽히게** 그린다. 그게 유일한 기준이다.

전체 화면 분위기는 `Projects/AVSR/Reference/Mockups/lobby_hub_v2.png` 를 본다.

## 지켜야 할 것 (그림 얘기가 아니라 붙이는 규격이다)

1. **배경은 마젠타 `#FF00FF` 한 색.** 투명은 내가 뚫는다. 그림 안쪽에 마젠타를 쓰지 마라
2. **「비움」은 가운데까지 마젠타로 뚫는다** — 그림 위에 겹쳐 얹는 테두리라, 속이 차 있으면
   안쪽이 통째로 가려진다
3. **9-slice**: 모서리 장식이 보더 안에 온전히 들어가고, 가운데와 네 변은 늘려도 티가 안 나게
   반복 가능해야 한다
4. **글자를 그리지 마라.** 기준 그림에 있는 글자는 무시한다 — 글자는 게임이 따로 얹는다

## 검수

기준 그림과 나란히 놓고 본다. **같은 게임의 UI 로 읽히면 합격이다.**

지난 판본이 왜 떨어졌는지만 참고로 남긴다 — 단색 채우기, 1 px 윤곽 하나,
장당 색이 4~8가지뿐이었다. 목업은 그렇지 않다.
