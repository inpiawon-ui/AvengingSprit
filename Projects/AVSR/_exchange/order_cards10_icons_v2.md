# 발주 (재작업) — 특성 카드 아이콘 10장, **시안 화풍으로**

## 무엇이 문제인가

레벨업 화면을 컨펌 시안(B 「돌 서판」)대로 다 붙였는데, **아이콘만 화풍이 다르다.**

지금 아이콘은 128×128 캔버스에 그린 **납작한 기호**다.
시안의 아이콘은 카드 안에서 훨씬 크고, **입체 음영이 들어간 작은 장면**이다.

| | 지금 | 시안 |
|---|---|---|
| 크기 | 128 × 128 (카드 폭의 52%) | **160 × 160 (카드 폭의 76%)** |
| 만듦새 | 단색 실루엣 + 옅은 발광 | **금속 질감 · 하이라이트 · 림 라이트 · 그림자** |
| 구성 | 상징 하나 | 상징 + 그 상징이 **하는 일**까지 보이는 한 장면 |

## 반드시 열어 볼 파일 — 이것이 기준이다

시안에서 아이콘 세 개를 그대로 오려 두었다. **이 세 장이 화풍 기준이다.**

| 파일 | 무엇 |
|---|---|
| `Projects/AVSR/_exchange/in/_ref/mockup_icon_shield.png` | 「수호 방패」 — 방패 셋이 **푸른 궤적을 그리며 도는** 장면 |
| `Projects/AVSR/_exchange/in/_ref/mockup_icon_axe.png` | 「처형」 — 도끼가 **내리꽂혀 돌을 부수고** 뒤로 주황 광선이 솟는 장면 |
| `Projects/AVSR/_exchange/in/_ref/mockup_icon_chain.png` | 「번개 사슬」 — 빛나는 구슬 셋을 **번개가 잇는** 장면 |
| `Projects/AVSR/_exchange/in/levelup_mockup_b.png` | 컨펌본 전체 화면 |
| `Assets/BaseResource/Card/cardpanel_rare.png` | 아이콘이 놓일 액자. 안쪽 면은 **어두운 청록** |

세 장을 보면 알 수 있는 규칙:

1. **상징이 캔버스를 꽉 채운다.** 여백 8px 이내
2. **금속에는 하이라이트와 그림자가 있다.** 방패의 빗면, 도끼날의 반사
3. **뒤에 기운이 깔린다.** 궤적·광선·번개가 상징 뒤에서 뻗어 나온다
4. **바닥에 부스러기·불티**가 있어 "지금 벌어지는 일"로 읽힌다
5. 어두운 청록 면 위에 놓이므로 **가장자리가 밝아야** 형태가 산다

## 규격

```
크기:   160 × 160  (지금은 128 × 128 — 커진다)
배경:   마젠타 #FF00FF 단색. 투명 PNG 로 주지 않는다
화풍:   픽셀아트. 안티에일리어싱으로 뭉개지 않는다
글자:   넣지 않는다
```

> ⚠ 지난번 카드 액자 납품에서 **모서리만 마젠타이고 그 안쪽에 색 띠가 한 겹 더**
> 칠해져 와서 게임에 분홍 막대가 섰다. 상징 바깥은 **한 픽셀도 남김없이** `#FF00FF` 여야 한다.
