# 인게임 팝업 4종 퀄리티 개선 방향

## 1. 캡처 기준 추가 진단

- 네 팝업은 외곽 재질뿐 아니라 제목 위치, 선택 영역의 형태, 버튼 강조법, 글꼴 인상까지 달라 같은 종류의 의사결정 화면으로 보이지 않는다.
- 큰 날개·뿔·천막·기둥이 화면을 많이 차지하지만 실제 정보 면적은 좁다. 특히 제단은 장식 대비 선택지가 작고, 상점은 상품 6개가 한 덩어리로 뭉친다.
- 레벨업은 카드 세 장의 실루엣은 잘 읽히지만 이름 아래 설명이 너무 아래에 있고 대비가 약하다. 희귀도, 그림, 이름, 설명 사이의 시선 흐름도 길다.
- 악마 창은 본문·비용·대가·두 행동의 위계가 불명확하고, 붉은 주 행동만 과도하게 강해 거래 조건을 읽기 전에 누르기 쉽다.
- 상점은 아이콘·이름·설명·가격이 한 줄에 경쟁한다. 보라 천막과 목재 장식도 새 HUD의 청색 네온·기계 배경과 가장 멀다.
- 영문 픽셀 HUD, 일본어 안내, 장식적인 한글 제목/본문이 한 화면에 섞여 타이포 체계가 분절돼 보인다.
- 팝업 뒤를 매우 어둡게 덮는데도 팝업 내부의 검정·남색 면이 많아 외곽과 내용 경계가 약하다. 선택 가능 영역도 창마다 발광, 화살표, 테두리 규칙이 다르다.
- 방 화면은 전투 판 자체가 세로 약 590px뿐이고 유닛·피격 이펙트가 중심을 점유한다. 이벤트 오브젝트에 이름표나 바닥 표식이 없으면 크기만 조금 키워도 전투 소품으로 오인될 가능성이 높다.

## 2. 시안 방향

### A. 네온 HUD 연장

장점은 새 HUD와 즉시 한 세트로 묶이고 정보 가독성을 가장 쉽게 확보한다는 것, 단점은 모든 창이 SF 메뉴처럼 보여 천사·악마·유령 상인의 맛이 약해질 수 있다는 것이다. **고칠 점:** HUD의 밝은 청색을 공통 외곽선 전체에 두르지 말고 모서리·선택 상태·작은 회로선에만 제한한다. 본체는 무광 흑철로 눌러 대표 색과 각 상징이 주인공이 되게 한다.

### B. 석조 + 보석

장점은 기존 제단과 악마의 물성 및 판타지 장식을 가장 적게 버리면서 정돈할 수 있다는 것, 단점은 새 HUD·로봇·폐공장 배경과 다시 분리될 위험이 있다는 것이다. **고칠 점:** 석조를 고성당 대리석이 아니라 공장에 회수된 낡은 석판으로 바꾸고, 동일한 금속 클램프·볼트·색 코어를 네 창에 공통 사용한다. 날개·뿔·천막은 제목 위 상징 크기로만 축소한다.

### C. 대체안 — 「원혼 회로」

기존 「유령 부적」은 동양 부적 문법이 현재의 산업 시설·로봇 호스트와 충돌할 수 있다. 대신 **검은 기계 프레임 안을 원혼이 전류처럼 흐르고, 선택 칸이 ‘빙의 슬롯’처럼 점등되는 원혼 회로**를 제안한다. 장점은 유령의 빙의, 로봇 호스트, 새 네온 HUD를 한 문법으로 묶어 이 게임만의 얼굴을 만들 수 있다는 것, 단점은 발광량을 제어하지 않으면 A안과 비슷한 범용 SF UI가 된다는 것이다. **고칠 점:** 직선 네온 대신 끊기고 맥동하는 혼백의 흐름, 손으로 긁은 듯한 원혼 문양, 낡은 공업 부품을 사용한다. 색은 레벨업 금·제단 청록·악마 진홍·상점 호박 한 색만 허용하고, 별·표창·십자 반짝이는 쓰지 않는다.

**PD 추천:** C를 1안, A를 안전한 2안으로 발주한다. C의 고유성이 부족하게 나오면 A의 정보 구조는 유지하고 원혼 회로의 표면 표현만 강화한다.

## 3. 공통 규칙 및 수치 제안 (720×1280 기준)

Claude 초안의 방향에는 동의하되, 실제 한글 줄 수와 3열 배치를 고려해 아래처럼 수정한다. 숫자는 축소 목표가 아니라 **최소 보장값**이며 TMP 자동 크기로 이보다 작아지게 하지 않는다.

| 항목 | 확정 제안 |
|---|---:|
| 팝업 외곽 폭 | 660~680px, 좌우 안전 여백 최소 20px |
| 팝업 외곽 높이 | 내용별 720~900px, 상·하단 주요 조작부는 안전 영역 안에 고정 |
| 제목 | 42~44px, 1줄 고정 |
| 선택지·카드 이름 | 기본 30px, 상점 상품명만 28px까지 허용 |
| 설명 | 기본 22px, 보조 문구 최소 20px; 20px 미만 자동 축소 금지 |
| 가격·비용·대가 | 28px, 아이콘과 숫자를 한 묶음으로 표시 |
| 주 버튼 / 보조 버튼 | 30px / 26px, 높이 최소 72px |
| 레벨업 카드 | 204×480px 3장, 카드 간격 12px 이상; 그림 영역 최소 150×150px |
| 제단·악마 선택 칸 | 유효 폭 600px 이상, 높이 112px 이상, 칸 사이 12px |
| 상점 상품 칸 | 2열×3행, 칸 288×132px 이상, 아이콘 72px, 이름과 가격은 첫 줄·설명은 둘째 영역 |
| 공통 테 | 외곽 8px, 내부 선택 테 4px; 비선택/선택/구매 불가의 상태 규칙을 네 창이 공유 |
| 제목 위 상징 | 64~80px, 창별 실루엣 하나만 사용 |
| 배경 딤 | 검정 65~70%; 화면 전체에 창 대표 색을 물들이지 않음 |

방 오브젝트는 “유닛의 1.7배”를 단순 가로폭이 아니라 **읽히는 세로 실루엣 기준**으로 적용한다.

- 제단·악마 오브젝트: 보이는 높이 240~260px, 핵심 실루엣 폭 최소 180px. 기존 192×192 논리 칸/충돌 범위는 유지해도 되지만 그림은 위로 넘겨 보이게 한다.
- 유령 노점: 보이는 폭 260~280px, 높이 220~250px. 천막보다 상인/영혼 등불과 거래대의 실루엣이 먼저 읽혀야 한다.
- 공통 바닥 표식: 대표 색 원형광 지름 180~220px, 불투명도 낮게. 위험 장판과 혼동되지 않도록 채운 원이 아니라 얇은 이중 링으로 통일한다.
- 머리 위 표식: 36~44px 아이콘, 오브젝트 최고점에서 16~24px 띄움. 제단=성배/날개, 악마=뿔 계약인, 상점=저울/동전처럼 외곽선만 보고 구분되게 한다.

## 4. 그림 담당 발주문에 반드시 넣을 문장

1. 네 창은 같은 외곽 프레임·제목 판·선택 칸·버튼 비율을 공유하고, 달라지는 것은 대표 색 한 가지와 제목 위 상징 한 가지뿐이다.
2. 720×1280 실제 크기에서 제목 42px, 이름 28px, 설명 20px 미만으로 줄어드는 레이아웃은 불합격이며, 반드시 100% 크기 캡처로 판독성을 확인한다.
3. 장식은 정보 영역을 침범하지 않게 프레임 바깥과 제목 상징에만 두고, 선택·구매 가능 상태가 장식보다 먼저 보여야 한다.
4. 인게임 오브젝트는 유닛보다 큰 240~260px 실루엣, 대표 색 이중 바닥 링, 36~44px 머리 위 상징을 한 세트로 함께 시안한다.
5. 게임과 같은 도트 밀도를 지키고 별·표창·십자 반짝이, 화면 전체 색 틴트, 서로 다른 재질의 과잉 혼합은 사용하지 않는다.
