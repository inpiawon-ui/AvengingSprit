# 재발주 — 인게임 방 배경 샘플 3차 (720 × 1692 한 장)

## 2차 평가 — 사장님 말 그대로

> 배경은 이쁜데... 지금 보면 배경이 톤이 너무 쎄서 인게임이 잘 안 보이는 게 있어.
> 내가 원하는 건 **배경은 죽어 있고, 그래서 그 위에 오브젝트랑 캐릭터가 잘 살아야** 되거든.
> 지금 배경이 너무 복잡하게 되어 있고...

- 2차: `Projects/AVSR/_exchange/in/roomfloor_env_junkyard_full.png` — **무대 · 분위기 · 한 장으로 이어지는 구성은 합격이다.** 이건 살린다
- 2차를 게임에 넣고 찍은 화면: `Projects/AVSR/_exchange/ref/ingame_floor_v2_screen.png` — **이걸 꼭 보고 판단해 달라.**
  캐릭터 · 적 · 장애물이 배경에 묻혀 잘 안 보인다
- 이번 목표: **같은 장면인데 배경이 한 발 뒤로 물러나 있어서, 그 위에 올라가는 것들이 또렷하게 사는 그림**
  - 특히 **걸어 다니는 바닥**이 조용해야 한다 — 지금은 톤이 세고 무늬 · 얼룩 · 빛이 많아 복잡하다
  - 방 아래 영역과 좌우 가장자리는 분위기를 맡아도 되지만, 역시 전투보다 튀면 안 된다

**어떻게 죽일지(색 · 명암 · 채도 · 디테일 양 · 조명)는 전부 그쪽이 정한다.**
사장님이 처음 준 예시 두 장도 다시 보고 참고해 달라 — 바닥이 단순해서 위에 얹힌 것들이 산다:
`Projects/AVSR/_exchange/ref/ingame_style_example_1.png` · `Projects/AVSR/_exchange/ref/ingame_style_example_2.png`

CH1 「쓰레기 집적장」 — 원작 STAGE 1 (쓰레기 더미에서 지도를 찾은 곳).
AVENGING SPIRIT: RE:BORN, 유령이 적에게 빙의해 싸우는 방 단위 로그라이크. 원작 느낌 + 요즘 게임 느낌.

## 규격 — 2차와 같다 (꼭 지킬 것)

```
 y 0     ┌────────────────────────────────┐
         │ 맨 위 약 56 px 는 구름 층에 가린다   │
         │    출구 문 x 252~468 (막지 말 것)   │  문 그림은 게임이 따로 얹는다
 y 180   │                                │  위 180 px: 적·장애물이 안 놓인다
         │   방 — 10 m × 16 m, 72 px = 1 m  │
         │   좌·우 24 px 안쪽은 전부 걸어 다닌다 │
         │          ● 플레이어 시작 약 y 1030 │
 y 1128  │ ─ ─ 캐릭터는 이 아래로 못 간다 ─ ─ │
 y 1152  ├────────────────────────────────┤  ← 내가 여기서 잘라 두 장으로 쓴다
         │   방 아래 영역 (아무도 안 걷는다)    │  조이스틱 · 스킬 버튼이 이 위에 뜬다
 y 1692  └────────────────────────────────┘
```

| 항목 | 값 |
|---|---|
| 파일 | `roomfloor_env_junkyard_full_v3.png` |
| 크기 | **720 × 1692 px 정확히** |
| 형식 | PNG, 완전 불투명 |
| 시점 | 위에서 내려다본 방, 바닥 칸은 어디서나 같은 크기 |
| 좌우 벽 | **얇게** — 방 구역에서 서 있는 벽·고철은 좌우 끝 **24 px 안에만**. 2차는 35~40 px 로 조금 넘쳤다 |
| 걸어 다니는 바닥 | 서 있는 물체 금지(장애물은 게임이 따로 얹는다). 납작한 것만 |
| 방 아래 영역 | 자유 — 아무도 안 걷는다 |
| 글자 | 글자 · 로고 · 숫자 금지 |

- 그 위에 올라가는 것: 픽셀아트 캐릭터 · 적(한 기 약 144 px), 장애물(72 px 격자 블록 · 상자 · 기둥 등), 체력바 · 조준 표시 같은 작은 UI
