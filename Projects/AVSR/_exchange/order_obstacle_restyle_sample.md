# 발주 — 인게임 장애물 새 화풍 샘플 1장: 블록 (72 × 102)

## 왜

CH1 「쓰레기 집적장」 배경을 새로 받아 **통과**했다. 그런데 그 위에 놓이는 장애물이 예전 그림이라
**새 배경과 전혀 안 어울린다**(사장님 지적).

사장님 요청 그대로:

> 좀 **심플하면서 잘 보이는** 걸로 부탁해

배경은 일부러 조용하게 죽여 놓았다 — **그 위에서 장애물과 캐릭터가 살아야 한다.**

**색 · 재질 · 형태 · 화풍 — 디자인은 전부 그쪽이 정한다.** 아래는 게임이 쓰는 규격뿐이다.

## 이번 샘플 — 블록

- 게임에서 **가장 많이 쓰이는 장애물**이다 (한 방에 여러 개, 옆으로 이어 붙여 벽처럼 쓰기도 한다)
- 캐릭터가 뒤에 숨는 **엄폐물**이자 길을 막는 벽이다 — 한눈에 「막힌 곳」으로 읽혀야 한다
- 무대: 쓰레기 집적장 (1991 원작 STAGE 1). 유령이 빙의해 싸우는 게임
- 이 한 장이 통과하면 **같은 화풍으로 나머지 13장**(블록 2종 · 기둥 · 레일 · 상자 · 큰 고철 · 낮은 엄폐물 · 바리케이드 · 도랑 2종 · 가시 함정 3프레임)을 이어 받는다

## 규격 — 게임이 이렇게 쓴다 (꼭 지킬 것)

```
  ┌──────── 72 ────────┐
  │   윗면 (높이 30)     │  ← 위에서 내려다본 윗면이 보이는 부분
  ├────────────────────┤
  │                    │
  │  발자국 72 × 72      │  ← 바닥에 닿는 칸. 여기가 판정이다
  │                    │
  └────────────────────┘
   캔버스 72 × 102 (폭 72, 높이 102)
```

| 항목 | 값 | 이유 |
|---|---|---|
| 파일 | `obj_junkyard_block_1.png` | 게임이 이 이름으로 찾는다 |
| 크기 | **72 × 102 px 정확히** | 아래 72 × 72 = 바닥 한 칸(1 m) 발자국, 그 위 30 px = 솟은 높이 |
| 형식 | PNG **투명 배경**(알파). 물체 밖은 완전히 투명 | 바닥 위에 얹힌다 |
| 채움 | 물체가 캔버스 **좌 · 우 · 아래 끝까지** 닿게 | 옆으로 이어 붙이면 벽이 된다. 틈이 생기면 안 된다 |
| 시점 | 새 배경과 같은 시점 — 위에서 비스듬히 내려다봐 윗면 + 앞면이 보인다 | |
| 그림자 | **그리지 마라** — 게임이 발밑에 타원 그림자를 따로 깐다 | 두 겹이 된다 |
| 글자 | 금지 | |

- 게임은 이 그림을 **70 %로 줄여서** 그린다(화면에서 약 50 × 71). 작게 줄어도 형태가 읽혀야 한다 — 잔무늬는 줄면 뭉개진다
- 같은 칸에 캐릭터(한 기 약 144 px 픽셀아트)가 옆에 선다
