# 상의 — 결과창(챕터 클리어) 금화 · 상자 빛을 파티클로 (2026-10-08)

규칙: `.claude/rules/project/08_fx.md` (빛 · 반짝임 · 아우라 = 파티클 + 빛 셰이더, 형태 있는 것만 그림, 물건 그림에 빛을 굽지 않는다, 코덱스와 같이 정한다)

## PD 피드백 원문(요지)
1. 「결과창 상자가 떨어질 때 이펙트 터지는 게 뎁스가 좀 애매하네.. 아싸리 박스 뒤에는 안 보이게 한다던가..」
2. 「결과창 골드 마지막 이미지는... 뒤에 이펙트는 이미지가 아니라 연출로 반짝이는 효과를 넣어야 하는데 이펙트를 이미지로 해서 이상하고,
   박스 뒤에 파란색 아우라 이미지도 저건 원래 이미지가 아니라 이펙트로 표현해야 되는 거야」
3. 「결과창 뜨고 골드 획득 +0 다음에 연출 딜레이가 너무 길어」 → 순서: 창 → 위 칸(골드 획득 글자) → 금화 더미가 쌓이며 금액이 같이 오름 → 아래 칸 → 상자(또는 「상자 칸이 가득 찼다」)
4. 상자 아우라를 그림 시트(분홍 바탕)로 받아 보여 줬더니 「설마 저게 박스 이펙트 아니지??」 — 딱딱한 별 덩어리. 그래서 파티클로 가기로 했다.

## 지켜야 할 예전 PD 규칙
- 별 · 표창 · 십자 모양 반짝이 금지(「표창처럼 보인다」) — 이번엔 PD 가 「연출로 반짝이는 효과」를 직접 요청했으니 **반짝임은 하되 표창처럼 안 보이게**(작고 짧게 · 부드러운 빛 점 위주 등) 어떻게 할지 답에 넣을 것
- 화면 전체 물들이기 금지 · 게임 정보(글자 · 숫자) 가리기 금지 · 열 때 한 번 「팍」 터지는 것 · 테두리 전부 빛나는 것 금지
- 팝업 장식은 은은하게 계속 도는 것(숨쉬기 · 흐름)

## 묻는 것
1. 위 안에서 **바꿀 것 · 뺄 것 · 더할 것**(특히 PD 가 싫어한 「싸구려 반짝임 · 과한 테두리 효과」 쪽으로 기울지 않는지).
2. 숫자(크기 · 알파 · 속도 · 개수 · 숨쉬기 주기 · 등급색 값) 조정안.
3. 상자 착지 먼지 — 바닥 높이 · 양옆으로만 퍼지는 게 「박스 뒤에는 안 보이게」와 맞는지, 아니면 아예 상자 뒤 깊이로 보내는 게 나은지.
4. 금화 더미 뒤 번짐이 필요한지(반짝임만으로 충분한지).
