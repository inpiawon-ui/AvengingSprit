# 공통 알림 팝업 디자인 검수

검수 대상: `popup_mock_v1.png` (720×1280)

## 1. 기존 UI와의 패밀리룩

큰 방향은 같은 게임의 UI로 보인다. 짙은 남청색 판, 각진 은색 금속 프레임, 시안 계열의 발광선, 모서리 볼트 구조는 결과 창·상자 창 틀의 재질과 문법을 잘 이어받았다. 노란 확인 버튼도 기존 노란 버튼의 형태와 색을 거의 그대로 사용해 패밀리룩이 명확하다.

다만 아래 요소는 다소 어긋난다.

- 팝업 외곽의 청색 발광이 결과/상자 창보다 더 굵고 균일해 네온 테두리처럼 보인다. 기존 창은 금속 구조가 먼저 읽히고 빛은 홈이나 에너지 포인트에 국소적으로 들어간다.
- 외곽 프레임의 좌우 중간과 상·하단 중앙에 밝은 빛이 반복되어, 기존 프레임보다 장식 밀도가 높고 시선이 본문보다 테두리로 분산된다.
- 취소 버튼은 확인 버튼과 크기·외곽 구조는 잘 맞지만, 내부가 팝업 본체와 거의 같은 남청색이라 비활성 버튼처럼 보일 여지가 있다. 기존 UI의 버튼은 바탕과 버튼 면의 재질/명도 차이가 조금 더 분명하다.
- 본문 글자는 선명하지만 기존 UI보다 현대적인 굵은 고딕과 강한 검은 그림자가 두드러진다. 글꼴을 바꾸지 않더라도 그림자 거리와 농도를 조금 줄이면 기존 픽셀풍 그래픽 안에 더 자연스럽게 놓인다.

## 2. 1~3줄 문구·버튼 구성과 9-slice 적합성

현재 1줄 문구와 버튼 2개 구성은 안정적이다. 그러나 같은 높이를 유지한 채 3줄 문구와 버튼 1개를 넣으면 성립은 가능해도 여백이 빠듯하다. 현재 본문 영역은 실제로 한 줄만 크게 차지하고 있으며, 본문과 버튼 사이의 여백이 넓지 않다. 3줄에서는 글자 크기와 줄간격을 함께 줄이지 않으면 상단·버튼 쪽이 답답해질 가능성이 높다.

권장 내부 규칙은 다음과 같다.

- 본문 영역과 버튼 영역을 분리하고, 본문은 최대 3줄 기준의 고정 높이 안에서 수직 중앙 정렬한다.
- 3줄 기준 글자 크기 30~34px, 줄간격 1.25~1.35배를 우선 검토한다. 현재 1줄 크기는 약간 커서 그대로 3줄에 적용하기 어렵다.
- 버튼 1개일 때는 기존 확인 버튼 폭을 유지해 중앙 배치한다. 팝업 폭 전체에 맞춰 버튼을 늘리면 기존 낱장 버튼과 패밀리룩이 깨진다.
- 버튼 2개는 현재처럼 같은 크기로 두되, 버튼 사이 간격과 좌우 안전 여백을 고정한다.

9-slice 제작 시 주의할 부분이 있다.

- 상·하단 중앙의 강한 청색 광점과 좌우 변 중앙의 발광 구간은 절단선이 지나거나 늘어나는 영역에 두면 길게 번지거나 비대칭이 된다. 이 장식은 코너 고정 영역 밖의 별도 오버레이로 분리하거나, 각 변의 고정 크기 장식으로 분리하는 편이 안전하다.
- 내부 판의 대각선 스크래치와 미세 질감은 늘림 영역에서 왜곡/반복이 드러날 수 있다. 무방향 노이즈로 약화하거나 별도 타일 레이어로 두는 것이 좋다.
- 모서리 볼트와 사선 금속 조립부는 반드시 고정 코너 영역 안에 완전히 포함해야 한다. 절단선이 볼트나 모서리 사선을 가로지르면 크기 변경 시 형태가 찌그러진다.
- 현재 중앙을 가로지르는 필수 문양은 없어 9-slice의 기본 구조 자체는 적합하다.

## 3. 가독성과 배경 딤

흰 본문과 노란 확인 버튼은 어두운 남청색 패널 위에서 대비가 충분하고, 실제 로비 화면 위에서도 즉시 읽힌다. 확인 버튼의 검은 글자도 노란 바탕과 대비가 좋아 명확하다. 취소 버튼의 흰 글자 역시 판독에는 문제가 없다.

배경 딤은 현재 약간 과하다. 팝업 집중도는 높지만 로비의 색과 오브젝트가 상당히 죽어, 사용자가 어느 화면에서 호출했는지 알아보는 맥락까지 약해진다. 검정 딤을 체감상 50~60% 수준으로 맞추고, 팝업 뒤의 밝은 보물상자·노란 버튼이 본문 가독성을 방해하지 않는 선에서 조정하는 것이 좋다. 딤 레이어가 전체 화면을 균일하게 덮고 팝업 및 버튼에는 적용되지 않는지도 구현 단계에서 확인해야 한다.

## 4. 수정 우선순위

1. **3줄 문구용 내부 레이아웃을 먼저 확정한다.** 본문 고정 영역, 최대 글자 크기/줄간격, 본문–버튼 간 최소 여백을 정의하고 3줄+버튼 1개 및 3줄+버튼 2개를 모두 실물 크기로 확인한다.
2. **9-slice 늘림 구간에서 발광 장식을 제거하거나 분리한다.** 상·하단 중앙 광점과 좌우 중간 발광은 별도 고정 장식으로 두고, 늘림 영역에는 반복이 눈에 띄지 않는 금속/암색 면만 남긴다.
3. **외곽 발광의 굵기와 밝기를 낮춘다.** 금속 프레임이 주재질로 먼저 읽히고 청색 빛은 포인트가 되도록, 특히 좌우 세로선의 균일한 네온 느낌을 줄인다.
4. **취소 버튼의 면 분리를 강화한다.** 본체보다 약간 밝은 면, 약한 내부 그라데이션 또는 하이라이트를 더해 ‘비활성’이 아니라 정상적인 보조 버튼으로 보이게 한다.
5. **배경 딤을 한 단계 완화하고 본문 그림자를 다듬는다.** 화면 맥락은 남기되 팝업 가독성은 유지하고, 본문 그림자는 거리·농도를 줄여 기존 UI의 질감과 조화시킨다.

## 결론

**고쳐서 다시 — 패밀리룩의 기반은 맞지만, 공통 팝업으로 확정하기 전에 3줄 레이아웃과 9-slice 발광 장식 처리를 반드시 보완해야 한다.**
