# 재발주 — `roomside_rooftop.png` (4챕터 밤의 공중기지 옥상)

앞선 납품 6종 중 **이것 하나만 반려**한다. 나머지 5종(junkyard · missile · street · lab · refinery)은 통과했다.

## 왜 반려하나

이 그림은 **오른쪽 변이 플레이 필드와 맞닿는 면**이다. 거기가 보여야 할 얼굴인데,
납품본은 구조물을 가운데(80~120 px)에 몰아넣고 **오른쪽 40 px 을 새까맣게 비웠다.**

세로 열별 평균 밝기를 재 보면 이렇다.

```
                0-40    40-80   80-120  120-160(필드 접면)
rooftop  (반려)   2.7     6.7     33.5     2.7   ← 접면이 텅 비었다
junkyard (통과)  16.0    26.6     32.4    34.4   ← 오른쪽으로 갈수록 밝아진다
lab      (통과)  15.2    29.5     32.7    34.7
missile  (통과)   7.6    15.3     21.7    27.6
```

통과한 것들은 **오른쪽으로 갈수록 밝아진다.** 필드에 가까울수록 잘 보이는 면이라 그렇다.
지금 rooftop 을 화면에 붙이면 필드 옆에 검은 띠가 하나 더 생길 뿐이다.

## 다시 그릴 것

`roomside_rooftop.png` — **160 × 320 px**

### 반드시 지킬 것

1. **오른쪽 변(x = 120~160)이 가장 잘 보이는 면이다.** 여기에 구조물의 앞면이 와야 한다.
   열별 평균 밝기가 **왼쪽에서 오른쪽으로 갈수록 커져야** 한다.
   목표: `0-40` 구간보다 `120-160` 구간이 **확실히 밝다.**
2. **오른쪽 8 px 을 비우지 마라.** 거기가 필드와 닿는 자리다.
3. 왼쪽 0~40 px 은 화면 밖으로 잘려 나갈 수 있다. 어두워도 된다.

```
[화면 왼쪽 끝] ← 어두워도 됨 ─── 점점 밝아짐 ───→ 밝은 앞면 → [플레이 필드]
      x=0                                              x=160
```

### 나머지 규격 (앞 발주와 동일)

| 항목 | 값 |
|---|---|
| 크기 | 160 × 320 px |
| 형식 | PNG, **완전 불투명 (RGB)** — 알파 · 마젠타 배경 쓰지 마라 |
| 이음 | 세로로 이어 붙였을 때 이음매가 안 보여야 한다 |
| 화풍 | 픽셀아트. 참고 바닥과 같은 픽셀 크기 · 같은 디더 밀도 |
| 밝기 | 참고 바닥(평균 38.4)보다는 어둡게. **평균 12~28 사이**를 노려라 |
