# 판정: 통과

승인 시안 `mock_fxstory_room_shop_v1.png`, 정지 비교판 `room_shop_vs_mock.png`, 동작본 `room_shop.gif`, 부품 원화와 `layers_room_shop()`을 최종 대조했다.

직전 회차의 필수 변경 두 건이 모두 반영됐다. `room_shop_soul_flame`은 `alpha=0.30`으로 낮아졌고, `room_shop_coin_ring`은 `(0,82,500,210)`, `alpha=0.58`, 가산 합성으로 넓어졌다. 현재 결과에는 PD에게 보여 줄 수 없을 만큼 시안과 다른 부분이 없다. 글자·버튼 가림, 별/십자 반짝이, 화면 전체 틴트도 없다. 대기 장식은 은은하게 유지되고, 접근과 작동 상태가 분리되어 읽힌다.

부품 다섯 종의 형태도 시안 의도와 맞으므로 **재발주 없음**.

## 1컷 — 대기(0.0~1.6초)

### 시안과 다른 점

- 필수 수정이었던 혼불 과노출이 해소됐다. 상인의 얼굴·모자·몸통 디테일이 읽히면서 혼불 윤곽만 은은하게 남아 시안의 대기 강도에 들어온다.
- 떠 있는 금화는 상점 좌우에 분산되고, 네 등불은 기존 등불 위치에서 서로 다른 간격으로 깜빡인다. 시안보다 밝지 않으며 상인 원화를 가리지 않는다.
- 컷을 막는 잔여 차이 없음.

### `layers_room_shop()`에서 바꿀 값

- **변경 없음.** 아래 값을 최종값으로 유지한다.
- `room_shop_soul_flame`: 좌표 `(0,4)`, 크기 `184 x 294`, 프레임 간격 `0.16`, `t0=0.0`, `t1=0.0`, `alpha=0.30`, `add=True`, `back=False`, `phase='open'`, `loop=True`.
- `room_shop_coin_float`: 좌표 `(0,-18)`, 크기 `390 x 220`, 프레임 간격 `0.18`, `t0=0.10`, `t1=0.0`, `alpha=0.62`, `add=True`, `back=False`, `phase='open'`, `loop=True`.
- 네 `room_shop_lantern`: 좌표 `[(-91,-49),(91,-49),(-91,23),(91,23)]`, 크기 `34 x 34`, 프레임 간격 `0.18/0.20/0.22/0.24`, `t0=0.00/0.18/0.36/0.54`, `t1=0.0`, `alpha=0.58`, `add=True`, `back=False`, `phase='open'`, `loop=True`.

## 2컷 — 다가감(1.6~2.8초)

### 시안과 다른 점

- 접근 시 눈 점등이 얼굴의 눈 위치에서 한 번만 재생된다. 크기와 밝기가 시안 범위이고, 낮아진 혼불 위에서도 접근 반응의 초점이 분명하다.
- 대기 장식이 갑자기 화면 전체를 밝히거나 색을 물들이지 않는다. 별/십자 반짝이도 없다.
- 컷을 막는 잔여 차이 없음.

### `layers_room_shop()`에서 바꿀 값

- **변경 없음.** `room_shop_eye_glow`의 좌표 `(0,-71)`, 크기 `48 x 24`, 프레임 간격 `0.10`, `t0=0.04`, `t1=0.46`, `alpha=0.78`, `add=True`, `back=False`, `loop=False`, `fade=0.05`, `phase='near'`를 유지한다.
- 1컷의 혼불·금화·등불 값도 그대로 유지한다.

## 3컷 — 접촉/작동 및 상점 창(2.8~3.8초)

### 시안과 다른 점

- 필수 수정이었던 금화 고리의 폭과 세기가 반영됐다. 고리가 상점 좌우로 넓게 퍼지고 하체부터 발밑까지 감싸며, 시안처럼 접촉 때 한 번만 읽히는 주효과가 됐다. `alpha=0.58` 가산이지만 시안보다 밝은 과노출은 아니다.
- 사용 직후 상점 오브젝트가 어두워지고, 0.35초 뒤 실제 `ShopPanel`이 앞에 열린다. 이펙트는 창 뒤에 남아 제목·보유 골드·상품명·설명·가격·`나가다` 버튼을 가리지 않는다.
- 승인 시안의 축약 상점 창과 실제 6칸 상점 창의 외형 차이는 `popup_c_layout.py` 및 글자 규칙을 적용한 실제 게임 UI 차이이므로 연출 불일치로 보지 않는다.
- 방 오브젝트 접촉 고리는 방 중앙에서 시작하고, 실제 선택/수락/구매 반응은 팝업 쪽 `atNode='ShopItem{slot}'`의 고른 칸 중심에서 시작하는 구조가 유지된다.
- 컷을 막는 잔여 차이 없음.

### `layers_room_shop()`에서 바꿀 값

- **변경 없음.** `room_shop_coin_ring`의 좌표 `(0,82)`, 크기 `500 x 210`, 프레임 간격 `0.08`, `t0=0.0`, `t1=0.48`, `alpha=0.58`, `add=True`, `back=False`, `loop=False`, `fade=0.06`, `phase='accept'`를 최종값으로 유지한다.
- `layers_room_shop()`에는 `atNode`를 추가하지 않는다. 구매 클릭 효과의 기점은 기존 팝업 연출의 `atNode='ShopItem{slot}'`에서만 유지한다.

## Claude가 바로 적용할 변경 목록

1. **없음. 현재 값으로 확정한다.**
2. `room_shop_soul_flame`의 `alpha=0.30`과 `room_shop_coin_ring`의 `(0,82,500,210)`, `alpha=0.58`, `add=True`를 되돌리지 않는다.
3. `room_shop_coin_float`, 네 `room_shop_lantern`, `room_shop_eye_glow`도 현재 값을 유지한다.
4. 사용 후 오브젝트 암전, 접촉 후 0.35초의 실제 상점 창 표시, 팝업의 앞 합성 순서를 유지한다.
5. 구매 반응은 팝업 쪽 `atNode='ShopItem{slot}'`에서 시작하게 유지한다.
6. **재발주 없음.** 별/십자 반짝이, 화면 전체 틴트, 전면 광막을 추가하지 않는다.
