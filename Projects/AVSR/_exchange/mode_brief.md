# 추가 게임 모드 브레인스토밍 — 상의 요청서

너는 모바일 액션 게임 기획자다. 아래 게임에 **메인 모드와 별개로 추가할 게임 모드**를 함께 구상해 달라.
코드나 파일을 고치지 말고, 생각만 해서 답해라. 답은 **한국어**로.

## 게임 — AVENGING SPIRIT: RE:BORN (일본 납품, 1991 Jaleco 아케이드 원작 리메이크)

- 세로 화면 탑다운 방 단위 로그라이크 액션 (궁수의 전설 계열). 조이스틱 이동, 멈추면 자동 공격.
- **핵심 = 빙의.** 플레이어는 약한 유령. 적에게 다가가 빙의 버튼으로 그 몸을 빼앗아 싸운다.
  몸(호스트)이 죽으면 유령으로 돌아오고, 다른 적에게 다시 빙의한다. 유령 에너지가 0이 되면 진짜 끝.
  - 스스로 몸에서 나올 수도 있다(유령 에너지 8% 비용). 몸을 입은 채 다른 몸으로 바로 옮길 수는 없다 — 반드시 유령을 거친다.
  - 버린 몸은 그 자리에서 쓰러져 사라진다.
- 호스트 23명(아마존 전사, 코만도 4종, 닌자, 드래곤 2종, 설녀, 흡혈귀, 야구선수, 폭력배, 구루, 사신 등). 각자 공격 방식·사거리·액티브 스킬·패시브가 다르다.
  직업은 근거리 6 / 중거리(기관총) 3 / 원거리 14.
- **상성(가위바위보)**: 파워 → 무기 → 마법 → 파워. 모든 몸과 적이 셋 중 하나. 유리 130% / 불리 70%. 적 머리 위에 표시.
- 진행: 챕터 6개 × 15방 (전투 11 · 천사 카드 방 1 · 중간보스 1 · 상점 1 · 보스 1). 목표는 라이브 서비스, 챕터 100개 이상.
- 방에 들어서면 적이 **한꺼번에 다 서 있다.** 증원(웨이브)은 두 번 만들었다가 지웠다 —
  방을 비운 순간 새 적이 나오면 빙의할 몸이 다 죽은 뒤라 유령 상태로 새 무리를 맞게 되어 대응할 길이 없었기 때문이다.
- 이미 있는 시스템: 판 안 레벨업 카드(3택1) · 천사/악마 카드 · 상점(동료 호스트 구매) · 회복 제단 · 소환물(해골·골렘·분신, 적의 표적을 바꾸는 도발 포함) · 로봇 포탑 · 보스 6종(패턴 24) · 중간보스 · 방 기믹(폭발통·포탑·가시·화염·지뢰·레이저) · 상자.
- 아웃게임: 골드 능력치 강화, 숙련도, 유령 레벨, **조각 모아 호스트 해금**. 숨긴 캐릭터 「사신」은 얻는 길이 아직 없다.
- 돈: 재화·조각 판매 + 배틀패스. 서버는 나중(지금은 로컬 저장, 실시간 대전 불가).
- 원작 감성(1991 아케이드)이 아트·연출의 제1원칙.

## 사용자 요청

「디펜스나 서바이벌 같은 추가 모드 두 가지」라고 말했지만, 그건 **이해를 돕기 위한 예시**일 뿐이다.
그 틀에 갇히지 말고, **이 게임만의 요소(빙의 · 유령 · 상성 · 원작)** 에서 출발한 모드를 폭넓게 제안하라.
디펜스·서바이벌도 후보로 넣어도 되지만 다른 것과 같은 기준으로 견줘라.

## 답 형식

1. 모드 후보 **8~10개**. 각각:
   - 이름(짧게) / 한 줄 설명
   - 핵심 규칙 2~3줄
   - 왜 이 게임이어야만 재미있는가 (빙의·상성과 어떻게 엮이나)
   - 다시 쓰는 기존 시스템 / 새로 만들어야 할 것
   - 반복 플레이 이유(보상·기록·매일)
   - 위험 · 약점
   - 개발 무게 (소 / 중 / 대)
2. 그중 **추천 2개**와 이유. 서로 성격이 겹치지 않게(예: 하나는 짧고 매일, 하나는 깊고 도전).
3. 사용자가 결정해야 할 질문 3~5개.
