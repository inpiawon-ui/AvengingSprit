# 로비 마지막 3장 — 모드 화살표 2장 · 상자 남은시간 판 1장

## 1·2. 게임 모드 좌우 화살표

지금은 글꼴 글자(`◀` `▶`)로 찍고 있어 **속이 꽉 찬 삼각형**인데, 목업은 **두꺼운
꺾쇠**다 — 흰 몸통에 검은 윤곽, 바깥으로 따뜻한 빛이 번진다.

```
기준: Projects/AVSR/_exchange/ref/arrow_ref.png   52 × 96 (오른쪽 꺾쇠, 1:1 크기)
```

| 파일 | 크기 | 방향 |
|---|---|---|
| `modearrow_right.png` | 52 × 96 | 기준 그림 그대로 |
| `modearrow_left.png` | 52 × 96 | 좌우로 뒤집은 것 (정확히 대칭) |

- 꺾쇠 몸통은 캔버스 가운데에 **가로 30 · 세로 66** 안팎
- 남는 여백은 빛무리. 가장자리로 갈수록 서서히 투명해진다

## 3. 상자 칸 「남은 시간」 판

목업은 시계·남은 시간 줄 뒤에 **어두운 판**이 깔려 있는데 지금은 없어서 글자가
배경 위에 그냥 떠 있다.

```
기준: Projects/AVSR/_exchange/ref/chesttimeplate_ref.png   246 × 48 (1:1 크기)
```

| 파일 | 크기 |
|---|---|
| `chesttimeplate.png` | 246 × 48 |

- 기준 그림의 **판만** 그린다 — 시계 아이콘과 글자는 빼라(게임이 얹는다)
- 반투명한 짙은 남색 속, 가는 하늘색 테, 좌우 모서리는 깎여 있다
- 9-slice 로 가로만 늘려 쓴다: 좌우 끝 40 px 이 장식, 가운데는 평평하게

## 지켜야 할 것

1. **배경은 완전 투명(알파 0).** 마젠타를 쓰지 마라
2. 빛무리·판 속은 **반투명으로 둔다.** 알파를 0 아니면 255 로 정리하지 마라
3. **글자를 그리지 마라**
