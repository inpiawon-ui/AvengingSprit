# 23차 워크오더 — 잡몹 2종 (`skeleton` · `bat`)

**총 80장.** 규격·시점·원칙은 [`WORKORDER.md`](WORKORDER.md) **15차**를 그대로 따른다.
납품은 `_exchange/in/` 에 평평하게(하위 폴더 없음).
**순서대로 가져간다. 한 종을 다 넣었으면 내 확인을 기다리지 말고 바로 다음으로 넘어간다.**

| 순서 | 슬러그 | 앵커 | 장수 |
|---|---|---|--:|
| 1 | `skeleton` | `Miscellaneous - Death__sheet.png` (머리) | 40 |

---

## 이 둘은 왜 새로 필요한가 — 반드시 읽을 것

지금 게임에 나오는 적 23종은 **전부 빙의할 수 있는 몸**이다.
몸이 널려 있으니 플레이어가 죽지 않고, 죽지 않으니 빙의가 판단이 아니라 습관이 됐다.

그래서 **빙의할 수 없는 잡몹**을 새로 넣는다.

```
숙주(기존 23종)   방에 1~2기.  빼앗아 무기로 쓴다.       머리 위 표식 ○
잡몹(이 2종)      방에 7~9기.  빼앗을 수 없다. 죽이거나 피한다.  표식 ✕
```

**가장 중요한 요구:** 플레이어가 **0.2초 안에** "저건 뺏을 수 있는 놈 / 저건 아닌 놈"을
구별해야 한다. 그래서 잡몹은 기존 23종과 **실루엣부터 달라야** 한다.

기존 23종은 전부 **사람 체형**(머리·몸통·팔다리, 옷을 입었고, 무기를 들었다).
잡몹 2종은 **사람이 아니다** — 뼈와 짐승이다. 이 대비가 이 게임의 읽힘 전부다.

## 공통 규격 (15차와 동일 · 다시 적지 않는다)

```
캔버스   96×96 · 투명 · 이진 알파(반투명 0) · 안티앨리어싱 없음
정렬     발밑 y=87 · 발 중심 x=48(바닥 6줄) · 머리끝 y=12
방향     s · se · e · ne · n   (왼쪽 3방향은 코드가 반전으로 만든다)
프레임   idle / walk1 / walk2 / atk1 / atk2 / hit / die1 / die2
장수     한 종 40장 (idle 5 + 동작 35)
파일명   unit_{슬러그}_{방향}.png · unit_{슬러그}_{방향}_{프레임}.png
         ※ 방향 없는 unit_{슬러그}.png 는 필요 없다

몸 안 구멍 3% 초과 = 반려 · 팔레트 밖 색 = 반려
공격은 발을 붙인 채 · 걷기는 발이 움직이고 몸통은 제자리(머리 중심 ±2px)
```

**빙의 자세(`possess1`/`possess2`)는 만들지 마라.** 이 둘은 빼앗을 수 없다.

## 1. `skeleton` — 해골 · 40장

### 게임에서 하는 일

방에 4~6기가 깔린다. **느리고 약하다. 대신 길을 막는다.**
플레이어가 몸을 잃고 유령이 되면, 이 벽을 뚫고 다음 숙주까지 가야 한다.
그래서 **덩치와 실루엣이 커야** 한다 — 작으면 벽으로 안 읽힌다.

```
HP 28 · 근접 · 느림(이동지수 74) · 공격간격 1.4초
```

### 앵커

```
15_original/Miscellaneous - Death__sheet.png      ← 머리(해골)
15_original/Miscellaneous - Death__palette.png    ← 쓸 수 있는 색
```

원작 사신의 **머리가 해골**이다. 1행 4칸에 정면·측면이 다 있다.
**그 두개골을 그대로 쓴다.** 눈구멍·코·턱선의 픽셀 배치를 바꾸지 마라.

사신의 **몸(분홍 로브·낫)은 쓰지 않는다.** 그건 이미 `death` 숙주가 쓰고 있어서
겹치면 "저건 뺏을 수 있나?" 하는 혼동이 생긴다.

### 몸

원작 두개골 + **로브 없는 맨 갈비뼈 골격**. 옷을 입히지 마라 — 옷을 입으면 사람이 되고,
사람이 되면 숙주로 오인된다.

```
비율     머리가 크다. 두개골이 전체 높이의 약 1/4
         (기존 23종은 약 1/6 — 이 차이가 실루엣 구별의 핵심이다)
몸통     갈비뼈가 보인다. 배 안쪽은 비우지 말고 어두운 색으로 채운다
         (뚫린 구멍 3% 규정에 걸린다)
팔다리   가늘다. 관절이 끊겨 보이게 그리되 픽셀은 붙여 둔다
무기     없다. 맨손으로 후려친다
```

### 프레임

```
idle     양팔을 늘어뜨리고 살짝 앞으로 기운 자세. 턱이 벌어져 있다
walk1/2  발을 끄는 걸음. 뼈라서 무릎이 안 굽는다 —
         다리를 통째로 앞뒤로 옮기고 몸통은 제자리(머리 중심 ±2px)
atk1     팔을 뒤로 크게 젖힌다 (선딜 — 이게 안 보이면 못 피한다)
atk2     팔을 앞으로 후려친다. 발은 붙인 채
hit      상체가 뒤로 꺾이고 두개골이 3~4px 뒤로 밀린다
die1     골격이 무너지기 시작. 무릎이 꺾이고 팔이 흩어진다
die2     **뼈 무더기.** 서 있는 형태가 남으면 안 된다 —
         바닥에 납작하게 깔린 두개골 + 뼛조각 몇 개
```

## 2. `bat` — 박쥐 · 40장

### 게임에서 하는 일

방에 3~4기. **빠르고 불규칙하게 날아서 끝까지 쫓아온다.**
몸이 있을 때는 성가신 정도지만, **유령이 됐을 때 이 게임의 진짜 위협**이다.
유령은 공격을 못 하고 도망만 칠 수 있는데, 박쥐는 그 도주선을 계속 따라붙는다.

```
HP 18 · 근접(들이받기) · 매우 빠름(이동지수 138) · 공격간격 0.9초 · 부양
```

### 앵커 — 원작에 이미 있다

```
15_original/Enemies - Vampire__sheet.png     ← 3행 4~5칸에 박쥐 2장
15_original/Enemies - Vampire__palette.png   ← 쓸 수 있는 색
```

뱀파이어가 박쥐로 변하는 연출용 스프라이트다. **어두운 청회색 몸에 펼친 날개.**
그 2장이 곧 날갯짓 1·2다. 색과 형태를 그대로 가져와 5방향으로 늘린다.

원작 박쥐는 아주 작다(약 16px). **96×96 캔버스 안에서 작게 유지한다** —
크게 부풀리면 해골과 실루엣이 붙어버린다.

```
몸통     캔버스 세로의 약 1/4 (24px 안팎)
날개폭   펼쳤을 때 가로 44~52px. 이 폭이 박쥐의 정체다
```

### 부양 — `guru` 규칙을 그대로 따른다

발을 딛지 않는다.

```
몸      **바닥선(y=87)에서 30~38px 위**에 뜬다 (guru 의 12~16px 보다 훨씬 높다)
그림자  바닥선(y=87)에 가로:세로 10:3 으로 눌린 타원 · 어두운 남색 단색 · 중심 x=48
        ← 해골보다 작게 (가로 20px 안팎)
걷기    발을 내딛지 않는다. 몸이 위아래로 3~4px 출렁이고
        **그림자는 바닥에 붙은 채 크기·진하기만** 변한다
        ← 그림자가 몸을 따라 오르내리면 떠 있는 것으로 안 읽힌다
사망    부양이 풀린다. 높이가 내려오며 그림자가 커지고 마지막엔 몸에 붙는다
```

### 프레임

```
idle     날개를 반쯤 접은 상태로 제자리 정지 비행
walk1    날개를 위로 완전히 펼침 (몸은 3~4px 위)
walk2    날개를 아래로 접음      (몸은 3~4px 아래)
         ← 이 두 장이 원작 3행 4·5칸 그대로다
atk1     날개를 크게 뒤로 젖히고 몸을 뒤로 뺀다 (선딜)
atk2     몸을 앞으로 내밀며 들이받는다. 날개는 뒤로 눕는다
hit      날개가 접히고 몸이 5~6px 뒤로 튕긴다
die1     한쪽 날개가 꺾이고 몸이 기운다. 높이가 절반으로
die2     바닥에 떨어져 날개를 편 채 뒤집힌다. 그림자가 몸에 붙는다
```

## 색 — 두 종을 서로도 구별해야 한다

```
skeleton   Death 팔레트의 뼈 색(밝은 회백)  — 화면에서 밝게 뜬다
bat        Vampire 팔레트의 박쥐 색(어두운 청회) — 화면에서 어둡게 가라앉는다
```

**밝은 뼈 / 어두운 박쥐.** 이 명암 대비가 겹쳐 있을 때 서로를 갈라 준다.
둘 다 각자의 원작 팔레트 안에서만 쓴다. 밖으로 나가면 반려.

## 3순위 — 아직 발주하지 않는다

원거리 잡몹(망령) 1종을 더 넣을 생각인데,
**원작 시트 전체에 앵커가 없다.** 원작 1991년판은 잡몹 자체가 없고
적 23종이 전부 빙의 가능한 몸이다.

앵커 없이 새로 그려야 하는 유일한 항목이라 **이번 차수에서는 뺀다.**
위 2종이 들어간 뒤 화면에서 보고 판단한다.
