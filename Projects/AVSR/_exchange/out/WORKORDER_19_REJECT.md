# 작업 지시 — 19차 · 18차 반려분 20장

18차 납품 84장 중 **64장 통과, 20장 반려**했다.
통과분은 이미 게임에 들어갔다 — `thug` 걷기 10장과 투사체 8종, `hopper` 아이콘 포함.

반려는 전부 **수치 검사에서 걸린 것**이다. 눈으로 보기 전에 걸렸다.

---

## 1. `amazon_elite` atk1 — 캔버스가 틀렸다 (5장)

```
unit_amazon_elite_{s,se,e,ne,n}_atk1.png
```

**96×96 로 왔다. 이 캐릭터는 엘리트라 128×128 이다.**

```
캔버스   128×128
발밑     y=118
발 중심  x=64
```

다른 프레임(idle·walk·atk2·hit·die)은 전부 128 로 맞게 와 있다.
atk1 만 일반 규격으로 그렸다. 그대로 넣으면 **공격하는 순간 몸이 한 등급 작아진다.**

---

## 2. `commando_mg` atk1·atk2 — 몸 안에 구멍 (10장)

```
unit_commando_mg_{s,se,e,ne,n}_atk1.png   구멍 5.9 ~ 7.2%
unit_commando_mg_{s,se,e,ne,n}_atk2.png   구멍 6.6 ~ 8.7%
```

한도는 **3%** 다. 두 배를 넘었다.

구멍이란 **몸 테두리 안쪽인데 알파가 0인 화소**다. 배경이 그대로 비쳐서
그림이 삭은 것처럼 보인다. 이 캐릭터는 기관총과 팔 사이, 탄띠 틈에서 많이 났다.

```
몸·장비 안쪽은 빈틈 없이 채운다. 총과 팔이 겹치는 부분도 마찬가지다.
"안 보이니까 비워도 된다" 가 아니다 — 그 뒤로 바닥이 비친다.
```

---

## 3. `salamander` atk2·hit — 몸 안에 구멍 (5장)

```
unit_salamander_{s,se,e}_atk2.png    구멍 3.2 ~ 4.0%
unit_salamander_{s,se}_hit.png       구멍 3.7 ~ 4.3%
```

한도 3% 를 조금씩 넘었다. 불을 뿜는 프레임이라 입·화염 경계에서 났다.
화염과 몸이 만나는 자리를 붙여서 채운다.

---

## 확인 방법

납품 전에 스스로 돌릴 수 있다.

```
몸 안 구멍  = 테두리에서 이어지지 않는 투명 화소의 비율. 3% 초과면 반려
캔버스      = amazon_elite 만 128×128, 나머지는 96×96
```

두 가지 다 그림을 열지 않고도 확인되는 값이다. **이번 20장은 눈으로 보기 전에
숫자에서 걸렸다** — 보내기 전에 한 번 재면 왕복이 줄어든다.

---
