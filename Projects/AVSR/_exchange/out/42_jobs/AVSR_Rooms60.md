## 2. 호스트가 언제 처음 나오나

> 005 에서 만나지만 못 뺏는다. 006 에서 일반 개체로 다시 나온다. **그때 뺏는다.**

| 4 옥상 | 집행자 · 순찰기 · 박쥐 · 코일 보행기 |
| 5 연구소 | 집행자 · 십자 포탑 · 해골 · 코일 보행기 |
| 6 정유소 | 집행자 · 코일 보행기 · 해골 · 십자 포탑 · 순찰기 |

CH1~3 은 기존 배정 그대로다. **CH4~6 은 같은 7종을 다시 섞는다.**
어려운 것(집행자 HOP · 코일 보행기 VAULT · 십자 포탑 CROSS)이 뒤로 갈수록 많아진다.

> ⚠️ **근접 잡몹이 셋뿐이다** (해골 · 박쥐 · 집행자). CH5~6 에서 해골이 다시 나오는 것은
> 연구소·정유소에 어울리지 않는다. **근접 잡몹 1종을 새로 그리면 뒤 세 챕터가 훨씬 나아진다** —
> 지금 발주 안 해도 굴러가지만, 여유가 생기면 여기가 가장 값싸게 좋아지는 자리다.

## 4. 방을 어떻게 채웠나

### 조합 — 앞세우는 태그 둘을 **번갈아** 뽑는다

| 조합 | 앞세우는 자리 |
|---|---|
| `FRONTLINE_PLUS_RANGED` 앞줄 + 원거리 | FRONT ↔ RANGED |
| `FLANK_REINFORCEMENT_PLUS_ZONER` 측면 + 지역제압 | FLANK ↔ RANGED |
| `BACKLINE_PRESSURE_PLUS_HUNTER` 후방 압박 + 추격 | BACK ↔ FLANK |

한쪽을 다 쓰고 넘어가면 **원거리가 통째로 빠진 방**이 나온다. 번갈아 뽑아야 그게 안 생긴다.
챕터마다 셋이 두 번씩 돌고, 이웃한 방은 서로 다른 조합이다.

### 빼앗을 몸의 자리

**BACK 은 후방이므로 원거리 자리다.** (정본 자리표도 BACK 을 코만도로 채웠다)
빼앗을 몸이 둘인 방은 **원거리 몸 하나 + 격투 몸 하나**를 세운다 — 방마다 선택지를 둘로 준다.

### 코드로 검증한 규칙 넷

| | |
|---|---|
| 1 | 모든 전투방에 빼앗을 몸이 최소 하나 |
| 2 | 모든 전투방에 원거리와 근접이 둘 다 |
| 3 | 같은 방에 같은 몸이 둘 있지 않다 |
| 4 | 데뷔 챕터보다 먼저 나오는 몸이 없다 |

> 2번은 실제로 걸렸다 — CH1 008(D 십자 분단)이 「후방 압박 + 추격」과 만나 **원거리가 0**이 됐다.
> 그래서 「하나도 없으면 마지막 자리를 원거리로 바꾼다」를 규칙으로 넣었다.

## 5. 엘리트 (009)

| | |
|---|---|
| 크기 | ×1.3 |
| HP | ×2 |
| 공격력 | ×1.2 |
| 빙의 | **가능** |

> 중간 보스(1.8배·빙의 불가)와 다르다. **엘리트는 빼앗을 수 있다** — 크고 아픈 몸이 곧 보상이다. 009 는 보스 직전이라 여기서 얻은 몸으로 010 에 들어간다

엘리트는 **그 챕터에 처음 나온 몸 중 대장이 아닌 하나**다. 대장과 겹치면 같은 얼굴을 두 번 본다.
