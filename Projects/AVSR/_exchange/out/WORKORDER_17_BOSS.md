# 작업 지시 — 17차 · 보스 3체

큐 23~28번을 "먼저 손대지 마라" 로 막아 둔 이유가 이것이다.
**보스는 캐릭터와 규격이 다르다.** 96×96 유닛 규격을 여기에 적용하지 마라.

---

## 먼저 알아야 할 것 — 보스는 한 장짜리 그림이 아니다

원작 보스 시트를 열어 보면 캐릭터 시트와 생김새가 아예 다르다.
사람 하나가 여러 자세로 있는 게 아니라 **아레나 한 벌**이 들어 있다.

```
Robot Snakes   아레나 배경 · 바닥(구멍 뚫린) · 덮인 구멍 타일 7 · 뱀 3프레임 · 레이저
Crusher        공장 배경 · 크레인(트롤리·사슬·집게 여러 상태) · 실드 · 컨베이어
               · 본체 캐빈 · 피격 섬광 · 경고등 7프레임
Python         하수도 전경(부서진 벽) · 배경 · 몸통 반복 띠 · 머리 3프레임 · 독구름 4프레임
```

그래서 이번 지시는 **2단계로 나눈다.**

| 단계 | 무엇 | 지금 상태 |
|---|---|---|
| **1단계** | 보스 본체 · 피격 · 예고 | **지금 그린다.** 게임이 바로 쓴다 |
| 2단계 | 아레나 장치(구멍·크레인·컨베이어·독구름) | **아직 그리지 마라.** 코드가 없다 |

2단계를 막는 이유는 분명하다. 지금 보스는 부채꼴·돌진·링 같은 원시 동작으로만 싸운다.
정본이 못박은 이름 붙은 패턴(팝업 레이저 · 실드 사이클 · 독구름)은 코드가 아직 없어서,
지금 장치를 그려 봐야 화면에 나올 곳이 없다. 코드가 붙는 대로 따로 지시한다.

## 규격

캐릭터와 **캔버스·정렬만** 다르다. 색·알파·안티앨리어싱 원칙은 15차 그대로다.

```
캔버스   256×256 · 투명 · 이진 알파(반투명 0) · 안티앨리어싱 없음
정렬     닿는 선 y=232 · 중심 x=128 · 위쪽 여백 y=32 이상
방향     s · se · e   (sw·w 는 코드가 반전으로 만든다)
프레임   idle / atk1 / atk2 / hit / move1 / move2  (방향마다 6장)
추가     die1 · die2 · tell  (정면 s 만)
장수     보스 1체당 3방향 × 6 + 3 = **21장**
파일명   unit_{보스키}_{방향}.png            ← idle
         unit_{보스키}_{방향}_{프레임}.png
경로     _exchange/in/ 에 평평하게
```

### 왜 256인가

일반 적 96 · 엘리트 128 다음 자리다. 화면에서 보스는 일반 적의 약 1.9배로 뜨는데
(적 84px · 보스 160px), 크레인 팔이나 뱀의 목처럼 **몸 밖으로 뻗는 부분**이 있어
몸통에 딱 맞춘 캔버스로는 잘린다. 여유를 준 값이다.

### `닿는 선 y=232` 가 보스마다 뜻하는 것

보스는 셋 다 "발로 서 있는" 것이 아니라서 발밑 대신 **닿는 선**으로 잡는다.
세 보스가 같은 숫자를 쓰되 무엇이 닿는지가 다르다.

```
demolisher     레일·바닥에 닿는 캐빈 아랫면
robot_snakes   뱀이 솟아 나오는 구멍의 바닥선  ← 솟은 높이는 프레임마다 달라도 이 선은 고정
python         머리가 빠져나오는 벽 구멍의 아랫선
```

이 선이 흔들리면 보스가 바닥에서 떠 보이거나 파묻힌다.

### 뒤통수는 그리지 않는다

보스는 방 위쪽에 자리 잡고 아래(플레이어)를 향한다. `n`·`ne` 는 화면에 나올 일이 없다.
그려 오면 쓰지 않는다.

## 3체

### `robot_snakes` — 로봇 스네이크 (챕터 1)

> `part_09~11`. 마디로 이어진 금속 뱀. 회색 몸통에 연두 마디 이음매,
> 머리에 붉은 눈과 턱. 구멍에서 **솟아 나온다.**

```
idle    구멍 위로 절반쯤 솟아 좌우로 느리게 흔들린다
atk1    몸을 뒤로 젖혀 머리를 든다 (레이저 예비 동작)
atk2    머리를 앞으로 뻗어 발사 — 목이 최대로 늘어난다
move1/2 솟은 높이가 달라진다. 낮게 ↔ 높게
hit     몸 마디가 흰빛으로 튄다. 자세는 idle 과 같게
die1/2  마디가 끊어져 흩어지고 구멍 안으로 무너져 내린다
tell    구멍 앞 바닥에 붉은 균열선 — 정본 예고 0.85초짜리다
```

⚠ **전신을 그리지 마라.** 이 보스는 원작에서도 하반신이 구멍 안에 있다.
캔버스 아래쪽 `y=232` 아래는 비워 둔다.

### `demolisher` — 데몰리셔 (챕터 2)

> `part_11`. 회색·주황 산업 기계. 파란 유리창, 주황 줄무늬 경고 도색,
> 앞쪽에 격자 그릴. 크레인 캐빈이 본체다. 원작 시트 이름은 Crusher 지만
> 정본 이름은 **Demolisher** 다.

```
idle    캐빈이 가볍게 상하로 떨린다. 유리창 안 불빛이 켜짐
atk1    앞 그릴이 열리며 안쪽이 붉게 달아오른다
atk2    열린 그릴에서 발사 — 반동으로 캐빈이 뒤로 밀린다
move1/2 레일 위를 미끄러진다. 아래쪽에 짧은 궤도 그림자
hit     `part_12` 가 원작의 피격 섬광이다. 실루엣을 흰색으로 채운 그림
die1/2  경고등이 터지고 캐빈이 기울어 주저앉는다. 연기는 넣지 마라(코드가 따로 낸다)
tell    캐빈 아래 바닥에 **검은 사각 그림자** — 정본 예고 1.0초짜리다
```

⚠ 크레인 팔·사슬·컨베이어는 **2단계**다. 지금은 캐빈만 그린다.
단, 캐빈이 매달린 짧은 기둥 밑동 정도는 캔버스 위쪽에 걸쳐도 된다.

### `python` — 파이썬 (챕터 3)

> `part_04` `part_06`. 초록 뱀 머리에 주황 턱·목주름. 흰 눈. 하수도의 거대 뱀.

```
idle    벽 구멍에서 머리만 내밀고 좌우로 흔든다
atk1    입을 벌리며 목을 뒤로 당긴다
atk2    머리를 앞으로 내지른다 — 입 안쪽 색이 밝아진다(정본 예고가 입 색이다)
move1/2 구멍에서 나온 길이가 달라진다. 짧게 ↔ 길게
hit     초록 몸이 흰빛으로 튄다
die1/2  힘이 빠져 머리가 아래로 늘어지고 구멍 안으로 끌려 들어간다
tell    바닥에 원형 착탄 표시 — 정본 예고 0.9초짜리다
```

⚠ 몸통 전체(반복 띠)는 **2단계**다. 지금은 **머리 + 목 두세 마디**까지만.

```
캔버스가 256×256 이 아니다
반투명 픽셀이 있다
00_palette.png 밖의 색을 썼다

전신을 그렸다(robot_snakes·python 은 아랫부분이 구멍 안이다)
2단계 장치를 그려 왔다
```
