# [AVSR] 55차 발주 — 무대별 지형지물 14장 (배치 3-B)

## 무엇이 왜 필요한가

방 48개를 손으로 짠 레이아웃 12종으로 채웠다. 레이아웃은 **발자국**만 정하고 그림은 무대가 고른다 — `PILLAR` 는 연구소에서 부서진 석조 기둥이고 옥상에서는 안테나여야 한다.

그런데 **무대별 그림이 14장 비어 있다.** 지금은 코드가 다른 무대 것을 빌려 쓴다(`EnvSprite` 의 폴백). 빈 상자는 안 뜨지만 **색이 그 방과 안 맞는다** — 밤거리에 수용실 덩어리가, 옥상에 수용실 기둥이 선다.

> 발주서에는 7장이라 적었는데 실측하니 **14장**이다. 세어 보지 않고 적은 값이었다.

## 공통 규격

| 항목 | 값 |
|---|---|
| 알파 | **0 또는 255 만.** 반투명 픽셀 0개 (기존 프롭 전부 그렇다) |
| 배경 | 완전 투명 |
| 색 수 | 제한 없음 (기존 프롭 4,500~21,000색) |
| 접지선 | 캔버스 **맨 아래**. 아래 발자국 높이만큼이 바닥에 닿는 면 |

캔버스 = 발자국 + 위로 솟는 높이. 아래쪽 발자국 부분이 바닥에 닿고, 나머지가 위로 솟는다.

```
PILLAR      72 ×  72 발자국 + 94 솟음 =  72 × 166
CRATE      144 ×  72 발자국 + 60 솟음 = 144 × 132
LOW_COVER  216 ×  72 발자국 + 30 솟음 = 216 × 102
BARRICADE  216 ×  72 발자국 + 30 솟음 = 216 × 102
BULK       144 × 144 발자국 + 94 솟음 = 144 × 238
BLADE      144 × 144 발자국 +  0 솟음 = 144 × 144  (바닥을 스치듯 돈다)
```

## 무대별로 무엇을 그리나

**발자국은 그대로, 물건만 그 무대 것으로 바꾼다.** 크기·실루엣 비율은 다른 무대의 같은 발자국과 같아야 한다.

### `obj_refinery_crate_1` — 정유소 상자 (8방)
기름통·드럼통 다발. 녹슨 철에 모래빛 얼룩. 정유소는 갈색 계열이라 다른 무대의 회청색 상자가 유난히 튄다.

### `obj_rooftop_pillar` — 옥상 기둥 (7방)
석조 기둥이 아니라 **안테나·환기구 굴뚝**. 옥상에는 돌기둥이 있을 자리가 없다. 세로로 길고 위가 가늘어져야 한다.

### `obj_street_bulk` — 밤거리 덩어리 (5방)
길가의 큰 물건 — 전기함·자판기·컨테이너. 청회색에 네온 반사 한 점. 사람 키를 넘는 부피여야 하고, 뒤가 비치면 안 된다.

### `obj_*_barricade` (4장) — 방호벽·난간
연구소·정유소에서는 철망 달린 파이프 난간이다. 무대마다:
- **쓰레기장** 찌그러진 철판을 세워 묶은 것
- **미사일기지** 콘크리트 방호벽 (군용, 각지게)
- **밤거리** 공사장 바리케이드 (반사 띠)
- **옥상** 낮은 난간·안전 펜스

### `obj_*_low_cover` (4장) — 낮게 깔린 엄폐물
연구소에서는 누운 파이프 다발이다. 무대마다:
- **쓰레기장** 쌓인 폐자재 더미
- **미사일기지** 탄약 상자 줄
- **밤거리** 화단 턱·연석
- **옥상** 낮은 설비 배관

`BARRICADE` 와 `LOW_COVER` 는 발자국이 같다(3×1). **실루엣으로 갈려야** 한다 — 난간은 위가 뚫려 보이고, 낮은 엄폐물은 꽉 찬 덩어리다.

### `obj_*_blade_1` (3장) — 도는 톱니
축을 중심으로 반경 2.2 m 를 돈다. **캔버스 한가운데가 축**이다.
- **밤거리** 공사장 원형 톱날
- **옥상** 환풍기 날개
- **정유소** 녹슨 밸브 휠

> 무대판은 **1장만** 만든다. 도는 나머지 3장은 기본 톱니를 그대로 쓴다.

## 확인 기준

1. 위 표의 캔버스 크기와 정확히 일치
2. 알파가 0 과 255 뿐 (반투명 픽셀 0개)
3. 접지면이 캔버스 맨 아래에 닿아 있다
4. 같은 무대의 기존 프롭과 나란히 놓았을 때 한 세트로 보인다
5. 다른 무대의 **같은 발자국** 프롭과 나란히 놓았을 때 크기·비율이 같다
6. `BARRICADE` 와 `LOW_COVER` 가 실루엣으로 구별된다
