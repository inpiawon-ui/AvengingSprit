## 왜 필요한가

**미사일 코만도(`commando_missile`)가 지금 딱총을 쏜다.**

캐릭터→탄 그림 대응표에 이 배우만 빠져 있어서, 기본 탄 한 장(`shot_1`)으로
떨어지고 있었다. 표는 방금 고쳤고 이제 `shot_missile_*` 을 찾는다 —
그림이 오면 바로 붙는다.

이 배우는 정본에서 **유일한 유도탄**이다(`PrimaryTrait: HOMING`, 유도 세기 0.25).
화면에서 천천히 휘어 들어오는 것이 이 몸의 정체인데, 지금은 점이 날아간다.

```
사거리 8.5 m (23종 중 최장)   탄속 4.69 m/s (가장 느림)   공격간격 1.82초 (가장 느림)
```

**느리고 크게 보여야 하는 탄이다.** 느린 만큼 눈에 오래 남으므로 대충 그리면 티가 난다.

## 앵커 — 원작에 전부 있다

```
15_original/Enemies - Commando (Missiles Pack)__sheet.png     ← 3행 오른쪽
15_original/Enemies - Commando (Missiles Pack)__palette.png   ← 쓸 수 있는 색
```

3행 오른쪽 덩어리에 **미사일이 방향별로 여러 장** 있고(빨간 탄두 + 회색 몸통),
그 오른쪽에 **회색 연기 3장**, 그 아랫줄에 **주황 불꽃 + 회색 연기 폭발 장면**이 있다.

### 방향은 그리지 마라 — 한 방향이면 된다

우리 탄은 **코드가 진행 방향으로 회전시킨다**(`Projectile` 이 `Atan2` 로 각도를 준다).
원작처럼 방향별로 그리면 회전이 겹쳐서 엉뚱한 데를 본다.

```
전부 **오른쪽(+X)** 을 향하게 그린다. 탄두가 오른쪽 끝, 꼬리불이 왼쪽 끝
```

## 1. `shot_missile_1~4` — 날아가는 미사일

기존 탄 규격을 그대로 따른다. `shot_grenade_1~4` 와 같은 캔버스를 쓴다.

```
캔버스   기존 shot_*.png 와 동일 (shot_grenade_1.png 을 열어 그 크기에 맞춘다)
방향     오른쪽(+X) 고정. 탄두가 오른쪽
투명     이진 알파 · 안티앨리어싱 없음
팔레트   Commando (Missiles Pack) 팔레트 안에서만
```

**4장은 회전이 아니라 꼬리불의 맥박이다.** 미사일 몸통은 **네 장 모두 같은 자리에
같은 모양**으로 있어야 한다 — 몸통이 흔들리면 날아가는 게 아니라 떠는 것으로 보인다.

```
1   꼬리불이 가장 짧다 (몸통 길이의 약 1/4)
2   꼬리불이 길어진다 (약 1/2)
3   꼬리불이 가장 길다 (약 3/4) · 끝이 갈라진다
4   꼬리불이 다시 줄고, 떨어져 나온 불똥 한두 점이 뒤에 남는다
```

1→2→3→4→1 로 계속 돈다. **4에서 1로 넘어갈 때 튀지 않아야** 한다.

몸통은 원작 3행의 미사일을 그대로 쓴다 — **빨간 탄두 · 회색 몸통 · 작은 날개.**

## 2. `impact_missile_1~3` — 터짐

원작 3행 아랫줄의 **주황 불꽃 + 회색 연기**가 그대로 정답이다.

```
캔버스   기존 impact_*.png 와 동일 (impact_grenade_1.png 크기에 맞춘다)
```

```
1   주황 불꽃이 가운데에서 터진다. 가장 밝고 작다
2   불꽃이 퍼지며 회색 연기가 섞인다. 가장 크다
3   불꽃이 사그라들고 회색 연기만 흩어진다. 옅다
```

수류탄 폭발(`impact_grenade_1~5`)보다 **한 단계 작게** 그린다 —
미사일은 한 발이고 수류탄은 광역이라, 같은 크기면 둘이 구분되지 않는다.

## 남은 대역품 2건 — 이번엔 발주하지 않는다

지금 탄 그림이 **제 것이 아닌** 배우가 둘 더 있다. 원작에 해당 탄이 없어서
대신 쓰고 있는 것이고, 급하지 않아 이번 차수에서는 뺀다.

```
amazon_elite   소닉웨이브(앞으로 나가는 충격파)인데 → 총알을 쓰고 있다
baseball       던지는 공인데                      → 총알을 쓰고 있다
```

둘 다 원작 시트에 그 탄이 없다. 필요해지면 그때 따로 판단한다.
