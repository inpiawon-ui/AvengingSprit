# 시안 보관 폴더

**사장님이 정한 시안 이미지를 여기에 파일로 둔다.**

대화창에 붙인 이미지는 다음 발주 때 다시 가리킬 수 없다.
그래서 같은 시안을 두고도 워크오더가 엉뚱한 파일을 앵커로 잡는 사고가
2026-08-24 에 네 번 반복됐다 — 석조 블록 3장을 다섯 번 그리게 했다.

## 규칙

```
시안이 정해지면 여기에 파일로 저장한다
워크오더에는 그 파일 경로를 박는다
"비슷한 것"을 대신 가리키지 않는다
```
