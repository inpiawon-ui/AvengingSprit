### ⚠ 4·5번 — 원통이 픽셀 단위로 겹쳐야 한다

「자네의 에너지는 한정돼 있네」를 말할 때 **두 장을 겹쳐 보여 준다.**
가득 찬 관에서 빈 관으로 넘어가는 연출이라, 원통 외곽선이 어긋나면 관이 튄다.

```
cut_start_5 는 cut_start_4 를 복사해서 안쪽 색만 파랑 → 초록으로 바꾼다.
원통 · 배경 · 받침은 한 픽셀도 건드리지 않는다.
```

**빈 관은 하양이 아니라 초록이다** — 원작 Parts 에 파란 관과 초록 관이 나란히 있다.
하양이면 "빈 것"이 아니라 "꺼진 것"으로 읽힌다.

### ⚠ 6~9번 — 투명도 단계가 아니라 애니메이션이다

원작 Parts 의 유령 넷은 **진하기가 같고 자세만 다르다.** 떠 있는 루프다.

```
그림   4프레임 애니메이션 — 같은 크기 · 같은 자리 · 같은 진하기 · 자세만 다름
알파   코드가 깎는다 (에너지 100 / 75 / 50 / 25%)
```

투명도 단계로 그리면 관 안 유령이 **정지 이미지**가 된다.
넷을 애니메이션으로 받으면 **추가 발주 없이 움직임과 4단계를 동시에 얻는다.**

### ⚠ 1·10번 — 박사는 같은 자리, 표정만 다르다

발포 5장에서 확인된 방식 그대로다.

```
cut_start_10 은 cut_start_1 을 복사해서 표정과 손만 고친다.
얼굴 위치 · 콘솔 · 배경은 한 픽셀도 건드리지 않는다.
```

## 통과 기준

1. 15장 전부 **640 × 640 · RGB 불투명 · 37~40색**
2. **디더링 없음** — 얼굴에 얼룩진 밝은 픽셀이 흩어져 있지 않다
3. 살색 하이라이트가 **따뜻하다** (회백색 아님)
4. 남자들이 **갈색 중절모 · 검은 선글라스 · 연보라 트렌치코트**다. 초록 정장이 아니다
5. `cut_prologue_3` 에 주인공과 여자친구의 **뒷모습**이 있다. 낮이다
6. 여자친구가 `1` · `3` · `4` · `cut_start_3` 넷에서 같은 인물로 보인다
7. 주인공이 `1` · `2` · `3` 셋에서 같은 사람으로 보인다
8. **`cut_start_4` 와 `5` 의 원통 외곽선이 0 px 차이** (안쪽 색만 파랑 → 초록)
9. **`cut_start_6~9` 가 같은 크기·자리·진하기**, 자세만 4프레임
10. **`cut_start_1` 과 `10` 의 얼굴 위치·콘솔·배경이 0 px 차이**
11. 액자 · 글자 · 말풍선 · 워터마크 없음
