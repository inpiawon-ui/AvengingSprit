## 틀린 것 — 세로 줄눈(x) 위상 하나뿐

세로 줄눈이 **x ≡ 22 (mod 36)** 에 있다. 즉 94 · 130 · 166 · 202 · … 이다.
있어야 할 자리는 **x ≡ 0 (mod 36)** — 72 · 108 · 144 · 180 · … 이다.

**안쪽 바닥 `(72,144)~(648,864)` 을 가로로 +14 px 밀면 맞는다.**
(왼쪽으로 22 px 밀어도 같다.)

증거: `31_grid/grid_x_offset_evidence.png`
빨강 = 있어야 할 세로 줄눈 · 노랑 = 지금 있는 세로 줄눈 · 초록 = 가로 줄눈(맞음)

계측으로도 확인했다 — 안쪽 바닥을 0~34 px 로 밀어 보며
`x ≡ 0` 자리의 어두움을 점수로 쟀다:

```
 0 px → -0.83     12 px → -0.33     24 px → -1.79
 2 px → -2.86     14 px → +4.29 ★   26 px → -1.80
 4 px → -2.99     16 px → -3.37     28 px → -1.87
 …                18 px → -2.49     30 px → -1.11
10 px → -3.22     22 px → -2.52     32 px → +0.62
```

**14 px 만 유일하게 양수**다. 다른 값은 전부 줄눈이 칸 한가운데를 지난다.

   무늬가 288 px 마다 반복되고 바닥 폭이 576 px(=288×2)이라 이어 붙여도 된다.
