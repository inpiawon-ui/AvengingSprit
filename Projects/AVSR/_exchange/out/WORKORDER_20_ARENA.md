# 작업 지시 — 20차 · 보스 아레나 (17차 2단계)

17차에서 "아직 그리지 마라" 로 막아 둔 2단계다. **코드가 붙어서 이제 풀린다.**

지금 화면에 나가는 것 —
```
장판    흰 원판 하나에 코드가 색만 입힌다. 다섯 효과가 전부 같은 모양이다
보스방  일반 던전 바닥과 똑같다. "여기가 그 방" 이라는 느낌이 없다
```

**여기 적힌 것은 전부 들어갈 자리가 이미 있다.** 파일을 넣으면 코드가 알아서 집는다 —
없으면 지금 그림으로 돌아가므로 순서대로 하나씩 납품해도 된다.

---

## 1. 장판 5종 (가장 급하다)

지금 다섯 효과가 **같은 흰 원판에 색만 다르다.** 화상인지 빙결인지가 색으로만 갈려서,
어두운 바닥 위에서 겹치면 무엇을 밟았는지 읽히지 않는다.

```
파일     field_burn · field_freeze · field_curse · field_slow · field_damage
캔버스   128×128 · 투명 · 원형
알파     반투명 허용 (바닥이 비쳐야 한다). 다만 **단계로 끊어라** — 4~6단계.
         부드러운 그라데이션은 이 화면에서 혼자 겉돈다
색       그림 자체에 색을 넣는다. 코드가 tint 하지 않는다
```

**안쪽은 옅게, 테두리는 진하게.** 안이 진하면 그 위에 선 캐릭터가 묻힌다.
경계가 어디까지인지 한눈에 보이는 것이 이 그림의 전부다.

| 파일 | 색 | 무늬 |
|---|---|---|
| `field_burn` | 주황~빨강 | 불티가 튀는 원. 안쪽에 그을음 |
| `field_freeze` | 청백 | 서리 결정이 바닥에 낀 원. 가장자리에 각진 얼음 |
| `field_curse` | 자주~검정 | 룬이 원을 따라 도는 마법진 |
| `field_slow` | 청회색 | 끈적한 늪. 동심원 물결 |
| `field_damage` | 회주황 | 갈라진 지면. 잔해 몇 조각 |

## 2. 보스방 바닥 3종

```
파일     roomfloor_robot_snakes · roomfloor_demolisher · roomfloor_python
캔버스   256×256 · **상하좌우 이음매 없이 반복**되어야 한다
         (코드가 Tiled 로 깐다 — 이음매가 보이면 방 전체에 격자가 생긴다)
불투명   전면 불투명. 투명 화소 없음
밝기     **어둡게.** 이 위에 캐릭터·탄·장판이 전부 올라간다.
         지금 던전 바닥(roomfloor)의 밝기를 넘지 마라
```

원작 시트의 배경을 **모티프로만** 쓴다. 원작은 횡스크롤 측면도라 그대로 못 쓴다 —
우리 방은 위에서 내려다보는 바닥이다.

| 파일 | 원작 모티프 | 그릴 것 |
|---|---|---|
| `roomfloor_robot_snakes` | 무너진 잔해·철골 | 콘크리트 파편이 깔린 바닥, 군데군데 철근 |
| `roomfloor_demolisher` | 공장 철골·컨베이어 | 기름 밴 철판, 리벳 이음매, 노란 경고 줄무늬 |
| `roomfloor_python` | 하수도 벽돌 | 젖은 벽돌, 이끼, 얕게 고인 물 |

앵커: `17_boss/{보스}/00_parts.png` 의 배경 조각과 `00_palette.png`.

## 3. 팝업 레이저 2종 (로봇 스네이크 전용)

지금 세로 광선이 **장판 원판으로** 나간다. 원래는 방을 세로로 관통하는 줄이다.

```
파일     obj_laser_crack · obj_laser_beam
캔버스   96×512 · 투명 · 세로로 이어 붙일 수 있게(위아래 이음매 없음)
```

- `obj_laser_crack` — **예고**다. 바닥이 갈라지는 붉은 금. 0.85초 동안만 보인다.
  피해가 없으므로 **위협적이되 벽처럼 보이면 안 된다** — 얇은 금 한 줄과 빛 번짐
- `obj_laser_beam` — 솟아오른 광선. 흰 심 + 청록 외곽. 위아래로 잘려도 자연스럽게

## 아직 그리지 마라

크레인(트롤리·사슬·집게) · 컨베이어 벨트 · 구멍 타일 · 실드 패널.

이것들은 **코드가 아직 없다.** 데몰리셔의 실드는 지금 보스가 깜빡이는 것으로만
표현하고, 구멍은 팝업 레이저의 금으로 대신한다. 코드가 붙으면 따로 지시한다.

> 17차에서 같은 이유로 막았고, 그 사이 팝업 레이저·독구름·실드 순환 코드가 붙어서
> 위 네 항목이 풀렸다. 남은 것도 같은 순서로 푼다.
