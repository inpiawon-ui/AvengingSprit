# 작업 지시 — 18차 · 프레임 일관성 수정 + 얼티밋 1 + 투사체

세 갈래다. **위에서부터 순서대로** 가져가라. 서로 기다릴 필요 없다.

---

## 무엇이 잘못됐나 — 한 캐릭터 안에서 사람이 바뀐다

지금까지 검수는 **캔버스·앵커·팔레트·구멍**만 봤다. 그래서
"idle 과 atk 가 같은 사람인가" 는 한 번도 확인되지 않았다. 수치로는 안 잡힌다 —
색은 그대로 쓰고 몸만 다르게 그리면 팔레트 검사를 통과하고,
공격 자세는 팔을 뻗어 원래 커지므로 면적 검사로도 안 갈린다.

이제 대조판을 만들었다. **작업 전에 반드시 자기 캐릭터 판을 열어라.**

```
18_identity/{슬러그}.png    ← idle·walk1·walk2·atk1·atk2·hit·die1·die2 를 한 줄에 늘어놓은 것
```

**이 판에서 한 줄이 같은 사람으로 보이지 않으면 그것이 반려 사유다.**

## 갈래 1 — `thug` 걷기 10장 (최우선)

🔴 **가장 심각하다.** `thug` 는 보라 정장에 중절모를 쓴 폭력배인데,
**걷기 프레임만 수염 난 올리브색 군복 사내**다. 5방향 전부 그렇다.
같은 캐릭터가 걷기 시작하는 순간 다른 사람이 된다.

```
대상   unit_thug_{s,se,e,ne,n}_walk1.png
       unit_thug_{s,se,e,ne,n}_walk2.png     — 10장
기준   같은 폴더의 unit_thug_{방향}.png (idle) 이 정답이다.
       보라 정장 · 중절모 · 토미건 · 갈색 구두. 그 사람이 걷는 그림을 그린다.
규격   15차 그대로 (96×96 · 발밑 y=87 · 발 중심 x=48 · 이진 알파)
```

## 갈래 2 — 프레임 일관성 수정 (7종)

같은 사람이긴 한데 **프레임마다 요소가 사라지거나 체구가 달라진다.**
아래 표의 프레임만 다시 그린다. **해당 캐릭터의 idle 을 기준으로 맞춘다.**
5방향 전부 확인하고, 어긋난 방향은 함께 고친다.

| 캐릭터 | 고칠 프레임 | 무엇이 어긋났나 |
|---|---|---|
| `amazon` | atk1 · atk2 · hit | idle·walk 에 있는 **분홍 팔목보호대가 사라진다.** 몸도 굵어진다 |
| `amazon_elite` | atk1 | **없는 무기가 나온다** — 노란 초승달 칼. 이 캐릭터는 맨주먹이다 |
| `commando_mg` | atk1 · atk2 | atk1 은 **총이 아예 없고**, atk2 는 idle 과 다른 총을 든다 |
| `commando_grenade` | atk1 | 이 프레임만 **몸이 확 작아진다.** 다른 프레임과 키가 안 맞는다 |
| `ninja` | atk1 | 이 프레임만 **몸이 가늘고 작아진다** |
| `salamander` | atk2 · hit | 붉은 상의·바지·신발 디테일이 뭉개져 다른 도마뱀으로 보인다 |
| `guru` | die2 | 이 프레임만 **몸이 절반 크기**다 |
| `vampire` | die1 · die2 | 캐릭터가 사라지고 **노란 원 + 흰 십자 아이콘**이 된다. 다른 캐릭터는 전부 몸이 쓰러진다 |

> `ninja` 의 die1·die2 가 연기만 있는 것은 **그대로 둔다.** 닌자가 연막으로 사라지는 연출이다.

## 갈래 3 — 얼티밋 아이콘 `hopper` 1장 재작업

납품분을 반려했다. 어두운 바탕에 어두운 몸이라 **실루엣이 안 읽힌다** —
밝은 화소가 3.6% 로, 기존 9장 중 가장 어두운 것(4.6%)보다도 어둡다.

```
16차 규격 그대로 (64×64 · 이진 알파 · 14~16색 · 채움 26~63%)
브리프도 그대로 — 공중에 뜬 실루엣 + 아래로 쏟아지는 탄 일고여덟 발
이번엔 밝기를 확보한다:
  · 인물 뒤에 밝은 총구 화염이나 궤적을 깔아 몸 테두리를 띄운다
  · 청록 청바지를 밝은 쪽 단계로 올려 다리를 배경에서 분리한다
  · 탄은 노랑~흰색으로 확실히 밝게. 지금은 탄도 어두워 안 보인다
※ hopper_smg 와 나란히 놓인다. 그쪽은 탄이 화면을 메우고 이쪽은 셀 수 있어야 한다
```

## 갈래 4 — 투사체 8종 (신규)

지금 **21종 캐릭터가 노란 탄 한 장을 같이 쓴다.** 레이저도 수류탄도 서리
브레스도 사슬낫도 전부 같은 총알로 날아간다. 무기별로 나눈다.

```
캔버스   24×24 · 투명 · 이진 알파 · 안티앨리어싱 없음
방향     오른쪽(→)으로 날아가는 그림 하나만. 코드가 각도에 맞춰 돌린다
정렬     날아가는 방향이 +x. 탄의 무게중심을 캔버스 중앙(12,12)에 둔다
파일명   shot_{종류}.png
기준     기존 shot.png (노란 탄) 이 밝기·굵기의 기준이다. 그보다 어둡게 만들지 마라
```

| 파일 | 쓰는 캐릭터 | 그림 |
|---|---|---|
| `shot_bullet` | gangster · thug · hopper · hopper_smg · commando_mg | 지금 것과 같은 계열. 짧은 노란 탄 + 꼬리 |
| `shot_laser` | commando_laser | 가로로 긴 **청록 광선.** 심은 흰색, 가장자리 청록 |
| `shot_grenade` | commando_grenade | 회록색 **수류탄** 하나. 회전하는 느낌으로 살짝 기울인다 |
| `shot_flame` | salamander · dragoon | 주황~노랑 **불덩이.** 뒤로 흩어지는 불티 |
| `shot_frost` | dragon_blue · snowwoman | 청백 **얼음 조각.** 육각 결정 하나 + 성에 가루 |
| `shot_shuriken` | ninja · ninja_chain | 회색 **표창.** 금속 반사 한 점 |
| `shot_magic` | white_wizard · medium | 보라~청색 **마법탄.** 둥근 핵 + 흔들리는 잔광 |
| `shot_pulse` | guru · robot | 흰~하늘색 **고리 파동.** 속이 빈 원 |

> 남는 캐릭터(amazon·amazon_elite·baseball·vampire)는 근접이라 투사체가 없다.
