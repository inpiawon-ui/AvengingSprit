# [AVSR] 54차 발주 — 잡몹 3종 스프라이트 (120장)

## 무엇이 왜 필요한가

방마다 서는 적 4~6기 중 **2~4기가 색 사각형**이다. 그림이 아직 없어서 코드가 대역을 세운다.

```
[Battle] skeleton 의 그림이 아직 없다 — 대역으로 세운다
[Battle] scrapgunner 의 그림이 아직 없다 — 대역으로 세운다
[Battle] bat 의 그림이 아직 없다 — 대역으로 세운다
```

이 셋은 **빼앗을 수 없는 잡몹**이다. 사람 모양 호스트(빼앗을 수 있음)와 **실루엣만으로 갈려야** 한다 — 그게 이 셋을 따로 만든 이유다.

> 사람 = 빼앗을 수 있다 / 뼈·짐승·기계 = 없다

CH1 에 셋 다 나온다. CH2·CH3 도 이 셋 중 일부를 계속 쓴다.

---

## 공통 규격 (3종 모두 동일)

| 항목 | 값 |
|---|---|
| 캔버스 | **96 × 96 px** 고정 |
| 발밑 | 아래에서 **8 px 위** (y=87 이 접지선) |
| 발 중심 | **x = 48** |
| 알파 | **0 또는 255 만.** 반투명 픽셀 없음 |
| 색 수 | **한 종당 40색 이하** (기존 유닛이 15~34색) |
| 배경 | 완전 투명 |

> ⚠ **발 중심이 48 이어야 한다.** 왼쪽 3방향은 코드가 좌우 반전으로 만들고, 반전축이 캔버스 중심이다. 48 이 아니면 왼쪽을 볼 때 몸이 옆으로 튄다.

기준 파일 (열어서 재 볼 것):

```
Assets/BaseResource/Unit/amazon/unit_amazon_s.png          96×96 · 30색 · 접지 y87 · 발중심 48
Assets/BaseResource/Unit/actor_enforcer/unit_actor_enforcer_s.png   128×128 (덩치 큰 예외)
```

## 장수 — 한 종당 40장

**방향 5개 × 동작 8개.** 왼쪽 3방향(sw · w · nw)은 만들지 않는다 — 코드가 뒤집는다.

방향 접미: `s` (정면) · `se` · `e` (옆) · `ne` · `n` (뒤)

| 동작 | 파일 접미 | 무엇 |
|---|---|---|
| 대기 | *(없음)* | 서 있는 자세 |
| 걷기 1 | `_walk1` | 걷는 두 장의 첫 장 |
| 걷기 2 | `_walk2` | 둘째 장 |
| 공격 1 | `_atk1` | 예비 동작 (치기 직전) |
| 공격 2 | `_atk2` | 치는 순간 |
| 피격 | `_hit` | 맞고 움찔 |
| 사망 1 | `_die1` | 쓰러지는 중 |
| 사망 2 | `_die2` | 쓰러진 뒤 |

파일명:

```
unit_{키}_{방향}.png            예: unit_skeleton_s.png
unit_{키}_{방향}_{동작}.png     예: unit_skeleton_se_walk1.png
```

**한 종 40장 × 3종 = 총 120장.**

## 종별 명세

### ① `skeleton` — 해골 · 벽

```
폴더  Assets/BaseResource/Unit/skeleton/
크기  다른 유닛과 같은 키 (96 캔버스 안에서 사람 크기)
```

- **역할**: 길을 막는다. 느리고 약하지만 앞줄에 서서 통로를 좁힌다
- **전투 수치**: HP 28 · ATK 6 · 이동 1.2 m/s · 사거리 1.4 m (근접)
- **그림**: 뼈만 남은 사람. 갈비뼈와 두개골이 실루엣에서 바로 읽혀야 한다
- **왜 뼈인가**: 사람 모양이지만 **빼앗을 수 없다**는 것이 한눈에 보여야 한다. 살이 붙어 있으면 플레이어가 빙의를 시도하다 헛손질한다
- 무기: 없거나 아주 짧은 것. 팔 자체로 친다
- 예비 동작(`_atk1`)이 커야 한다 — 0.45초를 주고 피하게 만드는 적이다

### ② `bat` — 박쥐 · 추격

```
폴더  Assets/BaseResource/Unit/bat/
크기  다른 유닛보다 작게 (캔버스 96 안에서 절반 정도)
```

- **역할**: 따라붙는다. 빠르고 약하다. 유령이 됐을 때 도주선을 끝까지 쫓는다
- **전투 수치**: HP 18 · ATK 4 · 이동 2.6 m/s (가장 빠름) · 사거리 1.2 m
- **그림**: 날개 달린 짐승. **공중에 떠 있다** — 접지선(y=87)에 몸이 닿지 않아도 되지만, 그림자나 발끝이 그 근처에 와야 어디 있는지 읽힌다
- 걷기 두 장(`_walk1` `_walk2`)은 **날갯짓**이다. 두 장이 확실히 달라야 한다 — 이 종만 유일하게 계속 움직인다
- 작고 빠르므로 **실루엣이 단순해야** 한다. 세부를 넣으면 움직일 때 뭉개진다

### ③ `scrapgunner` — 폐품 사수 · 사격

```
폴더  Assets/BaseResource/Unit/scrapgunner/
크기  사람 크기
```

- **역할**: **CH1 의 유일한 원거리 잡몹.** 붙기 전에 아프게 한다. 엄폐물이 이 종 때문에 값을 가진다
- **전투 수치**: HP 24 · ATK 7 · 이동 1.4 m/s · **사거리 5.2 m** · 예비동작 0.75초
- **그림**: 폐품을 뒤집어쓴 기계 또는 로봇. 총구가 어디인지 보여야 한다
- **⚠ 총 든 자세가 멀리서 보여야 한다.** 이 종만 원거리라, 방에 들어섰을 때 "저놈은 쏜다" 를 즉시 알아야 붙을지 피할지 정한다. 해골·박쥐와 실루엣이 헷갈리면 안 된다
- **⚠ 사람으로 보이면 안 된다.** 사거리가 있어 매력적인 몸처럼 보이는데 빼앗을 수 없다. 기계·고철 느낌을 확실히 준다
- `_atk1` 은 **총구가 번쩍이기 직전**, `_atk2` 는 발사. 0.75초를 눈으로 세게 만드는 것이 이 두 장의 일이다

## 셋을 나란히 놓았을 때

한 방에 셋이 같이 선다. **크기·자세·실루엣이 서로 달라야** 한다.

```
skeleton     사람 크기 · 서 있음 · 마른 세로 실루엣
bat          작음 · 떠 있음 · 가로로 퍼진 날개 실루엣
scrapgunner  사람 크기 · 서 있음 · 총을 든 각진 실루엣
```

색도 갈라 준다. 셋이 같은 회색이면 방이 한 덩어리로 보인다.

## 나눠 받아도 된다

120장이 한 번에 어려우면 이 순서로 나눈다. 한 종이 40장 다 와야 그 종이 화면에 선다 (한 동작이라도 방향이 하나 빠지면 코드가 그 동작을 통째로 안 쓴다).

```
1차  skeleton     40장   — 가장 많이 나온다
2차  scrapgunner  40장   — 원거리라 전투가 제일 크게 바뀐다
3차  bat          40장
```

## 확인 기준

1. 96 × 96 px · 한 종 40장
2. 알파가 0 과 255 뿐 (반투명 픽셀 0개)
3. 접지선이 아래에서 8 px 위, 발 중심 x = 48
4. 한 종 40색 이하
5. 5방향이 같은 인물로 읽힌다 (뒤통수가 다른 캐릭터처럼 보이지 않는다)
6. `_walk1` · `_walk2` 두 장이 번갈아 나올 때 걷는 것으로 읽힌다
7. 셋을 나란히 놓았을 때 크기·실루엣이 서로 다르다
8. 셋 다 **사람(빼앗을 수 있는 몸)으로 안 보인다**
