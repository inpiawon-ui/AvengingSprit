# 리소스 작업 큐 — 위에서부터 순서대로

**내 확인을 기다리지 말고 여기서 다음 항목을 가져가서 작업한다.**
한 항목을 `_exchange/in/` 에 넣었으면 바로 다음 항목으로 넘어간다.
검수에서 반려가 나오면 그 항목만 다시 오면 되고, 그동안 다음 항목은 계속 진행된다.

규격·시점·색 규칙은 [`WORKORDER.md`](WORKORDER.md) 13·14차를 그대로 따른다.
아래는 **무엇을 몇 장** 만드는지의 목록이다.

우선순위는 정본의 실제 스폰 수다. CH1 을 먼저 완성한다 — 첫 실행 목표가 CH1 완주다.

---

## 공통 규격 (모든 캐릭터 공통, 매번 다시 적지 않는다)

```
캔버스   96×96 · 투명 · 이진 알파(반투명 픽셀 0) · 안티앨리어싱 없음
정렬     발밑 y=87 · 발 중심 x=48(바닥 6줄 기준) · 머리끝 y=12
방향     s · se · e · ne · n  다섯 장. 왼쪽 3방향은 코드가 반전으로 만든다
프레임   idle / atk1 / atk2 / hit / walk1 / walk2 / die1 / die2

파일명   unit_{키}_{방향}.png                  ← idle
         unit_{키}_{방향}_{프레임}.png          ← 나머지
         ※ 방향 없는 `unit_{키}.png` 는 필요 없다. 코드가 정면(s)으로 대신한다

공격     atk1 = 타격·발사의 정점, atk2 = 반동·여파. 발은 붙어 있다
걷기     발이 움직이되 몸통은 제자리. 머리 가로 중심이 idle 과 ±2px
사망     눕히지 말고 주저앉힌다. die1·die2 모두 발밑 y=87
색       그 캐릭터 idle 팔레트 밖으로 나가지 않는다(총구 화염만 예외, 면적 6% 이내)

⚠ 특정 게임 캐릭터를 닮으면 반려한다. 류·켄·테리 같은 대전격투 캐릭터,
  그 외 알아볼 수 있는 타사 IP 금지. 이 게임은 1991 Jaleco 아케이드다 —
  어둡고 음습한 오컬트 액션 톤.
```

## 항목별 성격 (정본 ENEMY_DB · SOURCE_AUDIT)

이미 idle 이 있는 것은 **그 그림의 인물·복장·팔레트를 그대로** 쓰고 동작만 더한다.

| 키 | 정본 | 무기·전투 | 동작에서 살릴 것 |
|---|---|---|---|
| `salamander` | E003 샐러맨더 | 화염 브레스 ×2 | atk1 숨을 들이켠 뒤 뿜는 정점, atk2 여열. 원뿔이 앞으로 |
| `white_wizard` | E010 화이트 위저드 | 둔화 오브 | atk1 지팡이·손 앞에 오브가 맺힘, atk2 던진 뒤 팔이 남음 |
| `ninja` | E011 닌자 | 표창 | atk1 던지는 정점(표창이 손을 떠남), atk2 착지·자세 회복. 가장 빠른 템포 |
| `baseball` | E015 야구선수 | 배트 · 바닥 도탄 | atk1 배트가 공을 때리는 순간, atk2 스윙 여파로 몸이 돌아감 |
| `assault_gangster` | E007 어설트 갱스터 | 레이저 라이플 3점사 | atk1 총구에 가는 레이저 선, atk2 반동. 갱스터보다 총이 길다 |

### `guru` · `sensor_drone` 별항 — 부양

둘 다 바닥에 발을 딛지 않는다. 정본 구루의 AI 패턴이 문자 그대로 `Hover → Aura → Punch` 다.

```
몸      발끝이 바닥선에서 12~16px 위
그림자  바닥선(y=87)에 가로:세로 10:3 으로 눌린 타원. 쿼터뷰라 눌려 보인다
        어두운 남색 단색 · 이진 알파 · 중심 x=48
걷기    발을 내딛지 않는다. 몸이 2~3px 흔들리고
        **그림자는 바닥에 붙은 채 크기·진하기만** 변한다
        ← 그림자가 몸을 따라 오르내리면 떠 있는 것으로 안 읽힌다
사망    부양이 풀린다. 높이가 내려오며 그림자가 커지고 마지막엔 몸에 붙는다
```

### 엘리트 (EL01~03)

일반 적보다 **한 등급 크다. 캔버스 128×128, 발밑 y=118, 발 중심 x=64.**
나머지 규칙은 같다. 엘리트는 빙의 불가라 궁극기·빙의 동작이 필요 없다.

| 키 | 정본 | 성격 |
|---|---|---|
| `EL01` | 엔포서 | 돌진 → 내려찍기. 육중한 근접. 빗나가면 크게 빈다 |
| `EL02` | 실드 캡틴 | 방패 아크 → 밀치기. 뒤가 열린다 |
| `EL03` | 아크 워든 | 구체 고리 → 순간이동. 마법 계열 |

### 보스 (B01~03) — 별도 지시

보스는 캔버스·프레임 구성이 다르다. 앞 항목을 다 끝낸 뒤 **따로 지시한다.**
큐에서는 자리만 잡아 둔다. 먼저 손대지 말 것.

## 납품 방법

- 파일은 전부 `_exchange/in/` 에 평평하게 넣는다(하위 폴더 없음)
- 한 항목이 끝날 때마다 넣고 다음으로 넘어간다. 여러 항목을 모아서 한 번에 넣어도 된다
- 넣은 뒤 무엇을 넣었는지 한 줄로 알린다
