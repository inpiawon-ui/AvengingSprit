# 26차 워크오더 — 시점 통일 · 바닥 타일 · 지형 블록

**총 9장.** 이번 차수부터 [`VIEW_STANDARD.md`](VIEW_STANDARD.md) 를 **먼저 읽고** 시작한다.
납품은 `_exchange/in/` 에 평평하게(하위 폴더 없음).

| 순서 | 항목 | 장수 |
|---|---|--:|
| 1 | 지형 블록 `obj_block_1~3` | 3 |
| 2 | 바닥 타일 `floor_tile_ch1~3` | 3 |
| 3 | 벽 가장자리 `floor_edge_ch1~3` | 3 |

---

## 왜 이 차수가 필요한가

지금 한 화면 안에 **세 가지 시점**이 섞여 있다 — 바닥은 90° 수직,
기둥은 45° 아이소메트릭, 캐릭터는 정면. 그래서 어느 것도 바닥에 붙어 있어 보이지 않는다.

[`VIEW_STANDARD.md`](VIEW_STANDARD.md) 로 **65° 탑뷰**를 기준으로 정했다.
이번 차수의 6장이 그 기준의 첫 적용이고, 앞으로 나올 모든 지형 그림이 여기 맞춰진다.

그리고 지형 배치 방식도 바뀌었다. 예전에는 큰 사각형 한두 개를 통째로 놓아서
"덩어리가 하나 있을 뿐" 이고 형태가 없었다. 이제 **같은 크기 블록을 격자에 늘어놓아
모양을 만든다** — 긴 벽, 짧은 토막, 흩어진 기둥. 코드는 이미 그렇게 깔고 있다
(48방 · 블록 729개). **그 블록의 그림이 이번 1번 항목이다.**

## 1. `obj_block_1` · `_2` · `_3` — 지형 블록 3장

### 규격

```
캔버스        72 × 102 px  (전 장 동일)
바닥 접촉선   캔버스 **맨 아랫변**
차지하는 칸   72 × 72 px 정사각 (1 m)
윗면 : 앞면   대략 3 : 7   (위 30 px 이 윗면, 아래 72 px 이 앞면)
투명          이진 알파 · 안티앨리어싱 없음
```

### 무엇을 그리나

**모서리가 살짝 둥근 돌 큐브.** 좌면·우면은 보이지 않는다(윗면·앞면 둘뿐).

```
윗면   가장 밝다. 광원이 화면 위에서 온다
앞면   한 단계 어둡다
테두리 블록끼리 붙여 놨을 때 **경계가 보여야** 한다 —
       이어 붙여 벽이 되지만 낱개로도 읽혀야 하기 때문이다
```

### 옆으로 이어 붙는다

블록은 **가로로 딱 붙어** 긴 벽이 된다(`########`).
그래서 **좌우 끝이 캔버스 가장자리에 정확히 닿아야** 한다 — 안쪽으로 물리면 벽에 틈이 생긴다.

### 3장의 차이

같은 그림만 늘어놓으면 벽이 인쇄물처럼 보인다. **아주 조금씩만** 다르게 한다.

```
_1   기본. 아무 무늬 없음
_2   윗면에 금이 하나 (짧게)
_3   앞면 아래쪽에 이끼 또는 얼룩 한 점
```

셋을 나란히 놨을 때 **형태·크기·명암은 완전히 같아야** 한다.
다른 것은 표면의 잔무늬뿐이다.

## 2. `floor_tile_ch1` · `_ch2` · `_ch3` — 바닥 타일 3장

### 왜 타일 하나인가

지금 바닥은 방마다 큰 그림 한 장씩(`roomfloor_ch1_*`) 48장이다. 그런데
**너무 어둡고 무늬가 없어서 이동감이 없다** — 어디로 가고 있는지 화면에서 안 읽힌다.

코드는 이미 바닥을 `Tiled` 로 그린다. **작은 심리스 타일 하나면 48장을 대체한다.**

### 규격

```
캔버스   144 × 144 px  (= 2 m × 2 m · 1 m 칸 4개)
심리스   상하좌우가 이어져야 한다. 이어 붙였을 때 이음매가 보이면 반려
투명     없음. 불투명 단색 배경
시점     90° 수직. **바닥만은 정사각 격자다** (VIEW_STANDARD 참조)
```

### 무엇을 그리나

**체크무늬.** 1 m 칸마다 밝기가 번갈아 바뀐다 — 이게 이동감의 전부다.

```
밝은 칸 / 어두운 칸의 명도 차이   작게. 눈에 띄되 시끄럽지 않게
표면                              살짝의 잔결. 완전 단색이면 싸구려로 보인다
```

**캐릭터·블록보다 어두워야 한다.** 바닥이 밝으면 그 위에 선 것들이 안 읽힌다.
지금 바닥은 반대로 너무 어두워서 아무것도 안 보인다 — **중간 밝기**가 목표다.

### 챕터별 색

```
ch1   차가운 청록 계열
ch2   따뜻한 갈색·돌 계열
ch3   어두운 보라·재 계열
```

무늬 구조는 3장 모두 같다. 색만 다르다.

## 3. `floor_edge_ch1` · `_ch2` · `_ch3` — 방 가장자리 3장

방 좌우·위아래 끝에 둘러지는 **벽 띠**. 지금은 바닥 그림에 그려 넣어져 있어서
방 크기가 바뀔 때마다 늘어나 뭉개진다.

```
캔버스   72 × 144 px  (가로 1 m · 세로 2 m)
심리스   **세로로** 이어져야 한다 (좌우 벽에 세로로 반복해 붙인다)
시점     블록과 같은 65°. 윗면·앞면 2면
```

방 안쪽을 향한 면이 앞면이다. 블록과 같은 재질·같은 광원이어야 한다 —
가장자리와 블록이 서로 다른 돌로 보이면 방이 하나로 안 읽힌다.

## 이번 차수의 성공 기준

납품된 6장(블록 3 + 바닥 3)을 화면에 올렸을 때:

```
□ 블록이 바닥에 **붙어 있어** 보인다 (떠 있거나 파묻혀 보이지 않는다)
□ 블록을 가로로 이어 붙였을 때 벽이 되고, 이음매에 틈이 없다
□ 바닥 격자가 보여서 **움직이고 있다는 것**이 느껴진다
□ 블록·바닥·캐릭터가 같은 방에 있는 것으로 보인다
```

마지막 항목이 이번 차수의 목적 전부다.
