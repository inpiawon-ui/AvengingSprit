# [AVSR] 56차 발주 — 스킬 이펙트 75장 (배치 4-B)

## 이미 있는 것 — 다시 그리지 않는다

발주서 4-B 는 81장이지만 **6장은 이미 프로젝트에 있다.**

```
fx_slow_1~3   48×48   8월 27일 납품 완료   ← 발주서 "1순위 · 없음" 은 틀렸다
fx_dash_1~3   48×48   8월 28일 납품 완료
```

따라서 이번 발주는 **75장**이다.

---

## 공통 규격 (75장 전부)

| 항목 | 값 |
|---|---|
| 알파 | **0 또는 255 만.** 반투명 픽셀 0개 |
| 배경 | 완전 투명 |
| 안티에일리어싱 | **금지.** 도트 경계가 그대로 살아야 한다 |
| 프레임 간격 | 0.06초 기준 (3장 = 0.18초 · 5장 = 0.3초) |
| 파일명 | 표 그대로. 코드가 이름으로 찾고 **없으면 조용히 넘어간다**(오류가 안 난다) |

기준: **1 m = 72 px.** 아래 크기는 화면에 놓일 실제 픽셀이다.

> ⚠ **알파는 그라데이션이 아니라 계단으로 준다.** 부드럽게 흐르는 반투명은 도트 화면에서 혼자 매끈해 보여 오히려 튄다. 사라질 때도 60% → 35% → 15% 처럼 뚝뚝 끊는다.

기존 이펙트를 열어서 밀도를 맞출 것:

## 1순위 — 여러 호스트가 돌려 쓴다 (11장)

이것만 있어도 23명 중 절반이 화면에 뜬다.

| 파일 | 장 | 크기 | 쓰는 곳 | 무엇 |
|---|---:|---|---|---|
| `fx_burst_1~4` | 4 | 96×96 | 아마존정예 · 코만도MG · 화이트위저드 | 터지는 폭발 |
| `fx_muzzle_1~2` | 2 | 48×48 | 폭력배 · 코만도MG · 코만도레이저 | 총구 화염 |
| `fx_mark_1~2` | 2 | 48×48 | 갱스터 · 영매 | 적 머리 위 표식 · **루프** |
| `fx_reflect_1~3` | 3 | 64×64 | 슬러거 | 탄을 받아치는 순간 |

- `fx_mark` 는 **꺼지지 않고 계속 도는** 표식이다. 두 장이 번갈아 돌아도 어색하지 않게 그린다. 영매는 **같은 그림을 보라색으로 틴트**해서 쓴다 — 따로 그리지 않는다.
- `fx_muzzle` 은 총구에 얹힌다. 방향은 코드가 돌리므로 **오른쪽(+x)을 향한 한 방향만** 그린다.

### 타일링 두 종 (`fx_chain` · `fx_curse_beam`)

72×24 한 칸을 가로로 반복해 길이를 만든다.

- **좌우 끝이 이어져야** 한다. 이어붙였을 때 이음매가 보이면 안 된다
- 세로 24px 안에 다 들어와야 한다 — 위아래로 삐져나오면 반복할 때 어긋난다

### 형태 공유 두 종 (`fx_breath_fire` · `fx_breath_ice`)

**같은 실루엣에 색만 다르게** 그린다. 불은 주황·노랑, 얼음은 청록·흰색. 형태가 다르면 두 캐릭터가 같은 기술을 쓴다는 것이 안 읽힌다.

### 세로로 긴 두 종 (`fx_holy_beam` 144×576 · `fx_laser_wide` 216×576)

위에서 아래로 내리꽂는다. **위쪽 끝이 화면 밖에서 들어오는 것처럼** 잘려 있어야 자연스럽다 — 캔버스 맨 위에 딱 맞춰 시작한다.

## 그리지 않는 것 — 코드로 끝난다

발주 대상이 **아니다.** 혹시 목록에 넣지 말 것:

```
잔상 (아마존 · 호퍼SMG · 닌자)   몸 스프라이트 복제 + 알파 3단계 (60/35/15%)
분신 (닌자 표창)                  몸 스프라이트 알파 55% 복제
과열 총열 (코만도MG)              몸 스프라이트 틴트
반사탄 (슬러거)                   적 탄 스프라이트 색만 뒤집는다
폭발 예고 (화이트위저드)          바닥 흰 사각 윤곽선 · 도형
무적 링                            기존 fx_shield_1~2 재사용
영매 표식                          fx_mark 를 보라색으로 틴트
```

## 확인 기준

1. 표의 크기와 정확히 일치
2. 알파가 0 과 255 뿐 (반투명 픽셀 0개)
3. 안티에일리어싱 없음 — 색 경계가 계단이다
4. 루프 표기가 붙은 것(`fx_burn` · `fx_mark` · `fx_lava` · `fx_missile_trail`)은 마지막 장에서 첫 장으로 이어진다
5. 타일링 표기가 붙은 것(`fx_chain` · `fx_curse_beam`)은 좌우로 이어붙여도 이음매가 안 보인다
6. `fx_breath_fire` 와 `fx_breath_ice` 의 실루엣이 같다
7. `fx_slow_*` · `fx_dash_*` 는 **보내지 않는다** — 이미 있다
