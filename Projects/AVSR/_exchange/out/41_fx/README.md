# 41차 발주 — 확률 효과 연출 9장

확률로 터지는 효과(흡혈·스턴·쉴드)가 **몸 위에서 보여야** 한다.
지금 있는 이펙트는 전부 *탄이 맞은 자리*에 뜨는 것이라, 흡혈이 터졌는지 스턴이 걸렸는지 알 수가 없다.

## 공통 규격 (기존 이펙트와 동일)

- PNG · 알파 투명 · 안티에일리어싱 없음(픽셀 경계 선명)
- 유닛 스프라이트는 96×96, 기존 착탄 이펙트는 48×48
- 원작 1991 Jaleco 아케이드 팔레트 유지 — 기존 `impact_*.png` 와 같은 채도·명도대
- 배경 없음. 캔버스 정중앙 정렬

## 목록

### A. 스턴 — 3장 (`fx_stun_1.png` ~ `fx_stun_3.png`)
- 캔버스 **48×48**
- 머리 위에서 도는 표시. 3장이 **한 바퀴 회전 루프**가 되게 (1→2→3→1 이 끊기지 않을 것)
- 맞은 캐릭터 정수리 위에 뜬다. 아래쪽 절반은 비워 둘 것 (머리에 겹치면 얼굴을 가린다)

### B. 쉴드 — 2장 (`fx_shield_1.png`, `fx_shield_2.png`)
- 캔버스 **96×96** — 유닛과 같은 크기. 몸을 감싼다
- 1장 = 갓 생겼을 때(선명), 2장 = 유지 중(흐림). 둘을 번갈아 깜빡인다
- **몸이 비쳐야 한다** — 가운데는 비우고 테두리만. 꽉 채우면 캐릭터가 안 보인다

### C. 흡혈 발동 — 3장 (`fx_leech_1.png` ~ `fx_leech_3.png`)
- 캔버스 **48×48**
- 1→2→3 이 **한 번 재생되고 끝난다** (루프 아님)
- 방향은 **바깥에서 안쪽으로** — 빼앗아 내 몸으로 들어오는 흐름
- 기존 `impact_drain_1~2.png` 와 같은 계열색

### D. 쉴드 게이지 — 1장 (`hostshieldfill.png`)
- 캔버스 **8×5** — 기존 `hosthpbarfill.png` 와 정확히 같은 크기
- 단색 채움. HP바 위에 겹쳐 그린다
- HP 채움색과 **한눈에 구분되는 색**일 것

## 선택 (있으면 좋음, 없으면 기존 것 재활용)

- `fx_reflect_1~2.png` 48×48 — 탄 반사 (없으면 `impact_pulse` 재활용)
