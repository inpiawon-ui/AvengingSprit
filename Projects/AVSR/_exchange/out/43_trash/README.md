# 43차 발주 — 챕터별 원거리 잡몹 3종 (120장)

## 왜 필요한가

지금 잡몹은 **해골 · 박쥐 2종뿐이고 둘 다 근접**이다. 세 챕터가 전부 같은 둘을 쓴다.
**원거리 잡몹은 0종**이라, 방에 들어가면 늘 같은 것들이 같은 방식으로 달려온다.

근접 쪽은 이미 3종이 확보돼 있다 — 해골 · 박쥐 · `actor_enforcer`(프로젝트에 40장 완성본이
들어와 있는데 아직 아무 데서도 안 쓰고 있다). **이번 발주는 원거리 3종뿐이다.**

## 챕터별 무대

한 챕터가 무대 두 곳을 지난다. 그 두 곳 어디에 서 있어도 어색하지 않아야 한다.

| 챕터 | 무대 | 원거리 잡몹 |
|---|---|---|
| CH1 | 연구소 · 쓰레기장 | 1종 |
| CH2 | 미사일 기지 · 밤거리 | 1종 |
| CH3 | 옥상 · 정유소 | 1종 |

## 공통 규격 (기존 유닛과 동일 — 반드시 맞출 것)

- 캔버스 **96 × 96** PNG · 알파 투명
  - 참고: `unit_skeleton_*` · `unit_bat_*` 가 96×96 이다.
    (`actor_enforcer` 만 128×128 인데 그쪽이 예외다 — **96 에 맞춘다.**)
- 원작 1991 Jaleco 아케이드 팔레트 · 안티에일리어싱 없음
- **발밑이 캔버스 바닥에 닿게** 정렬. 캐릭터가 공중에 뜨면 깊이 정렬이 어긋난다
- 그림자 넣지 말 것 (엔진이 따로 처리한다)

## 한 종당 40장 = 방향 5 × 자세 8

**방향** (파일명 접미사): `e` · `ne` · `n` · `se` · `s`
> 서쪽은 동쪽을 좌우 반전해 쓰므로 그리지 않는다.

**자세** (방향 뒤에 붙는다):

| 자세 | 파일명 | 내용 |
|---|---|---|
| 대기 | (없음) | 서 있는 기본 |
| 걷기 1 | `_walk1` | |
| 걷기 2 | `_walk2` | 1과 번갈아 재생 |
| 공격 1 | `_atk1` | **겨누는 자세** — 아직 안 쏨 |
| 공격 2 | `_atk2` | **쏘는 순간** |
| 피격 | `_hit` | 맞고 움찔. **스턴 걸리면 이 자세로 굳는다** |
| 사망 1 | `_die1` | |
| 사망 2 | `_die2` | |

### 파일명 예시 (CH1 기준, `xxx` 자리에 종 이름)

```
unit_xxx_e.png        unit_xxx_e_walk1.png   unit_xxx_e_walk2.png
unit_xxx_e_atk1.png   unit_xxx_e_atk2.png    unit_xxx_e_hit.png
unit_xxx_e_die1.png   unit_xxx_e_die2.png
… 같은 8장을 ne · n · se · s 에 대해서도 (총 40장)
```

## ⚠ 원거리라는 것이 자세에서 읽혀야 한다

이번 발주의 **핵심**이다. 기존 근접 둘(해골 · 박쥐)과 한눈에 구분돼야 한다.

- `_atk1`(겨눔)과 `_atk2`(발사)가 **명확히 다른 자세**일 것.
  겨누는 동안이 플레이어가 피할 시간이므로, 겨눈 것이 보여야 한다
- 무기 · 팔 방향이 **화면 밖 정면이 아니라 그 방향을 향해야** 한다.
  5방향 전부 겨누는 방향이 달라야 한다
- 근접처럼 팔을 휘두르는 자세는 금지

## 종별 방향 (무대에 맞게)

각 종의 구체적 디자인 — 생물이냐 기계냐, 무엇으로 쏘느냐, 색과 재질 — 은 **그쪽에서 정한다.**
이쪽에서 지키는 것은 아래뿐이다.

| 챕터 | 지켜야 할 것 |
|---|---|
| CH1 | 연구소와 쓰레기장 **양쪽에** 서 있어도 어색하지 않을 것 |
| CH2 | 미사일 기지와 밤거리 양쪽에 어울릴 것 |
| CH3 | 옥상과 정유소 양쪽에 어울릴 것 |

셋이 서로 **실루엣이 달라야** 한다. 눈이 먼저 읽는 것은 재질이 아니라 윤곽이라,
색만 바꾼 셋은 같은 놈으로 보인다.

## 함께 필요한 것 — 탄 그림

원거리이므로 **날아가는 탄**이 필요하다. 종마다 한 세트.

- `shot_xxx_1.png` ~ `shot_xxx_3.png` — 캔버스 **24 × 24**
  - 참고: 기존 `shot_flame_*` · `shot_frost_*` 가 24×24 3장이다
  - 3장이 **작은 것에서 커지는** 순서 (태어나는 모습)
- `impact_xxx_1.png` · `impact_xxx_2.png` — 캔버스 **48 × 48**
  - 맞은 자리에서 터지는 그림 2장

종당 5장 추가 → **3종 15장**
