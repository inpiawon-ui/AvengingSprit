2. 통과 — 기존 화면의 픽셀 캐릭터, 짙은 남색 패널, 청록 네온 테두리, 노란 선택 강조와 아이콘 재질을 일관되게 사용해 새 스타일이 섞인 느낌이 없다.
3. 통과 — 몸 정보 → 능력치 → 스킬 → 호스트 목록 순서가 명확하고, 제목·패널·행의 좌우 정렬과 간격도 대체로 고르다.
4. 고칠 것 — 4열 2행 목록에서 둘째 줄이 잘려 선택 상태와 이름을 보기 불편하다. 하단 바 위에 카드 1행을 온전히 확보하고 가로 스크롤로 넘기게 하며, 정렬 드롭다운도 같은 영역 안에 유지할 것.
5. 고칠 것 — 호스트 카드 칸은 터치하기 충분하지만, 능력치의 노란 골드 버튼 높이가 약 37px로 44px 기준보다 작다. 각 능력치 행과 버튼 높이를 최소 44px로 키우고 행 전체도 동일한 터치 영역으로 잡을 것.
