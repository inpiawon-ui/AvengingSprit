# 연출 가이드 — 판이 끝날 때(실패) 「쓰러짐 → 결과창」 (PD 2026-10-30)

> PD: 「호스트가 죽고 고스트 HP 가 없어서 게임이 끝날 때 메인 · 서브 호스트들이 죽는 연출이 나오고 결과창을 띄워줘. 지금은 게임에서 튕겨 나가는 느낌」
> 지금: 유령 HP 0 → `BattleDirector.Finish(false)` 가 바로 불려 결과창(RbRunResult)이 뜬다. 쓰러지는 것을 볼 틈이 없다.

## 원칙
- 쓰러지는 자세는 **원작 그대로**(Unit.BeginDeath · 원작 죽음 프레임). 새 그림을 그리지 않는다.
- 빛 · 알갱이는 파티클(08_fx 1절) — 유령이 흩어지는 혼 알갱이는 기존 ParticleFxPool 의 것을 쓴다.
- 「판을 멈춘 듯」 어둡게 덮지 않는다(no-staged-pause 메모리) — 대신 **느려진다**.
- 결과창은 연출이 다 끝난 뒤(1-10 「이벤트가 끝나고 뜨게」와 같은 원칙).

## 박자표 (강약)
| 시각 | 무엇 | 세기 |
|---|---|---|
| 0.00 | 마지막 한 대(유령 HP 0) — 화면 흔들림 짧게 · 타격 멈칫 0.08초 | **강** |
| 0.00 → 0.30 | 시간이 0.35배로 느려진다(적 · 탄 모두). 적은 공격을 멈추고 제자리 | 약 |
| 0.10 | 메인 호스트가 원작 죽음 자세로 쓰러진다 | **강** |
| 0.35 | 보조 1 쓰러짐 · 0.55 보조 2 쓰러짐(엇박) — 보조는 혼이라 쓰러진 뒤 빛 알갱이로 흩어진다 | 중 |
| 0.70 | 유령(본체)이 몸에서 빠져나와 위로 떠오르며 흐려진다 — 혼 알갱이 위로 | 중 |
| 1.40 | 화면이 아래에서 위로 천천히 어두워진다(결과창 바닥과 같은 색) · 시간 배율 1 로 | 약 |
| 1.70 | 결과창(실패) 등장 — 지금 그대로 | — |

- 합계 약 1.7초. 길면 답답하다 — 2초를 넘기지 않는다.
- 보조가 없으면 0.35 · 0.55 박자를 건너뛰고 1.4 초에 맞춘다.
- 클리어(성공)는 지금처럼 바로 — 이 가이드는 실패만.

## 확인할 것(PD)
1. 박자 · 길이(약 1.7초)가 괜찮은지
2. 유령이 빠져나와 떠오르는 박자를 넣을지(원작에 유령이 몸에서 빠지는 모습이 있다)
3. 시안이 필요하면 코덱스 자유 시안 1장(쓰러진 파티 + 떠오르는 유령) — 그림 발주는 없다

## 만들 곳(확인 뒤)
- `BattleDirector.Finish(false)` 앞에 `FailSequenceAsync` — 위 박자 뒤 Finish 를 부른다(모드 판 · 포기는 제외)
- 메인 · 보조 `BeginDeath` · 혼 알갱이 ParticleFxPool · 시간 배율은 연출용 별도 값(타격 멈칫과 다투지 않게)
