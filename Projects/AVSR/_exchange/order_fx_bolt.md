# 발주 — 전기 줄기 4장 (`fx_bolt_1` ~ `fx_bolt_4`)

## 무엇이 문제인가

「감전」 카드의 전기가 **그냥 흰 막대기**로 나간다. 적과 적을 잇는 선을 그리기는
하는데, 그림 없이 흰 사각형을 돌려 늘여 쓰고 있어서 전기로 안 보인다 —
「전기 느낌이 아니고 그냥 줄만 나가는 느낌」이라는 말이 정확하다.

**가로로 긴 전기 줄기 그림**이 필요하다. 게임이 이 그림을 두 점 사이에 맞춰
늘이고 회전시킨다.

## 규격

```
파일: fx_bolt_1.png · fx_bolt_2.png · fx_bolt_3.png · fx_bolt_4.png
크기: 256 × 64  (넷 다 같은 크기)
배경: 마젠타 #FF00FF 단색
화풍: 픽셀아트. 안티에일리어싱으로 뭉개지 않는다
```

## 어떻게 그리는가 — 이게 핵심이다

**가로로 관통하는 번개 한 줄기.** 왼쪽 끝(x=0)에서 오른쪽 끝(x=255)까지
**끊기지 않고 이어져야** 한다 — 게임이 이 그림을 늘여서 두 점을 잇기 때문에
끝이 비면 전기가 중간에 끊어져 보인다.

| 요소 | 요구 |
|---|---|
| 심 | 한가운데를 지나는 **흰색 가는 심** (2~3px). 이것이 제일 밝다 |
| 몸통 | 심을 감싸는 **하늘색 줄기** (6~10px). 지그재그로 꺾인다 |
| 발광 | 몸통 바깥으로 **옅은 청색 번짐** (위아래 각 10px 정도) |
| 갈래 | 줄기에서 갈라져 나왔다 사라지는 **잔가지 2~4개**. 짧게 (20~40px) |
| 불티 | 줄기 둘레에 **점 몇 개**가 튀어 있다 |

- 꺾이는 폭은 위아래로 ±12px 안쪽. 너무 크게 꺾으면 늘였을 때 뭉개진다
- 세로 가운데(y=32)를 기준으로 오간다. 한쪽으로 쏠리면 회전했을 때 어긋난다

## 넉 장이 서로 달라야 한다

게임이 네 장을 빠르게 넘겨서 **지직거리는 느낌**을 만든다.
같은 줄기를 조금씩 바꾼 것이 아니라 **꺾이는 자리와 갈래 위치가 매번 다른**
네 장이어야 한다. 굵기와 밝기도 장마다 조금씩 달리한다
(1·3 은 굵고 밝게, 2·4 는 가늘고 어둡게 — 깜빡이는 것으로 읽힌다).

## 색

```
심     #FFFFFF
몸통   #A8E4FF → #5FC8FF
발광   #2E86D8 (옅게)
불티   #FFFFFF · #BFE9FF
```

붉은색·보라색을 섞지 않는다. **푸른 전기** 하나로 간다.

## 배경 처리 — 여기서 여러 번 어긋났다

- 줄기 바깥은 **한 픽셀도 남김없이 `#FF00FF`**
- 지난 납품들에서 **모서리만 마젠타이고 그 안쪽에 색 띠가 한 겹 더** 칠해져 와서
  게임 화면에 분홍 막대가 섰다. 실제로 두 번 그랬다
- 발광은 **그림 안에서** 끝낸다. 캔버스 밖으로 번지게 하지 않는다
- 투명 PNG 로 주지 않는다. 반드시 마젠타 단색 배경

## 크기 — 여기서도 어긋났다

- **256 × 64 캔버스를 가로로 꽉 채운다.** 줄기가 좌우 끝에 닿아야 한다
- 지난 납품에서 큰 캔버스 한가운데에 작게 그려 보낸 적이 두 번 있다
