# 빙의 파티 육성 제안 (PD 2026-10-29)

## PD 원문
- 「스텟 관련된 건 유령으로 옮기고, 스킬 관련은 호스트 육성으로(패시브 · 액티브 · 필살기)」
- 「유령 최대 HP 는 빼는 게 맞을 것 같아」
- 「스킬업은 어떤 식으로 조각과 골드로 하는 건지」
- 「이다음에 육성을 어떻게 할지도 같이 정리하고 한 번에 진행」

## 한 줄 요약
**유령 = 계정 하나의 스탯(골드) · 호스트 = 그 호스트의 스킬(조각으로 상한 · 골드로 레벨).**
파티에 누가 들어와도 유령 스탯은 그대로 따라가고, 내가 키운 호스트를 만나면 그 판이 확 세진다.

## 1. 왜 이렇게 나누나
| 질문 | 답 |
|---|---|
| 파티는 판마다 랜덤 호스트로 짜인다 — 호스트마다 스탯을 키우면? | 안 키운 호스트를 만나면 판이 약해진다 → 「키운 호스트 안 나오면 망한 판」. 스탯은 유령이 들고 다녀야 한다 |
| 그럼 호스트 육성은 왜 하나? | **스킬이 달라진다** — 키운 호스트는 액티브가 세고 · 추가 옵션이 붙고 · 필살기가 강화형이 된다. 「이 호스트 만나면 좋다」는 기대가 생긴다 |
| 인연과는? | 인연 효과의 세기 = **두 호스트의 성급 중 낮은 쪽**. 짝을 같이 키울 이유가 생긴다(수집 동기) |
| 보조로 들어갔을 때는? | 보조 스킬도 그 호스트의 액티브 레벨을 따른다 — 보조로 써도 육성이 보인다 |

## 2. 유령 육성 — 스탯 (골드)
- **유령 레벨** = 지금처럼 챕터 클리어 경험치로만 오른다. 레벨 = 유령 강화 상한(1:1).
- **유령 강화** 6줄, 골드로 한 단계씩. 메인 100% · 보조는 지금 규칙대로(공격 30%) 적용.

| 줄 | 단계당 (임시값) | 비고 |
|---|---|---|
| 공격력 | +2% | 호스트 공격력에 곱 |
| 호스트 체력 | +2% | 유령 HP 아님(PD 결정) |
| 치명타 | +0.3% | |
| 공격 속도 | +0.6% | |
| 이동 속도 | +0.3% | |
| 받는 피해 감소 | −0.3% | |

- 지금 있는 **호스트 탭 능력치 강화 6종은 없앤다** — 개발 단계라 테스트 세이브만 초기화한다.
- 수치는 GameConfig 에 모은 임시값 — 지금 호스트 강화(단계당 3.5%)가 빠지는 만큼 전투력이 비슷하게 맞도록 판에서 재서 맞춘다.

## 3. 호스트 육성 — 스킬 (조각 + 골드)
### 3-1. 두 개의 축
| 축 | 재료 | 하는 일 |
|---|---|---|
| **성급(별)** | 조각 + 골드 (지금 그대로 · 10단계 = 별 5개) | 기본 체력 · 공격 ×1.07/단계(유지) + **스킬 레벨 상한을 연다** |
| **스킬 레벨** | 골드 | 액티브 · 패시브 · 필살기를 **각각 따로** 올린다 — 무엇부터 올릴지 유저가 고른다 |

### 3-2. 스킬 레벨 표
| 스킬 | 레벨 | 상한 | 레벨당 | 마디 보상 |
|---|---|---|---|---|
| 액티브 | 1~10 | 성급 단계(최소 1) | 수치 +6% | **Lv5 추가 옵션**(지금 ★3 옵션 자리) · **Lv10 인연형 강화**(인연이 켜지면 한 단계 더) |
| 패시브 | 1~5 | 1 + 성급 단계 ÷ 2 | 단계표(호스트마다) | Lv5 수치 최대 |
| 필살기 | 1~5 | 1 + 성급 단계 ÷ 2 | 수치 +8% | **Lv5 강화형**(범위 · 연출 한 단계 위) |

- 골드 값(임시): 액티브 Lv n = 400 × n · 패시브 · 필살기 Lv n = 800 × n · 등급 배율 R ×1 · SR ×1.5 · SSR ×2(지금 성급 비용 배율과 같은 표).
- 성급 단계마다 지금처럼 「스킬 Lv 자동 상승」은 없앤다 — **상한만 열고 레벨은 골드로**. 그래야 「골드를 어디에 쓸까」 선택이 생긴다.

### 3-3. 못 가진 호스트
- 판에서는 못 가진 호스트도 빙의 · 보조로 쓸 수 있다(파티는 랜덤) — 스킬 **전부 Lv1**, 필살기는 지금처럼 판당 1회 체험.
- 즉 키운 호스트 = 같은 호스트라도 확실히 더 셈. 「다음에 또 만나고 싶다」 → 조각 모을 이유.

## 4. 조각은 어디서 나오나
| 나오는 곳 | 지금 | 제안 |
|---|---|---|
| 소환(가챠) | 있음 | 그대로 — 주 공급 |
| 챕터 클리어 보상 | 있음 | 그대로 |
| **판에서 같이 싸운 호스트** | 없음 | **새로** — 판 끝에 메인 · 보조로 있던 호스트마다 조각 +1(클리어 +2). 파티 플레이가 곧 수집이 된다 |
| 인연 완성 | 없음 | **새로** — 처음 인연을 켠 판에 짝 둘 다 조각 +2(한 번만) · 도감에 인연 칸이 열린다 |

## 5. 인연과 육성의 연결
- 인연 세기 = 두 호스트 성급 중 **낮은 쪽** 단계에 따라 3단계(0~3 · 4~7 · 8~10) — 높을수록 인연형 수치가 커진다.
- 액티브 Lv10 이면 인연이 켜졌을 때 한 단계 더(3-2 표).
- 육성 화면 호스트 상세에 **인연 짝 얼굴 + 「짝의 성급」**을 보여 준다 → 「이 짝도 키우자」.

## 6. 화면 (다음 시안에서 잡는다)
- 육성 = 탭 둘: **유령**(스탯 6줄 · 레벨 · 강화 버튼) · **호스트**(카드 목록 → 상세).
- 호스트 상세: 별 · 조각 게이지 · 성급 버튼 / 스킬 세 칸(액티브 · 패시브 · 필살기 — 칸마다 Lv x/상한 · 골드 버튼 · 다음 마디) / 인연 짝 칸.
- 성급을 올리면 세 칸의 상한 숫자가 함께 오르는 연결을 보여 준다(지금 노란 연결선 방식 이어 가기).

2. 판에서 같이 싸운 호스트 **조각 +1** — 가챠 매출과 부딪힐 수 있다. 양을 이 정도로 시작해도 되는가?
