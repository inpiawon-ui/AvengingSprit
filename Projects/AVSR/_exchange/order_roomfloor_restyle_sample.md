# 발주 — 인게임 방 바닥 새 화풍 샘플 1장 (720 × 1152)

## 왜

지금 인게임 방 바닥이 **너무 어둡고 퀄리티가 떨어진다**는 평을 받았다.
사장님이 원하는 방향은 **예시처럼 심플하고 보기 좋은 방** 에 **우리 챕터 컨셉을 녹이는 것**이다.

⚠ 예시를 **베끼라는 것이 아니다.** 예시의 무덤·골목은 "느낌"의 예일 뿐이다.
무대는 우리 챕터의 것이어야 한다.

**색 · 조명 · 재질 · 화풍 · 무엇을 어디에 그릴지 — 디자인은 전부 그쪽이 정한다.**
여기 적은 것은 게임이 돌아가는 데 필요한 규격뿐이다.

## 규격 — 게임이 이렇게 쓴다 (꼭 지킬 것)

| 항목 | 값 | 이유 |
|---|---|---|
| 파일 | `roomfloor_env_junkyard.png` | 게임이 이 이름으로 찾는다 |
| 크기 | **720 × 1152 px 정확히** | 그림 한 장이 **방 전체**다 (10 m × 16 m, **72 px = 1 m**). 다른 크기면 늘어나 찌그러진다 |
| 형식 | PNG, **완전 불투명**(알파·마젠타 없음) | |
| 시점 | 위에서 내려다본 방. 바닥 칸은 어디서나 같은 크기(원근으로 좁아지지 않게) | 유닛·장애물이 72 px 격자에 놓인다 |

### 어디가 걸어 다니는 곳인가

```
 x 0                                   720
 y 0    ┌────────────────────────────────┐
        │ 맨 위 약 56 px 는 구름 층에 가린다 │
        │     ┌── 출구 문 ──┐              │  문 그림은 게임이 따로 얹는다
        │     │ x 252~468  │              │  (216 × 180). 그 자리는 막지 말 것
 y 180  ├────────────────────────────────┤  ← 여기까지 위쪽 띠: 적·장애물이 안 놓인다
        │                                │
        │      전투가 벌어지는 바닥          │
        │   (적은 주로 위쪽 절반에 선다)      │
        │                                │
        │          ● 플레이어 시작          │  약 (360, 1030)
 y 1152 └────────────────────────────────┘
```

- **좌 · 우 · 아래 가장자리 24 px 안쪽까지 유닛이 걸어 다닌다.** 벽·담장·난간처럼 **서 있는 것**은 그 24 px 띠 안에만
- 방 **아래에는 문이 없다.** 아래로는 게임이 따로 붙이는 앞마당 그림(720 × 540)이 이어진다
- **장애물은 게임이 따로 얹는다** (블록·기둥·상자·바리케이드 등, 72 px 격자, 그림자 포함 — 예시 2 처럼).
  ⚠ 그래서 **걸어 다니는 바닥 위에 서 있는 물체를 그리면 안 된다.** 예전에 바닥에 그려진 물체를 플레이어가 **진짜 엄폐물로 착각**했다.
  바닥에 **납작하게 붙은 것**(금·얼룩·웅덩이·배수구·칠해진 표시·잔해 자국 등)은 괜찮다
- 유닛은 **픽셀아트 스프라이트**(한 기 약 144 px)다. 그 위에 유닛·적·장애물이 올라가도 **잘 읽혀야** 한다
- 글자 · 로고 · 숫자 금지
