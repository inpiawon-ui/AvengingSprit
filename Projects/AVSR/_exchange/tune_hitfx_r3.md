# 피격 FX 수치 조정표 r3

기준 시안: `in/mock_hitfx_v7.png`  
현재 비교: `ref/hitfx_ingame/compare_r2.png`의 맨 위 시안과 0.035 / 0.075 / 0.125초 게임 캡처(2배)  
r2의 새 값을 현재 값으로 본다. 넷째 적의 노란 해골 외형은 판정에서 제외한다. 표에 없는 함수 수치는 r2를 유지한다.

## 판정

**부분 통과.** 보통은 **통과**다. 치명은 금빛 중심과 규모는 맞지만 0.075초의 방사광이 서로 이어져 금지한 마름모·별 윤곽이 생긴다. 유리는 주황 원뿔의 중심이 비고 낱알이 분홍 파스텔로 바래서 시안의 진한 불길과 다르다. 불리는 반사 방향은 맞지만 0.035초 충돌면이 거의 읽히지 않아 “상성 때문에 막혀 튕겼다”는 시작이 약하다.

맞은 탄 자체가 되튀는 연출은 **계속 넣지 않는다.** 투사체의 소유권·궤적이 실제 반사로 오인되고 화면 안의 새 공격으로 읽힐 위험이 크다. 대신 충돌면을 짧고 단단하게 세우고, 은빛 낱알과 긴 빛꼬리가 모두 `-dir`로 벌어지는 것으로 튕김을 표현한다.

## 1. 시안 대비 r2 결과의 어긋난 점

시안의 적 몸통 폭을 약 70 px로 잡고, 블룸 경계 때문에 측정 오차는 ±3 px로 본다.

| 경우 | 시안 | r2 결과(측정) | 판정 |
|---|---|---|---|
| 보통 | 흰 중심광 약 22×22 px, 얇은 잔광 약 34×34 px, 작은 흰 파편 5개가 중심에서 18~42 px | 0.035초 중심광 약 21~25 px, 0.075초 파편 3~4개, 0.125초에는 작은 잔광만 남음 | **통과. 변경 없음.** |
| 치명 | 흰 중심 약 28 px, 금빛 큰 불티 약 62~68 px 범위, 서로 끊긴 가는 방사광 8개 | 0.035초 중심 약 30~35 px로 허용 범위. 0.075초 방사광 끝점 반경 약 48~56 px이나 대각선끼리 접속되어 약 62×78 px 마름모·별 외곽을 만듦 | 길이는 맞고 분리와 배열이 틀림. 8개를 7개로 줄이고 길이·각도·지연을 흩는다. |
| 유리 | 출구에서 폭 18~22 px, 끝 폭 약 46 px, 길이 약 82 px의 진한 주황 불길. 둥근 주황 불티 9~11개 | 원뿔 길이 약 72~82 px이나 몸통이 반투명 연기처럼 보이고 밝은 심은 약 3~5 px. 0.125초 낱알은 7~9개가 보이나 흰 중심 혼합 때문에 분홍빛 | 원뿔 Body·Core를 강화하고 Glow를 줄인다. 보통 섞기 점의 `_RingWhite`를 크게 낮춰 주황을 보존한다. |
| 불리 | 접촉점의 은백색 납작한 충돌면 약 54×12 px, 반대쪽으로 은빛 불티 7~9개와 긴 빛꼬리 3개 | 0.035초 충돌면이 흰 섬광에 묻혀 윤곽 약 28~34×5~7 px만 보임. 0.075초 이후 반사 파편 방향은 맞음 | 시작 충돌면만 확대·강화한다. 반사 파편과 꼬리는 유지한다. |

## 2. 함수별 바꿀 수치표

표에 없는 항목은 r2 그대로 둔다.

### HxTap — 보통

**통과. 변경 없음.**

### HxCrit — 치명

| 계층 | 항목 | 지금 값(r2) | 새 값(r3) |
|---|---|---|---|
| 방사광 | 개수 | `8` | `7` |
| 방사광 | 기준 각도 흔들림 | `±8°` | `±14°` |
| 방사광 | 속도 | `205~290` | `190~305` |
| 방사광 | 길이×폭 | `54×8` | `46~58 × 6` |
| 방사광 | 수명 | `0.18` | `0.16~0.19` |
| 방사광 | 생성 위치 | 중심 한 점 | 중심 반경 `0~4 px` 분산 |
| 방사광 | 생성 시각 | 동시 | `0 / 0.004 / 0.008 / 0.012초` 순환 |

7개는 등간격 별꼴로 고정하지 말고 기준각을 매번 회전시킨다. “개당 늦게”는 실제 지연 방출 대신 각 시간만큼 해당 광선 속도×시간 거리만큼 궤적 뒤에서 태어나게 한다. 목표는 0.075초에 광선 사이가 최소 4 px 끊기고, 닫힌 마름모·별·팔각형 외곽이 생기지 않는 것이다.

### HxPierce — 유리

| 계층 | 항목 | 지금 값(r2) | 새 값(r3) |
|---|---|---|---|
| 주 원뿔 | 알파 | `0.88` | `0.96` |
| 주 원뿔 | 시작→끝 크기 | `42×20 → 66×88` | `42×20 → 64×86` |

| 옅은 번짐 | 시작→끝 크기 | `46×22 → 74×92` | `44×20 → 70×88` |
| 큰 둥근 불티 | 개수 | `8` | `9` |
| 큰 둥근 불티 | 반각 / 속도 / 크기 | `34° / 190~330 / 14×10` | `30° / 185~315 / 13×11` |

### HxDeflect — 불리

면의 긴 축은 접선 방향을 유지한다. 반고리·방패·돔·새 투사체를 추가하지 않는다.

## 3. HxBuild 재질값

`_DstBlend = 10`은 보통 섞기, `_DstBlend = 1`은 더하기다. 아래는 피격 FX에서 쓰는 각 재질의 r3 목표값이다. `_RingWhite`는 점·고리 중심의 흰 혼합량, `_CoreWhite`는 빛기둥·원뿔 심의 흰 혼합량이다. 해당 셰이더에서 쓰지 않는 속성도 명시값으로 고정한다.

| 재질 | 역할 | 속성 | 지금 값(r2) | 새 값(r3) |
|---|---|---|---:|---:|
| `_hxDotMat` | 흰 점·잔광·긴 빛꼬리 | `_DstBlend / _RingWhite / _CoreWhite` | `1 / 0.70 / 0.80` | `1 / 0.70 / 0.80` |
| `_hxRingMat` | 흰·금빛 고리 | `_DstBlend / _RingWhite / _CoreWhite` | `1 / 0.70 / 0.80` | `1 / 0.62 / 0.80` |
| `_hxBeamMat` | 치명 방사광 | `_DstBlend / _RingWhite / _CoreWhite` | `1 / 0.70 / 0.80` | `1 / 0.70 / 0.72` |
| `_hxConeMat` | 유리의 진한 주황 원뿔 | `_DstBlend / _RingWhite / _CoreWhite` | `10 / 0.70 / 0.80` | `10 / 0.10 / 0.34` |
| `_hxConeMat` | 몸통·심 | `Body / CoreWidth / CoreBoost` | `0.92 / 0.035 / 0.12` | `0.98 / 0.10 / 0.72` |
| `_hxConeMat` | 가장자리 | `EdgeSoft / EdgeLine` | `0.14 / 0.06` | `0.10 / 0.08` |
| `_hxConeGlowMat` | 유리의 옅은 주황 번짐 | `_DstBlend / _RingWhite / _CoreWhite` | `10 / 0.70 / 0.80` | `10 / 0.08 / 0.18` |
| `_hxConeGlowMat` | 몸통·심 | `Body / CoreWidth / CoreBoost` | `0.28 / 0.02 / 0.00` | `0.22 / 0.06 / 0.28` |
| `_hxConeGlowMat` | 가장자리 | `EdgeSoft / EdgeLine` | `0.34 / 0.00` | `0.26 / 0.00` |
| `_hxPlaneMat` | 불리의 앞 흰빛면 | `_DstBlend / _RingWhite / _CoreWhite` | `10 / 0.70 / 0.80` | `10 / 0.22 / 0.46` |
| `_hxPlaneMat` | 몸통·심 | `Body / CoreWidth / CoreBoost` | `0.72 / 0.12 / 0.35` | `0.82 / 0.16 / 0.52` |
| `_hxPlaneBackMat` | 불리의 뒤 은빛면 | `_DstBlend / _RingWhite / _CoreWhite` | `10 / 0.70 / 0.80` | `10 / 0.12 / 0.30` |
| `_hxPlaneBackMat` | 몸통·심 | `Body / CoreWidth / CoreBoost` | `0.48 / 0.08 / 0.18` | `0.62 / 0.12 / 0.34` |
| `HxDotSolid` 복제재질 | 주황·금빛·은빛 낱알 | `_DstBlend / _RingWhite / _CoreWhite` | `10 / 0.70 / 0.80` | `10 / 0.08 / 0.80` |
| `HxDotSolid` 복제재질 | 점 가장자리 | `_RingWidth / _RingGlow` | `0.64 / 0.18` | `0.66 / 0.14` |
| `_hxHalfRingMat` | 피격 FX 미사용 | `_DstBlend / _RingWhite / _CoreWhite` | `10 / 0.70 / 0.80` | `10 / 0.20 / 0.80` |

`HxDotSolid`의 `_RingWhite = 0.08`은 세 색 낱알 공통값이다. 금빛·은빛도 색을 잃지 않으며, 흰빛이 필요한 중심광·방사광·긴 꼬리는 계속 더하기 재질을 쓴다.

## 4. 다음 캡처 점검표

| 시각 | 보통 | 치명 | 유리 | 불리 |
|---|---|---|---|---|
| 0.035초 | **통과 유지:** 중심 20~25 px, 몸통을 완전히 가리지 않음 | 중심 30~36 px, 방사광 5개 이상이 서로 떨어져 보임 | 폭 18~22 px의 진한 주황 몸통 안에 밝은 심 6~10 px가 보임 | 접촉점에 48~58×7~11 px의 납작한 은백색 면이 독립적으로 보임 |
| 0.075초 | **통과 유지:** 흰 파편 3개 이상 | 방사광 사이 최소 4 px 빈틈. 마름모·별·팔각형 윤곽 없음 | 원뿔 길이 70~86 px, 연기 덩어리가 아니라 불길의 몸통과 심으로 읽힘 | 은빛 불티 6개 이상이 모두 `-dir` 쪽에 있고 충돌면 잔광과 분리됨 |
| 0.125초 | **통과 유지:** 작은 잔광만 남음 | 금빛 낱알 8개 이상, 닫힌 선 윤곽 없음 | 둥근 주황 불티 9~11개. 분홍·살구·흰 파스텔이 아니라 진한 주황 | 면은 사라지고 은빛 낱알 5개 이상과 긴 꼬리 2~3개만 남음 |
| 색 확인 | 무채색 흰색 | 금빛 불티 + 흰 중심 | 진한 주황 몸통·주황 낱알 | 은백색 충돌면·은빛 낱알 |
| 금지 형태 | 별·고리 과장 없음 | **마름모·별·닫힌 다각형 없음** | 연기·분홍 파스텔·화살촉 없음 | 방패·반고리·돔·화살촉·새 투사체 없음 |

최종 통과 기준은 원본 720×1280에서 네 경우가 각각 `중심 형태 1개 + 방향성 파편`으로 즉시 구분되는 것이다. 보통은 현재 상태로 통과이며, r3에서는 치명의 닫힌 별꼴 제거, 유리의 진한 주황 심과 9~11개 둥근 불티, 불리의 0.035초 충돌면 가독성을 우선 확인한다.
