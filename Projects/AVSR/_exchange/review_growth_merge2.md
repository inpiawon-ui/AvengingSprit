# 호스트 육성 통합 화면 2차 검수

1. **고칠 것** — 몸 정보, 능력치 5줄(방어력 포함), 스킬 2개, 호스트 목록이 한 화면에 모두 보이며 스킬 설명도 잘리지 않는다. 다만 아래 터치 크기 문제를 고쳐야 한다.
2. **통과** — 기존 화면의 픽셀 아트, 짙은 남색 패널, 청록 발광 테두리, 노란 선택 강조와 금속성 UI 틀이 유지되어 새 스타일이 두드러지게 섞이지 않았다.
3. **통과** — 몸 정보 → 능력치 → 스킬 → 호스트 목록 순서가 명확하고, 섹션 제목·좌우 여백·행 정렬도 대체로 고르다.
4. **통과** — 호스트 목록을 한 줄로 바꾸고 오른쪽 항목이 일부 보이게 해 가로 스크롤 가능성을 알 수 있다. 각 카드의 선택 면적도 충분하다. 1차 지적의 하단 바 잘림은 해소됐다.
5. **고칠 것** — 호스트 목록 칸 높이는 약 140px로 충분하지만, 능력치 각 행의 골드 버튼 높이는 약 38~40px로 보여 권장 44px 이상에 못 미친다. 버튼 높이를 최소 44px로 키우고, 5개 행 모두 같은 높이와 간격을 유지할 것.
6. **통과** — 한글과 영문 모두 식별 가능하며 글자 깨짐이나 의미 없는 가짜 글자는 보이지 않는다.
