# 발주 — 이벤트 방 창 두 벌 (악마 궤짝 · 회복 제단) 7장

## 배경

`AVENGING SPIRIT: RE:BORN` 의 방 004 는 **이벤트 방**이다.
고스트 체력이 40% 위면 「악마」, 아래면 「천사(회복 제단)」가 나온다.

두 창 모두 **시안이 이미 컨펌되었다.** 지금은 그 시안을 게임에 붙일 수 있게
**조각으로 나눠 그리는 단계**다. 시안 두 장을 반드시 열어 보고,
**그 그림의 화풍·색·질감을 그대로** 가져온다. 새 화풍을 만들지 않는다.

| 컨펌 시안 (반드시 열어볼 것) | 무엇 |
|---|---|
| `Projects/AVSR/_exchange/in/event_mockup_a.png` | 악마 — 「봉인된 궤짝」 720×1280 완성 화면 |
| `Projects/AVSR/_exchange/in/angel_mockup_a.png` | 천사 — 「회복의 제단」 720×1280 완성 화면 |

| 이미 게임에 붙은 같은 종류의 창 (화풍·해상도 기준) | 실측 |
|---|---|
| `Assets/BaseResource/InGameMainUI/shopframe.png` | 620×700 · 상점 「유령 노점」 액자 |
| `Assets/BaseResource/InGameMainUI/shopitemslot.png` | 560×104 · 상점 진열 한 칸 |
| `Assets/BaseResource/InGameMainUI/shopleavebutton.png` | 360×62 · 상점 나가기 버튼 |

**해상도 감각은 `shopframe.png` 와 같게 맞춘다.** 픽셀아트 도트 크기,
테두리 두께, 명암 대비가 그 그림과 한 세트로 보여야 한다.
세 창(상점·악마·천사)이 같은 게임의 같은 화면에 번갈아 뜬다.

---

## 공통 규칙 (7장 전부)

1. **글자를 그리지 않는다.** 제목·본문·버튼 문구는 전부 게임이 얹는다.
   시안에 있는 「봉인된 궤짝」「값을 치른다」 같은 한글은 **빼고** 그린다.
   글자가 들어갈 자리는 **비워 둔다**(아래 각 장의 「글자 자리」 참조).
2. **배경은 마젠타 `#FF00FF` 단색.** 투명 PNG 로 주지 않는다.
   알파는 이쪽에서 직접 뚫는다. 그림 안에 마젠타 계열 색을 쓰지 않는다.
3. PNG, 지정한 크기 **정확히**. 여백을 더 붙이지 않는다.
4. 픽셀아트. 안티에일리어싱으로 뭉개지 않는다.
5. **시안의 바깥 배경(성당 내부 / 지옥 문)은 그리지 않는다.**
   창(액자)만 오려 낸다. 뒤 배경은 게임 화면이 비친다.
6. 아래에 적힌 좌표는 **시안을 실측해서 뽑은 값**이다. 게임이 그 자리에
   글자와 버튼을 얹으므로, 자리가 밀리면 글자가 무늬 위에 겹친다.

# B. 천사 — 「회복의 제단」

시안 `angel_mockup_a.png` 에서 액자는 **x 15~705 · y 185~1145** 에 있다
(690 × 960, 날개 끝 포함). 이것을 **620 × 860** 으로 줄여 옮긴다(약 0.90 배).

> ⚠ 시안에는 버튼이 둘(「축복을 받는다」/「지나간다」)이지만
> **실제 게임은 셋 중 하나를 고른다. 지나가기는 없다.**
> 그래서 안쪽 면에는 **선택 칸이 세 개** 들어간다. 액자 크기는 그대로 두고
> 칸만 셋으로 늘어난다 — 시안의 안쪽 면이 이미 셋을 담을 만큼 넓다.
