# 발주 — 화상(불붙음) 이펙트 `fx_burn_1~4`

## 왜 필요한가

적에게 **화상**이 걸리면 「몸에 불이 붙었다」가 보여야 한다.
그런데 지금은 보스의 **화염 브레스용 원뿔 그림**(`fx_breath_fire`)을 갖다 쓰고 있어서,
화상을 입은 적한테서 **누가 불을 뿜는 것처럼** 옆으로 불줄기가 뻗어 나간다. 완전히 다른 그림이다.

몸에 붙어 **위로 타오르는** 불이 필요하다.

## 규격

| 항목 | 값 |
|---|---|
| 파일명 | `fx_burn_1.png` ~ `fx_burn_4.png` (4장) |
| 크기 | **96 × 96 px** (전부 동일) |
| 배경 | **마젠타 `#FF00FF`** 로 꽉 채운다 (내가 알파를 뚫는다) |
| 화풍 | 픽셀아트. 같은 폴더의 `fx_hit_*` · `fx_crit_*` 와 같은 픽셀 크기·같은 디더 |
| 재생 | 1 → 2 → 3 → 4 를 **계속 돌린다**(loop). 4 에서 1 로 넘어갈 때 튀지 않아야 한다 |

## 무엇을 그리나

**적의 몸 한가운데에 겹쳐 놓이는 불꽃**이다. 캐릭터(84~128 px)보다 살짝 크게 덮는다.

- 불은 **아래에서 위로** 타오른다. 뿌리는 아래쪽 가운데, 혀는 위로 흔들린다
- 혀가 2~3 갈래로 갈라져 프레임마다 좌우로 살랑인다 — 그 흔들림이 곧 애니메이션이다
- 색: 안쪽 밝은 노랑 → 주황 → 바깥 붉은 주황. 바깥 테두리에 어두운 붉은색 한 겹
- 아래쪽에 작은 불똥 2~3 개가 위로 튀어 오르면 더 산다
- **가운데를 비운다.** 적 그림이 그 아래에 있으므로, 몸통 한복판이 불로 꽉 차면
  무슨 적인지 안 보인다. 불은 **가장자리와 아래쪽**에 몰리고 가운데는 성기게

```
    ^   ^        위로 타오른다
   ( ) ( )       혀가 갈라져 살랑인다
  \  ( )  /
   \_____/       뿌리는 발밑
```

## 하지 말 것

- ⚠ **옆으로 뻗는 원뿔·줄기 금지.** 지금 잘못 쓰고 있는 그림이 바로 그거다.
  방향이 있는 불(브레스·화염방사)이 아니라 **제자리에서 타는 불**이다
- 글자·숫자 금지
- 96 × 96 밖으로 나가지 않게 — 잘리면 이음이 보인다
- 프레임마다 위치가 확 바뀌지 않게. 뿌리는 제자리에 있고 혀만 흔들린다

## 검수 기준

1. 4 장 전부 정확히 96 × 96
2. 네 모서리가 마젠타 `#FF00FF`
3. 1→2→3→4→1 로 돌렸을 때 튀지 않는가
4. 가운데가 성겨서 **아래 캐릭터가 비치는가**
5. 옆으로 뻗지 않고 위로 타오르는가
