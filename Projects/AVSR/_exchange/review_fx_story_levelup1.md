# 판정: 반려 — 시안과 동일하지 않음

검수 기준은 `mock_fxstory_levelup_v1.png`의 3컷이며, `levelup_vs_mock.png` 아래쪽 재현 컷(0.25 / 2.00 / 4.15초)과 `levelup.gif`를 대조했다. 창 틀·칸·글자 배치는 대체로 맞지만 FX의 형태, 세기, 노출 순서가 다르다. 특히 2컷의 금빛 최대광이 부족하고 3컷의 흡수 줄기가 `LEVEL UP!`과 안내 문구 위를 지나가므로 현 상태는 PD 기준을 통과하지 못한다.

좌표는 모두 720×1280 화면 기준이다. 아래 값에서 `t0`, `t1`은 해당 phase 내부 시간이다. `add=True`는 가산, `add=False`는 덮기다.

## 1컷 — 등장 (0.25초)

### 시안과 다른 점

- 시안은 중앙 엠블럼 위에서 아래로 꽂히는 짧고 굵은 금빛 점화가 먼저 보이고, 그 충격이 좌우 관로로 번진다. 재현은 중앙 점화가 없고 작은 방사광과 관로의 상시 점등만 보여 등장 동작의 방향성이 약하다.
- 시안의 좌우 세로관은 관 안을 채우는 길고 가는 황금 에너지다. 현재 `levelup_tube_glow`는 문양이 든 불꽃 덩어리라 실루엣 자체가 다르다.
- 시안에서 0.25초의 큰 방사광은 아직 최대가 아니다. 현재 `levelup_emblem_rays`는 `t0=0.2`라 등장 컷부터 둥근 꽃 모양이 보인다.

### `layers_levelup()`에서 바꿀 값

- `levelup_emblem_rays`: 중심 `(360, 301)` 유지, `300×300 → 360×360`, `step 0.14 → 0.10`, `t0 0.20 → 0.40`, `t1 0 → 3.80`, `alpha 0.55 → 0.72`, `add=True`, `back=True`. 등장 0.25초에는 방사광이 앞서 나오지 않게 하고, 0.40초부터 최대/대기 장식으로 사용한다.
- 좌측 `levelup_tube_glow`: 중심 `(61, 410)`을 `(61, 435)`로, `60×150 → 54×220`, `step 0.12 → 0.10`, `t0=0.08`, `t1=3.80`, `alpha 0.80 → 0.62`, `add=True`, `back=False`.
- 우측 `levelup_tube_glow`: 중심 `(659, 410)`을 `(659, 435)`로, `60×150 → 54×220`, `step 0.12 → 0.10`, `t0=0.12`, `t1=3.80`, `alpha 0.80 → 0.62`, `add=True`, `back=False`, `flip=True`.
- 좌측 `levelup_pipe_flow`: 중심 `(205, 310)` 유지, `200×40 → 230×34`, `step=0.08`, `t0=0.12`, `t1=0.90`, `loop=False`, `alpha=0.78`, `add=True`, `back=False`.
- 우측 `levelup_pipe_flow`: 중심 `(515, 310)` 유지, `200×40 → 230×34`, `step=0.08`, `t0=0.16`, `t1=0.94`, `loop=False`, `alpha=0.78`, `add=True`, `back=False`, `flip=True`. 관로 흐름은 등장 때 한 번만 지나가고 대기 중 계속 불타지 않게 한다.

### 재발주

- **재발주: `levelup_tube_glow` 4프레임.** 투명 PNG, 기준 캔버스 96×320. 문양·구슬·별·십자 반짝이 없이, 가는 황금 액체/전류 한 줄이 세로관 내부를 아래에서 위로 흐르는 형태. 발광의 불투명 핵은 폭 12~18px, 외곽광은 폭 40px 이내. 프레임 간 밝기만 15% 이내로 숨 쉬며 전체 화면을 물들이는 안개는 금지.
- **신규 재발주: `levelup_emblem_strike` 4프레임.** 투명 PNG, 기준 캔버스 120×260. 엠블럼 중심 `(360,301)`로 내려꽂히는 금빛 전기 줄기, 위쪽에서 시작해 0.28초 안에 수축·소멸. 별/십자/사각 파티클 없음. 적용 줄은 `L('levelup_emblem_strike', 360, 226, 110, 250, 0.07, 0.00, 0.35, loop=False, add=True, alpha=0.90, fade=0.04, back=False)`.

## 2컷 — 최대 및 떠 있는 동안 (2.00초)

### 시안과 다른 점

- 시안은 엠블럼 뒤에 길고 굵은 금빛 방사선이 약 360px 범위로 퍼진다. 재현은 짧고 분홍빛이 섞인 톱니/꽃 모양이라 크기·색·실루엣이 모두 다르다.
- 시안의 세 카드 테두리는 따뜻한 황금색이 순환한다. 현재 `levelup_card_rim` 부품은 회백색 테두리라 재현에서 흰색/청색으로 보인다.
- 시안은 각 카드 아래에서 가늘고 긴 황금 상승광이 올라온다. 재현은 카드 하단에 작은 십자형 섬광만 보여 크기와 위치가 다르고, PD의 별/십자 반짝이 금지 기준도 위반한다.
- 대기 장식은 시안처럼 국소적으로만 빛나야 한다. 현재 값 조정은 화면 전체 착색을 만들지는 않으므로 전면 색막은 추가하지 않는다.

### `layers_levelup()`에서 바꿀 값

- `levelup_emblem_rays`는 1컷 항목의 값 `(360,301), 360×360, step=0.10, t0=0.40, t1=3.80, alpha=0.72, add=True, back=True`로 통일한다. 부품 프레임 자체에서 밝기 변화를 만들고 코드 알파를 더 올리지 않는다.
- 카드별 `levelup_card_rim`: 각 카드 중심 `(148,754)`, `(360,754)`, `(573,754)` 유지. 크기는 `181×346 → 175×336`, `step 0.14 → 0.10`, `t0`는 각각 `0.42 / 0.50 / 0.58`, `t1=3.80`, `alpha 0.50 → 0.68`, `add=True`, `back=False`. 세 카드가 동시에 번쩍이지 않도록 0.08초씩 순차 시작한다.
- 카드별 `levelup_card_rise`: 중심을 `(148,904)/(360,904)/(573,904)`에서 `(148,948)/(360,948)/(573,948)`로 내리고, `90×180 → 104×230`, `step 0.12 → 0.10`, `t0`는 각각 `0.48 / 0.56 / 0.64`, `t1=3.80`, `alpha 0.45 → 0.38`, `add=True`, `back=True`. 카드 아래에서 시작해 뒤로 올라오게 하여 이름·설명을 가리지 않는다.

### 재발주

- **재발주: `levelup_emblem_rays` 4프레임.** 투명 PNG, 기준 캔버스 420×420. 시안처럼 중심이 빈 금빛 방사광 18~24줄, 긴 줄 6~8개와 짧은 줄 혼합. 주황/금색만 사용하고 분홍색 금지. 끝이 별·십자·꽃잎처럼 갈라지지 않게 한다. 네 프레임의 최대 외곽 반경은 고정하고 광량만 `65% → 85% → 100% → 80%`로 변화.
- **재발주: `levelup_card_rim` 4프레임.** 투명 PNG, 기준 캔버스 190×350. 회백색 테두리가 아니라 시안의 주황-금색 얇은 전류가 카드 금속 외곽을 한 바퀴 도는 형태. 카드 내부는 완전 투명, 테두리 두께 5~9px, 외곽광 16px 이내, 사각 파티클·별·십자 없음.
- **재발주: `levelup_card_rise` 4프레임.** 투명 PNG, 기준 캔버스 104×230. 십자형 한 점을 폐기하고, 아래가 밝고 위로 갈수록 가늘어지는 3~5개의 세로 금빛 흐름으로 제작. 밝은 핵은 카드 하단 중앙에만 두고 폭 60px 이내, 별·십자·사각 파티클 없음.

## 3컷 — 선택/수락/구매 (누른 뒤 4.15초)

### 시안과 다른 점

- 시안은 선택한 첫 카드의 테두리가 넓고 따뜻한 금색으로 즉시 확대되며, 나머지 두 카드는 상대적으로 가라앉는다. 재현의 선택 외곽광은 존재하지만 시안보다 좁고 흰 중심이 강하다.
- 시안의 흡수 줄기는 선택 카드에서 시작해 굽은 한 줄기로 엠블럼에 들어간다. 재현은 여러 개의 곧은 선처럼 보이며 `LEVEL UP!` 제목과 `카드를 선택하세요` 문구를 직접 가린다. 이는 PD의 “글자·버튼을 가리지 않게” 기준 위반이다.
- 선택 반응의 시작점 자체는 고른 카드 중심을 쓰고 있어 맞다. 다만 광선이 카드 중심에서 바로 뻗어 카드 본문도 덮으므로, 시작점을 카드 위쪽으로 120px 올려야 한다.

### `layers_levelup()`에서 바꿀 값

- `levelup_pick_flare`: `atNode='BuffCard{slot}'` 유지, `194×358 → 210×378`, `step=0.08`, `t0=0.00`, `t1 0.60 → 0.55`, `alpha` 기본값 `1.00 → 0.78`, `loop=False`, `fade=0.04`, `add=True`, `back=False`. 0.55초 뒤 완전히 꺼서 대기 장식으로 남기지 않는다.
- `levelup_pick_stream`: 현재 `atNode` 중심 `(148,754)`에서 출발하는 방식은 본문과 제목을 가린다. `atNode`를 비우고 선택 슬롯별 시작 좌표를 계산하는 한 줄로 바꿔야 하며, 첫 슬롯 기준 시작점은 `(148,634)`, 목표점은 `(360,301)`이다. `h 70 → 96`, `step=0.06`, `t0 0.05 → 0.04`, `t1 0.60 → 0.52`, `alpha=0.82`, `loop=False`, `fade=0.04`, `add=True`, `back=True`, `beam=True`. 슬롯 1/2의 시작점도 각 카드 중심 x `(360/573)`과 y `634`를 사용한다. `back=True`로 제목·안내·카드 텍스트를 패널이 다시 덮게 한다.
- 선택 phase가 시작되는 순간부터 0.55초 동안은 평상시 카드 `levelup_card_rim`과 `levelup_card_rise`가 보이지 않도록 open 계층의 `t1=3.80`을 유지한다. 선택 뒤 화면 전체를 노랗게 덮는 레이어는 추가하지 않는다.

### 재발주 여부

- `levelup_pick_flare`는 값 조정 후 재사용 가능하다. 다만 현재 부품의 사각 입자가 최종 화면에서 카드 이름/설명 위로 튀면, 입자만 제거한 동일 실루엣으로 재발주한다.
- `levelup_pick_stream`의 원본은 굽은 금빛 줄기라 방향은 시안과 가깝다. 우선 위 값과 `back=True`로 다시 합성한다. 그래도 직선 다발로 보이면 **재발주**: 투명 PNG 4프레임, 기준 캔버스 120×500, 한 개의 S자 금빛 줄기(밝은 핵 10~16px, 외곽광 50px 이내), 가지·평행 직선·별·십자 없음. 카드 쪽이 굵고 엠블럼 쪽이 가늘어지며 프레임마다 굴곡만 조금 변화.

## 글자·버튼 및 합성 방식 확인

- `popup_c_layout.py`의 레벨업 글자 영역과 `consult_popup_typography.md` 규칙은 이번 비교에서 별도 수정 사유가 없다. 제목/안내/카드명/설명은 재현물에서 시안과 같은 위치에 있고, 1·2컷에서는 FX가 글자를 침범하지 않는다.
- 3컷 흡수 줄기만 명백히 제목과 안내를 가린다. 이를 해결하기 전에는 통과 불가다.
- 모든 대기 계층은 국소 가산 합성으로 유지하고, 화면 크기의 덮기/틴트 계층은 만들지 않는다. `levelup_*` 중 덮기(`add=False`)로 바꿀 계층은 없다.
