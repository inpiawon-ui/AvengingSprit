# 팝업 타이포그래피 미리보기 1차 검수 — 한국어

검수 기준은 `consult_popup_typography.md`의 역할별 글자 크기, 실제 Bold/Regular 분리, 같은 묶음의 공통 크기, 외곽선 규칙이다. 대상은 `popup_c_type_ko_*.png` 4종이며 좌표 표기는 `popup_c_layout.py`의 `node()` 값 그대로다. 부모가 있는 노드는 부모 기준 좌표다.

## 총평

폰트 계열과 역할별 위계는 이전보다 통일됐지만, 아직 모든 화면이 같은 타이포그래피 시스템으로 새로 잡힌 인상까지는 가지 못했다. 레벨업은 안정적이고, 회복의 제단은 설명 행의 내부 여백, 악마는 본문과 상단 장식선, 상점은 이름·가격·설명 칸의 밀도가 문제다.

실제 글자가 프레임 바깥으로 완전히 잘린 노드는 없다. 다만 상점 이름과 가격은 정의상 2px 겹치고, 악마 본문은 프레임 장식 위에 걸쳐 보여 사실상의 충돌이다. 같은 역할을 묶은 자동 축소 때문에 상점 설명 6개가 모두 가장 긴 문장에 맞춰 작아진 것도 크게 보인다.

## 1. 레벨업 — `BuffChoicePanel`

### 보이는 문제

- `BuffTitleText`: 삐져나감이나 테두리 접촉은 없다. 다만 현재 굵은 고딕은 아래의 `BuffSubText`, 카드 이름과 같은 계열로 읽혀 장식 제목의 개성이 약하다.
- `BuffSubText`: 칸 중앙과 상하 여백이 안정적이다.
- `BuffCard0/1/2Name`, `BuffCard0/1/2Desc`: 카드 경계 밖으로 나가거나 서로 겹치지 않는다. 이름 3개, 설명 3개의 크기도 각각 통일돼 있다.
- `BuffCard0/1/2Desc`: 외곽선이 없는 낮은 명도의 Regular라 배경이 밝은 부분에서 약간 묻힌다. 위치 문제는 아니며 공통 본문 외곽선 규칙을 적용하면 해결된다.

### 변경값

- `BuffTitleText`: 좌표와 칸 `x=176, y=162, w=349, h=80` 및 크기 34는 유지한다. 이 노드만 폰트를 `OriginalPixel`로 지정한다. `role='title'`, 색 `#FFC83D`, 중앙 정렬은 유지한다.
- `BuffCard0Desc`, `BuffCard1Desc`, `BuffCard2Desc`: 좌표·칸·역할은 유지하고 아래의 공통 `desc` 외곽선 수정만 받는다.
- 그 밖의 레벨업 노드는 변경하지 않는다.

### `LEVEL UP!` 제목 선택

**픽셀 폰트 장식을 유지한다.** 이 문구는 번역되지 않는 짧은 영문 표식이고, 가이드가 `LEVEL UP` 같은 12자 이하 고정 영문 장식에 `OriginalPixel`을 허용한다. 고딕으로 바꾸면 카드명·안내문과 같은 정보 텍스트처럼 보여 위계가 평평해진다. 픽셀 제목은 상단 HUD의 픽셀 문자와 팝업의 기계 장식을 연결하는 표식으로 기능한다. 단, CJK가 섞이거나 번역되는 제목에는 이 예외를 확대 적용하지 않는다.

## 2. 회복의 제단 — `ShrinePanel`

### 보이는 문제

- `ShrineChoice0Desc`, `ShrineChoice1Desc`, `ShrineChoice2Desc`: 설명 칸 높이가 26px뿐이라 16px Regular 글자와 외곽선을 담을 상하 여유가 부족하다. 설명이 슬롯의 아래 금속 테두리에 붙어 보인다.
- 위 세 설명과 `ShrineChoice0/1/2Icon`: 아이콘은 슬롯 기준 `x=10, w=56`으로 x=66에서 끝나고 텍스트는 x=76에서 시작하므로 실질 간격이 10px뿐이다. 외곽 광원과 글자 외곽선을 고려하면 답답하다.
- `ShrineChoice0/1/2Text`: 이름과 설명의 시작선은 같지만 아이콘 광원 때문에 첫 글자가 잠식돼 보인다. 세 행 자체의 정렬은 통일돼 있다.
- `ShrineTitleText`, `ShrineHintText`: 삐져나감·접촉·겹침이 없다. 변경 불필요다.

### 변경값

세 선택지에 같은 값을 적용한다.

- `ShrineChoice0`, `ShrineChoice1`, `ShrineChoice2`: `w=407` 유지, `h: 78 -> 82`.
- `ShrineChoice0Text`, `ShrineChoice1Text`, `ShrineChoice2Text`: `x: 76 -> 84`, `y=8`, `w: 300 -> 288`, `h=30`, `role='name'`, 좌측 정렬 유지.
- `ShrineChoice0Desc`, `ShrineChoice1Desc`, `ShrineChoice2Desc`: `x: 76 -> 84`, `y: 38 -> 42`, `w: 300 -> 288`, `h: 26 -> 28`, `role='desc'`, `nowrap=True`, 좌측 정렬 유지.
- 설명 색: `#9FDCE6 -> #B9EEF2`. 청록 계열은 유지하되 Regular 본문이 슬롯의 청록 광원에 묻히지 않게 명도만 올린다.
- 선택지의 화면 내 y값(`fy=(186, 282, 375)`, 노드 y=`fy-4`)은 유지한다. 높이 증가 뒤에도 행 사이 최소 11px가 남아 서로 겹치지 않는다.

## 3. 악마 — `EventPanel`

### 보이는 문제

- `EventBodyText`: 첫 줄이 제목 프레임의 아래 가로 장식선과 같은 높이에서 시작해 선이 글자 뒤를 통과한다. 글자 칸은 프레임 안이지만 시각적으로 테두리에 걸친다.
- `EventBodyText`와 `EventRewardPill`/`EventCostPill`: 본문을 단순히 아래로 내리면 값 칸과 붙을 수 있으므로 본문 높이를 함께 줄여 중앙을 아래로 이동해야 한다.
- `EventRewardText`와 `EventCostText`: 같은 `event_pair` 크기, 같은 세로 위치라 안정적이다. 색 구분도 역할에 맞다.
- `EventAcceptText`, `EventDeclineText`: 버튼 경계 안에 충분히 들어오며 서로 겹치지 않는다.

### 변경값

- `EventBodyText`: `x=80`, `w=500` 유지. `y: 182 -> 198`, `h: 88 -> 70`. `role='body'`, 중앙 정렬, 최대 3줄 규칙은 유지한다. 화면 절대좌표는 `(110, 570)`이 된다.
- `EventBodyText` 색은 `#C9D1D8` 유지. 위치를 바로잡은 뒤에도 배경 대비가 충분하며, 색을 더 밝히면 제목·값과 경쟁한다.
- `EventRewardPill`, `EventRewardText`, `EventCostPill`, `EventCostText` 이하 노드는 이동하지 않는다. 변경 후 본문 실제 2줄과 값 칸 사이에 별도 호흡이 생긴다.
- `EventBodyText`는 아래의 공통 `body` 외곽선 수정만 추가로 받는다.

## 4. 상점 — `ShopPanel`

### 보이는 문제

- `ShopItem0~5Name`과 `ShopItem0~5Price`: 이름 칸은 `x=76, w=118`이라 x=194까지 차지하고 가격 칸은 x=192에서 시작한다. 정의상 2px 겹친다. 캡처에서도 이름과 가격이 한 덩어리처럼 붙는다.
- `ShopItem0~5Desc`: `h=44`는 16px 두 줄과 행간을 담기 부족하여 `shop_desc` 묶음 전체가 최소 크기 쪽으로 축소된다. 가장 긴 설명 하나 때문에 짧은 설명까지 작아져 카드마다 빈 공간과 글자 밀도가 어색하다.
- `ShopItem0~5`: 현재 폭 260px에서는 아이콘, 이름, 가격의 안전 간격을 동시에 만들 여유가 작다. 두 열 사이에는 21px가 있으므로 각 슬롯을 10px 넓혀도 11px 간격을 확보할 수 있다.
- `ShopLeaveText`: 버튼 중앙에 안정적으로 들어온다. 다만 카드 높이를 늘리면 버튼도 내려야 한다.
- `ShopTitleText`, `ShopGoldText`, `ShopLimitText`: 삐져나감·접촉·겹침이 없다.

### 변경값

6개 상품에 모두 같은 값을 적용한다.

- `ShopItem0`~`ShopItem5`: `w: 260 -> 270`, `h: 83 -> 91`. 기존 x와 행 y `(179, 277, 374)`는 유지한다.
- `ShopItem0~5Name`: `x=76`, `y=5`, `w: 118 -> 116`, `h=30`, `role='name'`, 좌측 정렬과 `group='shop_name'` 유지.
- `ShopItem0~5Price`: `x: 192 -> 202`, `y=5`, `w=62`, `h=30`, `role='value'`, `group='shop_price'` 유지. 이름 칸 끝 x=192와 가격 시작 x=202 사이에 10px를 확보한다.
- `ShopItem0~5Desc`: `x: 78 -> 76`, `y: 36 -> 37`, `w: 176 -> 188`, `h: 44 -> 48`, `role='desc'`, 좌측 정렬과 `group='shop_desc'` 유지. 2줄 16px가 들어갈 높이와 폭을 확보해 공통 크기가 불필요하게 14px로 내려가는 것을 막는다.
- `ShopLeaveButton`: `y: 460 -> 472`, `w: 276 -> 296`, x는 가운데 정렬을 위해 `207 -> 197`, h=64 유지.
- `ShopLeaveText`: 부모 기준 `w: 276 -> 296`, h=64 유지.
- 세 번째 상품 행은 y=374, h=91로 y=465에서 끝나고 버튼은 y=472에서 시작하므로 7px 간격이 남는다. 버튼은 y=536에서 끝나 `ShopBox` 높이 545 안에 들어온다.

## 공통 `ROLES` 수정

가이드에는 본문도 얇은 외곽선을 쓰도록 되어 있으나 현재 `desc`, `body`는 외곽선 값이 0이다. 좌표 수정과 함께 다음 두 항목만 고친다.

```python
'desc': (False, 16, 14, 0.06, 0.08, '#07101ACC', '#C9D1D8', 2),
'body': (False, 19, 17, 0.06, 0.08, '#07101ACC', '#C9D1D8', 2),
```

`heavy=False`와 Regular 폰트는 그대로 둔다. 굵기를 올리지 않고 얇은 외곽선만 더해야 제목·이름과 위계가 섞이지 않는다. 나머지 역할의 크기·색·외곽선은 수정하지 않는다.

## Claude가 바로 적용할 변경 목록

1. `ROLES['desc']`, `ROLES['body']`를 각각 dilate `0.06`, outline `0.08`, outlineColor `#07101ACC`로 변경한다.
2. `BuffTitleText`만 `OriginalPixel` 폰트 예외로 지정한다. 좌표, 34px 상한, 노란색은 유지한다.
3. 제단 선택지 3개의 높이를 82로 늘리고, 이름/설명을 `x=84`로 맞춘다. 설명은 `y=42, w=288, h=28`, 색 `#B9EEF2`로 변경한다.
4. `EventBodyText`를 `x=80, y=198, w=500, h=70`으로 변경한다. 다른 악마 노드는 이동하지 않는다.
5. 상점 상품 6개를 `270 x 91`로 변경한다. 이름은 `x=76,w=116`, 가격은 `x=202,w=62`, 설명은 `x=76,y=37,w=188,h=48`로 통일한다.
6. `ShopLeaveButton`을 `x=197,y=472,w=296,h=64`, 자식 `ShopLeaveText`를 `0,0,296,64`로 변경한다.
7. 적용 후 한국어 캡처에서 제단 설명의 아이콘/하단 테두리 간격, 악마 본문과 상단 장식선, 상점 이름-가격 10px 간격 및 설명 16px 공통 크기만 재확인한다.
