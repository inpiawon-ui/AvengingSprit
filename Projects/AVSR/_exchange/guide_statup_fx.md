# 호스트 성장 — 능력치 강화(레벨업) 연출 가이드

> PD 2026-10-26 원문: 「스텟업을 할 때 녹색 이펙트가 있는데 저것도 먼가 따로 노는 느낌이야 노란색으로 레벨업 하는 느낌으로 바꿔줘 먼가 지금은 녹색 레이저 같애」
> 「레벨업 연출은 먼가 용암이 약하게 올라온다던가 저거 코덱스랑 상의 해서 진행해봐 니가 하지말고 지금 먼가 이상해」
> 브리프: `codex_brief_fx.md` 0-2절(호스트 성장 강화 = 금 · 노랑, 약~중)

## 목표 모습
능력치 칸 하나를 누르면 **그 칸 아래쪽에서 따뜻한 금빛이 용암처럼 약하게 차올랐다가** 가라앉는다.
차오르는 빛 위로 작은 불씨 알갱이가 몇 개 떠오르고, 값 글자가 톡 커지며 「올랐다」가 읽힌다.
빛은 칸 판 안에서만 — 옆 칸 · 위 영웅 칸으로 번지지 않는다.

## 무게
- 얼마나 자주: **아주 자주** — 한 번 누를 때마다, 길게 누르면 연속(약 0.1초 간격)으로 난다.
- 등급 없음. 그래서 세기는 **약~중**. 화면을 덮거나 번쩍이면 연속 강화 때 눈이 피곤하다.
- 연속일 때는 매번 새로 터지지 않고 **차오른 빛이 유지되며 출렁**이는 쪽이 낫다(머묾).

## 박자표 (한 번 누름)
| 시각 | 박자 | 강약 | 보이는 것 |
|---|---|---|---|
| 0.00 | 누름 | 중 | 칸 아래 테두리 안쪽에서 금빛(용암색 `#FFB83D` ~ `#FFDB52`)이 번지기 시작 |
| 0.05~0.20 | 차오름 | 중 | 빛이 칸 높이의 아래 1/3~1/2 까지 일렁이며 올라옴(물결 같은 윗면) · 불씨 알갱이 3~5개 위로 |
| 0.12 | 값 | 중 | 다음 값 글자가 톡(1.15배) · 금빛 테두리가 한 번 살짝 빛남 |
| 0.20~0.45 | 가라앉음 | 약 | 빛이 아래로 빠지며 사라짐 · 알갱이는 위에서 꺼짐 |
| 연속(길게 누름) | 머묾 | 약 | 차오른 빛이 아래 1/3 에 머물며 누를 때마다 살짝 출렁 · 알갱이 계속 몇 개씩 |

## 층
뒤 → 앞: 칸 판 → **부드러운 금빛 번짐(광원)** → **도트 결의 일렁이는 용암 윗면 · 불씨(모양)** → 글자 · 아이콘 → 떠오르는 작은 빛 알갱이.

## 피할 것 (짧게)
- 칸을 가로지르는 가는 빛줄기(지금 반려된 「녹색 레이저」) · 초록색
- 글자 · 숫자 · 금화 버튼을 덮는 빛
- 별 모양 섬광이 글자 한가운데서 터지는 것(지금 노란 빛살 — PD 「이상하다」)

## 요소 · 무엇으로 · 이유
| 요소 | 무엇으로 | 이유 |
|---|---|---|
| 칸 아래 도트 용암 물결 줄(산 모양 · 일렁임) | **그림 프레임**(가로 띠 8장 반복) | 도트 결의 모양이 움직여야 한다 — 크기 · 알파로는 물결이 안 일렁인다 |
| 용암 뒤 부드러운 금빛 번짐 · 칸 테 둘레 빛 | **빛 그림 1장**(가산) + 코드로 숨쉬기 · 누를 때 밝게 | 부드러운 광원(브리프 1절) — 프레임이 필요 없는 번짐 |
| 떠오르는 반짝이(점 · 작은 십자 · 마름모) | **파티클**(입자 그림 3종) | 여기저기 켜지고 오르는 것 — 수 · 수명 · 크기 곡선으로 |
| 누를 때 차오름 | 코드 — 용암 줄을 위로 0.2초 올렸다 내림 + 번짐 밝게 | 같은 그림을 쓴다(PD 「약간 차오르고」) |
| 누를 때 작은 터짐 | 파티클 — 같은 입자 4~6개가 칸 아래에서 튐 + 값 글자 톡 | 「약간의 터지는 것」 — 새 그림 없이 |
