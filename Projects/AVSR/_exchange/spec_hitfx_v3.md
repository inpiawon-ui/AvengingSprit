# 공통 피격 이펙트 설계 v3

## 0. 설계 기준

| 항목 | 기준 |
|---|---|
| 화면 / 캐릭터 | 세로 720×1280, 적 몸 약 90×140px. 아래 수치는 **720×1280 실기준 px** |
| 방향 벡터 | `D = 발사자에서 피격점으로 날아온 진행 방향`. 적의 앞면은 `-D` 쪽, 등 뒤는 `+D` 쪽 |
| 공통 문법 | 원·타원·고리·원뿔·사다리꼴의 빛, 불똥·무정형 작은 파편·알갱이만 사용 |
| 금지 | 표창, 별, 칼자국/X자 베기, 칼 표식, 총구 화염, 탄피, 탄두, 방패 그림, 실제 쇠판 그림 등 특정 무기·물체로 읽히는 형태 |
| 색 원칙 | 보통=흰색, 치명=금빛 노랑, 유리=주황, 불리=회색. 파워 빨강·무기 청록/금·마법 보라는 섞지 않음 |
| 숫자 / 표식 | 보통 흰 숫자, 치명 큰 금색 숫자, 유리 주황 숫자+주황 ▲, 불리 작은 회색 숫자+회색 ▼. 이펙트 본체는 화살표 없이도 의미가 읽혀야 함 |
| 폭발탄 | 수류탄·미사일은 자체 폭발을 사용하되, 판정 피드백이 필요하면 아래 코어/숫자만 얹고 공통 파편 폭발은 중복하지 않음 |

### 1-3. 유리 / 불리 판독 잠금 규칙

| 판독 요소 | 상성 유리 | 상성 불리 |
|---|---|---|
| 충격 종료 위치 | 적의 **등 뒤 `+D`** | 적의 **앞면**, 몸 진입 전 |
| 큰 덩어리 | 뒤로 갈수록 넓어지는 주황 원뿔 | 앞면에 수직으로 선 회색 사다리꼴 빛 평면 |
| 입자 흐름 | 100% `+D`, 발사자에게서 멀어짐 | 100% `-D`, 발사자에게 돌아감 |
| 적 몸 | 주황 빛이 몸을 가로질러 뒤까지 연결, 3px 밀림 | 등 뒤 빛 0, 이동·경직 0; 앞면만 번쩍 |
| 정지 프레임에서 읽을 단서 | **작은 입구 → 몸 관통 → 큰 출구** | **넓은 차단면 → 역방향 꼬리** |

유리와 불리는 색만 바꾼 동일 폭발이 아니다. 원뿔/차단면, 몸 뒤/몸 앞, 순방향/역방향, 적 밀림/무반응을 모두 반대로 고정한다.

## 2. 연사 시 축약 규칙

| 조건(동일 적 기준) | 유지 | 줄임 / 생략 | 비고 |
|---|---|---|---|
| 0~8 hit/s | 위 사양 100% | 없음 | 단발·느린 연사 |
| 9~20 hit/s | 코어 매 hit, 숫자 합산, 방향 문법 유지 | 고리 2발당 1회; 파티클 60%; 몸 플래시 재점등 간격 0.06s | 숫자는 0.12s 창으로 합산 후 갱신 |
| 21 hit/s 이상 | 6×6~12×10px 코어 매 hit; 유리 `+D` 꼬리 또는 불리 `-D` 튕김은 매 hit 최소 1개 | 고리 4발당 1회; 보통 파편 2개; 유리/불리 파편 3개; 플래시 0.09s 쿨다운 | 동시 활성 파티클: 적 1명당 18개, 화면 전체 80개 상한 |
| 같은 자리 0.08s 내 중첩 | 최신 피격 방향으로 코어 회전/갱신 | 새 코어를 계속 적층하지 않고 기존 코어 수명만 최대 0.04s 연장 | 흰 덩어리로 뭉개지는 것 방지 |

- 연사에서도 **유리의 등 뒤 출구**와 **불리의 앞면 차단+역류**는 삭제 금지다. 수량을 줄여도 방향 단서는 남긴다.
- 숫자는 개별 생성 대신 0.12s 동안 누적하고 마지막 타격 후 위로 띄운다. ▲/▼는 숫자 왼쪽에 한 번만 유지한다.
- 치명은 연사 축약보다 우선하며 화면 정지는 0.25s 쿨다운을 둔다. 쿨다운 중 치명은 큰 금색 고리와 숫자는 유지하고 정지만 생략한다.
- 지속 레이저·화염·독은 0.10s 간격의 시각 틱으로 제한한다. 판정 틱이 더 빨라도 새 이펙트는 합산 갱신한다.

## 3. 판정이 겹칠 때

| 조합 | 합성 방식 | 숫자 / 표식 | 적 반응 | 금지 |
|---|---|---|---|---|
| 치명 + 유리 | **주황 관통 구조를 골격으로 유지**: 작은 앞 입구 + 몸 통과 빛기둥 + 등 뒤 `+D` 원뿔. 출구에 금빛 치명 고리 1개(72px)와 금빛 방사 파편 5개를 추가 | 큰 금색 숫자. 바로 왼쪽에 주황 ▲; ▲는 숫자 높이의 55% | 5px `+D` 밀림, 0.12s 경직, 흰→금 플래시 0.09s, 정지 0.045s | 전체를 금색 원형 폭발로 덮어 관통 방향을 지우지 않음. 주황을 금색으로 치환 금지 |
| 치명 + 불리 | **회색 차단 구조를 골격으로 유지**: 앞면 차단면 + `-D` 역류. 차단 순간 금빛 얇은 고리 1개(68px)를 앞면에만 추가하고, 금빛 불똥 4개도 `-D`로 튕김 | 큰 금색 숫자. 바로 왼쪽에 회색 ▼; ▼는 숫자 높이의 55% | 적 이동 0px 원칙 유지, 자세 경직 없음, 앞면 흰→회색 플래시 0.07s, 정지 0.035s | 치명이라는 이유로 적을 밀거나 몸 뒤에 폭발 생성 금지. 회색 역류를 금빛 방사로 덮지 않음 |

합성 우선순위는 **상성의 공간 문법 > 치명의 규모·타격감 > 숫자**다. 치명은 크기와 순간 정지를 더하지만, 유리/불리의 진행 방향을 바꾸지 않는다.

## 4. 시안 발주문

### 납품 목적

한 화면만 보고 보통·치명·상성 유리·상성 불리의 차이를 검토하는 게임플레이 합성 시안. 예쁜 일러스트보다 **실제 720×1280 전투 화면에서의 판독성, 특히 유리와 불리의 반대 방향**을 검증한다.

### 화면 구성

| 항목 | 발주 내용 |
|---|---|
| 캔버스 | 720×1280 세로, 실제 게임 카메라 배율. 어두운 중성 전투 바닥, 의미색과 충돌하는 강한 배경색 금지 |
| 플레이어 | 화면 아래 가운데. 위쪽을 향해 총을 쏘는 동일 플레이어 1명. 총은 상황 설명용으로 작게 보이되 총구 화염·탄피는 표현하지 않음 |
| 적 | 동일 외형·동일 크기(몸 약 90×140px) 4명. 화면 위쪽에 가로로 충분히 간격을 두어 배치. 왼쪽부터 **보통 / 치명 / 상성 유리 / 상성 불리** |
| 탄도 방향 | 네 적 모두 플레이어에서 적을 향하는 방향 `D`, 즉 대체로 화면 아래→위. 얇고 희미한 탄도선은 시안 설명용으로만 허용하며 최종 이펙트 형태로 보이지 않게 함 |
| 라벨 | 검토용으로 각 적 위에 작은 중성색 텍스트 `보통`, `치명`, `유리`, `불리`. 이펙트와 겹치지 않음 |
| 순간 선택 | 각 이펙트의 방향이 가장 잘 보이는 피격 직후 0.05~0.09s 순간을 한 프레임에 합성 |

### 네 적에 그릴 것

| 적 | 시안 표현 |
|---|---|
| 보통 | 몸 앞 피격점에 38×34px 이내의 작은 흰 코어·얇은 고리·미세 파편 5개. 흰 숫자. “톡” 크기이며 몸을 가리지 않음 |
| 치명 | 피격점 중심 96×88px 금빛 노랑 충격 고리 2겹, 짧은 추상 광선과 파편. 보통보다 면적과 밝기가 명백히 큼. 큰 금색 숫자. 특정 무기 모양 없이 “쾅” |
| 상성 유리 | 주황 ▲와 주황 숫자. 적 앞(플레이어 쪽)에는 작은 입구만 두고, 가는 주황 빛이 몸을 관통하여 **적 등 뒤, 즉 화면 위쪽 `+D`로 82px 원뿔 폭발**. 원뿔은 적에게서 멀어질수록 넓고, 주황 파편 9개도 전부 화면 위쪽으로 뻗음. 적은 3px 위로 밀린 순간 |
| 상성 불리 | 작은 회색 숫자와 회색 ▼. 적 앞면, 즉 플레이어를 향한 화면 아래쪽 면에 폭 58px의 밝은 회색 사다리꼴 **차단 번쩍임**. 적 몸 안과 등 뒤에는 빛이 없음. 회색 알갱이 8개와 짧은 빛꼬리 3개가 **화면 아래쪽 `-D`, 플레이어 쪽으로 되튕김**. 적 자세와 위치는 완전히 그대로 |

### 유리·불리 필수 비교 구도

- 유리 적 주변의 가장 큰 주황 덩어리는 반드시 **적 등 뒤(화면 위)**에 둔다.
- 불리 적 주변의 가장 큰 회색 덩어리는 반드시 **적 앞(화면 아래)**에 둔다.
- 유리 파편의 끝점은 적에게서 멀어지는 위쪽, 불리 파편의 끝점은 플레이어에게 돌아오는 아래쪽이다.
- ▲/▼와 숫자를 가리고 보아도 `작은 입구→뒤쪽 큰 출구` 대 `앞 차단면→되튕김`으로 즉시 구분되어야 한다.
- 네 효과의 중심 간 여백을 확보해 서로 겹치지 않게 한다.

### 절대 금지 체크

| 금지 항목 | 판정 기준 |
|---|---|
| 특정 무기 형상 | 표창, 별, 칼자국, X자 베기, 칼 표식, 총구 화염, 탄피, 탄두가 한 개라도 보이면 반려 |
| 불리의 물체화 | 실제 방패나 금속판을 그리지 않음. ‘쇠판 번쩍’은 **평평한 회색 사다리꼴 빛면과 튕김 운동**으로만 표현 |
| 속성색 혼입 | 빨강·청록·보라를 공통 피격 본체에 사용하지 않음. 금색은 치명에만 사용 |
| 유리/불리 동일화 | 같은 방사형 폭발에 색만 바꾸는 구성 금지 |
| 방향 오류 | 유리의 주 파편이 플레이어 쪽으로 오거나, 불리의 주 파편이 적 등 뒤로 나가면 반려 |
| 과대 가림 | 이펙트가 적 몸 전체를 장시간 가려 실루엣과 반응을 읽을 수 없으면 반려 |
