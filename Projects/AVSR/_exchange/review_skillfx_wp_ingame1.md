# 무기 속성 스킬 이펙트 인게임 1차 검수

검수 범위는 `03_amazon`, `02_thug`, `05_hopper_smg`, `06_commando_mg`, `01_gangster`, `15_ninja`다. 호퍼 「정조준」과 갱스터 `gaexec`은 제외했다. 시간은 컷인 종료 뒤인 1.00초부터 보았다. 노란 별 공통 타격 이펙트와 이미 인지한 방벽 전개 초반 파란 쉴드 거품, 난사의 잦은 청백 코어는 아래 수정 목록에서 반복하지 않았다.

## 아마존 — 도약 강타

1. **판정: 손볼 것 있음**
2. **손볼 것**
   - 착지 펄스를 현재 원형에 가까운 표시에서 **156×52px(타격) → 168×56px(여운)**의 바닥 타원으로 고정한다. 중심은 시전자 몸이 아니라 **실제 착지 발밑**, 진하기는 타격 **55%**, 여운 **35→0%**, 전체 노출은 **0.33초(0.05+0.28초)**로 제한한다.
   - 큰 청색 파편은 **착지점 바깥 반경 24~72px**에만 **총 6개**, 크기 **12~24px**, 진하기 **40% 이하**로 둔다. 1.20~1.65초처럼 적마다 다시 크게 생기는 파편은 빼고 **착지 1회에만** 낸다.
   - 몸을 둘러싼 원형 고리는 빼고, `amland`는 착지 발밑에 **128×64px**, 진하기 **50%**, **0.28초**만 남긴다.
3. **예전보다 나아졌는지:** 회색 폭발 구름과 적색 광막은 사라져 훨씬 나아졌지만, 현재는 착지 하중보다 원형 고리와 반복 파편이 먼저 읽힌다.

## 터그 — 난사

1. **판정: 손볼 것 있음**
2. **손볼 것**
   - 세 갈래 탄도를 **청록 3px**, 진하기 **45%**, 각 **0.10초 이하**로 보이게 하고 **가운데→좌→우를 0.03초씩** 어긋나게 한다. 세 선이 동시에 켜지거나 다음 총구 섬광까지 남지 않게 한다.
   - 스킬 구간의 기존 주황 탄환·불덩이 잔선은 빼고, 총구 섬광은 **26px**, 진하기 **100% 1장(0.025초)**만 둔다.
   - 끊긴 잔선은 타격점 뒤쪽에 **2개**, 굵기 **1~2px**, 진하기 **30% 이하**, **0.18초**만 남긴다.
3. **예전보다 나아졌는지:** 화면 절반을 차지하던 굵은 주황 세 줄은 없어졌지만, 청록 3방향의 순차 발사 박자가 아직 한눈에 잡히지 않는다.

## 호퍼 SMG — 도약 강습

1. **판정: 통과**
2. **손볼 것:** 없음. 도약 뒤 `hsinv`가 몸 바깥에 붙고 얼굴과 몸통이 계속 보여 무적 상태로 읽힌다. 종료 페이드는 제공 구간이 2.05초까지라 확인 대상 밖이다.
3. **예전보다 나아졌는지:** 예전의 주황 불티와 무관한 피격 잔해 대신 얇은 청록 윤곽이 남아, 도약과 2초 무적의 인과가 훨씬 명확하다.

## 코만도 MG — 방벽 전개

1. **판정: 통과**
2. **손볼 것:** 없음. `cmwall`은 약 **112px** 크기로 몸 바깥에 서고 중앙이 비어 있으며, 청록 분절과 황금 결절이 지속 상태로 안정적으로 읽힌다.
3. **예전보다 나아졌는지:** 예전의 작은 원형 외피보다 방벽의 형태와 지속 상태가 명확하고, 캐릭터 실루엣도 덜 가린다.

## 갱스터 — 일제 표식

1. **판정: 통과**
2. **손볼 것:** 없음. 1.05~1.10초에 가는 주사선 뒤 여러 적의 몸 바깥에 표식이 함께 생기고, 이후 약 **58px / 55%**의 얇은 괄호로 따라붙는다. `gaexec`은 이번 판정에서 제외한다.
3. **예전보다 나아졌는지:** 화면 전체 황색 틴트와 큰 불덩이가 사라지고, 스킬 목적이 다중 적 표식으로 바로 읽힌다.

## 닌자 — 그림자 분신

1. **판정: 손볼 것 있음**
2. **손볼 것**
   - 전체 화면 1.0~2.4초 연속 컷에서도 분신이 보이지 않는다. 기존 닌자 몸 스프라이트를 **원본과 같은 크기·같은 애니메이션 프레임**, 진하기 **생성 45% / 유지 38~48%**로 복제해 **방 중앙(720×1280 기준 x=360±20, 전투 바닥 중앙 y=600±40)**에 둔다.
   - 분신은 생성 뒤 **4.73초 유지**, 종료 때 **0.15초 동안 30→0%**로 내린다. 원본이 이동하거나 자세가 바뀌어도 분신 위치는 방 중앙에 고정하고 스프라이트 프레임만 따라가게 한다.
   - 분신 바깥 `wpstate`는 **96px**, 진하기 **30%**, 프레임당 **0.10초**로 반복한다. 원본 몸에는 붙이지 않는다.
   - 1.30~2.05초에 계속 보이는 흰 수리검은 빼고, 생성 접점의 `wppulse`만 발밑 **82×28px / 0.05초**, 파편은 **44px 범위 4개 / 0.05초**로 끝낸다.
   - **새 그림 필요: 없음.** 기존 닌자 몸 스프라이트 복제로 처리한다.
3. **예전보다 나아졌는지:** 예전의 큰 폭발과 주황 불티는 줄었지만 핵심인 반투명 분신이 없어, 현재는 예전보다 스킬 정체성이 약하다.
