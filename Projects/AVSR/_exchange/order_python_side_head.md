# 발주 — 파이썬 옆보기 머리 (샘플 1장)

## 배경

`AVENGING SPIRIT: RE:BORN` 의 보스 3 「파이썬」은 거대한 뱀이다.
탑뷰 2D 픽셀아트 게임이고, 방은 위에서 내려다본 시점이다.

파이썬은 방 위쪽 벽에 뚫린 아치 구멍에서 **머리만 내밀고** 싸운다.
그런데 스킬 하나(「몸통 밀기」)에서는 머리가 왼쪽 벽 밖에서 나와
**방을 가로질러 오른쪽으로 지나간다.** 몸통이 그 뒤를 따른다.

지금 이 장면에 쓸 그림이 없어서, 정면 머리(`unit_python_s_out4.png`)를
90도 돌려 쓰고 있다. 그래서 **머리의 명암 방향이 몸통과 직각으로 어긋나고,
머리 두께가 몸통 두께의 절반**이라 따로 노는 것으로 보인다.

**오른쪽을 보는 머리 그림 한 장**이 필요하다.

## 만들 파일

```
크기:   256 × 256, PNG RGBA
```

## 그림 내용

- 뱀 머리가 **오른쪽(+x)을 향한다.** 주둥이·입이 오른쪽 끝이다.
- 시점은 **몸통 그림과 같은 시점**이다. `obj_python_body_1.png` 를 보면
  마디의 **위쪽은 초록(등), 아래쪽 가장자리는 주황(배)** 이다.
  머리도 **위쪽 초록 / 아래쪽 주황**이어야 한다. 이게 이번 발주의 핵심이다 —
  지금 틀린 것이 바로 이 방향이다.
- 눈은 **위에서 내려다본 자리**, 즉 머리 등쪽 위에 하나가 보이는 형태로 둔다
  (정면 그림처럼 두 눈이 나란히 오면 안 된다).
- 입은 **다물고 있다.** (이 파일은 지나가는 4장 중 1번, 기본 자세다)
- 왼쪽 끝(x 작은 쪽)은 **목이 이어질 자리**다. 잘린 단면처럼 두지 말고
  `obj_python_body_1.png` 의 마디와 자연스럽게 맞물리게 둔다.

## 지켜야 할 수치 (이대로 안 나오면 반려된다)

| 항목 | 값 | 왜 |
|---|---|---|
| 캔버스 | 256 × 256 | 유닛 시트 규격 |
| 불투명 세로 범위 | **y 67 ~ 189 안에 들어간다** (높이 122px 내외) | 몸통 마디의 불투명 높이(122px)와 같아야 목·몸과 두께가 맞는다 |
| 불투명 세로 **중심** | **y = 128 ± 3** | 지나갈 때 몸통 줄 한가운데에 놓인다 |
| 불투명 가로 범위 | x 40 ~ 250 안 (길이 180~210px) | 몸통 한 마디(240px)보다 짧아야 머리로 읽힌다 |
| 주둥이 끝 | 오른쪽, x ≥ 240 | 진행 방향이 얼굴이어야 한다 |
| 마젠타 픽셀 | **0개** (R>200 & B>200 & G<100) | 예전 납품에서 1px 외곽선이 섞여 반려된 적 있다 |
| 배경 | 완전 투명 (alpha 0) | |
| 안티에일리어싱 | 쓰지 않는다. 픽셀 경계는 딱딱하게 | 도트 게임이다 |
| 등(위쪽) 평균색 | 초록 계열, G > R 이고 G > B | `obj_python_body_1` 과 맞춘다 |
| 배(아래쪽 가장자리) 평균색 | 주황 계열, R > G > B | `obj_python_neck_1`(192/89/22) 과 맞춘다 |

## 만드는 방법 — 자유지만 권장

`unit_python_s_out4.png` 를 열어 색을 직접 뽑아 쓰면 화풍이 어긋나지 않는다.

**중요한 것은 결과물이 위 수치를 만족하고 몸통과 같은 시점으로 보이는 것**이다.
