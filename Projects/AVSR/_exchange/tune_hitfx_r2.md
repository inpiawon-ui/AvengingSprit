# 피격 FX 수치 조정표 r2

기준 시안: `mock_hitfx_v7.png`  
현재 비교: `compare_r1.png`의 맨 위 시안과 0.035 / 0.075 / 0.125초 게임 캡처(2배)  
r1의 새 값을 현재 값으로 본다. 표의 크기와 거리는 **HxScale 적용 전 입력값**이며 화면 예상치는 입력값 × 1.15이다. 색은 선형 `Color(r,g,b,a)` 입력값이다.

## 판정

**불합격.** 보통과 치명의 크기·방향성은 목표에 가까워졌지만, 유리와 불리는 밝은 회색 바닥에서 더하기 혼합 때문에 색 몸통과 낱알 실루엣이 소실됐다. 유리는 주황 원뿔이 아니라 흰 빛기둥, 불리는 은빛 불티가 아니라 흰 얼룩으로 읽힌다. 넷째 적의 노란 해골 그림은 판정에서 제외한다.

## 1. 시안 대비 r1 결과의 오차

시안의 적 몸통 폭을 약 70 px로 두고 밝은 외곽을 쟀다. 블룸과 2배 확대 보간을 포함한 측정 오차는 약 ±3 px이다.

| 경우 | 시안에서 잰 형태 | r1 적용 결과 | 판정 |
|---|---|---|---|
| 보통 | 흰 중심 약 22×22 px, 잔광 약 34×34 px, 둥근 파편 5개가 중심에서 18~42 px | 0.035초 중심은 약 25~29 px로 시안보다 조금 크고, 0.075초에는 둥근 점 3~4개가 읽힌다. 0.125초 잔광은 적당하다 | 거의 통과. 중심만 약 10% 축소하고 파편은 유지 |
| 치명 | 백색 중심 약 28 px, 금빛 폭발권 약 62~68 px, 가는 방사광 8개가 반경 35~62 px, 둥근 불티 10~12개 | 중심 백광이 약 42~48 px로 커서 몸통과 숫자를 덮는다. 금빛은 흰색에 밀리고, 0.075~0.125초 고리·방사광이 두꺼워 마름모/별 외곽처럼 붙는다 | 중심 20% 축소. 고리와 방사광 폭을 줄이고 금색 몸통은 보통 섞기로 보존 |
| 유리 | 뿌리 폭 18~22 px→끝 폭 약 46 px, 길이 약 82 px인 진한 주황 원뿔. 흰 심은 그 안의 좁은 축. 주황 불티 9~11개 | 0.035~0.125초 모두 폭 약 12~20 px의 흰 세로 기둥이 우세하다. 주황 몸통의 좌우 외곽과 불티가 바닥색에 날아가며, 원뿔 끝 폭이 시안의 절반 이하로 읽힌다 | 주황 몸통을 보통 섞기로 바꾸고 흰 심만 더하기 유지. 몸통 폭은 유지하되 코어를 크게 줄임 |
| 불리 | 접촉점의 은백색 얇은 면 약 54×12 px, 반대쪽으로 분리된 둥근 불티 7~9개가 25~75 px, 긴 빛꼬리 3개 | 얇은 면 방향은 좋아졌으나 0.035초부터 18×18 점 8개가 같은 자리에서 겹쳐 약 45×30 px 흰 얼룩이 된다. 0.075~0.125초에도 2~3덩어리로 합쳐져 낱알 수가 안 읽힌다 | 점 크기 18→10, 초기 위치·속도 분산 확대, 보통 섞기로 은색 보존. 긴 흰 꼬리만 더하기 유지 |

## 3. HxBuild 셰이더·재질 값

`_DstBlend = 10`은 보통 섞기, `_DstBlend = 1`은 더하기다. 아래 표는 **사용하는 모든 피격 FX 재질의 목표값**이며, 지정하지 않은 셰이더 수치는 r1을 유지한다.

| 재질 | 역할 | 속성 | 지금 값(r1) | 새 값(r2) |
|---|---|---|---:|---:|
| `_hxDotMat` | 흰/긴 잔광 | `_DstBlend` | `1` | `1` |
| `_hxRingMat` | 백색 고리 잔광 | `_DstBlend` | `1` | `1` |
| `_hxBeamMat` | 유리의 좁은 흰 심 | `_DstBlend` | `1` | `1` |
| `_hxBeamMat` | 흰 심 폭 | `CoreWidth / CoreBoost` | `0.16 / 1.00` | `0.09 / 0.72` |
| `_hxConeMat` | 유리의 진한 주황 몸통 | `_DstBlend` | `1` | `10` |
| `_hxConeMat` | 몸통/흰 심 | `Body / CoreWidth / CoreBoost` | `0.82 / 0.14 / 1.00` | `0.92 / 0.035 / 0.12` |
| `_hxConeMat` | 외곽 | `EdgeSoft / EdgeLine` | `0.18 / 0.10` | `0.14 / 0.06` |
| `_hxConeGlowMat` | 넓은 주황 번짐 | `_DstBlend` | `1` | `10` |
| `_hxConeGlowMat` | 몸통/흰 심 | `Body / CoreWidth / CoreBoost` | `0.34 / 0.20 / 0.32` | `0.28 / 0.02 / 0.00` |
| `_hxConeGlowMat` | 외곽 | `EdgeSoft / EdgeLine` | `0.42 / 0.00` | `0.34 / 0.00` |
| `_hxPlaneMat` | 불리 앞 은빛 면 | `_DstBlend` | `1` | `10` |
| `_hxPlaneMat` | 몸통/흰 심 | `Body / CoreWidth / CoreBoost` | `0.68 / 0.34 / 1.00` | `0.72 / 0.12 / 0.35` |
| `_hxPlaneBackMat` | 불리 뒤 강철색 면 | `_DstBlend` | `1` | `10` |
| `_hxPlaneBackMat` | 몸통/흰 심 | `Body / CoreWidth / CoreBoost` | `0.32 / 0.28 / 0.45` | `0.48 / 0.08 / 0.18` |
| `HxDotSolid` 복제재질 | 주황·금빛·은빛 둥근 낱알 | `_DstBlend` | `1` | `10` |
| `HxDotSolid` 복제재질 | 점 외곽 | `_RingWidth / _RingGlow` | `0.52 / 0.62` | `0.64 / 0.18` |
| `_hxHalfRingMat` | 피격 FX에서 미사용 | `_DstBlend` | 미지정 | `10` |

`HxDotSolid`는 색 낱알 전용이다. 백색 중심광·좁은 심·긴 빛꼬리만 더하기 재질을 사용한다. 한 재질 안에서 주황/은색 몸통을 흰색으로 크게 보간하지 않는다.

## 4. 숫자 시스템 별도 의견

이 항목은 FX 합격 판정과 분리하며, 기존 숫자 시스템을 고칠 때만 적용한다.

| 항목 | 지금 | 제안 |
|---|---:|---:|
| 숫자 생성 기준 Y | 적 머리/FX와 겹치는 현재 위치 | 현재 위치에서 화면 위쪽 `+18 px` |
| 보통 숫자 시작 배율→안착 배율 | `1.00 → 1.00`로 간주 | `0.92 → 1.00`, `0.06초` |
| 치명 숫자 첫 튐 배율→안착 배율 | 약 `1.35 → 1.00` | `1.12 → 1.00`, `0.08초` |
| 같은 프레임 다중 숫자 X 간격 | 겹침 | 중심 기준 좌우 교대 `18 px`, 최대 `±36 px` |
