# A. 판정

**보여 줘도 된다.**
빙의는 원작 진입 동작 뒤에 절제된 후행 이펙트가 붙어 동작을 가리지 않는다.  
되살리기는 대상 하나와 기상 순간이 전체 화면에서도 분명하며 방의 밝기를 해치지 않는다.

# B. 두 항목 반영 확인

1. **빙의 순간 — 풀렸다.** 발밑 물결과 몸 둘레 기운이 캐릭터 뒤에서 작고 옅게 보여 빙의 완료 표식만 남기며, 유령이 줄어들어 들어가는 구간과도 겹치지 않는다.
2. **되살리기 빛기둥 — 풀렸다.** 솟기·최고 밝기·풀리기의 박자가 명확하고, 최고 밝기 구간의 기상과 맞물려 되살리기가 충분히 읽힌다.
