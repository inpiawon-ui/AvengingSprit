# 판정: 불합격 — 시안과 동일하지 않음

검수 대상: `mock_fxstory_room_devil_v1.png` / `room_devil_vs_mock.png` / `room_devil.gif`  
검수 범위: 방 오브젝트 원화는 제외하고 이펙트 층만 검수. 기준 좌표는 `layers_room_devil()`의 제단 중심 상대 좌표다.

현재 재현은 1·2컷에서 제단 중앙의 불꽃과 상단 연기가 시안보다 지나치게 크고 밝아 오브젝트 그림을 덮는다. 3컷은 시안의 핵심인 좌우 사슬 해방이 없고, 연기 고리가 너무 낮고 불투명하다. 더 큰 문제로 3.05초 비교 컷에는 열려야 할 거래 팝업이 없으며 제단만 45%로 흐려진다. 따라서 현재 자료로는 글자·버튼 비가림까지 포함한 최종 화면 검수가 불가능하다.

별/십자 반짝이와 화면 전체 틴트는 현재 없으며, 앞으로도 추가하지 않는다.

## 1컷 — 멀리 대기

### 시안과 다른 점

- 시안은 뿔 끝의 작은 불씨와 제단 내부의 좁은 원혼 일렁임이 중심이다. 재현은 `fire_smoke`가 제단 폭 대부분과 HUD 바로 아래까지 번지고, `core_glow`가 문양·사슬·몸통을 강한 흰빨강으로 덮는다.
- 시안의 대기 장식은 제단 윤곽을 읽을 수 있는 수준인데, 재현은 네 프레임마다 큰 불덩이/자홍 연기 덩어리가 반복되어 “은은한 대기”가 아니라 계속 최대 출력처럼 보인다.
- 양쪽 뿔 불꽃도 시안보다 길고 밝다. 중앙 불꽃과 합쳐져 세 층이 한 덩어리로 뭉친다.

### `layers_room_devil()`에서 바꿀 값

아래 값으로 교체한다.

```python
L('room_devil_fire_smoke', 0, -92, 270, 270, 0.18, 0.0,
  add=False, alpha=0.30, back=True, fade=0.18)
L('room_devil_core_glow', 0, -2, 104, 208, 0.16, 0.0,
  add=True, alpha=0.48, back=False, fade=0.18)
L('room_devil_horn_fire', -80, -146, 34, 68, 0.14, 0.10,
  add=True, alpha=0.66, back=False, fade=0.14)
L('room_devil_horn_fire', 80, -146, 34, 68, 0.14, 0.17,
  add=True, alpha=0.66, back=False, flip=True, fade=0.14)
```

- 네 층 모두 `t1=0.0`, `loop=True`, `phase='open'`은 유지한다.
- `fire_smoke`만 덮기(`add=False`)·뒤(`back=True`)로 두고, 나머지는 가산·앞으로 둔다.
- 대기층에는 화면 전체 색 덮기, 별/십자 반짝이를 추가하지 않는다.

## 2컷 — 가까워짐 / 최대

### 시안과 다른 점

- 시안은 접근 순간 눈이 짧게 번쩍여 1컷과 상태가 분명히 달라진다. 재현은 중앙 대기 불꽃이 너무 강해 눈이 묻히며, `eye_flash`는 0.32초 분량의 네 프레임을 한 번 재생한 뒤 근접 구간이 끝나기 전에 사라진다. 그 뒤에는 1컷과 구분이 없다.
- 시안의 눈은 얼굴 안쪽에 작게 붙어 있다. 현재 80×80은 눈 주변까지 큰 발광 덩어리로 만들 가능성이 높다.
- 접근 중에도 대기 불꽃이 계속 최대 밝기로 보여 “멀리/가까이”의 단계 차이가 약하다. 1컷 값 축소를 먼저 적용해야 눈 반응이 읽힌다.

### `layers_room_devil()`에서 바꿀 값

```python
L('room_devil_eye_flash', 0, -48, 54, 54, 0.12, 0.0, 1.2,
  loop=True, add=True, alpha=0.62, fade=0.08,
  phase='near', back=False)
```

- 근접 구간 전체(1.6~2.8초)에만 반복하고 접촉 즉시 끝낸다.
- 크기 54×54, 중심 `y=-48`로 얼굴 내부에 고정한다.
- 새 연기나 화면 틴트를 더해 세기를 올리지 말고, 작은 눈 점멸만으로 1컷과 구분한다.

## 3컷 — 닿아서 작동 / 팝업 열림

### 시안과 다른 점

- 시안의 1순위 동작은 제단 사슬이 좌우로 해방되는 짧고 확실한 파열이다. 현재 발주 부품에는 사슬 해방이 전혀 없어 값 조정만으로 재현할 수 없다.
- 시안의 연기 고리는 제단 중단을 중심으로 얇게 바깥으로 퍼지고 팝업 뒤로 빠진다. 재현은 중심이 너무 아래(`y=140`)이고 420×210, 알파 1.0이라 플레이어와 제단 하부를 가리는 두꺼운 적색 띠가 된다.
- 시안에서는 작동과 동시에 우측 거래 팝업이 열리고 제단 원화는 정상 가독성을 유지한다. 재현 3.05초에는 팝업이 없고 `render_room()`이 제단과 링을 각각 45%, 30%로 낮춘다. 이는 `layers_room_devil()` 값으로 해결할 수 없는 비교 렌더 문제다.
- 팝업이 없는 현 상태에서는 연기/사슬이 제목·본문·수락·거절 버튼을 가리는지 검수할 수 없다. `popup_c_layout.py`의 실제 `EventPanel`을 합성한 캡처가 필요하다.

### `layers_room_devil()`에서 바꿀 값

연기 고리는 아래처럼 낮은 불투명도·짧은 단발·뒤 레이어로 줄인다.

```python
L('room_devil_smoke_ring', 0, 52, 360, 150, 0.09, 0.0, 0.54,
  loop=False, add=False, alpha=0.48, fade=0.07,
  phase='accept', back=True)
```

- 현재 `x=0, y=140, w=420, h=210, alpha=1.0`에서 위 값으로 변경한다.
- 고리는 제단 중심에서 시작해 바깥으로 퍼지되, 우측 팝업의 글자와 버튼 위로 올라오지 않도록 반드시 `back=True`를 유지한다.
- 작동층은 접촉 후 0.54초 안에 끝내고 반복하지 않는다.

### 재발주 — 사슬 해방 부품

`room_devil_chain_release`를 새로 발주한다.

- 투명 PNG 시퀀스 6프레임, 각 512×256.
- 제단 중앙 양옆에서 검고 굵은 쇠사슬 두 가닥이 좌우 위쪽으로 순간적으로 풀려 나가는 동작. 1프레임은 장력 축적, 2~4프레임은 좌우 전개, 5~6프레임은 붉은 잔광만 남기고 소멸.
- 금속 본체는 검정/암회색 덮기용이며 가장자리에만 붉은 발광. 연기, 불덩이, 별, 십자, 화면 틴트, 배경, 제단 원화, 글자는 넣지 않는다.
- 중앙 190×210 영역은 제단 원화를 과도하게 가리지 않도록 비우고, 좌우 사슬 실루엣이 주 피사체가 되게 한다.
- 실제 적용값:

```python
L('room_devil_chain_release', 0, 6, 410, 205, 0.07, 0.0, 0.42,
  loop=False, add=False, alpha=0.90, fade=0.04,
  phase='accept', back=False)
```

사슬은 팝업보다 아래 렌더 순서에 있어야 한다. 팝업 위에 그려지는 구조라면 `back=False` 값만으로 안전하지 않으므로, 런타임에서 방 오브젝트 FX 전체를 `EventPanel` 뒤로 보내야 한다.

## 비교 렌더에서 별도 수정할 사항

이는 이펙트 값이 아니라 최종 검수 증거의 문제다.

1. `render_room()`의 `used` 구간에 실제 악마 거래 팝업을 합성한다. 제목·본문·비용·수락·거절 버튼이 보이는 상태여야 한다.
2. 작동 시 제단 `0.45`, 링 `0.30`으로 강제 감광하는 현재 미리보기 처리를 제거하고 실제 게임의 정렬·알파와 동일하게 캡처한다.
3. 최종 나란히 컷은 위=시안, 아래=재현의 같은 시점(1.00 / 2.00 / 3.05초)을 유지하되 3.05초에 팝업이 반드시 열린 화면을 쓴다.
4. 3.05초 캡처에서 사슬/연기 고리가 `EventTitleText`, `EventBodyText`, `EventRewardText`, `EventCostText`, `EventAcceptText`, `EventDeclineText`를 한 픽셀도 침범하지 않는지 확인한다.

4. `eye_flash`: `(0,-48)`, `54×54`, 간격 `0.12`, `0.0~1.2`, 반복, 알파 `0.62`, 가산, 앞, 근접 전용.

위 7개가 반영되기 전에는 PD 최종 검수본으로 올리지 않는다.
