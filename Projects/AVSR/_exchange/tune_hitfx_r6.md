# 최종 미통과 — r6 마지막 보정

기준 시안: `in/mock_hitfx_v7.png`  
최종 확인: `ref/hitfx_ingame/r5/compare_r5.png`, `ref/hitfx_ingame/r5/l1_00.png`~`l1_17.png`  
판정 기준: 원본 `720×1280`. 비교판의 중복 숫자와 유리 적 앞의 모래주머니는 판정에서 제외했다.

## 1. 최종 판정

**미통과.** FX 네 종류의 중심 형태·방향·색·소멸 순서는 통과했으며, 보통·치명·불리 FX는 종료한다. 남은 미통과는 아래 두 항목뿐이다.

| 항목 | 측정 | 판정 |
|---|---:|---|
| 유리, 0.13초 독립 주황 불티 | `5개(±1개)` | r5 종료 하한 `7개` 미달. 시안보다 적고 연하다. |
| 숫자와 적 체력바 | 숫자 상단이 빨간 막대 영역에 약 `4~6 px` 침범 | 겹침 금지 조건 미달. |

유리 불티는 원뿔·중심광과 분리된 둥근 주황 낱알만 셌다. 흐린 블룸이 이어진 한 덩어리와 모래주머니에 가려 확인할 수 없는 것은 세지 않았다.

## 2. 숫자 위치 결론

`+18 px 위`는 폐기한다. **기존 위치에서 화면 위쪽 `+10 px`**로 확정한다. 즉 r5 결과에서는 화면 아래쪽으로 `8 px` 되돌린다.

- `+18 px` 상태의 체력바 침범 `4~6 px`를 해소하고 약 `2~4 px` 간격을 남기는 값이다.
- 원래 위치로 완전히 복귀하면 다시 얼굴과 FX 중심을 가리므로 복귀하지 않는다.
- 더 위로 올리면 체력바 겹침이 커지므로 금지한다.
- 숫자 배율은 이번에 바꾸지 않는다. 실제값인 **보통 `1.35`, 치명 `1.9`를 유지**한다. 치명이 크게 터지며 뜨는 2026-09-15 기획 결정을 우선한다.
- 같은 판의 앞 회차 숫자 잔류는 위치 판정에서 제외한다.

## 3. 마지막 수치표

표에 없는 FX·재질·숫자 값은 r5 적용 결과를 유지한다.

| 대상 | 항목 | 현재(r5 결과) | r6 최종값 |
|---|---|---:|---:|
| 숫자 공통 | 생성 기준 Y | 기존 위치에서 위 `+18 px` | 기존 위치에서 위 `+10 px` |
| 보통 숫자 | 첫 튐 배율 | `1.35` | `1.35` 유지 |
| 치명 숫자 | 첫 튐 배율 | `1.9` | `1.9` 유지 |
| 유리 큰 둥근 불티 | 개수 | `11` | `15` |
| 유리 작은 둥근 불티 | 개수 | `3` | `4` |
| 유리 경량 둥근 불티 | 개수 | `2` | `3` |
| 유리 전체 불티 | 총 생성수 | `16` | `22` |
| 유리 큰 둥근 불티 | 크기 | `15×13 px` | `16×14 px` |
| 유리 작은 둥근 불티 | 크기 | `11×11 px` | `12×12 px` |
| 유리 경량 둥근 불티 | 크기 | `11×9 px` | `12×10 px` |
| 유리 모든 주황 불티 | 생성 시각 | `0 / 0.008 / 0.016 / 0.024초` 순환 | 동일 |
| `HxDotSolid_Orange` | `_DstBlend / _RingWhite / _CoreWhite` | `1 / 0.48 / 1.00` | 동일 |
| `HxDotSolid_Orange` | `_RingWidth / _RingGlow` | `0.56 / 0.20` | 동일 |

불티의 속도·반각·생성 위치·수명·재질은 더 건드리지 않는다. 현재 색 분리는 성립하므로 개수와 낱알 크기만 올려 0.13초 가시 수를 확보한다. 수명 연장으로 연기처럼 이어 붙이지 않는다.

## 4. 종료 조건

원본 `720×1280`의 0.13초 프레임 한 장에서 독립 주황 불티가 **`7~10개`**, 그중 원뿔 가장자리보다 접선축으로 `8 px` 이상 밖에 있는 낱알이 좌우 합계 **4개 이상** 보여야 한다. 숫자는 빨간 체력바와 **최소 `2 px`** 떨어지고, 적 얼굴 및 FX 중심을 가리지 않아야 한다. 두 조건을 만족하면 추가 조정 없이 최종 통과한다.
