# CH8 무너지는 바닥 + 스위치 발판
무너지는 바닥은 노랑·검정 위험 띠 테두리와 금속 격자를 묶고, 균열이 벌어지며 어두운 영구 구덩이로 이어지게 결정했다.
스위치는 같은 위험 띠 프레임 안에서 판 높이와 표시등만 바뀌며, 레이저 문은 동일 기둥에 광선 유무로 상태를 구분한다.

## 통과 후 받을 부품
- `floor_collapse`: 72×72px, 4프레임(멀쩡/금1/금2/구덩이), 투명 배경.
- `switch_plate`: 72×72px, 2프레임(상승·붉은 등/눌림·초록 등), 투명 배경.
- `laser_gate_post`: 36×108px, 1프레임, 투명 배경(좌우 배치는 반전 처리).
- `laser_beam`: 72×12px, 1프레임, 투명 배경(점멸·길이 조절은 게임 처리).

## 공용 부품
- 기존 피스톤의 노랑·검정 위험 띠 팔레트와 붉은 레이저 광선 표현을 공용으로 사용한다.
- 발판 표시등은 색상 전환만 게임에서 처리하고, 문 OFF는 기둥 공용 부품에서 광선만 숨긴다.
