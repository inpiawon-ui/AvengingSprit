# 10챕터 「일방 문」
낮은 매립형 철제 문틀과 굵은 쇠창살로 구성하며, 황·검 위험 띠와 좌상단 광원·발밑 그림자를 기존 피스톤/기계물과 맞춘다.
열림은 바닥의 위쪽 화살표, 닫힘은 내려온 쇠창살과 자물쇠로 즉시 구분한다.

## 통과 시 받을 부품 (1칸=72px 제작 기준)
- 문틀/문턱 공용: 216×72px, 1프레임, 투명 배경.
- 쇠창살 문짝: 216×144px, 1프레임, 투명 배경.
- 자물쇠: 48×48px, 1프레임, 투명 배경.
- 위쪽 화살표 바닥 표시: 72×72px, 1프레임, 투명 배경.

## 공용 부품
- 황·검 사선 위험 띠는 기존 피스톤 머리의 공용 위험 띠 팔레트/패턴을 재사용한다.
- 문 닫힘 이동·충돌 흔들림·점멸은 게임 처리하며 별도 프레임으로 받지 않는다.
