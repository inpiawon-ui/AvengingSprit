# 생김새 결정
라인업 3·6·7·8의 실루엣과 색을 유지하고, 기존 방의 굵은 외곽선·좌상단광·접지 그림자에 맞췄다.
아르마딜로는 황금 장갑과 올리브색 배, 버섯은 적색 갓, 미라는 백색 붕대, 알 거미는 자주색 갑각과 알주머니로 구분한다.
# 통과 시 받을 부품 (방 1칸=72px)
- 아르마딜로 기본/방어 말기: 각 72×72px, 각 4프레임, 투명 배경.
- 아르마딜로 피격 불꽃: 24×24px, 4프레임, 투명 배경(탄 튕김 이동·회전은 게임 처리).
- 폭탄 버섯 기본/자폭 폭발: 72×72px/144×144px, 4/8프레임, 투명 배경(백색 점멸은 게임 처리).
- 붉은 예고 원: 216×216px, 1프레임, 투명 배경.
- 미라 기본/방사 시전: 각 72×72px, 각 4프레임, 투명 배경.
- 보랏빛 저주탄: 18×18px, 4프레임, 투명 배경(12발 배치·회전·이동은 게임 처리).
- 알 거미 기본/산란: 각 108×96px, 각 4/6프레임, 투명 배경(후퇴 이동은 게임 처리).
- 새끼 거미: 36×36px, 4프레임, 투명 배경(좌우 반전·이동은 게임 처리).
# 공용 부품
붉은 예고 원과 피격 불꽃은 기존 공용 이펙트 규격을 재사용한다.
