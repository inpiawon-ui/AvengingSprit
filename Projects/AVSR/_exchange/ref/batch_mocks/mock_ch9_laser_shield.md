# CH9 회전 레이저 기둥 + 방패 발전기
- 회전 기둥은 짙은 강철 원통과 노랑·검정 위험 띠, 붉은 발사구로 정리했다. 발전기는 같은 골격에 푸른 코어를 넣고 파손형은 갈라진 외장과 꺼진 코어로 구분한다.
- 보호막은 적 실루엣을 가리지 않는 반투명 청색 구체 막이며, 파손 상태에는 작은 불꽃·연기만 남긴다.
## 통과 후 받을 부품 (방 좌표 1칸=72px)
- `laser_pillar`: 72×86px, 1프레임, 투명 배경. 회전은 게임 처리.
- `shield_generator_on`: 72×96px, 4프레임(코어 맥동), 투명 배경. 깜빡임은 게임 처리.
- `shield_generator_broken`: 90×100px, 1프레임, 투명 배경. 연기·불꽃은 공용 이펙트로 분리.
- `shield_overlay`: 180×180px, 4프레임, 투명 배경. 대상 위치 추적·이동·반전은 게임 처리.
## 공용 부품
- 붉은 레이저 광선은 기존 게임 광선, 노랑·검정 위험 띠는 기존 피스톤 머리 표현을 재사용한다.
- 파손 연기·불꽃은 공용 피격/파괴 이펙트, 보호막은 적 종류와 무관한 공용 오버레이로 사용한다.
