AVENGING SPIRIT: RE:BORN — 상성 삼각판 «마법 기준» 한 장

API 키를 쓰는 CLI 폴백은 쓰지 마라. 내장 이미지 생성 기능만 써라.

상성 속성이 「파워 · 무기 · 마법」 으로 바뀌었다. 게임 HUD 오른쪽 위 원형 배지 안에 들어가는 **삼각판**을 새 아이콘으로 다시 받는다.
삼각판은 **지금 내 몸의 속성마다 한 장씩**(세 장) 있고, 그 몸 기준으로 빛난다. 이번에는 «마법» 기준 한 장이다.

■ 그릴 것
  · 세 아이콘을 삼각으로 : **파워 위 가운데 · 무기 오른쪽 아래 · 마법 왼쪽 아래.**
  · 화살표 셋은 「이긴다」 방향 : 파워 → 무기, 무기 → 마법, 마법 → 파워 (시안과 같은 방향으로 돈다).
  · 기준인 **마법** 아이콘만 크게 빛난다(빛살 · 밝은 테두리). 나머지 둘은 평소 밝기.
  · 화살표 색 : 마법 에서 **나가는** 화살표(내가 이긴다) = **초록**, 마법 로 **들어오는** 화살표(나를 이긴다) = **빨강**,
    나머지 하나(나와 상관없음) = **어두운 회청색**.
  · 글자 · 「유리」 딱지 · 아이콘 아래 이름표 · 바깥 원형 테두리는 **넣지 마라**(게임이 배지 테두리를 따로 깐다).
