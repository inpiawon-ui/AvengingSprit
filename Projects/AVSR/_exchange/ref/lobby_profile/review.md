# 로비 프로필 안 검수
A 장점: 재화 줄과 높이·네온 프레임이 맞고, 레벨·막대·수치가 720px에서도 가장 빠르게 읽힌다.
A 문제: 로고를 완전히 빼 브랜드 노출이 사라지고, 큰 직사각 판이 상단 시선을 다소 독점한다.
B 장점: 로고를 유지해 타이틀 인지가 가장 좋고 프로필도 기존 상단 UI 안에 무리 없이 들어간다.
B 문제: 로고 아래로 압축되어 레벨·경험치가 A보다 작고, 재화 줄과 기준선이 달라 상단이 두 단으로 보인다.
C 장점: 원형 경험치 링이 유령 캐릭터와 잘 맞고 세 안 중 개성과 공간 효율이 가장 좋다.
C 문제: 720px에서 경험치 막대·수치가 너무 작고 링의 진행량도 정밀하게 읽기 어려우며 구현 부담이 가장 크다.
추천: A안 — 핵심 질문인 레벨·경험치의 즉시 판독, 재화 줄 정렬, 기존 사각 HUD 재사용성이 가장 안정적이다.
다듬기 1: 좌측 상단에 축소 로고 또는 워터마크를 넣어 브랜드 손실을 보완한다.
다듬기 2: 경험치 수치와 막대를 한 단계 키우고 대비를 높여 작은 화면 가독성을 확보한다.
다듬기 3: 판의 폭·외곽 광량을 조금 줄여 재화 UI와 간격을 맞추고 배경 주인공 시선을 살린다.
