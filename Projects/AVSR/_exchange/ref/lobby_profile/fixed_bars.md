# 상·하단 고정 바 시안 의견
상단 고정 영역은 120px이며, 108px 공통 HUD 아래에 12px 어두운 분리 띠를 배치했다.
프로필 판·금화·다이아·우편·설정은 세 화면에서 동일 좌표와 동일 픽셀을 사용했다.
하단 내비게이션은 y=1170부터 110px 높이로 고정해 터치 영역과 시선 위치를 통일했다.
로비와 챕터 선택은 PLAY, 육성은 HOST에 금색 선택 테두리를 적용했다.
육성은 기존 로고와 중복 재화 띠를 제거하고 카드·능력치 행·스킬 사이 간격을 줄였다.
챕터 선택은 자체 뒤로/재화 막대를 제거하고 챕터·호스트·랜덤 선택 영역을 압축했다.
「도전하기」는 하단 바 바로 위에 두어 진행 동선을 유지하며, 모든 요소는 720×1280 안에서 겹침 없이 정리했다.
