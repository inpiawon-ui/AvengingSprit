API 키를 쓰는 CLI 폴백은 쓰지 마라.

[첫 샘플 발주서 01 — 공통 산업 출입구 / 닫힘]

정정: 선정 이유
한 장짜리 CH1 전용 문이 아니라, 현재 게임이 실제로 사용하는 `닫힘 → 열림1 → 열림2 → 열림(유지)` 4상태 공통 출입구의 미술 규칙을 먼저 검증한다. 이번 샘플은 `닫힘` 1장만 제작하며, 승인 뒤 나머지 세 장을 같은 구도·팔레트·고정 영역으로 제작한다.

목표
AVENGING SPIRIT: RE:BORN의 어느 챕터에도 함께 쓸 수 있는 회색 콘크리트 + 철제 셔터 계열 산업 출입구를 픽셀 아트로 제작한다. 기존 보라 석재·청록 타일의 판타지 인상을 없애되, 1990년대 아케이드 캐릭터 도트와 같은 세계의 공용 설비로 읽히게 한다.

정정: 공통 리소스 원칙
- 모든 방의 위쪽 벽 중앙에 하나만 배치되는 공통 출입구다.
- 챕터별 문을 추가하지 않는다. 한 벌 4장만 모든 방·모든 챕터가 공유한다.
- 챕터 분위기는 방 바닥·벽의 기존 그림자와 런타임 틴트로만 흡수한다. 문 자체에는 특정 챕터에 종속되는 강한 색을 넣지 않는다.
- 특별한 게임플레이 기능이 새로 생기지 않는 한 외형 변형이나 챕터별 파생 리소스를 늘리지 않는다.

정정: 산출 규격
- 논리 캔버스: 기존과 동일한 216×180px. 게임이 이 크기를 방 좌표 한 칸에 직접 그리며, 실제 화면에서는 약 185×155px로 보인다.
- 크기 유지 근거: 기존 4상태가 같은 216×180 좌표와 위쪽 벽 중앙 자리를 공유하고, 약 72px 폭(3개 바닥 타일)의 통로가 캐릭터 약 30~40px 폭보다 넓어 통과 가능하게 읽힌다. 폭을 키우면 방 위 벽과 양옆 구조물을 침범하고, 줄이면 캐릭터 대비 통로가 답답해진다.
- 최종 상태 수: 4장 — `닫힘`, `열림1`, `열림2`, `열림`(열린 채 유지). 단, 이번 샘플 납품은 `닫힘` 1장뿐이다.
- 샘플 저장 경로: `Projects/AVSR/_exchange/ref/quality_audit/sample_01_gate_closed.png`.
- 배경: 완전 투명 알파 PNG. 마젠타 키 금지. 불투명 본체 가장자리에 반투명 안티앨리어싱 픽셀을 두지 않는다.
- 픽셀 아트: 매끈한 벡터선·블러·글로우 없이 단단한 픽셀 군집으로 표현한다.
- 파일에는 출입구 본체와 본체에 붙은 접점 그림자만 넣고, 설명문·가이드선·색상표·캐릭터·UI는 넣지 않는다.

정정: 반드시 직접 대조할 실제 그림
- `Assets/BaseResource/InGameMainUI/exitgate_closed.png`: 닫힌 벽과 앞쪽 접근 바닥의 전체 실루엣·배치 기준.
- `Assets/BaseResource/InGameMainUI/exitgate_open1.png`: 중앙 벽이 처음 갈라지는 위치 기준.
- `Assets/BaseResource/InGameMainUI/exitgate_open2.png`: 좌우 고정 구조와 드러나는 통로 폭 기준.
- `Assets/BaseResource/InGameMainUI/exitgate_open.png`: 완전 열린 뒤 이어지는 복도 축과 소실 방향 기준.
- 방 배치와 실제 화면 크기: `Projects/AVSR/_exchange/ref/quality_audit/ROOM_CH1_003.png`, `ROOM_CH2_009.png`, `ROOM_CH3_009.png`, `ROOM_CH5_013.png`, `ROOM_CH6_007.png`.
- 기존 4장은 상태 전환 구조와 점유 범위만 참고한다. 보라 석재, 청록 타일, 판타지 문양은 계승하지 않는다.

정정: 상태 연속성 규칙(승인 후 3장 제작 시 적용)
- 네 장 모두 216×180, 같은 피벗·같은 바깥 실루엣·같은 좌우 프레임 위치를 사용한다.
- `닫힘`: 중앙 철제 셔터가 통로를 완전히 막는다. 안쪽 복도는 보이지 않는다.
- `열림1`: 셔터 중앙 또는 상단에서 첫 틈이 생긴 초기 프레임이다.
- `열림2`: 셔터가 더 걷혀 통로와 안쪽 바닥 조명이 드러나는 중간 프레임이다.
- `열림`: 약 72px 폭의 통로가 완전히 열리고 세로 복도가 화면 위로 자연스럽게 이어진 채 유지된다.
- 프레임 사이에 좌우 기둥, 볼트, 균열, 그림자가 흔들리거나 새로 생기지 않는다. 움직이는 것은 셔터와 그에 따라 드러나는 내부뿐이다.

형태와 원근
- 탑다운 3/4 시점. 화면 위쪽 벽 중앙에서 아래쪽 방 바닥으로 돌출되는 구조다.
- 기존과 같은 중앙 축과 약 72px 통로 폭을 유지한다. 닫힘에서도 셔터 폭으로 통로 위치가 즉시 읽혀야 한다.
- 좌우 콘크리트 프레임은 전체 형태가 안정적으로 대칭이되, 작은 균열·녹·볼트 손실만 비대칭으로 배치한다.
- 실루엣은 철제 롤링 셔터/공장 격벽으로 읽혀야 한다. 석문, 제단, 포털, 성문처럼 보이면 실패다.
- 하단 접점 그림자는 본체 바로 아래에 밀착하고, 별도 부유 그림자처럼 떼지 않는다.

재질과 팔레트
- 회색 콘크리트 프레임 + 저채도 철제 셔터 + 제한된 적갈색 녹 + 소량의 기름때.
- 중성~냉회색을 주조색으로 한다. 어느 챕터 바닥 위에서도 튀지 않도록 고채도 색과 발광색을 쓰지 않는다.
- 외곽선은 순검정이 아니라 지역 최암색을 쓴다. 순백색 하이라이트 금지.
- 광원은 화면 좌상단 45°. 오른쪽 면과 하단 접점이 더 어둡다.
- 밝은 청록, 네온 블루, 마젠타, 보라 발광, 챕터 고유 문양을 사용하지 않는다.

도트 밀도
- 216×180 원본에서 읽히는 픽셀 군집을 사용한다. 작은 녹 점·긁힘을 1px 잡음처럼 전면에 뿌리지 않는다.
- 손상은 최소 2×2px 덩어리로 묶고, 캐릭터보다 촘촘한 사진성 텍스처를 피한다.
- 볼트와 패널선은 기계 구조를 설명하는 데 필요한 수만 남긴다.

금지 사항
- API 키를 쓰는 CLI 또는 외부 CLI 폴백 사용 금지.
- 마젠타 키 배경, 글자, 로고, 숫자, UI, 화살표 금지.
- 기존 보라 석재/청록 타일 출입구의 색과 판타지 문양 복제 금지.
- 포토리얼, 3D 렌더, 부드러운 그라데이션, 안티앨리어싱, 블러, 글로우, 렌즈 효과, 거울 반사 금지.
- 캐릭터나 소품을 함께 그리지 않는다.
- 캔버스를 임의 확대하거나 여러 시안을 한 파일에 배열하지 않는다.

정정: 샘플 승인 기준 5개
1. 파일이 정확히 216×180 RGBA PNG이며 배경은 실제 투명 알파이고 마젠타 키가 없다.
2. 기존 `exitgate_closed.png`와 같은 위쪽 벽 중앙 점유 범위·중앙 축·약 72px 통로 폭을 유지해 현재 방 좌표에 바로 교체 가능하다.
3. 회색 콘크리트 + 철제 셔터의 산업 시설로 즉시 읽히며, 보라 석재·청록 타일·판타지 문양이 없다.
4. 실제 화면 약 185×155에서 캐릭터보다 먼저 튀지 않고, 큰 형태와 셔터 닫힘 상태는 분명하다.
5. 픽셀 군집, 좌상단 광원, 밀착 접점 그림자, 제한된 녹·손상 표현이 일관되며 이후 `열림1/2/열림` 3장을 같은 고정 구조로 확장할 수 있다.
