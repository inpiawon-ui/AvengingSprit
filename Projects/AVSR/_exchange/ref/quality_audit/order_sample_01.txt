API 키를 쓰는 CLI 폴백은 쓰지 마라.

[첫 샘플 발주서 01 — P2 / CH1 출입구]

선정 이유: 한 장으로 신규 자산 전체의 픽셀 밀도·3/4 원근·외곽선·재질·접지를 검증할 수 있어 후속 챕터 일괄 발주의 기준점이 된다.

목표
AVENGING SPIRIT: RE:BORN의 CH1 회색 공장 방에 들어갈 녹슨 철문/콘크리트 출입구 1종을 픽셀 아트로 제작한다. 기존 공통 보라 석재·청록 타일 출입구를 대체한다. 1990년대 아케이드 캐릭터 도트와 함께 놓였을 때 같은 세계의 산업 시설로 보여야 한다.

산출 규격
- 논리 캔버스: 136×64px.
- 표시 배율: Point 필터 정수 3배, 화면 표시 408×192px.
- 프레임 수: 1프레임 정지 이미지.
- 색 수: 투명색 제외 최대 16색.
- 배경: 완전 투명 알파 PNG. 반투명 안티앨리어싱 픽셀 금지. 그림자만 단계형 알파를 허용한다.
- 저장 경로: `Projects/AVSR/_exchange/ref/quality_audit/sample_01_ch1_gate.png`.
- 파일에는 출입구 본체와 바닥 접점 그림자만 넣고, 설명문·가이드선·색상표·여백 장식은 넣지 않는다.

참조할 실제 그림
- 방 배치·CH1 재질·기존 캐릭터/소품 크기: `Projects/AVSR/_exchange/ref/quality_audit/ROOM_CH1_003.png`.
- 기존 공통 출입구에서 교체해야 할 크기와 화면 위치: `Projects/AVSR/_exchange/ref/quality_audit/ROOM_CH2_009.png`, `Projects/AVSR/_exchange/ref/quality_audit/ROOM_CH3_009.png`, `Projects/AVSR/_exchange/ref/quality_audit/ROOM_CH5_013.png`, `Projects/AVSR/_exchange/ref/quality_audit/ROOM_CH6_007.png`.
- 캐릭터 도트의 굵기와 명암 단계 기준은 위 방 캡처 속 인간형·해골 캐릭터를 따른다. 기존 출입구의 보라 석재와 청록 타일 색·재질은 따르지 않는다.

형태와 원근
- 탑다운 3/4 시점. 정면 수직면과 상단 윗면 노출 비율은 약 2:1.
- 중앙 통로는 화면 표시 기준 150~170px 폭으로 읽히게 한다. 논리 픽셀 기준 약 50~57px.
- 좌우 구조는 기본 대칭으로 하되 녹, 찍힘, 볼트 손실, 균열을 비대칭으로 배치해 복제 느낌을 없앤다.
- 실루엣은 멀리서도 철제 셔터/공장 격벽으로 읽혀야 한다. 판타지 석문, 제단, 포털처럼 보이면 실패다.
- 바닥 접점 그림자는 논리 높이 3~4px, 색 `#071018`, 최대 알파 0.40. 본체 아래에 밀착시키고 별도 부유 그림자로 만들지 않는다.

재질과 팔레트
- 재질: 회색 콘크리트 프레임 + 녹슨 철제 셔터/격벽 + 소량의 기름때.
- 전체는 저채도 냉회색을 주조색으로 하고, 녹은 갈색/적갈색 보조색으로 제한한다.
- 외곽선은 순검정이 아니라 지역 최암색의 1 논리 px.
- 내부 명암은 기본 3단, 핵심 모서리만 4단까지 허용한다.
- 광원은 화면 좌상단 45°. 오른쪽과 하단 접점이 더 어둡게 읽혀야 한다.
- 밝은 청록, 네온 블루, 마젠타, 보라 발광은 사용하지 않는다.

도트 밀도
- 작은 녹 점·긁힘을 1px 잡음처럼 전면에 뿌리지 않는다. 손상은 최소 2×2 논리 px 덩어리로 묶는다.
- 캐릭터보다 더 촘촘한 사진성 텍스처, 부드러운 그라데이션, 안티앨리어싱을 금지한다.
- 볼트·패널선은 동일 간격 반복을 피하고, 주요 형태를 읽는 데 필요한 수만 남긴다.

금지 사항
- API 키를 쓰는 CLI 또는 외부 CLI 폴백 사용 금지.
- 이미지 안에 글자, 로고, 숫자, UI, 화살표를 넣지 않는다.
- 기존 보라 석재/청록 타일 출입구의 색과 판타지 문양을 복제하지 않는다.
- 포토리얼, 3D 렌더, 벡터형 매끈한 선, 블러, 글로우, 렌즈 효과, 금속 거울반사를 금지한다.
- 순검정 외곽선, 순백색 하이라이트, 16색 초과, 마젠타 키 배경을 금지한다.
- 캐릭터나 소품을 함께 그리지 않는다.
- 지정 캔버스를 임의 확대하거나 여러 시안을 한 파일에 배열하지 않는다.

승인 기준
1. 3배 Point 표시에서 기존 캐릭터와 도트 굵기가 충돌하지 않는다.
2. CH1의 회색 공장 재질로 즉시 읽힌다.
3. 통로 폭과 3/4 원근이 방 바닥에 자연스럽게 맞는다.
4. 접점 그림자로 바닥에 붙어 보인다.
5. 100% 화면 캡처에서 출입구가 캐릭터보다 먼저 튀지 않는다.
