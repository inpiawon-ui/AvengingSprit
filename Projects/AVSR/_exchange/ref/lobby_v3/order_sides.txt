[작업] 게임 로비 그림을 좌우로 넓히기 1장 (태블릿 화면 양옆 채우기)

API 키를 쓰는 CLI 폴백은 쓰지 마라. 내장 이미지 편집 기능만 써라.
스크립트로 픽셀을 복사·늘리기·뒤집기·칠해서 때우지 마라.

입력(먼저 열어 확인해라, 열 수 없으면 멈추고 알려라):
- Projects/AVSR/_exchange/ref/lobby_v3/src_sides.png  (1281×1672)
  가운데 170~1110px = 게임 로비 화면(밤 골목 배경 위에 글자판 · 버튼 · 상자 칸 · 모드 카드 · 하단 버튼 줄).
  왼쪽 0~169px, 오른쪽 1111~1280px = 자홍색(마젠타) 빈 곳.

할 일: **양옆 자홍색 빈 곳만** 그려 채운다. 가운데 그림은 바꾸지 마라.
- 채울 것은 **배경 풍경만**: 가운데 그림 가장자리에 보이는 밤 골목(벽돌 벽 · 창문 · 파이프 · 가로등 불빛 · 나무 상자 더미 · 돌바닥)을
  같은 높이에서 바깥쪽으로 자연스럽게 이어 간다. 같은 픽셀아트 화풍 · 같은 어두운 남색 색감.
- 가운데의 UI(글자판 · 버튼 · 상자 칸 틀 · 카드 · 하단 버튼 줄 · 테두리 선)는 **바깥으로 늘이지 마라.**
  UI 는 원래 자리에서 끝나고, 그 바깥은 골목 풍경만 보이게.
- 바깥쪽 끝으로 갈수록 조금 어두워져도 좋다(가운데로 시선이 가게).
- 넣지 마라: 글자, 버튼, 새 판(UI), 사람 · 유령 · 동물.
- 170px · 1110px 이음매가 보이면 안 된다.
