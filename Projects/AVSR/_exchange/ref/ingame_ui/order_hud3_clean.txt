AVENGING SPIRIT: RE:BORN — 확정된 인게임 UI(D안)를 게임에 넣기 위한 «빈 판» 두 장

API 키를 쓰는 CLI 폴백은 쓰지 마라. 내장 이미지 생성 기능만 써라.

PD 가 D안을 확정했다. 이제 게임에 넣는다. 게임은 글자 · 숫자 · 얼굴 · 막대 채움을 **코드가 실시간으로 얹는다.**
그래서 시안에서 그것들을 뺀 **빈 판**이 필요하다. 나는 이 판을 부품별로 잘라 시안과 같은 자리에 붙인다.

  1) Projects/AVSR/_exchange/ref/ingame_ui/hud3_clean_host.png    ← hud_draft_D2.png 에서
  2) Projects/AVSR/_exchange/ref/ingame_ui/hud3_clean_ghost.png   ← hud_draft_D2_ghost.png 에서

  두 장 모두 :
  · **UI 부품만 남기고 나머지는 전부 마젠타 #FF00FF 단색**으로 칠한다(전투 판 · 바닥 · 캐릭터 · 적 · 적 머리 위 막대 · 배경 건물 모두 지운다).
  · 부품의 **자리 · 크기 · 모양 · 테두리 · 색은 시안 그대로** — 1픽셀도 옮기지 마라. 겹쳐 놓고 자를 것이다.
  · 부품 테두리 바깥의 빛 번짐(글로우)은 남겨도 되지만, 부품끼리 붙지 않게.
  · 부품 안에서 아래 것들을 **지운다**(그 자리는 부품 안쪽 바탕색으로 자연스럽게 메운다) :
      모든 글자와 숫자(PLAYER SOUL · GHOST · LV. 5 · HP · 100 / 100 · CHAPTER 3 · 밤의 도시 거리 · ROOM 01 / 15 ·
        CURRENT HOST · AMAZON · 아마존 · 143 / 196 · NO HOST · 빙의할 몸을 찾으세요 · 41 · ACTIVE · POSSESS · -8 · 「—」)
      얼굴(유령 얼굴 · 아마존 얼굴)과 점선 실루엣 → **둥근 얼굴 테두리 안은 비운다**
      HP 막대와 진행 막대의 **채움**(빨강 · 보라 · 하늘색, 불꽃) → 빈 막대 홈만 남긴다
      상성 배지 안의 보석 · 화살표 → **둥근 테두리 안은 비운다**
      ACTIVE 버튼 안의 아마존 스킬 그림 → 비운다
  · 지우지 않고 **남기는 것** : 금화 칩의 금화 아이콘 · 일시정지 버튼의 두 막대 · 빙의 버튼 안의 유령 그림 ·
      조이스틱 받침과 빨간 손잡이 · 레벨 배지 틀 · 버튼 아래 이름표 틀.
