# AVENGING SPIRIT: RE:BORN — 인게임 UI D안 / 유령 상태
- 기준 화면 `hud_draft_D2.png`와 동일한 1080×1920 전투 화면.
- 상단 유령·스테이지·몸 HUD의 자리와 외곽 크기를 D2 기준으로 통일.
- CURRENT HOST는 점선 실루엣, `NO HOST`, 안내문, 빈 HP, `—`로 표시.
- PLAYER SOUL HP는 유령 상태 수치 `72 / 100`과 감소 막대를 적용.
- 상성 배지는 잠금 상태, ACTIVE는 캐릭터 없는 중립 자물쇠/별 표식.
- POSSESS는 발광 강조를 유지하고 비용은 `-8`로 표기.
- 판 위 유령과 나머지 전투 구성, 하단 조작부 위치·크기는 D2 흐름을 유지.
