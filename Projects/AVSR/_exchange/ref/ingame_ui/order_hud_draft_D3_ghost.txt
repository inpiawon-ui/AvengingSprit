API 키를 쓰는 CLI 폴백은 쓰지 마라. 내장 이미지 생성 기능만 써라.

PD 지적 : 「스킬 아이콘은 호스트가 없으면 비어 있어야지. **잠긴 것과 비어 있는 것은 다르다.**」
  · 잠김 = 있는데 못 쓴다(조건을 채우면 풀린다). 자물쇠.
  · 비움 = 지금 아무것도 없다(몸을 얻으면 그 몸의 것이 채워진다). **자물쇠 없음.**
유령 상태에서 스킬과 상성은 «비움»이다. 상성도 몸 기준이라 몸이 없으면 기준이 없다.
