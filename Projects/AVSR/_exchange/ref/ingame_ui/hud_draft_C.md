# HUD 2차 C안 배치 의견
상단은 짙은 남색 그라데이션만 남기고 모든 정보 상자를 제거해 전투 시야를 넓혔다.
PLAYER SOUL과 CURRENT HOST는 좌우 정렬과 충분한 여백으로 한 쌍처럼 읽히게 구성했다.
얼굴에만 작은 시안색 둥근 테두리를 두어 초점은 살리고 프레임의 무게는 줄였다.
HP, 레벨, 이름은 원작풍 각진 픽셀 글꼴의 강한 위계로 빠르게 판독되도록 했다.
한글은 굵은 고딕으로 통일해 로비와 전투 화면의 인상을 한 벌로 맞췄다.
스테이지 정보는 우측에 가볍게 띄우고 진행 막대만 남겨 별도의 패널처럼 보이지 않게 했다.
상성 삼각은 중앙 상단의 작은 원형 배지로 분리해 스테이지와 다른 규칙 정보임을 명확히 했다.
런 재화는 금화 아이콘과 41만 표시해 불필요한 자원 패널과 다이아 정보를 없앴다.
조이스틱과 ACTIVE·POSSESS는 하단 양쪽 끝에 두어 전투 판 가림을 B안 이하로 유지했다.
각 부품은 서로 겹치지 않고 독립된 간격을 확보해 이후 낱장 분리와 실제 구현에 대응한다.
