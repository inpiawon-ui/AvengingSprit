AVENGING SPIRIT: RE:BORN — 인게임 UI D안 최종본 · **몸이 없을 때(유령 상태)** 화면

API 키를 쓰는 CLI 폴백은 쓰지 마라. 내장 이미지 생성 기능만 써라.

D안 최종본(hud_draft_D2.png)이 PD 에게 올라갔는데, PD 지적 :
「호스트가 없을 때도 뭔가 있어야 한다. 내가 유령 상태일 때 UI 가 어색하지 않아야 한다.」
이 게임은 플레이어가 유령으로 시작하고, 적에게 빙의해 몸을 얻고, 몸이 죽으면 다시 유령이 된다.
유령 상태는 자주 오는 **정상 상태**다. 빈 칸 · 사라진 버튼 · 한쪽이 뜯긴 화면처럼 보이면 안 된다.
너는 이 게임 UI 의 아트 디렉터다. 유령 상태 화면을 설계해 완성 화면 한 장으로 그려라.

■ 유령 상태에서 게임이 실제로 하는 일 (설계의 근거)
  · 몸이 없으니 CURRENT HOST 칸에 넣을 얼굴 · 이름 · 레벨 · 계열 보석 · 몸 HP 가 없다.
  · 스킬(ACTIVE)은 몸의 기술이라 쓸 수 없다.
  · 상성 표시는 지금 몸의 계열과 적의 관계라, 몸이 없으면 의미가 없다.
  · 유령 HP(PLAYER SOUL)는 몸 없이 떠 있는 동안 서서히 줄어든다 — 빨리 빙의해야 한다.
  · 이때 플레이어가 할 일은 **가까운 적에게 다가가 POSSESS(빙의) 버튼을 누르는 것**이다.

■ 그릴 것 — 같은 전투 판, 유령 상태
  · 판 위 내 캐릭터 자리에 아마존 대신 **유령**(기준 그림과 같은 생김새)이 떠 있다. 적 셋은 그대로.
  · CURRENT HOST 알약 : 사라지지 말고 **「몸 없음」 상태로 디자인된 모습**으로.
    예 : 초상 원 안에 점선 · 반투명 실루엣, 「NO HOST」(픽셀 글꼴) + 「빙의할 몸을 찾으세요」(고딕) 같은 안내,
    HP 막대 대신 비어 있음을 보여 주는 표시 … 정답은 네가 정해라. 다만 칸의 모양과 자리는 몸이 있을 때와 같게 —
    몸을 얻으면 같은 자리에서 내용만 채워지는 느낌이어야 한다.
  · 상성 배지 : 없애서 구멍이 생기게 하지 말고, 의미 없음이 읽히는 상태(흐리게 · 잠김 등)로. 어떻게 할지는 네 판단.
  · ACTIVE 버튼 : 사라지지 말고 **쓸 수 없는 상태**로(흐리게 · 잠김 등).
  · POSSESS 버튼 : 지금 해야 할 일이니 **가장 눈에 띄게**(빛 · 맥동 느낌).
  · PLAYER SOUL : 유령 HP 가 줄고 있음을 알 수 있게(예 : 100/100 이 아니라 72/100 처럼, 막대 끝이 깜빡이는 느낌).
  · 금화 · 일시정지 · 스테이지 정보는 D2 그대로.
