# 알 거미 동작 시안
기존 알 거미의 회백색 알배·적황색 관절·검은 외곽선을 유지하고, 기본 공격은 낮은 자세와 독 방울로 읽히게 했다.
산란은 배를 든 뒤 알주머니가 팽창하고, 낙하한 알에서 새끼가 튀어나오는 흐름으로 구분했다.

## 통과 시 받을 부품
- `spider_attack_e`: 128×128px, 3프레임, 투명 배경.
- `spider_poison_glob`: 36×36px, 1프레임, 투명 배경(비행 이동·회전·크기·투명도는 게임 처리).
- `spider_spawn_e`: 128×128px, 3프레임, 투명 배경.
- `spider_hatch_fx`: 72×72px, 1프레임, 투명 배경(알 파편과 갓 나온 새끼 포함).
- 오른쪽 방향 원본만 받고, 반전·이동·크기 조절은 게임에서 처리한다.

## 공용 부품
- 독 방울은 다른 독성 적의 느린 투사체로 공용 가능하며, 부화 알 파편은 다른 소형 알 몬스터의 생성 효과로 공용 가능하다.
