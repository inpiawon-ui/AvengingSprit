# 4챕터 레일 톱날
- 바닥 매립형 이중 가이드 홈에 톱날 축이 물리고, 양 끝의 스프링 완충 멈춤쇠가 왕복 범위를 잡는 산업 설비로 결정.
- 가로판은 톱날이 끝에, 세로판은 톱날이 가운데에 있어 이동 상태를 한 화면에서 비교한다.
## 통과 시 받을 부품
- `rail_bed`: 432×72px, 1프레임, 투명 배경 — 6칸 직선 홈과 가이드만 포함.
- `rail_end_stop`: 72×72px, 1프레임, 투명 배경 — 한쪽 멈춤쇠 1개만; 반대쪽은 게임에서 반전.
- `rail_axle_carriage`: 72×72px, 1프레임, 투명 배경 — 홈 속 축과 슬라이더.
- `saw_blade`: 144×144px, 4프레임, 투명 배경 — 회전감용 날/하이라이트 변화만.
- 가로·세로 방향, 왕복 위치, 회전, 반전, 이동, 크기 및 투명도 변화는 게임에서 처리한다.
## 공용 부품
- `saw_blade`는 기존 톱날 함정과 공용 가능.
- `rail_end_stop`의 스프링 완충기 표현은 피스톤·압착 함정의 종단 완충 장치와 공용 가능.
