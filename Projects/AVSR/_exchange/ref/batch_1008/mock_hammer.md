# 가로 해머(추) 시안
천장 높이의 양측 브래킷에 걸친 철골 레일과 중앙 트롤리 피벗에서, 경고 도색된 중량추가 사슬 진자로 좌우 이동한다.
한 화면에 왼끝·중앙·오른끝을 겹쳐 비교하며, 중앙 그림자는 크고 진하고 양끝 그림자는 작고 옅다.

## 통과 시 받을 부품 (방 좌표 1칸=72px)
- 철골 레일 모듈: 720×72px, 1프레임, 투명 배경.
- 좌·우 레일 지지 브래킷: 각 72×144px, 각 1프레임, 투명 배경.
- 중앙 트롤리·피벗: 72×72px, 1프레임, 투명 배경.
- 사슬 반복 타일: 24×24px, 1프레임, 투명 배경(회전·길이 조절·반전은 게임 처리).
- 중량추: 144×108px, 1프레임, 투명 배경(좌우 이동·회전·반전·투명도는 게임 처리).
- 바닥 그림자: 144×48px, 1프레임, 투명 배경(거리별 크기·투명도 변화는 게임 처리).

## 공용 부품
- 철골 레일, 브래킷, 트롤리, 사슬 타일, 바닥 그림자는 다른 천장 함정·매달린 장애물에도 공용 사용.
