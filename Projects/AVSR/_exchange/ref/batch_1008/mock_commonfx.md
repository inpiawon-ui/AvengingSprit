# 공용 피격·죽음 이펙트 결정안
청백색 핵광, 시안 고리, 옅은 보랏빛 혼기와 소량의 금빛 불티로 통일한다.
물질 파편 대신 빛과 혼이 위로 걷히므로 「쓰레기가 터지는」 무게감·난잡함을 없앤다.

- 1줄 피격: 평타 접점에 128px 기준 0.12~0.20초, 화면 표시 지름 18~28px.
- 기존 피격의 큰 불꽃·회색 연기·과한 파편은 빼고 짧은 핵광과 가는 빛살만 쓴다.
- 2줄 치명타·약점: 160px 기준 0.22~0.32초, 화면 표시 지름 36~56px.
- 평타보다 밝은 별빛과 얇은 고리, 금빛 불티 3~5개만 추가한다.
- 3줄 잡몹 죽음: 160px 기준 0.45~0.65초, 화면 표시 지름 48~72px·상승 높이 64~96px.
- 기존 잡몹 죽음의 돌 조각·shard_dust·smoke_dust를 빼고 혼 고리→상승→소멸로 교체한다.
- 4~5줄 보스 죽음: 256px 기준 1.20~1.60초, 화면 표시 지름 180~260px·상승 높이 220~320px.
- mock_burst와 동시 사용 시 첫 섬광을 겹치고, 0.08~0.15초 뒤 혼 고리와 상승 연출을 잇는다.
- 기존 보스 죽음의 회갈색 돌 파편·흙먼지·덩어리 연기는 전부 뺀다.
- 아래 낱장은 빛 조각 6~12개, 혼 연기 1~3개, 빛 알갱이 8~18개, 가는 빛살 4~8개 권장.
- 모든 낱장 파티클은 위쪽 편향, 감속·페이드아웃으로 쓰며 지면 무너짐·착지용 먼지와 분리한다.
