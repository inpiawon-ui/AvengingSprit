# 피격 FX 수치 조정표 r4

기준 시안: `in/mock_hitfx_v7.png`  
현재 비교: `ref/hitfx_ingame/compare_r3.png`의 맨 위 시안과 0.035 / 0.075 / 0.125초 게임 캡처(2배)  
r3 적용 결과를 현재 값으로 본다. 단, 불리의 실제 적용값은 Claude가 정정한 `56×9 → 70×12`, `50×5 → 66×8`이다. 넷째 적의 노란 시험판 외형은 판정에서 제외한다. 표에 없는 함수 수치는 r3를 유지한다.

## 판정

**부분 통과.** 보통은 **통과**다. 치명·유리·불리는 아직 미통과다.

- **보통: 통과. 변경 없음.** 크기, 흰 중심, 잔광과 파편의 밀도가 시안 허용 범위다.
- **치명: 미통과.** 방사광의 길이와 밝기는 충분하지만 0.035초에 모든 광선의 안쪽 끝이 같은 중심에서 만나 십자·별로 읽힌다.
- **유리: 미통과.** 주황 낱알이 사실상 보이지 않고 원뿔도 밝은 심이 없는 흐린 주황 덩어리다. 시안의 `밝은 노랑·흰 심 → 주황 몸통 → 진한 주황 외곽` 3단이 없다.
- **불리: 미통과.** 0.035초에 충돌면이 생기기는 했지만 시안보다 작고 짧아서 “막혀 튕겼다”는 첫 박자가 약하다.

`_hxBeamMat`은 치명 방사광 재질이 아니라 **유리의 몸 관통 빛기둥 재질**이다. 치명 방사광은 HxDot 파티클이므로 이번 치명 수정은 HxDot의 생성 위치와 길이만 건드린다.

맞은 탄 자체의 반사체, 방패, 반고리, 돔은 계속 추가하지 않는다. 불리는 납작한 충돌면과 `-dir` 방향 파편만으로 튕김을 표현한다.

## 1. 시안 대비 r3 결과의 어긋난 점

시안과 비교 캡처는 2배 표시를 원본 720×1280 기준으로 환산해 쟀다. 블룸과 숫자 겹침을 포함한 측정 오차는 ±3 px다.

| 경우 | 시안 | r3 결과(측정) | 판정 |
|---|---|---|---|
| 보통 | 흰 중심 약 22×22 px, 얇은 잔광 약 34×34 px, 작은 흰 파편 5개 | 0.035초 중심 약 21~25 px, 이후 흰 파편과 잔광의 소멸 순서도 맞음 | **통과. 변경 없음.** |
| 치명 | 흰 중심 약 28 px. 방사광 8개가 중심 주위에서 각각 끊겨 시작하고 바깥으로 퍼짐 | 0.035초 중심광은 약 30~35 px로 맞지만, 방사광의 안쪽 끝 5~7개가 반경 0~3 px에 몰려 약 28~36 px 십자·별 매듭을 만듦 | 바깥 길이가 아니라 **안쪽 시작점** 문제다. 시작 반경을 벌리고 길이를 줄여 중심과 겹치지 않게 한다. |
| 유리 | 출구 폭 18~22 px, 끝 폭 약 46 px, 길이 약 82 px. 중앙의 노랑·흰 심은 약 7~10 px, 주황 불티 9~11개가 원뿔보다 좌우 8~18 px 넓게 분산 | 0.035~0.125초 원뿔 길이는 약 72~84 px로 맞지만 폭 전체가 비슷한 연주황. 중심의 밝은 심은 약 3~5 px이고 독립된 주황 불티는 0~2개만 식별됨 | 크기보다 명도 계층과 낱알 분리가 틀림. 원뿔 심을 강화하고 주황 낱알 전용 재질을 분리한다. |
| 불리 | 접촉점의 은백색 충돌면 약 54×12 px. 첫 프레임부터 납작한 면이 몸통 앞에 독립적으로 읽힘 | 실제 r3 값은 뒤 면 `56×9 → 70×12`, 앞 면 `50×5 → 66×8`. 그런데 0.035초 화면에서 읽히는 합성 윤곽은 약 38~44×7~9 px로 시안보다 폭 10~16 px 부족 | 생성 크기와 알파를 함께 올리고 수명을 조금 늘린다. 파편·꼬리는 건드리지 않는다. |

## 2. 함수별 바꿀 수치표

표에 없는 항목은 r3 그대로 둔다.

### HxTap — 보통

**통과. 변경 없음.**

### HxCrit — 치명

치명 방사광은 `_hxBeamMat`이 아니라 **HxDot 파티클**이다.

| 계층 | 항목 | 지금 값(r3) | 새 값(r4) |
|---|---|---|---|
| HxDot 방사광 | 개수 | `7` | `7` |
| HxDot 방사광 | 기준 각도 흔들림 | `±14°` | `±17°` |
| HxDot 방사광 | 속도 | `190~305` | `205~310` |
| HxDot 방사광 | 길이×폭 | `46~58 × 6` | `40~52 × 5` |
| HxDot 방사광 | 수명 | `0.16~0.19` | `0.15~0.18` |
| HxDot 방사광 | 생성 위치 | 중심 반경 `0~4 px` 분산 | 중심 반경 **`10~16 px`**, 각 광선 방향으로 바깥 이동 |
| HxDot 방사광 | 생성 위치의 접선 흔들림 | 없음 | 각 광선 접선축 `-3~+3 px` |
| HxDot 방사광 | 생성 시각 | `0 / 0.004 / 0.008 / 0.012초` 순환 | `0 / 0.006 / 0.012 / 0.018초` 순환 |

핵심은 중심에서 선을 뽑지 않는 것이다. 각 광선의 안쪽 끝이 흰 중심광 가장자리 밖에서 시작해야 한다. 0.035초에 서로 닿는 안쪽 끝이 있으면 실패다. 바깥 도달 반경은 현재와 비슷하게 유지하되, 짧아진 길이는 시작 위치와 속도로 보상한다.

## 3. HxBuild 재질값

`_DstBlend = 10`은 보통 섞기, `_DstBlend = 1`은 더하기다. 아래 표는 피격 FX에서 쓰는 **모든 재질의 r4 목표값**이다. `_RingWhite`와 `_CoreWhite`를 쓰지 않는 셰이더도 명시값으로 고정한다.

| 재질 | 역할 | 지금 값(r3) `_DstBlend / _RingWhite / _CoreWhite` | 새 값(r4) `_DstBlend / _RingWhite / _CoreWhite` |
|---|---|---:|---:|
| `_hxDotMat` | 흰 점·잔광·긴 빛꼬리 및 치명 HxDot 방사광 | `1 / 0.70 / 0.80` | `1 / 0.70 / 0.80` |
| `_hxRingMat` | 흰·금빛 고리 | `1 / 0.62 / 0.80` | `1 / 0.62 / 0.80` |
| `_hxBeamMat` | **유리의 몸 관통 빛기둥** | `1 / 0.70 / 0.72` | `1 / 0.78 / 0.88` |
| `_hxConeMat` | 유리의 진한 주황 원뿔 | `10 / 0.10 / 0.34` | `10 / 0.08 / 0.72` |
| `_hxConeGlowMat` | 유리의 바깥 주황 번짐 | `10 / 0.08 / 0.18` | `10 / 0.04 / 0.10` |
| `_hxPlaneMat` | 불리의 앞 흰빛면 | `10 / 0.22 / 0.46` | `10 / 0.30 / 0.62` |
| `_hxPlaneBackMat` | 불리의 뒤 은빛면 | `10 / 0.12 / 0.30` | `10 / 0.18 / 0.42` |
| `HxDotSolid_Gold` | 치명 금빛 낱알 | `10 / 0.08 / 0.80` | `10 / 0.18 / 0.80` |
| `HxDotSolid_Silver` | 불리 은빛 낱알 | `10 / 0.08 / 0.80` | `10 / 0.38 / 0.82` |
| `HxDotSolid_Orange` **신규 분리** | 유리 주황 낱알 | 공용 `10 / 0.08 / 0.80` | `1 / 0.58 / 0.92` |
| `_hxHalfRingMat` | 피격 FX 미사용 | `10 / 0.20 / 0.80` | `10 / 0.20 / 0.80` |

원뿔의 3단 명도는 다음 보조값으로 만든다.

| 재질 | 속성 | 지금 값(r3) | 새 값(r4) |
|---|---|---:|---:|
| `_hxConeMat` | `Body / CoreWidth / CoreBoost` | `0.98 / 0.10 / 0.72` | `1.00 / 0.18 / 1.15` |
| `_hxConeMat` | `EdgeSoft / EdgeLine` | `0.10 / 0.08` | `0.07 / 0.12` |
| `_hxConeGlowMat` | `Body / CoreWidth / CoreBoost` | `0.22 / 0.06 / 0.28` | `0.14 / 0.04 / 0.12` |
| `_hxConeGlowMat` | `EdgeSoft / EdgeLine` | `0.26 / 0.00` | `0.30 / 0.00` |
| `_hxPlaneMat` | `Body / CoreWidth / CoreBoost` | `0.82 / 0.16 / 0.52` | `0.90 / 0.20 / 0.68` |
| `_hxPlaneBackMat` | `Body / CoreWidth / CoreBoost` | `0.62 / 0.12 / 0.34` | `0.72 / 0.15 / 0.46` |
| `HxDotSolid_Gold` | `_RingWidth / _RingGlow` | `0.66 / 0.14` | `0.62 / 0.18` |
| `HxDotSolid_Silver` | `_RingWidth / _RingGlow` | `0.66 / 0.14` | `0.60 / 0.20` |
| `HxDotSolid_Orange` | `_RingWidth / _RingGlow` | 공용 `0.66 / 0.14` | `0.48 / 0.30` |

`HxDotSolid_Orange`만 더하기(`_DstBlend = 1`)로 분리해 작은 낱알에서도 노랑·흰 심을 살린다. `_RingWhite = 0.58`은 전체를 흰색으로 바꾸는 값이 아니라 중심만 밝히는 값이며, 바깥 몸색은 주황을 유지해야 한다. 유리 원뿔은 `_hxConeMat`의 심을 세우고 `_hxConeGlowMat`을 낮춰 밝은 중심과 진한 외곽 사이가 뭉개지지 않게 한다.

## 4. 다음 캡처 점검표

| 시각 | 보통 | 치명 | 유리 | 불리 |
|---|---|---|---|---|
| 0.035초 | **통과 유지:** 중심 20~25 px, 몸통을 완전히 가리지 않음 | 흰 중심 가장자리와 방사광 안쪽 끝 사이 `2~6 px` 빈틈. 방사광끼리 중심에서 만나지 않음 | 폭 18~22 px의 주황 몸통 안에 노랑·흰 심 `7~10 px`. 독립 주황 불티 4개 이상 | 접촉점에 합성 윤곽 `52~62×10~14 px`의 납작한 은백색 면이 독립적으로 보임 |
| 0.075초 | **통과 유지:** 흰 파편 3개 이상 | 방사광 5개 이상이 각각 끊겨 보임. 십자·별·마름모 없음 | 원뿔 길이 `70~86 px`. `밝은 심 → 주황 몸 → 진한 외곽` 3단이 보이고 불티 7개 이상 | 충돌면 잔광과 `-dir` 은빛 불티가 분리되어 보임 |
| 0.125초 | **통과 유지:** 작은 잔광만 남음 | 금빛 낱알 8개 이상, 닫힌 선 윤곽 없음 | 둥근 주황 불티 `9~11개`; 원뿔보다 좌우로 넓게 퍼진 낱알 4개 이상 | 면은 사라지고 은빛 낱알 5개 이상과 긴 꼬리 2~3개만 남음 |

| 금지 형태 | 별·고리 과장 없음 | **중심 십자·별·마름모·닫힌 다각형 없음** | 흐린 연기 덩어리·분홍 파스텔·단색 주황 면·화살촉 없음 | 방패·반고리·돔·화살촉·새 투사체 없음 |

최종 통과 기준은 원본 720×1280에서 네 경우가 각각 `중심 형태 1개 + 방향성 파편`으로 즉시 구분되는 것이다. 보통은 **통과 유지**다. r4에서는 치명 방사광의 중심 분리, 유리의 밝은 심과 9~11개 주황 불티, 불리의 0.035초 충돌면 크기를 우선 확인한다.
