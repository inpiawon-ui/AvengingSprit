# A. 총평

시안의 핵심 흐름인 이탈→후보 선택→빙의와 실패→되살리기는 모두 실제 화면에서 읽힌다.
다중 후보의 강조 이동과 빙의/나가기 버튼 분리는 지난 판보다 분명해져 기능 전달은 통과 수준이다.
다만 빙의·부활의 전기와 빛기둥이 캐릭터보다 커서 원작 동작을 덮으므로, 크기와 밝기를 한 단계 더 절제해야 한다.

# B. 고칠 것

1. **`_review_soul_target.png` 7~8번째 프레임** — 빙의 직후 양옆 전기가 캐릭터 폭보다 넓고 몸통까지 겹쳐 원작 빙의 동작의 실루엣이 끊긴다. 전기 외곽 폭을 지금의 **0.65배**, 높이를 **캐릭터 키의 0.9배**, 중심부 불투명도를 **40% 낮추고**, 캐릭터 몸통에서 좌우 **12 px**를 비운다.
2. **`_review_soul_revive.png` 8~9번째 프레임** — 부활 기둥이 캐릭터 키의 약 2배 이상 솟고 중심 섬광이 몸 전체를 덮어, 내려온 유령과 일어서는 몸의 순서가 한 덩어리로 보인다. 기둥 높이를 **캐릭터 키의 1.5배**, 폭을 지금의 **0.7배**, 중심 백색광 불투명도를 **35% 낮추고**, 기둥이 최고 밝기에 머무는 시간을 **0.20초 이하**로 제한한다.
3. **`_review_soul_exit.png` 2~3번째 프레임** — 발밑 물결과 혼줄의 청백광이 동시에 강해 쓰러지는 몸보다 이펙트가 먼저 읽힌다. 물결 지름을 지금의 **0.8배**, 외곽 점광 수를 **30% 줄이고**, 혼줄 굵기를 지금의 **0.6배**로 줄인다.
4. **`_review_soul_target.png` 1~4번째 프레임** — 선택되지 않은 후보의 빛줄기도 선택 후보와 크기·채도가 가까워 현재 버튼 입력 대상이 한눈에 고정되지 않는다. 현재 후보는 폭을 **캐릭터 폭의 1.35배**, 밝기를 현행 **100%**로 두고, 비선택 후보는 폭을 그 빛줄기의 **0.65배**, 밝기를 **45%**, 채도를 **60%**로 낮춘다. 세 후보 모두에는 최소 **캐릭터 키의 0.25배** 높이의 약한 발밑 고리를 남긴다.
5. **`_review_soul_revive.png` 1~2번째 프레임** — 실패 문구가 버튼 테두리와 너무 가깝고 작아 전투 화면에서 놓치기 쉽다. 문구를 버튼 위로 **16 px** 띄우고, 배경 패널 폭을 글자 폭보다 좌우 **12 px**씩 넓히며, 표시 시간을 **1.2초**로 둔다.
6. **`_review_soul_revive.png` 3~7번째 프레임** — 혼줄의 굴곡과 굵기가 프레임마다 크게 달라져 유령이 줄을 따라 내려간다기보다 위치가 건너뛰는 인상이 난다. 혼줄 굵기를 전 구간 **2 px**로 통일하고, 유령 하강 거리를 프레임당 **캐릭터 키의 0.25배 이하**로 제한하며, 몸에 닿기 전 **0.15초** 감속 구간을 둔다.

# C. 그대로 둘 것

- `_review_soul_exit.png` 후반의 방 어두워짐과 후보 몸 위 빛줄기 전환은 전투 상태와 선택 상태를 즉시 갈라 준다.
- `_review_soul_target.png`에서 유령 이동에 따라 가장 밝은 빛줄기가 다른 몸으로 옮겨 가는 규칙은 다중 후보를 명확히 설명한다.
- `_review_soul_revive.png`의 유령 대기→혼줄 하강→몸 기상 순서는 되살리기의 원인과 결과가 끊기지 않는다.
