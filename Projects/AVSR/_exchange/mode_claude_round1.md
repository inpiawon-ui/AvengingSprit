# 클로드 1차 후보 (코덱스 답을 보기 전에 적음)

1. **현상수배 (Bounty)** — 매일 바뀌는 수배 대상(특정 호스트) 하나를 무리 속에서 찾아 상성 맞는 몸으로 잡는다. 보상 = 그 호스트의 조각. 조각 해금 경제와 바로 연결. 소~중.
2. **빙의 퍼즐 (Possession Puzzle)** — 손으로 짠 한 방 문제. 정해진 몸만 있고, 기둥을 넘는 몸·뚫는 몸·밀리지 않는 몸을 순서대로 갈아타야 출구가 열린다. 별 3개. 방 손배치 도구 재사용. 중.
3. **영혼 릴레이 (Relay / 타임어택)** — 몸이 10초 만에 썩는다. 계속 갈아타며 최단 시간에 방들을 뚫는다. 빙의 횟수·연쇄가 점수. 중.
4. **망령의 탑 (Tower)** — 끝없는 층. 층마다 규칙 하나(모든 적 마법 / 몸 체력 1 / 유령 에너지 회복 없음). 주간 기록. 중.
5. **아케이드 클래식 (1991 모드)** — 원작 순서 · 목숨 3 · 크레딧 · 점수 · 원작 음악. 레트로 팬 어필. 대(원작 무대 재현).
6. **역빙의 / 보스가 되어라** — 보스(평소 못 뺏는 몸)에 빙의해 몰려오는 호스트 부대를 쓸어 버린다. 짧은 이벤트형. 중.
7. **빙의 서바이벌** — 시간 버티기. 몸이 먼저 들어오는 웨이브. 중.
8. **영혼의 등불 (디펜스)** — 버린 몸이 수비대가 된다. 대.

추천(잠정): 현상수배(매일·짧게·조각 경제) + 빙의 퍼즐 또는 망령의 탑(깊게·도전).
