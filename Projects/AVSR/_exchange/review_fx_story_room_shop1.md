# 판정: 수정 필요 — 시안과 동일하지 않음

검수 대상은 방 오브젝트 원화가 아니라 `layers_room_shop()`의 이펙트 층이다. 비교 기준은 승인 시안 `mock_fxstory_room_shop_v1.png`, 정지 비교판 `room_shop_vs_mock.png`, 동작본 `room_shop.gif`이다.

현재 재현은 대기와 다가감에서 같은 큰 불꽃이 계속 오브젝트 전면을 덮어 두 상태가 거의 구분되지 않는다. 작동 컷은 상점 창이 없는 채 오브젝트만 반투명해지고, 금화 고리가 과노출되어 시안의 “짧고 확실한 작동 + 즉시 열린 상점”과 다르다. 별/십자 반짝이와 화면 전체 틴트는 없어 금지 조건은 지켰다.

부품 그림은 다섯 종 모두 시안의 형태와 맞는다. **재발주 없음.** 문제는 크기·좌표·합성·알파·단계 배정이다.

## 1컷 — 대기(멀리 있을 때, 0.0~1.6초)

### 시안과 다른 점

- 시안의 혼불은 상점 실루엣을 따라 가늘고 은은하게 일렁이며 원화를 읽을 수 있다. 재현은 `room_shop_soul_flame`이 정면에 강한 가산 합성으로 붙어 얼굴과 몸통을 거의 불덩이로 만든다.
- 시안의 떠 있는 금화는 오브젝트 좌우 바깥까지 넓게 흩어져 있다. 재현은 `200 x 200` 안에 몰려 중앙 불꽃과 겹치며 별도 장식으로 읽히지 않는다.
- 시안의 등불은 기존 네 등불 자리에서 하나씩 잔잔하게 밝아진다. 재현은 `46 x 46`, 알파 `0.85`, 가산 합성이라 네 곳이 모두 흰색에 가깝게 과노출된다.
- 대기 장식이 전부 앞층이라 오브젝트 표면을 가린다. 시안처럼 혼불과 떠 있는 금화는 뒤층, 등불만 앞층으로 분리해야 한다.

### `layers_room_shop()`에서 바꿀 값

- `room_shop_soul_flame`
  - `(x, y)`: `(0, 0)` → `(0, 4)`
  - `(w, h)`: `(210, 320)` → `(184, 294)`
  - 프레임 간격: `0.12` → `0.16`
  - 시작/끝: `t0=0.0, t1=0.0` 유지(대기 동안 반복)
  - 알파: `0.70` → `0.28`
  - 합성: `add=True` → `add=False`(덮기)
  - `back=False` → `back=True`
  - `fade=0.15`, `phase='open'`, `loop=True` 유지
- `room_shop_coin_float`
  - `(x, y)`: `(0, -120)` → `(0, -18)`
  - `(w, h)`: `(200, 200)` → `(390, 220)`
  - 프레임 간격: `0.14` → `0.18`
  - 시작/끝: `t0=0.2, t1=0.0` → `t0=0.10, t1=0.0`
  - 알파: `0.70` → `0.52`
  - 합성: `add=True` 유지
  - `back=False` → `back=True`
  - `fade=0.15`, `phase='open'`, `loop=True` 유지
- 네 개 `room_shop_lantern`
  - 중심 좌표: `[(-95,-55),(95,-55),(-95,25),(95,25)]` → `[(-91,-49),(91,-49),(-91,23),(91,23)]`
  - 크기: 네 층 모두 `46 x 46` → `34 x 34`
  - 프레임 간격: 각기 `0.12/0.14/0.16/0.18` → `0.18/0.20/0.22/0.24`
  - 시작: `0.00/0.07/0.14/0.21` → `0.00/0.18/0.36/0.54`
  - 끝: 모두 `t1=0.0` 유지
  - 알파: `0.85` → `0.58`
  - 합성: `add=True` 유지
  - `back=False`, `fade=0.15`, `phase='open'`, `loop=True` 유지

이 값이면 대기 컷은 혼불 윤곽, 좌우 부유 금화, 순차 등불만 남고 상점 원화의 얼굴·몸통·외곽을 가리지 않는다.

## 2컷 — 다가감(240 안, 1.6~2.8초)

### 시안과 다른 점

- 시안은 접근 순간 눈이 짧게 점등되고, 네 등불의 점멸이 조금 또렷해지는 것이 핵심이다. 재현은 대기 불꽃이 계속 가장 밝아 눈 점등이 묻힌다.
- `room_shop_eye_glow`가 `70 x 35`로 넓어 두 눈이 아니라 얼굴 전체의 불빛처럼 보인다.
- 시안의 접근 강조는 오브젝트 내부에만 머문다. 현재 큰 혼불 때문에 접근 전후 밝기 변화가 불분명하다.

### `layers_room_shop()`에서 바꿀 값

- 1컷의 혼불·금화·등불 수정값을 그대로 유지한다. 접근 단계에서도 이들은 은은한 배경 장식이어야 한다.
- `room_shop_eye_glow`
  - `(x, y)`: `(0, -95)` → `(0, -71)`
  - `(w, h)`: `(70, 35)` → `(48, 24)`
  - 프레임 간격: `0.08` → `0.10`
  - 시작/끝: `t0=0.0, t1=0.4` → `t0=0.04, t1=0.46`
  - 알파: 기본 `1.0` → `0.78`
  - 합성: `add=True` 유지
  - `back=False`, `loop=False`, `fade=0.05`, `phase='near'` 유지

눈 점등은 접근 뒤 0.04초에 시작하여 0.46초에 끝나는 1회 반응으로 두고, 접근 구간 전체를 계속 번쩍이게 하지 않는다. 별/십자 파티클은 추가하지 않는다.

## 3컷 — 작동/상점 열림(2.8~3.8초)

### 시안과 다른 점

- 시안은 닿는 순간 금화 고리가 상점 발밑에서 넓게 한 번 퍼지고, 동시에 상점 창이 열린다. 재현은 고리가 지나치게 밝고 두꺼우며 화면 중앙에서 흰 띠처럼 보인다.
- 재현은 작동 순간 오브젝트 원화가 알파 약 `0.45`로 흐려진다. 승인 시안은 상점이 정상 명도로 남아 있다.
- 비교판의 재현 3.05초에는 상점 창이 전혀 없다. 이 때문에 “글자·버튼을 가리지 않음”과 “선택 반응이 고른 칸에서 시작”을 이 산출물로는 최종 판정할 수 없다.
- 방 오브젝트 접촉 반응인 금화 고리는 선택 칸 기점 효과가 아니다. 실제 구매 클릭 반응을 이 층으로 대신 쓰면 안 된다. 구매 반응은 상점 팝업 쪽 별도 `accept` 층이 `atNode='ShopItem{slot}'`에서 시작해야 한다.

### `layers_room_shop()`에서 바꿀 값

- `room_shop_coin_ring`
  - `(x, y)`: `(0, 100)` → `(0, 112)`
  - `(w, h)`: `(420, 210)` → `(390, 156)`
  - 프레임 간격: `0.09` → `0.08`
  - 시작/끝: `t0=0.0, t1=0.6` → `t0=0.0, t1=0.48`
  - 알파: 기본 `1.0` → `0.72`
  - 합성: `add=True` → `add=False`(덮기; 금화의 노랑/주황 픽셀색 보존)
  - `back=False` 유지. 앞쪽 금화가 오브젝트 발 앞을 지나야 한다.
  - `loop=False`, `fade=0.06`, `phase='accept'` 유지/변경(`fade`는 `0.08` → `0.06`)
- 작동 중 대기층은 `render_room()`의 `used` 분기로 이미 꺼지므로 별도 `t1`을 넣지 않는다. 고리는 0.48초 한 번만 재생하고 반복하지 않는다.
- `layers_room_shop()`에는 `atNode`를 넣지 않는다. 이 함수의 `panel`이 빈 문자열이고 방 기준 좌표를 쓰므로 `ShopItem{slot}`을 해석할 수 없다. 구매 클릭 반응은 팝업 상점의 별도 레이어 표에서 `atNode='ShopItem{slot}'`로 두어야 한다.

## 합성표만으로 해결되지 않는 검수 차단점

아래 두 항목은 `layers_room_shop()` 값이 아니므로 이번 값 수정과 분리해서 처리해야 한다. 다만 둘 중 하나라도 남으면 승인 시안과 같은 최종 화면이 아니므로 통과시킬 수 없다.

1. `render_room()`은 작동 시 오브젝트를 `0.45` 알파로 낮춘다. 최종 런타임/캡처에서는 오브젝트를 `1.0`으로 유지해야 한다.
2. `room_shop_vs_mock.png` 아래 3컷은 상점 팝업을 합성하지 않는다. 최종 검수본은 실제 `ShopPanel`을 띄운 상태로 다시 캡처해야 한다. 창 배치는 `popup_c_layout.py`의 `SP=(15,395)`, `ShopBox 690 x 545`를 따르고, 글자는 `consult_popup_typography.md`의 상점 규칙을 그대로 사용한다. 이펙트는 제목, 보유 골드, 상품명·가격·설명, 버튼 위를 지나거나 가려서는 안 된다.
