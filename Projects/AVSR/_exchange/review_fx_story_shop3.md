# 판정: 통과

검수 기준: `mock_fxstory_shop_v1.png`, `shop_vs_mock.png`, `shop.gif`, `layers_shop()`, `popup_c_layout.py`, `consult_popup_typography.md`.

2회차 필수 수정인 여섯 칸 `shop_cell_rim alpha=0.48`이 제대로 반영됐다. 등장 순서, 대기 중 은은한 장식, 선택한 칸에서 시작하는 구매 반응, 창이 닫힌 뒤 플레이어 몸에 남는 능력치 적용 빛까지 PD 시안의 의도와 일치한다. 글자·버튼을 가리는 효과, 별/십자 반짝이, 화면 전체 착색은 없다. PD에게 최종본으로 제시할 수 없을 만큼 시안과 다른 부분은 남지 않았다.

## 1컷 — 등장 (0.25초)

### 시안과 다른 점

- 없음. 중앙 등불이 먼저 켜지고 좌우 관과 상단 배관이 뒤따르는 읽기 순서가 시안과 같다.
- 중앙 광륜은 제목과 보유 골드 글자를 가리지 않고, 좌우 관의 혼불도 상품명·설명 영역을 침범하지 않는다.

### `layers_shop()`에서 바꿀 값

- 없음. 아래 값을 유지한다.
- `shop_lamp_glow`: 좌표 `(360, 435)`, 크기 `160×160`, 프레임 간격 `0.10`, 시작 `0.00`, 종료 없음, `alpha=0.72`, 가산, `back=True`, `untilAccept=True`.
- 좌우 `shop_tube_ghost`: 좌표 `(46, 695)` / `(674, 695)`, 크기 `44×300`, 프레임 간격 `0.14`, 시작 `0.16` / `0.22`, 종료 없음, `alpha=0.68`, 가산, `back=False`, 오른쪽만 `flip=True`, `untilAccept=True`.
- 좌우 `shop_pipe_flow`: 좌표 `(205, 463)` / `(515, 463)`, 크기 `200×36`, 프레임 간격 `0.10`, 시작/끝 `0.22~0.82` / `0.28~0.88`, `loop=False`, `alpha=0.50`, 가산, `back=True`.

## 2컷 — 최대/대기 (2.00초)

### 시안과 다른 점

- 없음. 2회차에서 약했던 여섯 상품 칸의 주황 테두리 호흡이 `alpha=0.48` 적용 후 시안처럼 분명하게 읽힌다.
- 테두리 호흡과 한 번 지나가는 얇은 광택이 상품명·가격·설명의 판독성을 해치지 않는다. 대기 장식도 화면 전체를 물들이지 않고 창 내부에만 은은하게 머문다.

### `layers_shop()`에서 바꿀 값

- 없음. 이번 회차 반영값을 그대로 유지한다.
- 여섯 `shop_cell_sheen`: 각 칸 중심 `cen(c)`, 크기 `270×91`, 프레임 간격 `0.10`, 시작 `0.38+0.06*i`, 끝 `0.62+0.06*i`, `loop=False`, `fade=0.08`, `alpha=0.22`, 가산, `back=True`, `untilAccept=True`.
- 여섯 `shop_cell_rim`: 각 칸 중심 `cen(c)`, 크기 `282×103`, 프레임 간격 `0.16`, 시작 `0.72+0.07*i`, 종료 없음, `loop=True`, `fade=0.16`, `alpha=0.48`, 가산, `back=False`, `untilAccept=True`.

## 3컷 — 선택/수락/구매 (4.05초, 누른 뒤 0~0.35초)

### 시안과 다른 점

- 없음. 반응은 고른 칸 가운데에서 시작한다.
- 금화 파열과 HUD 골드 방향 줄기, 반대 방향으로 올라가는 아이콘 궤적이 시안의 두 갈래 반응과 같다. 선택 칸의 상품 글자를 지속해서 가리는 면광도 없다.
- 구매 효과는 모두 0.34초 안에 끝나며, 대기 장식은 수락과 함께 종료된다.

### `layers_shop()`에서 바꿀 값

- 없음. 아래 값을 유지한다.
- `shop_coin_burst`: `atNode='ShopItem{slot}'` 중심 `(0, 0)`, 크기 `130×130`, 프레임 간격 `0.07`, 시작/끝 `0.00~0.28`, `loop=False`, `fade=0.04`, `alpha=0.72`, 가산, `back=False`.
- `shop_coin_to_gold`: 같은 중심에서 `(75, 152)` 방향, 높이 `18`, 프레임 간격 `0.05`, 시작/끝 `0.02~0.32`, `loop=False`, `fade=0.03`, `alpha=0.90`, 가산, `back=False`, `beam=True`, `tint=(255, 200, 61)`.
- `shop_item_arc`: 같은 중심 기준 `(0, -175)`, 크기 `250×390`, 프레임 간격 `0.06`, 시작/끝 `0.03~0.34`, `loop=False`, `fade=0.03`, `alpha=0.92`, 가산, `back=False`.

## 4컷 — 창이 닫힌 뒤 능력치 적용 빛 (4.55초)

### 시안/추가 조건과 다른 점

- 없음. 선택 뒤 약 0.35초에 창이 닫히고 플레이어 몸에서 상점 이벤트색 빛이 시작된다.
- 빛은 플레이어 몸 주변의 `180×220` 범위에 한정되어 화면 전체를 물들이지 않는다. 별/십자 반짝이도 없다.

### `layers_shop()`에서 바꿀 값

- 없음. `powerup('shop')`을 유지한다.
- 플레이어 몸 기준 `(0, -10)`, 크기 `180×220`, 프레임 간격 `0.07`, 시작/끝 `0.35~0.95`, `alpha=0.95`, 가산, `back=False`, `tint=(255, 174, 32)`, `fromAvatar=True`.
