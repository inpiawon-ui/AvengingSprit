## 코덱스 답과 다르게 정한 것
- **아래 바는 지금 4칸(HOST · PLAY · SUMMON · SHOP) 유지**, PLAY 만 가운데 1.15배로 크게. 코덱스 안(SHOP 빼고 HOME)은 상점 매출 동선을 끊어서 — PD 가 원하면 그때 바꾼다.
- **위 막대는 재화 3종(⚡행동력 · 골드 · 젬)** — 행동력은 출전 비용이라 늘 보여야 한다. 우편 · 설정 · 시즌은 프로필 쪽으로.
- 도트 캐릭터는 **정수 배율(2배 · 3배)**, 유령은 PD 지정 기준 그림 그대로(`ref/ui_v2/ghost_anchor.png` — 통통한 달걀 몸 · 짧은 꼬리 · 큰 눈 · 큰 입).
- 성급 표기 · 등급은 이미 정한 것 유지: 「N성」 + 은별 1~4 · 5성마다 큰 금별, R · SR · SSR 배지.

- 터치 72×72 이상 · 주 버튼 높이 84~96
- 한 화면: 주 행동 1 · 주 구역 3 · 카드 4 또는 목록 6행. 넘치면 탭 · 시트 · 다음 페이지
- 뎁스 4층: 홈 → 전체 화면 페이지 → 아래 시트(55~75%) → 확인 팝업
- 호스트 육성은 `기본 능력 / 스킬 / 성급` 탭 셋으로 나누고, 세부는 시트로
- 소환은 장면 전환 흐름(코덱스 답 3절 표): 대기 → UI 퇴장 0.35초 → 장치 개방 0.8 → 빙의 탐색 0.7~1.2 → 등급 확정 → 결과(1회 / 10회), 건너뛰기 0.6초 뒤
