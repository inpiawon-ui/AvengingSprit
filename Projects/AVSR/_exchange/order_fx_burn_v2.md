# 발주 — 화상(불붙음) 이펙트 다시: `fx_burn_1~4`

## 왜 다시 하나

지난번 `fx_burn` 은 몸을 **둥글게 감싼 불 고리**로 왔다. 적이 고리 안에 서 있는 것처럼 보여서
「몸에 불이 붙었다」로 안 읽힌다. 기획 요청 그대로 옮긴다 —

> 주변에 불꽃 애니 3~4프레임 정도로 **몸이 불타고 있다는 느낌**

## 무엇을 그리나

**몸 여기저기에 붙어 타는 작은 불꽃 여러 개**다. 고리·원·테두리가 아니다.

- 캔버스 한 칸 = 96 × 96. 적 몸은 이 칸 **가운데 약 56 × 72** 자리를 차지한다(그림에는 몸을 그리지 마라)
- 그 몸 **가장자리에 작은 불꽃 5~7 개**를 따로따로 붙인다
  - 어깨·머리 위 1~2 개, 왼쪽 옆구리 1~2 개, 오른쪽 옆구리 1~2 개, 발밑 1 개
  - 불꽃 하나 크기: 폭 10~18 px, 높이 14~26 px. 전부 **위로** 타오른다
- 몸통 한가운데(가로 30~66, 세로 30~70)는 **비워 둔다** — 적 그림이 보여야 한다
- 작은 불똥 2~3 개(1~2 px)가 위로 튀면 좋다

```
      ᐱ   ᐱ          어깨·머리 위
   ᐱ  (  몸  )  ᐱ    옆구리 — 불꽃은 따로 떨어져 있다
   ᐱ  (      )  ᐱ
       ᐱ   ᐱ          발밑
```

## 애니메이션

- **4 프레임 루프** (1 → 2 → 3 → 4 → 1)
- 불꽃 **자리는 그대로**, 모양만 바뀐다 — 혀 높이가 들쭉날쭉하고 좌우로 살랑인다
- 4 → 1 로 넘어갈 때 튀지 않게
- ⚠ **4 칸을 한 장에 같이 그려라**(가로 4칸). 따로 부르면 칸마다 불꽃 자리가 달라진다.
  그린 뒤 칸마다 잘라서 저장한다

## 하지 말 것

- ⚠ **고리·원·U 자로 불꽃을 잇지 마라.** 지난번이 그랬다. 불꽃끼리 **떨어져 있어야** 한다
- ⚠ **불꽃 속을 비우거나 마젠타로 칠하지 마라.** 불꽃 하나하나는 속까지 불 색으로 꽉 채운다.
  지난번 불꽃 속 마젠타가 게임에서 분홍 띠로 떴다
- 옆으로 뻗는 불줄기(브레스) 금지 — 제자리에서 타는 불이다
- 몸·캐릭터를 그려 넣지 마라. 글자·숫자 금지
- 96 × 96 밖으로 나가지 않게

| 항목 | 값 |

| 화풍 | 픽셀아트. 같은 게임의 `Assets/BaseResource/InGameMainUI/fx_hit_1.png` 와 같은 픽셀 크기 |

## 검수 기준

1. 4 장 전부 96 × 96, 네 모서리 마젠타
2. 불꽃이 5~7 개로 **서로 떨어져** 있다 (고리 아님)
3. 불꽃 속에 마젠타가 없다
4. 가운데 30~66 × 30~70 이 비어 있다
5. 4 장에서 불꽃 자리가 같고 모양만 흔들린다
