# 팝업·특수 오브젝트·스테이지 클리어 FX 부품 발주/구현안

## 전제

- 검토 기준: `mock_fxstory_levelup/altar/devil/shop/room_heal/room_devil/room_shop_v1.png`, `mock_fxstory_clear_v1.png`와 현재 게임 화면 7종. `mock_fxstory_clear_v2.png`는 없으므로 clear는 v1 기준이다.
- 목표는 시안의 인상을 그대로 복제하는 것이 아니라, **읽을 수 있는 UI 위에 짧은 반응을 더하는 것**이다. 입력을 막는 연출은 팝업 최초 등장 0.20초 이내만 허용하고, 이후 애니메이션 중에도 선택/이동은 가능하게 한다.
- 아래의 “발주 없음”은 기존 오브젝트 그림과 UI 트윈, `ParticleFxPool`만으로 처리한다는 뜻이다. 코드에서 선·원·도형을 새로 그리지 않는다.
- `Impact`용 프레임 애니메이션은 모두 `fx_ui_이름_1..8`의 8장, 한 칸 256×256 px를 기본으로 한다. 빔만 1장 256×64 px를 가로로 늘여 쓴다.
- 색상 곱하기를 쓰는 공용 원화는 **백색~중성 회색 발광 + 알파**로 납품받는다. 한 프레임 안에 서로 다른 색이 반드시 필요한 부품은 색 곱하기 대상에서 제외한다.
- 반짝임은 점·짧은 선·불씨만 사용한다. 별, 표창, 십자 모양 반짝이는 발주하지 않는다. 화면 전체 색 오버레이도 사용하지 않는다.

**총 발주량:** 8프레임 애니메이션 8종 = 64장, 빔 1장 = **합계 65장**. 모든 이름은 그대로 `fx_ui_*_1..8` 규칙에 맞춘다. 정지 그림 변형, 색상별 복제, 화면별 전용판은 추가 발주하지 않는다.

### 발주하지 않고 기존 도구로 처리할 것

| 표현 | 처리 방식 |
|---|---|
| 점, 불씨, 수증기 보조, 금화 알갱이 | `ParticleFxPool`의 점·불씨·연기·금화 알갱이와 색 지정 |
| 팝업/카드/행/버튼/오브젝트의 등장, 호흡, 흔들림, 눌림 | UI 또는 오브젝트 트윈: 크기·위치·알파·색 |
| 선택 순차 강조, 카운트업, HUD 숫자 반응 | 코드 타이밍 및 색/크기 트윈 |
| 빔의 길이·방향·수명 | `Impact` 빔의 가로 늘이기, 회전, 색, 수명 |
| 원혼/물방울/금화의 화면 내 이동 경로 | 완성 도형을 새로 그리지 않고 발주 부품 또는 기존 입자를 위치 트윈 |

## 3. 시안에서 그대로 하면 안 되는 것과 수정안

| 화면/시안 요소 | 문제 | 수정안 |
|---|---|---|
| 전 화면의 지속 발광·다중 점멸 | 모든 부위가 계속 움직이면 강조 순서가 사라지고 피로도가 높다 | 등장/결정 때만 1회성 큰 반응. 대기는 링·점·불씨 중 최대 2계통만 저밀도로 유지 |
| 레벨업의 굵은 상승 혼·빔 | 중앙 카드 제목/설명과 상단 안내문을 가리고 선택 결과 확인이 늦다 | 스트림은 선택 카드 외곽에서 출발해 카드 사이 여백을 지나도록 좁히고 0.38초 안에 종료 |
| 레벨업의 카드 전체 순환 발광 | 3개 카드가 동시에 최우선처럼 보여 포커스가 불명확하다 | 최초 1회만 순차 점등. 이후에는 현재 포커스 카드만 알파/색 호흡 |
| 제단의 화면 위까지 긴 물방울 행렬 | HUD와 HP 숫자를 덮고 화면 전체 연출처럼 보인다 | 팝업 우측 바깥 경로로 6개 이하만 이동. HP 도착 링 1회로 결과를 끝냄 |
| 악마 팝업의 하단 대량 붉은 연기 | 조이스틱·LEAVE 버튼 및 배경을 넓게 물들여 화면 전체 틴트처럼 보인다 | 연기는 팝업 뒤/하단 경계 안에 2개, 알파 낮게. 컨트롤 영역에는 생성하지 않음 |
| 악마 팝업의 사슬 철컥/당김 반복 | 지속 진동은 게임이 멈추거나 UI가 고장 난 인상을 준다 | 등장 시 ±3 px 2회, 수락 시 ±6 px 1회만 실행하고 즉시 정지 |
| 상점의 모든 상품 테두리 동시 호흡 | 가격·아이콘·구매 가능 여부를 읽기 어렵다 | 진입 순차 점등 뒤 포커스 칸 하나만 호흡. 구매 완료 칸은 즉시 저채도/저알파 |
| 구매 시 큰 아이콘이 HUD까지 이동 | 상품 목록과 보유 골드 숫자를 동시에 가린다 | 상품 아이콘은 제자리 눌림만. HUD로는 작은 금화 알갱이 6개만 이동 |
| 회복 장치의 높은 빛기둥 | 화면 상단 HUD까지 침범하고 접근 중 이동을 멈춘 듯 보인다 | 빛기둥은 장치 폭과 높이 안에서 0.32초만, 플레이어 조작/이동은 유지 |
| 악마 장치의 큰 연기 고리 확산 | 방 전체를 붉게 물들이며 거래 창 뒤 정보까지 흐린다 | 고리 확산 삭제. 장치 뒤 연기 2개와 사슬 파손 1회로 작동을 전달 |
| 상점 장치의 금화 고리 지속 회전 | 팝업이 열린 뒤에도 배경에서 시선을 뺏고 성능 비용이 누적된다 | 작동 시 1회전만 하고 0.42초 내 소멸. 열린 뒤에는 저밀도 금화 알갱이만 유지 |
| 클리어의 화면 전폭 광선·낙뢰 | 화면 전체 플래시가 되고 보상 텍스트와 경고 문구를 가린다 | 방사광은 제목 프레임 뒤, 아크는 좌우 프레임 가장자리로 제한. 전폭 섬광/전체 색 덮기 금지 |
| 클리어의 낙하 금화와 상자 충격을 동시에 크게 재생 | 골드 숫자·상자명·경고가 겹쳐 읽히지 않고, 긴 자동 연출로 탭이 늦어진다 | 골드→상자 순으로 0.10초 차를 두고 총 0.65초 안에 정착. OK는 등장 직후부터 입력 가능 |
| 시안 전반의 작은 별/십자 반짝이 | PD 금지 형태이며 기존 도트 UI와도 충돌한다 | 모두 원형 점, 짧은 불규칙 선, 불씨, 연기로 교체. `burst_rays`에도 별 모양 중심을 넣지 않음 |

## 구현 우선순위

1. 공용성이 가장 큰 `ring_pulse`, `energy_arc`, `soul_stream`, `beam_soft` 4종을 먼저 적용한다.
2. 기존 ParticleFxPool과 트윈만 붙여 각 화면의 등장/선택/작동 박자를 완성한다.
3. 악마 전용 `chain_snap`, 상점/클리어 공용 `coin_orbit`, 클리어용 `reward_pop`을 더한다.
4. 마지막으로 각 화면에서 **텍스트 안전 영역, 동시 파티클 수, 반복 밀도, 즉시 입력 가능 여부**를 확인한다.
