③ 새 게임 출발 세트

스튜디오에 이미 공식 절차가 있다 — Docs/game/new-game-repo.md. 원본을 복제해 부모(upstream)로 두고, 원본이 바뀌면 동기화 명령으로 받는 구조다. 그래서 「출발 세트」를 따로 만들지 않고 ②를 원본에 올려 두는 것이 곧 출발 세트다.

  1. 리포 만들기 — 공식 절차 0~4절(원본 복제 · upstream 연결 · 계층 선언 · 패키지를 git URL 로).
  2. 켤 에이전트 고르기 — 보관 프로필에서 그 게임에 필요한 것만 복사(①-2 와 같은 방식).
  3. 게임 값 채우기 — constants · summary · terminology, 이펙트 · UI 스킬의 project.md.
  4. 코덱스 브리프 새로 — ②-1 양식에 그 게임의 색의 뜻 · 장면 분위기 · 기준 그림을 채운다(첫 시안 통과 뒤).
  5. 포맷 기준 확인 — 대상 기기 · 압축(ASTC 등)을 ②-3 규칙으로 처음부터.
