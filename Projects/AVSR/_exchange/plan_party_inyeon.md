# 빙의 파티 — 인연 표 (PD 2026-10-29)

## 규칙 (PD 확정)
- 호스트마다 **인연 하나** — 그 호스트가 **메인일 때만** 켜지는 **액티브 스킬 변화**(필살기 아님 — 액티브가 더 자주 나가 매번 보인다).
- **짝이 보조에 있으면 켜진다.** 어느 짝으로 켜지든 바뀌는 내용은 같다.
- 짝 수: **R · SR 1명 · SSR 2명**(둘 중 하나만 있어도 켜짐). SSR 메인이 인연을 켜기 쉽다 = 높은 등급의 이득. 인연 세기는 등급과 상관없이 비슷하게.
- 지금 메인의 짝은 호스트 자리 출현 확률 **약 2배**(시험판에서 조정).
- 한 판에 짝을 만날 확률(대략): R · SR 메인 약 45% · SSR 메인 약 70%.
- 사신(히든)은 따로 — 얻는 길이 정해지면 특별 인연.

## 화면에 보이는 것
- 왼쪽 시너지 칸 맨 위에 **금빛 인연 칸 하나**: 켜지면 인연 이름 + 메인 얼굴 · 꺼져 있으면 「짝: ○○」 흐리게.
- 스킬 버튼에 「인연」 표시.
- 짝이 「빙의 가능」이 되면 금빛 「인연」 말풍선 + 테두리 — 「데려오면 ▶ 인연 「업화」」.
- 출전 전 호스트 정보에 「인연 짝: ○○」.

## 태그 시너지(스탯)와 함께
- 태그 시너지(속성 · 조직 2명 약 / 3명 강) = **스탯만**(공속 · 회피 · 치명 · 받는 피해 · 체력 · 쿨 · 회복 · 보조 간격) — 기획 대화 10-29 표.
- 인연 = **스킬 변화**. 두 종류가 겹치지 않는다.
