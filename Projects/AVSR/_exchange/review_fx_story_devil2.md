# 악마의 거래 연출 2회차 검수

## 판정

**불합격 — 1회차 지적 중 배치 문제는 고쳐졌으나, 2컷의 광량과 3컷의 핵심 형상이 시안과 아직 다르다.**

검수 기준은 `mock_fxstory_devil_v1.png`의 3컷과 `devil_vs_mock.png` 아래쪽의 동일 시점 3컷(등장 0.25초, 대기 2.00초, 수락 4.15초)이다. GIF의 구간 길이는 등장 0.6초 → 대기 3.2초 → 수락 1.0초로 맞다.

1회차 지적 가운데 다음은 수정 완료로 확인했다.

- 등장 연기가 하단 조작 버튼까지 덮던 문제
- 혼 및 혼 번개의 출발점이 HUD 초상에 있던 문제
- 좌우 `chain_glow`가 틀의 사슬과 어긋나던 문제
- 수락 때 `chain_pull`이 아예 없던 문제
- 대기 열기의 과도한 불투명도와 크기
- 문장 불꽃 위치, 대기 버튼 맥동, 수락 버튼 밝기 함수의 1회차 수치

아래에는 아직 남은 차이만 적는다.

## 1컷 — 등장 (0.25초)

### 시안과 다른 점

남은 유의미한 차이 없음. 연기가 EventBox 아래 바닥에서 피어오르고 하단 조작 버튼을 침범하지 않는다. 1회차의 크기·위치·종료 시점 수정이 반영됐다.

### `devil()` 변경값

없음. 현재 값을 유지한다.

```python
Part(S, 'smoke', (360, 930), (620, 300), 0.12,
     0.00, 0.60, loop=False, add=False, alpha=0.48, fade=0.10)
```

`smoke` 재발주 없음.

## 2컷 — 최대/대기 (2.00초)

### 시안과 다른 점

- `heat`는 1회차보다 크게 개선됐지만, 재현본에서는 창 바로 아래에 경계가 읽히는 진한 적색 띠로 남는다. 시안은 붉은 덩어리가 아니라 바닥과 창 가장자리에 얇게 번지는 열기다.
- 수락 버튼 외곽광은 재현본의 흰 중심광이 시안보다 강하고 두껍다. 시안은 붉은 테두리의 재질을 유지하면서 약하게 맥동한다.
- 좌우 `chain_glow`의 축은 실제 사슬에 맞았다. 이 항목은 수정하지 않는다.

### `devil()`에서 바꿀 값

#### 열기

```python
# 현재
Part(S, 'heat', (360, 900), (610, 240), 0.12,
     0.30, T_END, add=True, alpha=0.38, fade=0.15)

# 변경
Part(S, 'heat', (360, 890), (610, 210), 0.12,
     0.30, T_END, add=True, alpha=0.24, fade=0.18)
```

- 중심: `(360,900)` → **`(360,890)`**
- 크기: `610×240` → **`610×210`**
- 알파: `0.38` → **`0.24`**
- fade: `0.15` → **`0.18초`**
- 프레임 간격 `0.12초`, 시작/끝 `0.30~4.80초`, 가산 합성은 유지한다.

#### 수락 버튼 외곽광

```python
# 현재
Part(S, 'button_glow', cen(acc), btn, 0.20,
     T_IDLE, T_END, add=True, alpha=0.58)

# 변경
Part(S, 'button_glow', cen(acc), btn, 0.20,
     T_IDLE, T_ACC + 0.30, add=True, alpha=0.40)
```

- 알파: `0.58` → **`0.40`**
- 종료: `4.80` → **`4.10초(T_ACC + 0.30)`**. 수락 컷에서는 베이스 버튼의 붉은 테두리만 남긴다.
- 중심·크기·프레임 간격·시작 `0.60초`·가산 합성은 유지한다.
- `acc_fn`의 대기 `+0.08` 및 수락 `+0.18/0.30초`는 그대로 둔다.

`heat`, `button_glow` 재발주 없음. 남은 차이는 배치와 합성 강도로 교정 가능하다.

## 3컷 — 수락 (4.15초)

### 시안과 다른 점

- 혼 위치와 번개 출발점은 고쳐졌다. 그러나 `soul_beam`은 재현본에서 가늘고 옅은 분홍 단선으로 보인다. 시안은 붉은 다중 번개, 중심의 흰 고광, 주변 적색 발광과 입자가 함께 문장까지 이어진다. 굵기 값만 키우면 현재 선을 세로로 늘린 모양이 되어 시안 형상이 되지 않는다.
- 새 `chain_pull`은 좌우 위치와 당겨지는 방향은 들어갔지만, 재현본에서는 보상 pill 양옆의 짧은 주황 불꽃 덩어리처럼 보인다. 시안의 것은 화면 양끝 사슬에서 안쪽으로 팽팽하게 당겨지는 길고 가는 적백색 평행 빛줄기다. 1회차의 “없음”은 해결됐으나 형상은 통과하지 못했다.
- `reward_burst`와 좌우 당김 빛이 겹치면서 보상 pill 주변이 시안보다 넓고 노랗게 뭉친다. `chain_pull` 재발주본이 가늘어지면 대부분 해소되며, 그 뒤에도 남을 경우에만 `reward_burst` 알파를 낮춘다.

### `devil()`에서 바꿀 값

#### 혼 번개

현재의 좌표와 타이밍은 맞으므로 유지한다.

```python
Beam(S, 'soul_beam', (112, 292), (360, 424), 62, 0.06,
     T_ACC, T_ACC + 0.62)
```

- 출발 `(112,292)`, 도착 `(360,424)`, 굵기 `62`, 간격 `0.06초`, 구간 `3.80~4.42초`, 가산 합성 유지.
- **재발주:** `soul_beam`. 720×1280 배치 굵기 62px 안에서 붉은 번개 2~3가닥, 흰 중심선, 붉은 외광과 작은 불티가 같이 보여야 한다. 현재 부품은 단선 형상이라 값 조절만으로 시안과 같아지지 않는다.

#### 사슬 당김

좌표는 시안 방향과 맞으나, 재발주 부품의 형상이 바뀌면 화면에서 너무 두꺼워지지 않도록 굵기만 줄인다.

```python
# 현재
Beam(S, 'chain_pull', (0, 616), (116, 676), 72, 0.06,
     T_ACC, T_ACC + 0.48)
Beam(S, 'chain_pull', (720, 616), (604, 676), 72, 0.06,
     T_ACC, T_ACC + 0.48)

# 변경
Beam(S, 'chain_pull', (0, 616), (116, 676), 52, 0.06,
     T_ACC, T_ACC + 0.48)
Beam(S, 'chain_pull', (720, 616), (604, 676), 52, 0.06,
     T_ACC, T_ACC + 0.48)
```

- 굵기: `72` → **`52px`**
- 좌우 시작/끝 좌표, 프레임 간격 `0.06초`, 구간 `3.80~4.28초`, 가산 합성은 유지한다.
- **재발주:** `chain_pull`. 1024×128 투명 RGBA, 가로 진행형 4프레임이라는 규격은 유지하되, 중앙 불꽃 덩어리를 없애고 화면상 2~3개의 가늘고 긴 적백색 평행 스트릭이 보여야 한다. 바깥쪽에서 안쪽으로 모이며 당겨지는 방향성이 프레임마다 읽혀야 한다. 현재 부품은 주황색 화염 폭발에 가까워 시안의 “사슬 당김”으로 읽히지 않는다.

#### 보상 폭발

재발주한 `chain_pull`을 적용한 뒤에도 노란 면적이 시안보다 넓을 때만 아래처럼 낮춘다.

```python
Part(S, 'reward_burst', cen(rw),
     (rw[2] / 0.6, rw[3] / 0.35), 0.08,
     T_ACC + 0.25, T_END,
     loop=False, add=True, alpha=0.78, fade=0)
```

- 기존 기본 알파 `1.0` → **`0.78`**
- 중심·크기·프레임 간격·시작/끝·가산 합성은 유지한다.
- `reward_burst` 자체는 재발주하지 않는다.

## Claude가 바로 적용할 변경 목록

1. `heat`: 중심 `(360,890)`, 크기 `610×210`, 간격 `0.12`, 구간 `0.30~4.80`, 가산, 알파 `0.24`, fade `0.18`.
2. `button_glow`: 중심·크기·간격 유지, 구간 `0.60~4.10(T_ACC+0.30)`, 가산, 알파 `0.40`.
3. `smoke`, `chain_glow`, `flame`, `pill_sparks`, `panel_fn`, `acc_fn`, `ghost`, `emblem`은 현재 2회차 값을 유지.
4. **재발주 `soul_beam`:** 현재 좌표·굵기·타이밍은 유지하고, 붉은 다중 번개 + 흰 중심 + 붉은 외광/불티 형상으로 교체.
5. **재발주 `chain_pull`:** 주황 불꽃 덩어리 대신 가늘고 긴 적백색 평행 스트릭 2~3개가 바깥에서 안으로 당겨지는 4프레임으로 교체.
6. 새 `chain_pull` 적용 시 Beam 굵기 `72` → `52`; 좌우 좌표와 `0.06초`, `3.80~4.28초`, 가산 합성은 유지.
7. 새 `chain_pull` 적용 뒤에도 3컷의 보상 주변 노란 면적이 넓으면 `reward_burst`에 `alpha=0.78`만 추가.
8. 다시 뽑을 때 비교 컷은 기존과 동일하게 `0.25 / 2.00 / 4.15초`, GIF는 `0.6 / 3.2 / 1.0초`로 유지한다.
