# 발주 — 인게임 UI 조각: eventframe (620 × 792)

## ⚠ 재발주 — 1차를 게임에 넣어 보니 어긋난 곳

찍은 화면: `Projects/AVSR/_exchange/ref/ui_new_demon_v1.png`

- **틀 안쪽이 비쳐서 뒤의 전투 화면(캐릭터 · 체력바)이 창 위로 보였다.** 안쪽 면은 **불투명**해야 한다
- **제목 판이 제목 글자보다 위에 있어 글자가 판 위쪽 테에 걸쳤다.**
- 게임이 틀 위에 얹는 것들의 자리(이 틀 캔버스 620 × 792 기준, 왼쪽 위가 0,0):

| 얹히는 것 | 자리 |
|---|---|
| 제목 글자 | x 190~430 · y 98~160 (**가운데 310, 129**) |
| 본문 2~3줄 | x 100~520 · y 195~275 |
| 대가 알약 | x 182~438 · y 292~338 |
| 「代価を払う」 버튼 | x 95~525 · y 352~456 |
| 「放っておく」 버튼 | x 95~525 · y 468~552 |

- **제목 판의 가운데를 (310, 129)에** — 판 안에 글자(높이 약 40)가 여유 있게 들어가게
- **x 85~535 · y 180~565 은 불투명한 어두운 안쪽 면으로만.** 장식이 들어오면 안 된다
- 생김새는 1차(`Assets/BaseResource/InGameMainUI/eventframe.png`)와 시안 그대로 두고 위만 맞춘다

## 왜

인게임 UI 퀄업 시안이 **통과**했다: `Projects/AVSR/_exchange/in/ui_mockup_demon.png`
그 시안을 게임에 넣을 수 있게 **조각으로** 받는다. 이 조각은 그중 하나다.

**통과한 시안과 똑같은 생김새**여야 한다 — 시안을 가장 먼저 열어 해당 부분을 보고 그대로 맞춰 달라.
색 · 재질 · 장식은 시안이 정답이다(새로 디자인하지 마라).

## 이 조각

- 무엇: **악마 창 전체 틀** — 시안의 뿔 달린 해골 장식 · 철제 틀 · 청록 등불 · 제목 판(「野戦衛生兵」 자리). **판만, 글자는 비워 둔다.** 본문 · 보상 줄 · 대가 알약 · 두 버튼은 따로 얹힌다
- 게임: AVENGING SPIRIT: RE:BORN — 세로 모바일, 기준 화면 720 × 1280. 시안이 이 크기라 **시안 속 크기가 곧 게임 속 크기**다
- ⚠ **글자는 게임이 지금 자리에 찍는다.** 제목 판 · 명판 · 버튼의 글자 자리는 `Assets/BaseResource/InGameMainUI/eventframe.png` 와 **같은 자리**에 둔다 — 옮기면 글자가 판 밖으로 나간다
