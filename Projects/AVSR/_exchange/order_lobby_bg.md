# 발주 — 로비 배경 「밤의 공업 지구 골목」 (1장)

> ⚠ **그리기 스크립트로 만들지 마라.** `ImageDraw` 의 `rectangle`·`polygon`·`ellipse`·`line`
> 으로 도형을 조립하는 방식은 불합격 사유다. 손으로 그린 픽셀아트여야 한다.
> **매끈한 직선 격자·완전 대칭·그라데이션 채우기가 보이면 불합격이다.**

## 왜 다시 그리나

로비 화면을 2026-09-16 목업대로 다시 세웠다. 지금 배경(`lobbybackground.png`)은
예전 구성에 맞춰 그린 것이라 **새 목업의 골목 분위기와 맞지 않는다.**

```

    승인된 로비 목업. 이 그림에서 **UI 판을 걷어낸 배경만** 그리는 것이 이번 일이다.
```

## 무엇을 그리나

- **밤의 공업 지구 골목.** 좌우로 창고·공장 벽이 서고, 가운데로 길이 뻗어 먼 도시가 보인다
- 위쪽 `1/6`: 먼 도시 실루엣과 네온, 철골 구조물, **따뜻한 주황 가로등** 두어 개
- 가운데 `3/6`: 창고 벽 · 철제 셔터 · 배관 · 환기구. 벽에 희미한 도색 자국
- 아래쪽 `2/6`: **젖은 바닥.** 위쪽 불빛이 세로로 길게 비쳐 반사된다. 아래로 갈수록 검어진다
- 사람·유령·상자·고양이를 그리지 마라 — 그것들은 UI 판 안에 따로 들어간다

## ⚠ 글자가 얹힐 자리는 어둡고 밋밋하게

이 그림 위에 UI 판과 흰 글자가 얹힌다. 아래 띠는 **어둡고 잔무늬가 적어야** 한다.
밝은 점·또렷한 무늬가 있으면 글자가 안 읽힌다.

| 목업 y 범위 | 그리는 법 |
|---|---|
| 231 ~ 607 | 유령 수색 판 자리 — 어둡게, 큰 덩어리만 |
| 621 ~ 896 | 상자 판 자리 — 어둡게, 큰 덩어리만 |
| 1466 ~ 1656 | 하단 바 자리 — 가장 어둡게 |

밝은 가로등·네온은 `y 90~230` 과 `y 1200~1400` 에만 둔다.

## 규격

| 항목 | 값 |
|---|---|
| 파일 | `lobbybackground.png` |
| 크기 | **941 × 1672** (9:16. 게임 캔버스 720×1280 으로 줄여 쓴다) |
| 배경 | 불투명 한 장. 투명 픽셀을 만들지 마라 |
| 화풍 | 픽셀아트, 안티에일리어싱 없이. 색 띠가 **계단으로** 나뉜다 |
| 해상도감 | 목업과 같은 굵기의 픽셀. 1 px 점묘로 잔무늬를 깔지 마라 |

## 검수 기준

1. 크기가 정확히 941 × 1672, 투명 픽셀 0개
2. 목업 `lobby_hub_v2.png` 와 나란히 놓았을 때 **같은 장소로 읽힌다**
3. `y 231~607` · `y 621~896` · `y 1466~1656` 세 띠가 눈에 띄게 어둡고 밋밋하다
4. 도형이 아니다 — 자로 그은 듯한 직선 격자·완전 대칭이 없다
5. 사람·유령·상자·고양이가 없다
6. 그라데이션 채우기가 아니라 **계단 색 띠**로 밝기가 바뀐다
