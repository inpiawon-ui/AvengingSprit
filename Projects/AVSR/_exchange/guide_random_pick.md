# 로비 「?(랜덤 선택)」 카드 · 랜덤 설명 칸 — 연출 가이드 (2026-10-12)

## 목표 모습
- 호스트 카드 줄 맨 왼쪽 「?」 카드와, 그 카드를 고르면 아래에 나오는 「랜덤 선택」 설명 칸.
- **한눈에 「무엇이 나올지 모르는 특별한 칸」 으로 읽히고, 「낮은 확률로 전설이 나온다」 는 기대가 생긴다.**
- 지금 게임 화면의 네온 테두리 · 금색 버튼 화풍 안에서 가장 눈에 띄는 칸 하나(다른 카드보다 한 단계 화려하게).

## 다른 게임이 쓰는 방식 (참고)
| 방식 | 예 | 우리 게임에 옮기면 |
|---|---|---|
| 룰렛 | 스매시브라더스 「랜덤」 칸 · 마리오카트 아이템 박스 — 칸 안에서 후보가 빠르게 돌다 멈춘다 | 카드 안에서 원작 초상들이 휙휙 바뀌는 잔상 + 「?」 |
| 카드 뒷면 | 가차 게임 카드 뒷면 — 문장 · 홀로그램 반짝임, 등급 빛(금빛)으로 희귀 암시 | 유령 불꽃 문장이 그려진 카드 뒷면 + 금빛 가장자리 |
| 미스터리 구슬 · 상자 | 빛나는 상자 · 수정구 + 「?」 · 반짝이 | 영혼 안개가 소용돌이치는 수정구 속 「?」 |

## 박자표
| 시각 | 박자 | 강약 | 보이는 것 |
|---|---|---|---|
| 머묾(안 골랐을 때) | 숨쉬기 2초 | 약 | 「?」 가 은은하게 빛나고 빛 알갱이 몇 개가 떠오른다 |
| 고르는 순간 | 0.3초 | 강 | 카드가 확 밝아지고 빛이 한 번 퍼진다(룰렛이면 후보가 빠르게 돈다) |
| 골라진 동안 | 반복 | 중 | 금색 테두리 + 가끔 금빛 반짝임(전설 암시) · 아래 설명 칸은 은은하게 |

## PD 원문
- 「너무 구린데.. 저걸 좀 이쁘게 표현할 수 없을까? 다른 방식으로 좀 이쁘게 표현해 줘」
- 「저렇게 캐릭터 리스트로 넣을 필요도 없고」
- 「다른 게임은 어떤 식으로 표현했는지를 좀 참고하면 좋을 것 같아」

## 지킬 것
- 원작 캐릭터를 새로 그리지 않는다(IP — 넣는다면 원작 그림 그대로). 캐릭터 줄은 넣지 않는다.
- 설명 칸은 지금 칸 크기(667 x 155, 도전하기 버튼 바로 위) 안에서. 글자 · 숫자를 가리지 않는다.
- 빛은 도트 모양 + 셰이더 번짐 · 파티클로(`codex_brief_fx.md`).
