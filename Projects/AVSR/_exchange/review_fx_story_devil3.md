# 악마의 거래 연출 3회차 검수

## 판정

**불합격 — 2회차 지적의 핵심 효과 형상은 고쳐졌지만, 수락 컷에 두 가지 차이가 남았다.**

검수 기준은 `mock_fxstory_devil_v1.png`의 3컷과 3회차 `devil_vs_mock.png` 아래쪽의 동일 시점 3컷(등장 0.25초, 대기 2.00초, 수락 4.15초), 그리고 `devil.gif`의 등장 0.6초 → 대기 3.2초 → 수락 1.0초이다.

2회차 변경 목록 가운데 다음은 수정 완료로 확인했다.

- `heat`: 중심 `(360,890)`, 크기 `610×210`, 알파 `0.24`, fade `0.18`이 반영되어 대기의 진한 적색 덩어리와 하드한 띠가 없어졌다.
- `button_glow`: 알파 `0.40`은 반영됐다.
- v2 `soul_beam`: 붉은 다중 번개, 흰 중심, 적색 외광과 불티 형상으로 교체됐다. 출발·도착 좌표와 굵기도 맞는다.
- v2 `chain_pull`: 주황 불꽃 덩어리가 없어지고 가는 적백색 수평 스트릭으로 교체됐다. 좌우 배치, 당김 방향, 굵기 `52`가 맞는다.
- 새 `chain_pull` 적용 뒤 보상 폭발 면적은 시안 허용 범위다. 조건부였던 `reward_burst alpha=0.78` 보정은 적용하지 않은 현재 값이 맞다.

아래에는 3회차에도 남은 차이만 적는다.

## 1컷 — 등장 (0.25초)

### 시안과 다른 점

남은 유의미한 차이 없음. 연기는 창 아래 바닥에서 피어오르며 하단 조작 버튼을 덮지 않는다.

### `layers_devil()`에서 바꿀 값

없음. 현재 값을 유지한다.

```python
L('devil_smoke', 360, 930, 620, 300, 0.12,
  0.0, 0.6, loop=False, add=False,
  alpha=0.48, fade=0.10, back=True)
```

재발주 없음.

## 2컷 — 최대/대기 (2.00초)

### 시안과 다른 점

남은 유의미한 차이 없음. 2회차에서 지적한 열기의 진한 적색 덩어리와 버튼의 과광량이 교정됐고, 좌우 사슬 빛도 틀의 실제 사슬 축에 맞는다.

### `layers_devil()`에서 바꿀 값

없음. `heat`, `chain_glow`, `flame`, `pill_sparks`, `button_glow`의 현재 중심·크기·알파·프레임 간격·시작값·합성 방식을 유지한다.

재발주 없음.

## 3컷 — 수락 (4.15초)

### 시안과 다른 점

1. 시안에는 창 왼쪽 위 화면 안 `(112,292)` 부근에 번개를 보내는 플레이어 혼 본체가 보이지만, 3회차 재현 컷에는 혼 본체가 없다. 번개의 출발 좌표만 옮겨져 선이 빈 공간에서 시작한다. HUD 초상 `(95,75)`을 출발점으로 쓰던 문제와는 별개로, 최종 비교 화면에 실제 혼 표시가 필요하다.
2. 2회차에서 지정한 `button_glow` 종료 `T_ACC + 0.30`이 코드에 반영되지 않았다. 현재 행에는 `t1` 인수가 없어서 기본값 `0.0`(계속 재생)이 적용되고, 수락 컷에서도 넓은 주황·백색 외곽광이 남는다. 시안의 수락 컷은 버튼 재질의 붉은 테두리만 남는다.

v2 `soul_beam`과 v2 `chain_pull`의 형상·위치·타이밍은 통과다. `reward_burst`도 현재 기본 알파 `1.0`에서 시안 범위를 넘지 않으므로 2회차의 조건부 `0.78` 보정은 하지 않는다.

### `layers_devil()`에서 바꿀 값

#### 플레이어 혼 본체

- 중심: **`(112,292)`**
- 크기: **`96×96`**
- 시작/끝: 수락 시작 기준 **`0.00~0.62초`** (`T_ACC~T_ACC+0.62`)
- 알파: **`1.0`**
- 합성: **덮기(일반 알파), 가산 아님**
- 프레임 간격: 게임의 기존 플레이어 혼 애니메이션 간격을 유지한다. 정지 이미지라면 간격값은 두지 않는다.
- 표시 순서: 배경보다 위, `soul_beam`보다 앞. 번개 출발점과 혼 본체 중심을 동일한 `(112,292)`로 맞춘다.

`soul_beam` 값은 바꾸지 않는다.

```python
L('devil_soul_beam', 112, 292, 0, 62, 0.06,
  0.0, 0.62, phase='accept', beam=True,
  x2=360, y2=424, fromAvatar=True)
```

**재발주 없음.** 혼은 신규 FX 부품이 아니라 게임의 기존 플레이어 혼 스프라이트를 표시해야 한다. 현재 차이는 `soul_beam` 그림 문제가 아니라 혼 본체가 최종 비교본에서 빠진 합성 문제다.

#### 수락 버튼 외곽광

```python
# 현재
L('devil_button_glow', *cen(acc),
  acc[2] / 0.88, acc[3] / 0.70,
  0.20, 0.60, alpha=0.40)

# 변경
L('devil_button_glow', *cen(acc),
  acc[2] / 0.88, acc[3] / 0.70,
  0.20, 0.60, T_ACC + 0.30,
  add=True, alpha=0.40)
```

- 중심·크기: 유지
- 프레임 간격: **`0.20초`** 유지
- 시작: **`0.60초`** 유지
- 종료: 기본값 `0.0`(계속) → **`4.10초(T_ACC+0.30)`**
- 알파: **`0.40`** 유지
- 합성: **가산** 유지
- `acc_fn`의 대기 맥동과 수락 밝기 함수는 유지한다.

재발주 없음. 부품 형상은 맞고 종료값 누락만 고치면 된다.

## Claude가 바로 적용할 변경 목록

1. `devil_button_glow` 행에 위치 인수 `t1=T_ACC+0.30`을 추가한다. 최종 구간은 `0.60~4.10초`, 간격 `0.20초`, 가산, 알파 `0.40`이다.
2. 수락 구간 `0.00~0.62초`에 기존 플레이어 혼 본체를 중심 `(112,292)`, 크기 `96×96`, 알파 `1.0`, 일반 알파 합성으로 표시한다. `soul_beam`보다 앞에 놓고 번개 출발 중심과 일치시킨다.
3. `soul_beam`, `chain_pull`, `reward_burst`, `heat`, `smoke`, `chain_glow`, `flame`, `pill_sparks`, `panel_fn`, `acc_fn` 값은 더 바꾸지 않는다.
4. 부품 재발주는 없다.
5. 다시 뽑을 비교 컷은 `0.25 / 2.00 / 4.15초`, GIF 구간은 등장 `0.6초` → 대기 `3.2초` → 수락 `1.0초`를 유지한다.
