꺾쇠**다 — 흰 몸통에 검은 윤곽, 바깥으로 따뜻한 빛이 번진다.

```
Projects/AVSR/Reference/Mockups/lobby_hub_v2.png
   x 892~941 · y 1112~1200   오른쪽 꺾쇠 (빛무리 포함)
```

## 내보낼 것

| 파일 | 크기 | 방향 |
|---|---|---|
| `modearrow_right.png` | 52 × 96 | 오른쪽(`>`) |
| `modearrow_left.png` | 52 × 96 | 왼쪽(`<`) — 오른쪽과 좌우 대칭 |

- 꺾쇠 몸통은 캔버스 가운데에 **가로 30 · 세로 66** 안팎
- 남는 여백은 빛무리. 가장자리로 갈수록 서서히 투명해진다
- 두 장은 **정확히 좌우 대칭**이어야 한다

## 지켜야 할 것

1. **배경은 완전 투명(알파 0).** 마젠타를 쓰지 마라
2. 빛무리는 반투명으로 둔다 (알파를 0 아니면 255 로 정리하지 마라)
3. 글자를 그리지 마라
