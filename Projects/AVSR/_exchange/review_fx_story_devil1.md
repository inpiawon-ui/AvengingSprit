# 악마의 거래 연출 1차 검수

## 판정

**불합격 — 수정 후 PD 최종 검수 필요.** 창 본체와 기본 등장 타이밍은 시안의 방향에 들어왔지만, 연기·열기·혼 빔·사슬 발광의 위치와 강도가 시안과 다르다. 특히 수락 컷의 양옆 「사슬 당김」 빛줄기가 빠져 있어 현재 상태는 “시안과 똑같이” 재현된 최종본으로 볼 수 없다.

검수 기준은 `mock_fxstory_devil_v1.png`의 3컷과 `devil_vs_mock.png`의 같은 순간 3컷이다. 좌표는 모두 720×1280 원본 화면 기준이며, 시간은 GIF 시작 기준이다. 구간은 등장 `0.00–0.60초`, 대기 `0.60–3.80초`, 수락 `3.80–4.80초`로 유지한다.

## 1컷 — 등장 (0.25초 대표 프레임)

### 시안과 다른 점

- 재현 연기는 화면 폭을 거의 다 채운 큰 폭발 구름이며, 하단 조작 버튼과 장비 아이콘 위까지 올라온다. 시안은 EventBox 하단 바닥에서 얇게 피어올라 창을 받쳐 주고, HUD 조작부의 가독성을 유지한다.
- 재현 연기는 검붉은 불덩어리의 덩어리감이 강하다. 시안은 같은 붉은 계열이지만 검은 핵이 덜 보이고, 바닥 안개처럼 낮고 옅다.
- 현재 `smoke` 종료가 0.90초라 등장 구간이 끝난 뒤에도 큰 연기 덩어리가 남는다. 시안의 “등장 연기”는 0.60초 안에서 주 동작을 끝내고 이후에는 `heat`만 남아야 한다.

### `devil()`에서 바꿀 값

현재:

```python
Part(S, 'smoke', (box[0] + 330, box[1] + 600), (760, 760), 0.16,
     0.0, 0.9, loop=False, add=False, fade=0.2)
```

변경:

```python
Part(S, 'smoke', (360, 930), (620, 300), 0.12,
     0.00, 0.60, loop=False, add=False, alpha=0.48, fade=0.10)
```

- 중심: `(360, 972)` → **`(360, 930)`**
- 크기: `760×760` → **`620×300`**
- 프레임 간격: `0.16` → **`0.12초`**
- 시작/끝: `0.00–0.90` → **`0.00–0.60초`**
- 합성: **덮기(`add=False`) 유지**, 알파 **`0.48`** 지정
- 페이드: `0.20` → **`0.10초`**

이 값은 유효 연기 영역을 대략 `x=50–670`, `y=840–1040`에 두어 EventBox 하단(`y=967`)을 중심으로 피게 하고, 하단 조작부를 덮는 면적을 줄인다.

### 부품 판정

`smoke`는 **우선 재발주하지 않는다.** 현재 부품의 붉은 구름 형태 자체는 시안 계열과 맞고, 오차의 주원인은 760×760 과대 확대와 불투명 합성이다. 위 값으로도 검은 덩어리가 시안보다 두드러지면 그때 `smoke`만 재발주한다. 재발주 조건은 “검은 핵 제거, 위로 솟는 폭발이 아니라 낮게 깔리는 붉은 바닥 안개, 투명 여백 포함 512×512”이다.

## 2컷 — 최대/대기 (2.00초 대표 프레임)

### 시안과 다른 점

- 시안의 열기는 창 하단과 양옆을 감싸는 반투명한 붉은 아지랑이다. 재현은 창 아래에 불투명한 검붉은 덩어리로 뭉쳐 밝은 프레임보다 먼저 눈에 들어온다.
- 좌우 `chain_glow`가 실제 프레임 사슬보다 폭이 넓고 안쪽으로 걸쳐, 사슬 위 발광이 아니라 별도 붉은 장식처럼 보인다.
- 수락 버튼과 두 조건 pill의 발광이 시안보다 희고 강하다. 특히 재현의 버튼 외곽은 넓은 백색 띠가 되어, 시안의 붉은 테두리 맥동보다 과하다.
- 문장 상단 문장(emblem)의 불꽃은 재현에서 조금 높고 크다. 시안은 문장 바로 위에 붙어 짧게 탄다.

### `devil()`에서 바꿀 값

#### 하단 열기

현재:

```python
Part(S, 'heat', (box[0] + 330, box[1] + 560), (640, 320), 0.14,
     0.3, T_END, add=False, alpha=0.9)
```

변경:

```python
Part(S, 'heat', (360, 900), (610, 240), 0.12,
     0.30, T_END, add=True, alpha=0.38, fade=0.15)
```

- 중심: `(360, 932)` → **`(360, 900)`**
- 크기: `640×320` → **`610×240`**
- 프레임 간격: `0.14` → **`0.12초`**
- 시작/끝: **`0.30–4.80초` 유지**
- 합성: 덮기 → **가산(`add=True`)**
- 알파: `0.90` → **`0.38`**

#### 좌우 사슬 발광

현재 두 Part를 다음으로 교체한다.

```python
Part(S, 'chain_glow', (52, 732), (132, 300), 0.12,
     0.15, T_END, add=True, alpha=0.58, fade=0.12),
Part(S, 'chain_glow', (668, 732), (132, 300), 0.12,
     0.15, T_END, add=True, alpha=0.58, flip=True, fade=0.12),
```

- 중심: 좌 `(72,732)` / 우 `(648,732)` → **좌 `(52,732)` / 우 `(668,732)`**
- 크기: `190×380` → **`132×300`**
- 프레임 간격: `0.16` → **`0.12초`**
- 시작: 좌우가 어긋난 `0.20/0.25` → **둘 다 `0.15초`**
- 종료: **`4.80초` 유지**
- 합성/알파: **가산, `0.58`**

좌우 중심을 프레임 바깥쪽으로 옮겨 부품에 그려진 세로 사슬의 축을 원본 프레임 사슬에 맞춘다. 크기를 줄여 원본 사슬과 이중으로 보이는 폭도 없앤다.

#### 문장 불꽃

```python
Part(S, 'flame', (360, 405), (38, 76), 0.10,
     0.25, T_END, add=True, alpha=0.82, fade=0.12)
```

- 중심: `(360,383)` → **`(360,405)`**
- 크기: `44×88` → **`38×76`**
- 프레임 간격: **`0.10초` 유지**
- 합성: **가산**, 알파 **`0.82`**

#### pill 및 수락 버튼 발광

```python
Part(S, 'pill_sparks', cen(rw), pill_w(rw), 0.12,
     T_IDLE, T_END, add=True, alpha=0.62),
Part(S, 'pill_sparks', cen(cs), pill_w(cs), 0.12,
     T_IDLE + 0.05, T_END, add=True, tint=(255, 90, 70), alpha=0.52),
Part(S, 'button_glow', cen(acc), btn, 0.20,
     T_IDLE, T_END, add=True, alpha=0.58),
```

`acc_fn`의 대기 맥동 밝기 가산도 `0.18`에서 **`0.08`**로 낮춘다.

```python
br += 0.08 * (
    math.exp(-((ph - 0.1) / 0.05) ** 2)
    + math.exp(-((ph - 0.3) / 0.05) ** 2)
)
```

`panel_fn`의 등장 pop 값 `ease_pop(t, 0, 0.3, 0.96)`과 최초 0.3초 흔들림은 시안과 큰 차이가 없어 **유지**한다.

### 부품 판정

- `heat`, `chain_glow`, `flame`, `pill_sparks`, `button_glow`: **재발주 없음.** 현재 차이는 크기·위치·알파·합성 방식으로 교정 가능하다.
- 단, `chain_glow`는 부품 안에 사슬 형상이 함께 그려져 있으므로 위 정렬값을 임의 확대하지 않는다. 확대하면 원본 프레임 사슬과 반드시 이중선이 난다.

## 3컷 — 수락 (4.15초 대표 프레임)

### 시안과 다른 점

- 혼 번개의 출발점이 HUD 초상 `(95,75)`에 있어 화면 최상단에서 내려온다. 시안의 혼은 EventBox 왼쪽 위, HUD 아래의 게임 화면 안에 떠 있고 번개가 그 혼에서 문장으로 이어진다.
- 재현에는 시안 양옆의 「사슬 당김」 붉은 빛줄기가 전혀 없다. 이 효과는 수락 순간에만 나타나 프레임을 좌우에서 안쪽으로 조이는 핵심 동작이다.
- 시안의 혼 번개는 혼에서 문장까지 짧고 굵게 연결된다. 재현은 시작점 오류 때문에 길고 가는 세로 낙뢰로 읽힌다.
- 수락 직후 버튼 밝기 상승이 시안보다 강해 백색 테두리가 된다. 시안은 붉은 버튼 상태를 유지하면서 순간적으로만 밝아진다.

### `devil()`에서 바꿀 값

#### 혼과 혼 번개

```python
emblem = (360, 424)
ghost = (112, 292)
```

```python
Beam(S, 'soul_beam', ghost, emblem, 62, 0.06,
     T_ACC, T_ACC + 0.62)
```

- 출발점: `(95,75)` → **`(112,292)`**
- 도착점: `(360,417)` → **`(360,424)`**
- 굵기: `70` → **`62`**
- 프레임 간격: **`0.06초` 유지**
- 시작/끝: `3.80–4.50` → **`3.80–4.42초`**
- 합성: `Beam`의 **가산 합성 유지**

`ghost`는 시안의 혼 중심 기준이다. 실제 부품의 번개가 혼의 손에서 나와야 한다면 `(112,292)`를 혼 중심으로 쓰지 말고, 별도 `beam_origin=(126,306)`을 두어 Beam 시작점만 그 좌표로 사용한다. HUD `(95,75)`로 되돌리면 안 된다.

#### 수락 시 창/버튼 반응

`panel_fn`의 수락 흔들림은 시안의 당김 충격과 맞으므로 진폭/구간 `5px, 0.25초`를 **유지**한다. `acc_fn`의 수락 밝기는 `0.4`에서 **`0.18`**로 낮춘다.

```python
if t >= T_ACC:
    br = 1 + 0.18 * max(0, 1 - (t - T_ACC) / 0.30)
```

- 수락 버튼 밝기 상승: `+0.40 / 0.40초` → **`+0.18 / 0.30초`**
- 수락 버튼 glow Part: 앞 절의 **가산, 알파 `0.58`** 적용

`reward_burst`의 중심, 크기와 `3.80+0.25초` 시작은 시안의 보상 pill 방향과 맞으므로 **현 값 유지**한다.

### 「사슬 당김」 부품 판정 — 재발주

**재발주 필요.** 현재 `chain_glow`는 세로 사슬 자체가 포함된 발광 오버레이이고, `soul_beam`은 분홍색 번개다. 어느 쪽을 회전·확대해도 시안의 양옆 붉은 직선형 당김 잔상과 같아지지 않으며, `chain_glow`를 돌리면 원본 사슬 그림까지 대각선으로 중복된다.

발주 사양:

- 이름: `fx_devil_chain_pull_1.png` ~ `fx_devil_chain_pull_4.png`
- 캔버스: **1024×128 RGBA**, 가로 진행형, 배경 완전 투명
- 형태: 중심선 1개가 아니라 **2–3개의 평행한 붉은/주황 당김 잔상**, 끝으로 갈수록 가늘어짐
- 금지: 사슬 고리, 프레임 장식, 분홍 번개 지그재그, 검은 연기 포함
- 합성 전제: 가산 합성, 화면 배치 굵기 72px

입고 후 추가할 값:

```python
Beam(S, 'chain_pull', (0, 616), (116, 676), 72, 0.06,
     T_ACC, T_ACC + 0.48),
Beam(S, 'chain_pull', (720, 616), (604, 676), 72, 0.06,
     T_ACC, T_ACC + 0.48),
```

- 좌: `(0,616)` → `(116,676)`
- 우: `(720,616)` → `(604,676)`
- 굵기: **`72`**, 프레임 간격: **`0.06초`**
- 시작/끝: **`3.80–4.28초`**
- 합성: `Beam`의 **가산 합성**

오른쪽 부품 방향이 반대로 보이면 새 그림을 뒤집어 별도 로드하지 말고, `Beam`에 `flip` 선택지를 추가하거나 오른쪽 전용 미러 프레임을 로더에서 생성한다. 최종 화면에서는 양쪽 빛줄기의 밝기와 길이가 대칭이어야 한다.

## 최종 확인 기준

- 1컷: 연기가 EventBox 하단 바닥에서만 피고, 하단 조작 버튼의 원형 외곽과 아이콘을 가리지 않는다.
- 2컷: 붉은 열기는 반투명하고, 좌우 사슬 발광의 세로축이 원본 사슬과 한 줄로 겹친다.
- 3컷: 혼이 HUD가 아닌 창 왼쪽 위 게임 화면 안에 있고, 번개가 혼에서 문장으로 연결되며, 양옆 사슬 당김 빛줄기가 동시에 보인다.
- 세 컷 공통: 붉은 효과가 글자, 수치, 버튼 라벨을 먹지 않고 시안과 같은 우선순위를 유지한다.
