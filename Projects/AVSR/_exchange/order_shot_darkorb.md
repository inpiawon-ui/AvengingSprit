## 무엇을 그리나

- 크고 **흰 속**을 **옅은 청록 → 하늘색 테**가 감싸고, 가장 바깥이 **짙은 파란 가는 윤곽**인 빛 구슬
- 네 칸이 이어져 **은은하게 일렁인다** — 테 두께가 칸마다 1 px 정도씩 들고 나고, 속의 밝은 면 자리가 조금 옮겨 간다
- 테 바깥에 **작은 빛 알갱이 1~3개**가 칸마다 다른 자리에 붙었다 떨어진다
- 방향이 없다 — 꼬리를 그리지 마라

## 규격

| 항목 | 값 |
|---|---|
| 파일 | `shot_darkorb_sheet.png` |
| 크기 | **256 × 64** (64×64 × 4칸, 가로로 왼쪽부터) |
| 구슬 지름 | 칸 안에서 **약 40~44 px** (라이트와 같게), 중심은 각 칸 한가운데 |
| 배경 | 마젠타 `#FF00FF` 한 색 (투명은 내가 뚫는다). 그림 안쪽에 마젠타를 쓰지 마라 |
| 경계 | 칸 경계 열에 그림이 **0 px**. 칸 안쪽에 최소 4 px 여백 |
| 화풍 | 픽셀아트, 안티에일리어싱 없이 또렷하게. 원작처럼 **색 띠가 계단으로** 나뉜다 |

## 팔레트 (원작 시트 실측값)

| 쓰임 | 색 |
|---|---|
| 속 (가장 밝은 곳) | `#F7F7F7` |
| 속 바깥 · 옅은 청록 | `#ADEFE7` |
| 테 · 하늘색 | `#00C6F7` |
| 테 바깥 · 파랑 | `#529CD6` |
| 윤곽 (가는 선) | `#3173B5` |

이 다섯 색 밖의 색을 넓게 쓰지 마라. **보라·연두를 쓰지 마라**(지금 그림의 도깨비불 색이다).

## 검수 기준

1. 시트 크기가 정확히 256 × 64
2. 배경 마젠타 한 색, 칸 경계 침범 0 px
3. 원작 앵커와 나란히 놓았을 때 **같은 구슬로 읽힌다** — 흰 속 · 청록/하늘색 테 · 파란 윤곽
4. 라이트 빛 구슬과 나란히 놓았을 때 **색만 다른 짝**으로 읽힌다
5. 도형이 아니다 — 매끈한 원·완전 대칭이 없다 · 꼬리가 없다
6. 네 번째 칸에서 첫 칸으로 끊김 없이 이어진다
