# UI 전체 컨셉 제안 답변

## 먼저 결론

현재 화면은 배경, 판, 테두리, 숫자, 아이콘이 모두 같은 강도로 빛나서 중요한 정보의 순서가 보이지 않는다. 리뉴얼의 공통 목표는 **배경은 분위기, 큰 판은 과업, 강조색은 현재 행동 하나만 담당**하게 만드는 것이다. 네 시안 가운데 우선 검증할 방향은 **A 「빙의 아케이드」**다. 원작 아케이드의 활기, 유령의 개성, 모바일 가독성을 가장 함께 살리기 쉽다. 성인 취향의 분위기를 더 원하면 B, 도트 세계 자체를 브랜드로 삼으려면 C, 폭넓고 가벼운 시장성을 우선하면 D가 적합하다.

## 1. 디자인 컨셉 4개

### A. 빙의 아케이드 — 굵고 경쾌한 현대식 아케이드

한 줄 요지: **검은 아케이드 캐비닛 위에 큰 크림색 정보판과 유령빛 포인트를 얹어, 한눈에 읽히고 손맛이 나는 방향.**

| 항목 | 제안 |
|---|---|
| 실제 게임 레퍼런스 | **Brawl Stars**의 큰 덩어리와 명확한 주 행동, **Clash Royale**의 카드 위계와 굵은 숫자, **TMNT: Shredder's Revenge**의 현대적으로 정리된 복고 색감 |
| 색 | 바탕 `#11131A` 먹색, 주 판 `#F2E8CE` 크림, 보조 판 `#283044` 남청, 유령 강조 `#79F2D0` 민트, 행동 강조 `#FFCA3A` 노랑, 위험/SSR `#FF4D67` 산호빨강. 한 화면의 발광색은 민트 또는 노랑 하나만 사용 |
| 글꼴 느낌 | 한·일·영 모두 폭이 넓고 단단한 산세리프. 제목 ExtraBold, 본문 SemiBold, 숫자 Black. 외곽선은 배경 위 큰 제목에만 2px 어두운 선, 판 내부 본문에는 외곽선 금지 |
| 판 모양·뎁스 | 12~16px 둥근 모서리, 2px 단색 테두리, 아래로 6px 떨어진 짙은 그림자로 누르는 장난감 같은 깊이. 선택 판만 노랑 상단 띠. 중첩 테두리와 내부 네온선 제거 |
| 배경 | 현재 배관 배경은 홈의 상단 영웅 구역에만 크롭해 남기고 55% 어둡게, 3~5px 흐림. 육성·상점·패스에서는 단색 먹색과 희미한 픽셀 패턴만 사용 |
| 도트 캐릭터와의 결합 | 캐릭터 도트를 2배 또는 3배 정수 배율로 크게 두고, 주변 UI는 매끈한 큰 면으로 비워 도트 실루엣을 주인공으로 만든다. 유령은 판 밖으로 살짝 떠오르게 배치해 ‘빙의’의 장난기 표현 |
| 게임에 맞는 이유 | 1991 아케이드의 경쾌함을 보존하면서 현재의 복잡한 네온을 걷어낸다. 복수의 어두움보다 ‘적의 몸을 갈아타는 독특한 액션’을 전면에 내세워 접근성이 좋다 |

**시안 발주용 한 단락:** 세로 720×1280 모바일 UI, 굵고 경쾌한 현대식 아케이드 스타일. 홈은 상단 360px에 어두워진 밤 도시와 큰 유령, 중앙에는 현재 출전 호스트와 노란 PLAY 버튼, 아래에는 ‘이어 하기·일일 임무·이벤트’ 세 장의 큰 카드만 둔다. 호스트 육성은 화면 왼쪽 42%에 정수 배율 도트 캐릭터, 오른쪽 58%에 레벨·전투력·성급, 하단에 스킬 카드 3장과 큰 성장 버튼을 둔다. 소환 화면은 크림색 픽업 배너, 중앙의 유령 포털, 하단 1회/10회 버튼만 남긴다. 소환 연출은 한 장에 5컷으로 ‘버튼 입력 → 캐비닛 화면 꺼짐 → 민트 유령이 호스트 실루엣을 고름 → 등급색 충돌 → 카드 결과’를 표현한다. 본문 24px, 보조 20px, 숫자 28~36px, 화면 제목 36px, 주 버튼 글자 28px, 모든 터치 칸 높이 72px 이상. 청록 네온 격자와 가는 칸의 반복은 사용하지 않는다.

### B. 복수의 극장 — 다크 코믹 누아르

한 줄 요지: **검은 무대와 붉은 커튼 사이에 유령과 호스트를 배우처럼 세우는, 서사와 복수에 무게를 둔 방향.**

| 항목 | 제안 |
|---|---|
| 실제 게임 레퍼런스 | **Hades**의 강한 인물 초상과 명확한 판, **Dead Cells**의 어두운 세계와 뜨거운 포인트, **Persona 5**의 대담한 사선 구성과 제한색 |
| 색 | 바탕 `#0B0B10` 흑색, 주 판 `#24212A` 먹보라, 종이 판 `#DED3BE` 회백색, 강조 `#D52D3A` 복수의 적색, 유령 `#8DE6D1` 창백한 민트, SSR `#E6B94A` 금색 |
| 글꼴 느낌 | 제목은 좁고 각진 Display Black, 본문은 가독성 높은 Medium/SemiBold. 제목에만 1~2px 검정 그림자, 숫자는 고정폭 느낌의 Bold. 긴 한국어 본문에는 장식 금지 |
| 판 모양·뎁스 | 모서리를 한두 곳 사선으로 자른 큰 판. 테두리 없이 명도 차와 10px의 깊은 그림자로 층 구분. 붉은 브러시/찢긴 종이 모티프는 제목 띠와 선택 상태에만 제한 |
| 배경 | 배관 도시는 홈의 ‘무대 뒤’로만 남겨 70% 어둡게 하고 비네트 처리. 기능 페이지는 거의 검은 단색, 인물 뒤에 큰 달·창문·커튼 실루엣 하나만 둔다 |
| 도트 캐릭터와의 결합 | 도트 캐릭터는 큰 스포트라이트 안에 놓고, 선택 시 뒤로 확대된 제한색 실루엣 초상을 겹친다. 픽셀 가장자리는 흐리지 않고 정수 배율 유지 |
| 게임에 맞는 이유 | 유령의 죽음과 복수라는 정서를 가장 강하게 전달한다. 호스트 교체를 ‘배역 교대’, 챕터를 ‘막’, 방을 ‘장면’으로 이름 붙일 수 있어 세계관과 메뉴 구조가 결합된다 |

**시안 발주용 한 단락:** 세로 720×1280, 다크 코믹 누아르 모바일 UI. 홈은 검은 무대 위 붉은 사선 제목 띠, 중앙 스포트라이트 속 유령과 현재 호스트, 하단의 큰 ‘다음 장면’ 버튼으로 구성한다. 호스트 육성은 왼쪽 큰 캐릭터 무대와 오른쪽 세로 정보판으로 나누고, 기본 능력·스킬·성급은 상단 탭 세 개로 분리한다. 소환 화면은 붉은 커튼이 닫힌 극장과 중앙의 창백한 유령, 하단 검정/금색 소환 버튼만 보인다. 연출 스토리보드는 6컷 ‘표 구입 → 조명 소등 → 커튼 개방 → 호스트 그림자 등장 → 유령 빙의 → R/SR/SSR 인물 카드 공개’로 구성한다. 본문 24px, 보조 20px, 숫자 30px, 제목 38px, 주 버튼 28px, 터치 높이 72px 이상. 빨강은 선택·위험·주 행동에만 쓰고 모든 판에 반복하지 않는다.

### C. 영혼의 픽셀 연대기 — HD-2D 박물관

한 줄 요지: **도트 캐릭터와 원작의 역사성을 중심에 두고, 종이·목재·달빛으로 차분하게 전시하는 프리미엄 리메이크 방향.**

| 항목 | 제안 |
|---|---|
| 실제 게임 레퍼런스 | **Octopath Traveler II**의 도트 주인공과 깊이 있는 조명, **Sea of Stars**의 선명한 픽셀 색과 정돈된 메뉴, **Live A Live HD-2D**의 리메이크 감성 |
| 색 | 바탕 `#151A24` 잉크 남색, 주 판 `#E8DFC8` 양피지, 보조 판 `#343A46` 슬레이트, 강조 `#62C7B5` 영혼 청록, 금속 `#C89B45` 고동금, 위험 `#A84343` 적갈색 |
| 글꼴 느낌 | 제목은 고전 RPG풍의 단정한 명조 또는 세리프 Bold, 본문은 산세리프 Medium/SemiBold. 외곽선 대신 1px 그림자만 사용. 숫자는 크고 탁 트인 Bold |
| 판 모양·뎁스 | 8px의 작은 라운드, 1px 고동금 테두리, 넓고 부드러운 그림자. 판 내부는 구분선보다 여백으로 묶는다. 작은 장식은 모서리 한 곳의 픽셀 문양만 허용 |
| 배경 | 배관 도시를 화면 전체에 반복하지 않는다. 홈은 달빛 도시를 깊이감 있는 한 장면으로 쓰고, 각 페이지는 남색 단색 위에 해당 챕터 장소의 흐린 픽셀 디오라마를 상단 30%에만 배치 |
| 도트 캐릭터와의 결합 | 캐릭터 도트가 UI 장식이 아니라 전시물이다. 중앙에 큰 정수 배율로 두며 발밑 그림자, 뒤쪽 흐린 환경, 앞쪽 판의 세 층으로 HD-2D 같은 깊이를 낸다 |
| 게임에 맞는 이유 | ‘1991년 작품의 귀환’을 가장 품격 있게 보여 준다. 수집한 23명의 호스트를 도감·연대기처럼 보이게 해 수집 동기를 만들고, 일본 시장의 클래식 RPG 취향에도 잘 맞는다 |

**시안 발주용 한 단락:** 세로 720×1280, 프리미엄 HD-2D 픽셀 리메이크 UI. 홈은 상단 절반에 달빛 도시 디오라마와 큰 유령, 그 앞에 현재 호스트가 서고, 하단 절반은 양피지색 ‘계속하기’ 카드와 작은 임무 카드 두 장으로 정리한다. 호스트 육성은 중앙 큰 도트 캐릭터를 중심으로 상단에 이름·등급·성급, 하단에 전투력과 스킬 3장, 가장 아래 성장 버튼 하나를 둔다. 상세 수치는 ‘능력 상세’ 시트로 내린다. 소환 화면은 어두운 영혼 기록실, 중앙의 낡은 아케이드 기판 또는 명부, 하단 1회/10회 버튼으로 구성한다. 연출 5컷은 ‘명부 개방 → 픽셀 영혼 방출 → 과거 호스트 장면 점등 → 빙의 실루엣 → 금빛 기록 카드 공개’. 본문 24px, 보조 20px, 숫자 30px, 제목 36px, 버튼 26~28px, 터치 높이 72px 이상. 배경은 정보판과 명도 경쟁을 하지 않도록 어둡고 흐리게 한다.

### D. 고스트 쇼케이스 — 캐릭터 진열 중심의 밝은 모바일 팝

한 줄 요지: **유령과 23개 호스트를 장난감 컬렉션처럼 크고 밝게 보여 주는, 가장 대중적이고 즉시 읽히는 방향.**

| 항목 | 제안 |
|---|---|
| 실제 게임 레퍼런스 | **Archero 2**의 큰 캐릭터 중심 성장 화면, **Survivor.io**의 간결한 카드와 행동 버튼, **Pokémon Masters EX**의 캐릭터 쇼케이스와 등급 연출 |
| 색 | 바탕 `#E8F0F2` 옅은 회청, 주 판 `#FFFFFF` 흰색, 진한 글자 `#182738` 네이비, 유령 강조 `#55D6C2` 민트, 행동 `#FFB82E` 오렌지, SSR `#8B5CF6` 보라 |
| 글꼴 느낌 | 둥글고 친근한 산세리프. 제목 Black, 본문 SemiBold, 숫자 ExtraBold. 외곽선은 캐릭터명과 이벤트 배너에만 2px 흰색; 일반 텍스트에는 사용하지 않음 |
| 판 모양·뎁스 | 20px 큰 라운드, 테두리 없이 명도 차와 8px 소프트 그림자. 카드가 겹칠 때 12px 이상 층 간격. 선택 카드에만 4px 등급색 테두리 |
| 배경 | 현재 배관 배경은 홈의 이벤트 배너 한 장 안에서만 사용. 기본 화면은 옅은 단색과 큰 유령 물결 도형으로 정리. 소환에서만 어두운 배경으로 반전해 이벤트성을 만든다 |
| 도트 캐릭터와의 결합 | 도트를 흰 카드 중앙에 매우 크게 놓고 이름·역할·등급만 즉시 보이게 한다. 하단 캐러셀은 한 번에 4명만 노출하고 선택 캐릭터를 15% 확대 |
| 게임에 맞는 이유 | 빙의 대상 23명의 차이를 가장 쉽게 판매하고 수집 욕구를 높인다. 복잡한 아케이드 지식 없이도 진입 가능하며, 작은 화면에서 정보 인지가 가장 빠르다 |

**시안 발주용 한 단락:** 세로 720×1280, 밝고 둥근 캐릭터 쇼케이스형 모바일 UI. 홈 상단은 흰 배경에 큰 유령과 선택 호스트, 중단에는 주황색 ‘PLAY’ 버튼, 하단에는 ‘성장 가능·무료 소환·시즌’ 큰 카드 세 장을 한 줄 또는 2+1로 둔다. 호스트 육성은 화면 상단 46%를 캐릭터 전시 구역으로 비우고, 하단에 레벨·전투력, 스킬 카드 3장, 큰 성장 버튼을 배치한다. 소환 화면은 흰색 픽업 카드와 큰 도트 호스트, 중앙 유령 물결, 하단 1회/10회 버튼만 둔다. 연출 5컷은 ‘유령 터치 → 배경 어두워짐 → 후보 실루엣 카드 세 장 회전 → 등급색 폭발 → 큰 캐릭터 카드 공개’. 본문 24px, 보조 20px, 숫자 32px, 제목 36px, 버튼 28px, 터치 높이 76px 이상. 장식용 아이콘 수를 줄이고 카드마다 핵심 수치 한 개만 노출한다.

## 2. 공통 레이아웃 원칙 — 큼직하게, 정리, 뎁스

### 글자·터치·정보량

| 항목 | 720px 폭 기준 규칙 |
|---|---|
| 최소 본문 | **24px**. 반복 목록의 보조 설명만 20px 허용. 약관·확률표 외에는 20px 미만 금지 |
| 숫자 | 재화 22~24px, 카드 핵심 수치 28~32px, 전투력·가격·보상 32~40px |
| 제목 | 화면 제목 36~40px, 구역 제목 28~32px, 카드 제목 24~28px |
| 버튼 글자 | 26~28px SemiBold 이상. 핵심 버튼은 동사와 비용을 두 줄로 나누지 말고 한눈에 읽히게 구성 |
| 터치 칸 | 최소 **72×72px**, 주 행동 버튼 높이 84~96px, 인접 터치 영역 간격 최소 12px |
| 한 화면 정보 상한 | 큰 주 행동 1개, 주 구역 3개, 카드 4개 또는 목록 6행, 상단 재화 2종. 초과 정보는 탭·시트·다음 페이지로 이동 |

### 뎁스 구조

**홈 → 전체 화면 페이지 → 아래 시트 → 확인 팝업**의 4층으로 고정한다.

1. **홈:** 현재 호스트, 이어 할 챕터, 즉시 처리할 알림 2개까지만 보인다. 상점 상품·시즌 보상 목록·세부 능력치는 올리지 않는다.
2. **전체 화면 페이지:** PLAY, HOST, SUMMON, 시즌/상점처럼 하나의 과업만 맡는다. 페이지 안의 기본 탭은 최대 3개다.
3. **아래 시트:** 능력 상세, 스킬 설명, 재료 출처, 확률, 보상 미리보기처럼 ‘읽고 닫는’ 정보를 화면 높이 55~75% 시트로 연다. 뒤 화면은 45% 어둡게 한다.
4. **팝업:** 구매·성급 상승·재화 부족처럼 결정이 필요한 경우만 쓴다. 제목, 변화 요약, 취소/확인 두 버튼만 둔다. 팝업 안 스크롤 목록은 금지한다.

**현재 호스트 육성 분리:** 기본 화면에는 캐릭터, 레벨/전투력, 성급, 장착 스킬 3개, 성장 버튼만 둔다. `기본 능력 / 스킬 / 성급` 세 탭으로 나누고, 세부 계수와 다음 단계 변화는 항목 터치 시 아래 시트로 연다. 하단 호스트 목록은 한 번에 4명만 보이는 캐러셀로 만들며 전체 목록은 별도 선택 페이지로 보낸다.

**현재 출전 화면 분리:** 첫 화면에는 챕터명, 큰 대표 장면, 권장 전투력, 예상 보상 3개, 출전 버튼만 둔다. 출전 버튼을 누른 다음 별도 ‘편성’ 시트에서 호스트/유령/동료를 정하고 시작한다. 난이도, 클리어 조건, 보스 정보는 ‘정보’ 시트로 내린다. 챕터 선택은 좌우 이동 또는 별도 목록으로 분리해 한 화면에서 챕터 설명·편성·보상을 동시에 편집하지 않는다.

### 위 막대와 아래 바

- **위 막대:** 왼쪽에 뒤로/화면 제목, 오른쪽에 골드와 유료 재화 **2종만** 둔다. 에너지, 우편, 설정, 시즌 레벨은 홈의 별도 상태 줄 또는 프로필 시트로 이동한다. 재화의 `+`는 상점으로 가는 공통 아이콘 하나만 둔다. 높이 88px, 작은 테두리와 발광은 제거한다.
- **아래 바:** `HOME · HOST · PLAY · SUMMON`의 4칸으로 바꾸고 **PLAY를 중앙에서 1.15배 크게** 만든다. SHOP은 상시 핵심 순환이 아니므로 홈 카드와 재화 `+`를 통해 진입시킨다. 각 칸은 아이콘+현지화 명칭, 높이 104px, 선택 상태는 채운 면과 상단 4px 띠로 표시한다. 미선택 칸은 발광하지 않는다.
- 알림 배지는 탭마다 하나만, 숫자는 `9+`까지만 보인다. 무료 소환처럼 바로 처리할 항목에만 빨간 점을 허용한다.

## 3. 가챠(소환) 장면 전환 흐름

| 단계 | 시간 | 화면과 동작 | R/SR/SSR 강약 및 건너뛰기 |
|---|---:|---|---|
| 1. 소환 화면 | 대기 | 픽업 호스트 큰 이미지, 보장/천장 수치, 보유 재화, `1회`와 `10회` 버튼. 확률과 기록은 아래 시트로 분리 | 등급 연출색을 미리 남발하지 않는다. 버튼을 누르면 비용 확인은 재화가 충분할 때 생략 가능 |
| 2. 진입 전환 | 0.35초 | UI 판이 아래로 사라지고 화면이 어두워지며 유령만 중앙으로 이동. 홈/하단 바 완전 제거 | 이 시점부터 화면 우상단에 `건너뛰기` 표시. 첫 소환은 0.6초 뒤 표시 |
| 3. 포털 개방 | 0.8초 | 유령이 포털·아케이드 캐비닛·명부 등 선택 컨셉의 핵심 장치를 연다. 10회는 작은 영혼 10개가 모임 | R: 흰/민트 한 겹, SR: 보라 파동 두 겹과 진동 1회, SSR: 금빛 균열·잠깐의 무음·강한 진동. 색맹 대응으로 파동 수와 형태도 다르게 함 |
| 4. 빙의 탐색 | 0.7~1.2초 | 호스트 실루엣이 빠르게 지나가고 유령이 하나를 선택해 돌진 | R 0.7초, SR 0.9초, SSR 1.2초. SSR이면 실루엣 직전 0.25초 정지해 기대감 형성 |
| 5. 등급 확정 | 0.45~0.9초 | 충돌 순간 화면을 덮는 등급별 형상: R 원형, SR 별/마름모, SSR 깨지는 금빛 문장 | R은 짧고 조용하게, SR은 캐릭터 음성/효과음, SSR은 전용 0.9초 컷과 이름 콜. 광과 플래시는 밝기 설정을 따름 |
| 6A. 1회 결과 | 대기 | 큰 캐릭터 도트, 이름, R/SR/SSR, 신규 여부, 조각 수. 아래에 `한 번 더`와 `닫기` | 신규 또는 SSR이면 캐릭터의 짧은 대사 한 줄. 중복은 ‘조각 ×N’ 변환을 같은 자리에서 즉시 표시 |
| 6B. 10회 결과 | 대기 | 2×5 카드 배열. 카드는 0.12초 간격으로 열고, 높은 등급은 마지막에 연다. 상단에 신규 수, 하단에 `10회 더`와 `확인` | 결과 카드 정렬은 획득 순서를 유지하되 SR/SSR 테두리만 지속. SSR 카드를 누르면 큰 상세 시트가 열림 |

**전체 길이:** R 1회는 약 2.3초, SR은 약 2.8초, SSR은 약 3.5초. 10회는 결과 펼침을 포함해 4.5~6초를 목표로 한다.

**건너뛰기 규칙:** 버튼은 전환 시작 0.6초 후부터 활성화한다. 누르면 아직 보지 않은 연출을 생략하고 결과 화면으로 이동하되, 신규 SSR이 있으면 0.6초의 최소 공개 컷만 보여 준다. 설정에 `R 연출 자동 생략`, `중복 연출 자동 생략`, `모든 연출 축약`을 둔다. 결과 화면에서 다시 소환할 때는 비용과 천장 변화가 버튼 바로 위에 보이며, 연타 방지를 위해 입력 후 버튼을 즉시 잠근다.

## 4. 시안 발주 목록

각 컨셉별로 아래 **4장**을 같은 내용·같은 정보량으로 제작해 비교해야 한다. 장마다 720×1280 원본 한 장이며, 소환 연출만 한 장 안에 5컷을 담는다. 즉 **4컨셉 × 4장 = 총 16장**이다.

| 화면 | 반드시 들어갈 요소 | 배치·크기 기준 |
|---|---|---|
| 홈(로비) | 플레이어/레벨, 골드·유료 재화, 현재 유령과 호스트, 이어 할 챕터, 주 PLAY, 처리할 카드 최대 3개, 하단 바 | 상단 막대 88px, 캐릭터/세계 구역 330~400px, 주 버튼 84~96px, 카드 2~3개, 하단 바 104px. 본문 24px, 제목 36~40px |
| 호스트 육성 | 캐릭터명·등급·성급, 큰 도트 캐릭터, 레벨·전투력, 기본 능력/스킬/성급 탭, 스킬 3개, 성장 재료와 버튼, 호스트 캐러셀 4명 | 캐릭터가 화면의 최소 35% 차지. 탭 높이 64px 이상, 스킬 카드 높이 96px 이상, 성장 버튼 88px. 상세 계수는 시트 진입 표시만 |

**비교 검수 조건:** 모든 시안은 동일한 샘플 데이터(동일 호스트, 동일 전투력, 동일 재화, 동일 문구)를 사용한다. 720×1280 이미지를 실제 휴대폰 표시 크기로 축소했을 때 본문이 읽혀야 하며, 각 화면을 3초 본 뒤 사용자가 ‘현재 위치, 가장 중요한 수치, 다음에 누를 버튼’을 답할 수 있어야 한다. 네온 외곽선 수, 동시에 보이는 카드 수, 20px 미만 글자 수를 계수해 현재 화면보다 명확히 줄었는지도 함께 검수한다.
