# 에셋 매니페스트 (Asset Manifest) — 표준 양식

> **역할**: Stage 2b→3 다리. 화면 설계의 **Image 요소**를 "생성할 에셋 목록"으로 모은다.
> ComfyUI(또는 AI 이미지) 입력이 되고, **파일명 = 요소명 = 프리팹 슬롯**으로 자동 적용된다.
> **사용법**: `Projects/[ProjCode]/[ProjCode]_AssetManifest.md`로 복사해 채운다.

---

## 0. 글로벌 아트 디렉션 (ComfyUI 공통 프롬프트 기준)
- 스타일: `[예: 픽셀 도트, 파스텔 힐링 팔레트]`
- 배경/포맷: `[스프라이트=투명 PNG, 배경=풀 이미지]`
- 해상도 원칙: `[소스 px → 업스케일 규칙]`
- 팔레트/톤: `[핵심 색]`

## 1. 파일·적용 규약
- 파일명 = 화면 설계서 **요소 이름**과 동일(소문자 케밥 허용). 예: 요소 `PetView` → `petview` 또는 `pet_[stage]`.
- 포맷: PNG(투명). Addressable/아틀라스 그룹은 리포 규약(02/05) 따름.
- 적용: 생성 → `Assets/BaseResource/` 또는 `BundleResource/` import → 프리팹 Image에 할당(unityMCP/에디터).

## 2. 에셋 목록

> 우선순위 P0(코어 화면 필수) / P1 / P2. 개수는 세트로 묶어도 됨.

| 에셋 ID(파일명) | 용도/요소 | 화면 | 소스 크기(px) | 스타일·프롬프트 힌트 | 개수 | 우선 |
|-----------------|-----------|------|---------------|----------------------|:---:|:---:|
| `[id]` | `[요소/용도]` | `[S#]` | `[예: 128×128]` | `[프롬프트 키워드]` | `[n]` | `[P0]` |

### 카테고리 예시(게임에 맞게 조정)
- 캐릭터/펫 스프라이트(단계·표정·상태)
- 배경(방·타이틀·연출)
- 아이콘(게이지·재화·버튼·상태)
- UI 프레임(버튼·패널·팝업·바 — 9-slice)
- 아이템 썸네일(꾸미기·소모품 — 카탈로그)
- 이펙트(파티클/연출 이미지)
