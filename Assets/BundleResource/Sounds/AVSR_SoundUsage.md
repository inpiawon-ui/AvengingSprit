# AVSR 원작 사운드 사용처 매칭

이 폴더(`Assets/BundleResource/Sounds/`)의 원작 음원이 **원작 어디에서 쓰였는지**와, **현재 프로젝트의 챕터·호스트·보스·화면 중 어디에 대응하는지**를 정리한 문서다.
원본 추출 기록은 [`Projects/AVSR/AVSR_SoundExtract.md`](../../../Projects/AVSR/AVSR_SoundExtract.md)에 있다.

**근거 등급**

| 등급 | 뜻 |
|---|---|
| **확정** | 원작 프로그램 코드, 또는 실제 게임 진행(무적·자연 빙의·보스 실제 격파)에서 직접 확인했다 |
| **추정** | 간접 근거만 있다. 이유를 함께 적었다 |
| **확인 불가** | 이번 조사 방법으로는 정할 수 없다. 이유와 확정 방법을 4절에 적었다 |

- 파일명 숫자 = 원작 사운드 번호 (`bgm_02` = BGM 2번, `sfx_19` = SFX 19번).
- 원작 코드는 같은 효과음을 연달아 낼 때 번호를 NN ↔ NN+24로 번갈아 보낸다. 40–62번은 16–38번과 **같은 소리**라서 파일이 따로 없다.
- 원작 호스트 번호 = 적 객체의 종류값(+0x10). 빙의하면 이 값이 호스트 변수 `$7a51e`로 복사된다.

원작 스테이지 순서와 프로젝트 챕터는 **보스 순서가 같다**(`BossDefTable.cs`). 이 기준으로 맞췄다.

### 1.3 호스트 (빙의 캐릭터)

**판정 방식 — 자연 빙의 통제 실험.**
- 무적 상태에서 유령을 목표 캐릭터 위로 옮겨 **실제로 빙의**시켰다. 빙의하면 몸체도 그 캐릭터가 된다.
- 이후 2초마다 가장 가까운 적 옆으로 옮기며 **공격 버튼 3초 누름 / 3초 뗌**을 반복했다. 적의 소리는 두 구간에 고르게 섞이므로, 누를 때만 크게 늘어나는 소리가 그 호스트의 공격음이다.

- **"원작 미사용" 8개의 근거**: 원작 프로그램이 소리를 요청하는 길은 네 가지뿐이고, 모두 조사했다.
  - 요청 루틴 `$2bcc` 직접 호출 35곳 (상수·표·레지스터 값 전부 추적)
  - 애니메이션 스크립트 명령 `F030 번호` — ROM 전체 스캔
  - 연출 스크립트 명령 `0044 번호` — ROM 전체 스캔
  - 사운드 큐 직접 기록 `0x0211` (코인)

  8개 번호는 어느 길에도 없다. 사운드 CPU 테이블과 서비스 모드 사운드 테스트 목록에만 있다.
- `Samples/`(OKI 원본 샘플) 37개의 개별 사용처는 5절에 있다. OKI2 샘플 1–22는 SFX 16–38과 1:1로 대응하고, OKI1 샘플은 BGM 드럼 파트다.

## 3. 조사 방법

1. **원작 게임 구동**
   - ROM에 입력 보호 MCU 덤프가 없어 원래는 게임이 진행되지 않는다.
   - 메인 프로그램 **복사본**의 MCU 대기 루틴 2곳(`$fd6`, `$ffa`)을 "쓰고 바로 읽기"로 패치하고, 읽는 값은 MAME Lua가 입력 포트 값으로 돌려준다. 원본 ROM 폴더는 수정하지 않았다.
2. **사운드 요청 기록**
   - 모든 소리는 `$2bcc`(논리 ID → 명령 변환 후 큐 적재)를 거친다. 큐에 들어가는 순간 호출 위치 · 스테이지 `$79582` · 구역 `$79583` · 빙의 호스트 `$7a51e` · 소리를 낸 객체의 종류(+0x10)를 기록하고 화면을 찍었다.
3. **무적**
   - 유령 에너지 `$79e54`(최대 0xC8)와 빙의 호스트 에너지(`$79eea`+0x66, 최대 +0x68)가 **줄어드는 쓰기를 막는** 쓰기 탭. 컨티뉴 0회로 검증했다.
4. **범위 확보**
   - 스테이지·구역 번호를 쓰기 탭으로 강제해 모든 스테이지·보스방에 진입했다. 엔딩 확인 때는 보스방 진입만 한 번 강제하고 이후 게임 흐름을 그대로 두었다.
   - 적 객체 배열(`$7a54c`, 20칸)을 스캔해 구역마다 등장하는 원작 번호를 목록화했다.
5. **호스트 공격음 — 자연 빙의 통제 실험**
   - 유령을 목표 번호 적 위로 옮겨 실제로 빙의시키고, 다른 캐릭터에 빙의하면 호스트를 버리게 했다.
   - 빙의 후 적 옆으로 주기적으로 옮기며 공격 버튼 3초 누름/뗌 대비를 집계했다.
6. **정적 분석**
   - BGM 선택표 `$2b46` · 논리 ID 표 `$2c18` · 호스트 피격음 표 `$162ea` · 아이템 분기 `$dfc6` · 반사 루틴 `$16182` · 연출 표(`$74f4`/`$7644`) · 게임 상태 분기 `$58ce` · 스크립트 명령 스캔
7. 전체 에뮬레이션은 병렬로 약 12시간 분량이다. 재현 도구: [`Projects/AVSR/_sound_extract/usage/`](../../../Projects/AVSR/_sound_extract/usage/)
