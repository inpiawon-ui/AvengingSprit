# Assets/Scenes — 이 프로젝트 씬 설정

이 파일은 **이 게임 프로젝트 전용** 씬 구성 정보입니다.
게임 장르·프로젝트가 바뀌면 이 파일만 수정합니다.
씬 구성 규칙(SafeAreaPanel, InGame 규약 등)은 `.claude/rules/project/04_scenes.md` 참조.

---

## 씬 구조

> ※ 씬 이름은 프로젝트에 따라 다르다. 신규 프로젝트 시 실제 씬 이름으로 교체한다.

| 씬 이름 | 역할 |
|---|---|
| `BootScene` | 부팅 전용. Additive로 로드되는 씬 |
| `TitleScene` | 게임 시작 시 메인으로 표시되는 씬 |
| `LobbyScene` | 타이틀에서 로그인 후 진입하는 기본 씬 |
| `GameScene` | 인게임 컨텐츠 씬 |

---

## 레이어 / 태그 설정

> ※ 레이어 번호와 태그는 **프로젝트 시작 시 반드시 게임 장르에 맞게 교체한다**.
> 아래 값은 예시이며, 신규 프로젝트에서 그대로 사용 금지.

Physics2D 충돌 판정에 사용되는 레이어와 태그이다. 새 오브젝트 추가 시 반드시 아래 값으로 설정한다.

```
Layers:
  [레이어 번호]  [레이어 이름]
  ...

Tags:
  [태그 이름] / ...
```
