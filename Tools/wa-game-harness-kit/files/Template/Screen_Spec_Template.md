# 화면 설계서 (Screen Spec / Wireframe) — 표준 양식

> **역할**: 기획 Stage 2b. 한 화면의 **레이아웃 + 요소 트리**를 정한다. 박스 목업(HTML/SVG)과 짝을 이룬다.
> **씬 그룹핑은 여기서 안 한다** — 어느 화면을 어느 씬/팝업으로 묶을지는 Stage 3(디자인).
> **사용법**: 화면마다 `Projects/[ProjCode]/wireframes/[ProjCode]_Screen_[화면명].md` + 같은 이름의 `.html` 목업.
> 규약: 요소 이름 = 프리팹 GameObject 이름 = 클라 바인딩 키 (동일하게). UI 타입은 06_ui 규약.
