# 이펙트 · 아트 제작 순서 (fx-art-pipeline)

> 이 게임의 경로 · 도구 · 브리프 위치는 **같은 폴더의 `project.md`** 에 있다. 이 문서는 게임과 상관없는 순서다.
> 역할: 코덱스 = 아트(시안 · 부품 그림) / Claude = 가이드 · 발주 · 게임 반영 · 타이밍 · 검증 · 보고. Claude 는 그림을 그리지 않는다.
> 출처: AVSR(2026-10) — 숫자(알파 · 크기)만 코덱스와 주고받다 「퀄 엉망」을 몇 번 받았고, **코덱스 자유 시안**(코덱스가 아트 디렉터로
> 그린 완성 화면)을 먼저 보여 주자 PD 가 한 번에 골랐다. 이 순서가 그 결과다.

## 코덱스에게는 항상 브리프를 같이 준다
- 브리프(`project.md` 의 「브리프」) — 색의 뜻 표 · 장면별 분위기 표, 빛 = 도트 모양 + 셰이더 광원 · 파티클, 강약, 기승전결,
  PD 원문 금지 사항, 통과 기준 그림과 그 「가져올 것 · 피할 것」. 새 게임이면 `codex_brief_template.md` 로 먼저 만든다.
- 가이드 · 발주문의 **색은 브리프 색의 뜻 표, 세기는 장면 분위기 표 그 줄에서** 가져온다 — 「예뻐 보여서」 고른 색 · 세기는 쓰지 않는다.
- 시안 · 부품 · 상의 발주문 첫 줄에 「먼저 이 브리프를 읽는다」.
- PD 와 새로 정한 것은 **브리프에 먼저 적는다** — 그래야 코덱스가 처음부터 같은 생각으로 그린다(광원 얘기를 빼먹어 툰으로만 그린 적이 있다).

## 0. 시작 전
- 유니티를 다른 세션과 같이 쓰면 그 규칙을 따른다. 세이브는 시험 전에 백업, 끝나면 되돌린다. 지우지 않는다(`verify_and_report.md`).

## 1. 지금 모습 캡처 (바탕)
- 게임에서 그 장면을 녹화한다 — **힘주는 순간**(완성 · 착지 · 획득)과 **머무는 장면** 두 컷.
- 해당 칸만 잘라 2배로 키워 교환 폴더 `ref/<주제>_mock/base_*.png` 에 둔다(글자가 읽히는 크기).

## 2. 연출 가이드 (짧게 · 목표 먼저) — `guide_<주제>.md`
- **목표 모습**을 먼저 쓴다 — 기준 그림이 있으면 그 느낌이 목표. 「떼라」는 「없애라」가 아니라 「더 멋지게 살려라」.
- **박자표**: 시각 · 박자 · **강약(강 / 중 / 약)** · 무엇이 보이나. 힘줄 박자는 확실히 세게, 머묾은 은은하게.
- PD 원문을 그대로 옮긴다. 금지 사항은 맨 뒤에 짧게(앞세우면 코덱스가 「최소」로 쏠린다).

### 2-0. 보상의 무게부터 따진다
- 얼마나 자주 보나 · 얼마나 얻기 어렵나 · 등급 어디인가 → 연출 세기를 가이드에 한 줄로 적어 PD 에게 보인다.
- 클리어 보상은 최하 등급도 승인 시안 수준이 바닥.

### 2-1. 등급이 있으면 레벨링 표부터
| 원칙 | 내용 |
|---|---|
| 바닥 | **가장 낮은 등급 = 승인 시안 수준.** 시안보다 낮추지 않는다 |
| 크기 | **모든 등급이 같다.** 위 등급이라고 빛 · 후광 · 빛살을 키우지 않는다 |
| 힘 | 위로 갈수록 **파티클 수를 조금씩 늘리고 이펙트 종류를 한 겹씩 더한다** |
| 색 | 등급색이 구분을 맡는다(더하기로 그리므로 진한 색) |
| 남김 | 최상위만의 겹을 하나 이상 남겨 둔다 |

코드는 등급 → 단계 값 **표 하나**로(흩어진 if 금지). 시안도 등급별로 받아 나란히 비교한다.

## 3. 코덱스 시안 (한 장씩 · 한 줄로)
- **자유 시안**(필수): 「네가 아트 디렉터라면 어떻게 꾸미겠나」 — 힘주는 순간 · 머무는 장면 2컷. 이게 보통 정답이 된다.
- **가이드 시안**(선택): 박자표대로 2컷.
- 발주 요령은 `.claude/rules/project/codex_art_orders.md` (한 장씩 · 실행기 한 줄 · API 키 금지).

## 4. PD 선택
- 비교 시트 한 장(열 = 자유 시안 · 가이드 시안 · 지금 화면, 행 = 힘주는 순간 · 머무는 장면) + 파일 경로.
- **같은 매체끼리 비교한다** — 멈춘 그림 시안과 움직이는 게임 녹화를 한 줄에 섞지 않는다.
- **층별로 고르게 한다** — 「모양(빛살 · 반짝 별 · 화풍)」과 「광원 느낌(번짐 · 블룸 · 입자 움직임)」을 따로 묻는다.
- 내 판단 한 줄을 붙인다. **고른 시안 = 게임 연출의 정답.** 통과 전에는 게임에 넣지 않는다.

## 5. 부품 발주 (고른 시안이 앵커)
- 시안을 크롭해 **앵커로 경로를 박는다**. 「비슷한 것」을 말로 대신하지 않는다.
- 물건 그림은 **빛 없이 깨끗하게**(빛은 이펙트로 따로).
- 이펙트 그림: 머묾 반복 8장 · 힘주는 순간 터짐 6~8장. 빛 · 빛살 · 반짝 별 = **검은 바탕**(가산), 형태 있는 것 = 분홍 바탕 → 뚫기.
- 모양은 도트 그림, **광원 느낌**은 셰이더 번짐(맨 뒤) + 파티클 알갱이(앞)로 겹친다. 층: 셰이더 번짐 → 도트 빛살 → 반짝 별 · 파티클.
- **부품마다 사양 한 덩이를 가이드 「부품 표」에 먼저 적고 발주한다.** 발주문은 이 덩이에서 만들고, 납품 검수는 이 덩이와 맞대어 본다.
  ```
  FX-<주제>-NN  게임 파일 이름
  · 무엇: 한 줄 (브리프 색의 뜻 · 장면 분위기 중 어느 줄이 근거인가)
  · 크기 · 장 수 · 반복(머묾) / 터짐(힘줄 박자) · 바탕(검정 = 빛 / 분홍 = 형태)
  · 앵커: 시안 크롭 경로
  · 금지: (십자 금지 · 외곽선 금지 · 판 금지 …)
  · 상태: 필요 → 발주 → 납품 → 검수 통과 → 반영 / 폐기(방향이 바뀌면 — 다시 받을 것)
  ```
  여러 화면이 같이 쓰는 부품(예고 · 노티)은 새로 만들지 않고 그 번호를 가리킨다.
- **요소마다 무엇으로 만들지 따진다**(그림 / 파티클 / 셰이더 / 섞음) — 한 가지로 몰지 않는다. 회전 · 크기 · 알파 · 색 곱하기로 되는 반복은
  프레임으로 받지 않는다. 그렇다고 「무조건 최소 장 수」도 아니다. 발주 전에 「요소 · 무엇으로 · 이유」 표를 PD 에게 보인다.
- **아이콘**은 `art_resource_format.md` 의 아이콘 규격(정사각 · 2의 거듭제곱 · 구도 비율)을 발주문에 그대로 적는다.

## 6. 게임 반영
- 박자표대로 타이밍 · 강약 · 깊이(물건 뒤 / 앞) · 글자 안 가리기. 등장 곡선은 이징 함수로(숫자 배율을 그대로 박지 않는다).
- **넣자마자 포맷 세팅**(`art_resource_format.md`) → 점검 스크립트 → 보고에 「포맷 세팅 · 점검 통과」 한 줄.
- 갈아 끼운 옛 그림은 아틀라스 폴더에서 뺀다(지우지 않고 PD 확인 뒤 Assets 밖으로).

## 7. 검수 → 보고
- **판정은 첫 줄 하나로** — `판정: 통과 / 우려 / 반려 / 미검`.
  - **미검** = 볼 것이 없어 판단을 못 했다. 통과가 아니다. ① 게임에서 녹화한 **움직이는 GIF** ② 고른 시안과 **같은 크기로 나란히** 놓은
    비교 시트 — 둘 중 하나라도 없으면 미검이다. 정지 스샷만 있으면 미검이다. 조건이 안 맞아 효과가 아예 안 났으면 그것도 미검이다.
  - 미검이면 「됐다」고 하지 않는다 — 무엇이 없어서인지 · 언제 채울지 적는다. 우려 · 반려면 부품 번호와 「시안과 다른 점」을 같이.
- **고른 시안 수준이 최소 기준이다** — 시안보다 약하거나 다르면 보고하지 않고 더 맞춘다.
- 움직임도 본다: 크기가 튈 때 피벗이 엉뚱하면 물건이 툭툭 밀린다 — 바닥에 놓이는 것은 바닥 가운데 기준.
- 넣기 전 · 후 한 번씩 코덱스 의견(검수 1회). 같은 주제 여러 회차 핑퐁 금지.
- PD 보고: GIF + 비교 시트 + 파일 경로 + 내가 보기에 아직 다른 점.

## 방향이 바뀌면 리소스도 새로
- 브리프 · 시안 · PD 방향이 바뀌면 **그 전 방향으로 받은 리소스는 새로 발주한다.** 밝기 깎기 · 크기 줄이기 · 알파 낮추기로 살리지 않는다.
- 새로 받을 때는 시안부터(3단계).

## 하지 말 것
- 그림 목표 없이 숫자(알파 · 크기 · 간격)부터 만지기
- Claude 가 셰이더 · 도형으로 시안 대신 그리기
- 상의서에 금지만 나열하기
- 물건 밑에 단색 실루엣 판(그림자처럼 보임)
