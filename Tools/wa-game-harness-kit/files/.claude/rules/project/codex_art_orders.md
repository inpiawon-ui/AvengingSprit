# 코덱스(GPT 이미지)로 그림 발주하기

> 그림 리소스는 Claude 가 그리지 않는다 — 코덱스 CLI 로 발주하고, Claude 는 브리프 · 발주문 · 받은 것 검수 · 규격 맞춤 · 게임 반영을 한다.
> 출처: AVSR 2026-09 ~ 10 실측. L2 `Docs/game/image_pipeline.md` 의 한계표와 다른 곳은 **이 문서(실측)가 이긴다.**

## 1. 부르는 법
```
$env:OPENAI_API_KEY = $null      # ChatGPT 로그인으로만 — API 키 금지
codex exec --sandbox workspace-write --skip-git-repo-check "<발주문>"
```
- 발주문 첫 줄: 「이미지 생성 도구로 직접 그린다. **API 키를 쓰는 CLI 폴백은 쓰지 마라.** 스크립트로 도형을 그려 때우지 마라. 한 장만 그린다.」
  — 이 줄이 없으면 스킬 문서만 뱉고 아무것도 안 만들고 끝난다.
- 참조 그림은 `-i` 로 붙이지 않는다(윈도우 샌드박스가 읽기를 막는다). **작업 공간 안 경로**로 적는다.
- 브리프가 있으면 「먼저 이 브리프를 읽는다」 + 경로.

## 2. 한 장씩 · 한 줄로
- **한 발주문에 한 장.** 여러 장을 한 번에 시키면 스크립트로 때운다(일곱 장 전부 원본 줄 복사로 돌아온 적이 있다). 한 장씩이면 제대로 그린다.
- **실행기는 한 줄로만** — `Tools/harness/run_codex_orders.ps1 -Sheets a,b,c`. 두 줄을 동시에 돌리면 겹치는 순간 **429**가 난다.
  - 429 는 사용량 한도가 아니라 「짧은 시간 요청 몰림」 속도 제한이다(PD 에게도 그렇게 설명한다). 실행기는 5번 · 2분 간격으로 다시 시도한다.
- 애니메이션 프레임은 **한 장에 같이** 그리게 한다(따로 부르면 호출마다 다른 캐릭터가 나온다) — 받아서 자른다.
- 샘플 하나를 먼저 통과시키고 나머지를 한 번에 돌린다.

## 3. 받은 그림의 함정 (실측)
- **배경은 안 뚫려 온다.** 분홍(#FF00FF) 바탕으로 시키고 Claude 가 뚫는다(반영 도구는 알파 처리를 안 한다). 가장자리 분홍 찌꺼기를 잰다.
- **크기는 안 지킨다**(128 을 시키면 1254 가 온다). 규격(캔버스 · 여백 · 가운데 · 축소)은 Claude 가 후처리한다.
- **「못 그렸다」여도 그림은 남아 있을 수 있다.** 이미지 도구가 투명 바탕으로 그려 오면 코덱스가 「바탕이 다르다」며 저장본을 지운다 —
  원본은 `%USERPROFILE%\.codex\generated_images\<세션>\exec-*.png` 에 남는다. 발주문에 「투명 바탕으로 나오면 그대로 저장」을 넣는다.
- **「이어 그려라」 · 「늘려라」는 원본 줄 복사로 때운다.** 검수에 원본 줄 대조(새 줄 비율 · 같은 줄 반복)를 넣는다.
- **구도를 안 정하면 옆으로 긴 장면이 온다.** 아이콘은 `art_resource_format.md` 2-1 규격(구도 비율)을 발주문에 숫자로 적는다.
- 색 · 디자인은 코덱스에 맡긴다 — hex · 팔레트를 적지 않는다. 단 **뜻이 있는 색**(브리프 색의 뜻 표)은 적는다.

## 4. 받으면 바로 검수
- 스크립트로 때웠는지 · 지시(금지 사항)를 어겼는지 · 시안과 화풍이 같은지 · 규격(비율 · 분홍 찌꺼기)을 잰다(`python Tools/harness/icon_tool.py review`).
- 뜻이 안 읽히면 「무엇이 안 읽히는지」를 발주문에 적어 `_v2` 로 다시 받는다(원본은 남긴다).
- 넣은 뒤에는 **실제 게임 칸 크기**에서 다시 본다 — 큰 시트에서 멀쩡해도 작은 칸에서 눌리거나 안 읽힌다.
