# 리소스 포맷 규칙

> 출처: AVSR 2026-10-09 PD 「포맷이 제대로 안 되어 있으면, 생성하고 나서 포맷을 세팅하는 걸 기본으로」.
> 점검해 보니 아틀라스 57개가 전부 압축 없음(RGBA32)이었다 — 인게임 아틀라스 하나가 약 272MB, ASTC 4x4 로 약 32MB.
> ⚠ L2 의 Unity 스킬 `2d-pixel-perfect` 는 「압축 없음」이 기본이다. **이 문서가 이긴다**(모바일 메모리 실측 근거).

## 1. 만들거나 받으면 그 자리에서 포맷까지 한다
1. 리소스를 만든다 · 받는다 · 반영 도구로 넣는다
2. 아래 표대로 **임포트 설정**(아틀라스에 넣는 그림이면 아틀라스 설정까지)
3. 점검 — `python Tools/harness/resource_audit.py` · 새로 넣은 파일에 경고가 없어야 한다
4. 그 뒤에 커밋 · 보고. 보고에 「포맷 세팅 · 점검 통과」 한 줄

## 2. 기본 세팅 (안드로이드 기준)
| 종류 | 세팅 |
|---|---|
| 도트 그림(아틀라스에 묶임) | Sprite · **Point** · 밉맵 끔 · Read/Write 끔. 압축은 원본이 아니라 아틀라스에서 |
| 일러스트 그림(아틀라스에 묶임) | Sprite · Bilinear · 밉맵 끔 · Read/Write 끔 |
| 아틀라스 | **안드로이드 Override · ASTC 4x4** · 최대 2048 · 밉맵 끔 · Read/Write 끔 · 도트는 Point · 여백 4 |
| 아틀라스 밖 큰 그림 | 안드로이드 ASTC 4x4 · 최대 크기 ≥ 원본 긴 변 · 밉맵 끔 · Read/Write 끔 |
| 예외 — 읽어야 하는 그림 | (코드가 픽셀을 읽는 것) Read/Write 켬 · 압축 없음 — 이유를 적는다 |
| BGM | Vorbis · Compressed In Memory · 품질 0.7 |
| 효과음 | ADPCM · Decompress On Load · 짧은 것은 Mono |
| 폰트 | 동적 SDF · `Clear Dynamic Data On Build` 켬 |

- **압축 없음(RGBA32)은 쓰지 않는다.** 꼭 필요하면 이유를 적고 PD 에게 보인다.
- ASTC 6x6 은 도트의 잔 점이 뭉개진다 — 쓰지 않는다. 압축 형식을 처음 바꾸는 종류는 전 · 후를 같은 크기로 나란히 PD 에게 한 번 보인다.
- 최대 크기가 원본보다 작으면 그림이 줄어 흐려진다 — 원본 긴 변 이상으로.

## 2-1. 아이콘 규격 — 정사각 · 2의 거듭제곱 (AVSR 2026-10-22)
> 「정사각 · 90% 채움」으로만 발주했더니 「유령 → 탄 → 적」 옆으로 긴 장면이 와 칸 높이의 59% 만 채웠고, 작은 칸에서 눌리거나 잘렸다.

| | 규격 |
|---|---|
| 게임 파일 | **정사각 2의 거듭제곱** — 가장 큰 표시 칸보다 크면서 가장 작은 것(예: 칸 104 → **128**). 여러 칸이 **같은 그림을 줄여 쓴다. 자르지 않는다** |
| 발주 원본 | 게임 파일의 **2배**(예: 256) · 분홍 바탕 |
| 구도 | 그림 덩어리 가로 : 세로 = **1.0 ~ 1.3**(긴 변은 맞춤 도구가 칸의 94% 로 맞춘다). 효과 · 대상을 가운데 크게. 옆으로 늘어놓는 구도 금지 |
| 검수 | `python Tools/harness/icon_tool.py review` 가 비율 1.3 초과를 빨갛게 띄운다 — 걸리면 다시 받는다 |

## 3. 이름으로 꺼내는 것은 빌드에 넣는다
- 코드가 이름으로 찾는 것(`Shader.Find` · 주소 · 아틀라스 이름)은 재질 · 어드레서블 · 「항상 포함 셰이더」 중 하나로 빌드에 걸려 있어야 한다.
  에디터에서는 돌아도 휴대폰 빌드에서는 없다.

## 4. 안 쓰게 된 리소스
- 새 그림으로 갈아 끼웠으면 옛 그림은 아틀라스 폴더에서 뺀다(안 써도 아틀라스 메모리를 먹는다).
- 지우지 않는다. PD 확인 뒤 Assets 밖(예: `Projects/<ProjCode>/_archive/`)으로 옮긴다(.meta 같이).
- 원본 · 작업용(`*_full` · `*_v3` · 발주 원본 · 스크린샷)은 `Assets/` 에 두지 않는다 — 교환 폴더에 둔다.
