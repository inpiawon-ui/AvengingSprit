# Unity Open and Implement Guide

권장 기준: Unity 2022.3 LTS 또는 개발팀 표준 LTS, URP 2D, New Input System, 2D Physics, NavMeshPlus 또는 검증된 Grid Path 중 프로젝트 표준 선택. 모바일 Android/iOS 세로 9:16.

개발 순서: 프로젝트 설정 → Runtime JSON → Registry → Core Runtime → Placeholder → CH1_N01 → Importer/Generator → Nav/Collider → Smoke Test → CH01~03.

프로젝트가 다른 Unity LTS/Navigation을 사용하면 기술 선택만 대체하고 Data Contract와 게임 규칙은 변경하지 않는다.
