# 리소스 포맷 규칙

> PD 결정 2026-10-09 「포맷이 제대로 안 되어 있으면, 생성하고 나서 포맷을 세팅하는 걸 기본으로 해야 된다」.
> 점검해 보니 아틀라스 57개가 전부 **압축 없음(RGBA32)** 이었다 — 인게임 아틀라스 하나만 그림 면적으로 약 146MB.
> 점검 결과: `Projects/AVSR/_exchange/ref/resource_audit/report.md`

## 1. 만들거나 받으면 그 자리에서 포맷까지 한다

리소스 작업은 **「파일이 들어왔다」가 끝이 아니다. 포맷을 세팅하고 점검을 통과해야 끝이다.**

1. 리소스를 만든다 · 받는다 · 반영 툴로 넣는다
2. 아래 표대로 **임포트 설정을 세팅한다**(아틀라스에 넣는 그림이면 아틀라스 설정까지)
3. 점검을 돌린다 — 새로 넣은 파일에 경고가 없어야 한다
   ```
   python Projects/AVSR/Tools/resource_audit.py
   ```
   → `Projects/AVSR/_exchange/ref/resource_audit/format.tsv` · `unused.tsv`
4. 그 뒤에 커밋 · 보고한다. 보고에 「포맷 세팅 · 점검 통과」를 한 줄 적는다

## 2. 기본 세팅 표 (안드로이드가 기준 — 프로젝트 기본 압축은 ASTC)

| 종류 | 어디 | 세팅 |
|---|---|---|
| **도트 그림(아틀라스에 묶임)** | `BaseResource/Unit · InGameMainUI · PopupFx · Card` 등 | Sprite · **Point** · 밉맵 끔 · Read/Write 끔. 압축은 원본이 아니라 **아틀라스**에서 정한다 |
| **일러스트 그림(아틀라스에 묶임)** | 로비 · 타이틀 · 로딩 · 육성 | Sprite · Bilinear · 밉맵 끔 · Read/Write 끔 |
| **아틀라스** | `BundleResource/Atlas/*.spriteatlasv2` | **안드로이드 따로 세팅(Override)** · **ASTC 4x4**(도트 · 일러스트 모두) · 최대 2048 · 밉맵 끔 · Read/Write 끔 · 도트는 Point · 여백 4 |
| **아틀라스 밖 큰 그림** | 방 바닥 · 배경 · 화면 한 장 그림 | 안드로이드 **ASTC 4x4** · 최대 크기 ≥ 원본 긴 변 · 밉맵 끔 · Read/Write 끔 |
| 예외 — 읽어야 하는 그림 | 컷신(색 빼기 `GetPixels32`) | Read/Write **켬** · 압축 없음 유지 — 압축하면 색 빼기가 안 될 수 있다 |
| **BGM** | `Sounds/BGM` | Vorbis · Compressed In Memory · 품질 0.7 |
| **효과음** | `Sounds/SFX` | ADPCM · Decompress On Load · 짧은 것은 Mono |
| **폰트** | `BaseResource/Fonts` | 동적 SDF · `Clear Dynamic Data On Build` 켬 |

- **압축 없음(RGBA32)은 쓰지 않는다.** 꼭 필요하면(압축 무늬가 눈에 띄는 작은 그림) 이유를 적고 PD 에게 보인다.
- **ASTC 4x4 로 정했다**(PD 2026-10-12 — 인게임 아틀라스 비교 `_exchange/ref/resource_audit/compress/compare_ingamemainui.png`: 원본과 구별 안 됨, 272MB → 약 32MB. 6x6 은 잔 점이 뭉개져 안 쓴다).
- 압축 형식을 처음 바꾸는 종류는 **바꾸기 전 · 후를 같은 크기로 나란히** 찍어 PD 에게 한 번 보인다(도트가 뭉개지는지).
  통과한 뒤로는 그 종류의 기본값이 된다.
- 최대 크기가 원본보다 작으면 그림이 **줄어 흐려진다** — 원본 긴 변 이상으로 둔다.

## 2-1. 아이콘 규격 — 정사각 · 2의 거듭제곱 (PD 2026-10-22)

> 카드 아이콘을 「320 정사각 · 90% 채움」으로만 발주했더니 코덱스가 「유령 → 탄 → 적」 옆으로 긴 장면을 그려 왔다.
> 새 카드 23장이 칸 높이의 평균 59% 만 채웠고(예전 카드 90%), 상점 칸(72 px)에서는 가늘게 눌리거나 잘렸다.

| | 규격 |
|---|---|
| **게임 파일** | **128 × 128** 정사각 한 장 — 레벨업 카드 칸(104) · 상점 칸(62) · 제단 칸이 **같은 그림을 줄여 쓴다. 자르지 않는다** |
| **발주 원본** | **256 × 256**(게임 파일의 2배) · 분홍 바탕 |
| **구도** | 그림 덩어리의 가로 : 세로 = **1.0 ~ 1.3**(긴 변은 맞춤 도구가 칸의 94% 로 맞춘다). 효과 · 대상을 가운데 크게. 옆으로 늘어놓는 「유령 → 탄 → 적」 금지 — 유령은 구석에 작게 곁들이거나 뺀다 |
| **검수** | `Projects/AVSR/Tools/icon_review_sheet.py` 가 가로세로비 1.3 초과를 빨갛게 띄운다 — 걸리면 다시 받는다 |

- 왜 128: 2의 거듭제곱 중 가장 큰 칸(104)보다 크면서 가장 작다. 160 은 거듭제곱이 아니고, 256 은 칸의 2.5배라 아틀라스만 4배로 먹는다.
- 화면 UI(상점 · 악마 · 천사 칸)가 가로형인 것은 나중에 UI 를 다시 설계할 때 고친다 — 아이콘은 그와 상관없이 정사각으로 받는다.

## 3. 이름으로 꺼내는 것은 빌드에 넣는다

- 코드가 **이름으로 찾는 것**(`Shader.Find` · 주소 · 아틀라스 이름)은 재질 · 어드레서블 · 「항상 포함 셰이더」 중 하나로 빌드에 걸려 있어야 한다.
  에디터에서는 돌아도 휴대폰 빌드에서는 없다.
  > 2026-10-09 점검: `UI/Gray`(쓰러진 몸 잿빛) · `UI/Silhouette` 가 어디에도 안 걸려 있었다.

## 4. 안 쓰게 된 리소스

- 새 그림으로 갈아 끼웠으면 **옛 그림은 아틀라스 폴더에서 뺀다** — 아틀라스 폴더에 남으면 안 써도 아틀라스 메모리를 먹는다.
- 지우지 않는다. PD 확인 뒤 `Projects/AVSR/_archive/` 같은 Assets 밖으로 옮긴다(.meta 같이).
- 원본 · 작업용(`*_full` · `*_v3` · 스크린샷)은 `Assets/` 에 두지 않는다 — `Projects/AVSR/_exchange/` 에 둔다.

## 5. 하지 말 것

- 파일만 넣고 포맷은 기본값 그대로 두기
- 도트 아틀라스를 압축 없이 4096 으로 두기
- 점검 경고를 보고 「나중에」로 미루기 — 그 자리에서 세팅하거나, 못 하면 이유를 보고에 적는다
