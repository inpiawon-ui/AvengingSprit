# UI 규칙

## UI 타입 및 네이밍 규칙

### UI 프리팹 접미사

| 접미사 | 역할 | 수량 | 예시 |
|--------|------|------|------|
| `~UI` | 씬 시작 시 기본으로 깔리는 베이스 UI | 씬당 1개 | `LobbyMainUI`, `TitleMainUI`, `InGameMainUI` |
| `~Panel` | 버튼 클릭 등으로 여는 주요 콘텐츠 창 | 제한 없음 | `CharacterSelectPanel`, `PetSelectPanel` |
| `~Popup` | Panel 위에 추가로 뜨는 부가 창 | 제한 없음 | `CharacterDetailPopup` |
| `SystemPopup` | 코드로 생성하는 최상위 단발성 알림 | 1개 (클래스 고정) | `SystemPopup` |

- 위 4가지 외의 접미사 사용 금지.
- `~UI`는 씬당 1개만 존재한다.

> 수치 값(기준 해상도, `~Panel`/`~Popup` 높이, `SystemPopup` sortingOrder)은
> [`.claude/project/constants.md`](../../project/constants.md) 3절을 단일 출처로 한다.
> 본 문서의 `sortingOrder 999` 등은 설명용 표기이며 실제 값은 constants.md를 따른다.

## UI 레이어 및 팝업 처리 규칙

### 렌더링 순서
- `~Panel` 또는 `~Popup` 활성화 시 `SetAsLastSibling()`을 호출하여 렌더링 최상단으로 올린다.
- `SystemPopup`은 독립 Canvas (sortingOrder 999)를 사용하므로 항상 모든 UI 위에 표시된다.

### Popup 열기 방식
- **기본**: 기존 Popup을 유지한 채 새 Popup을 위에 추가로 열기.
- **선택적**: 기존 Popup을 모두 닫고 새 Popup 열기 (`closeOthers: true` 명시).

```csharp
// 기본 — 기존 Popup 유지, 위에 추가
panel.OpenPopupAsync<CharacterDetailPopup>();

// 기존 Popup 닫고 새로 열기
panel.OpenPopupAsync<CharacterDetailPopup>(closeOthers: true);
```

### Popup 닫기 방식
- `~Popup`은 닫을 때 **Destroy하지 않고 `SetActive(false)`** 로 비활성화한다.
- 재오픈 시 `SetActive(true)`로 이전 상태를 유지한 채 다시 표시한다.

### 뒤로가기(Back Button) 처리 우선순위

**구현**: `Assets/Scripts/Module/Common/UI/BackButtonRouter.cs` + `IBackTarget`
`~UI` 가 `IBackTarget` 을 구현하고 Awake 에서 `gameObject.AddComponent<BackButtonRouter>()` 한다.
라우터가 ESC(안드로이드 백 포함)를 받아 1·4순위를 직접 처리하고, 2·3순위는 `IBackTarget.OnBackPressed()` 에 위임한다.
`OnBackPressed()` 가 `false` 를 반환하면 라우터가 종료 확인 `SystemPopup` 을 띄운다.

아래 순서대로 확인하여 가장 높은 우선순위 항목을 닫는다.

1. **SystemPopup** 열려있음 → SystemPopup 닫기
2. **Popup** 열려있음 → `PopupParent` 내 최상단 Popup 닫기 (`SetActive(false)`)
3. **Panel** 열려있음 → Panel 닫기 (`SetActive(false)`)
4. **MainUI만 있는 상태** → 게임 종료 SystemPopup 표시
5. **게임 종료 SystemPopup 표시 중 뒤로가기** → SystemPopup 닫기 (1번 규칙 적용, 토글 반복 가능)

1·4순위는 라우터가 공통 처리하므로 `~UI` 는 2·3순위만 구현한다.
처리했으면 `true`, 넘길 것이 없으면 `false` 를 반환한다.

```csharp
// LobbyMainUI — 로비에서 열리는 것은 호스트 선택 패널뿐이다
public bool OnBackPressed()
{
    if (_hostSelectPanel != null && _hostSelectPanel.IsOpen)
    {
        _hostSelectPanel.Close();
        return true;
    }
    return false;   // 라우터가 종료 확인 SystemPopup 을 띄운다
}

// TitleMainUI — 되돌아갈 화면이 없다
public bool OnBackPressed() => false;
```

`SystemPopup` 은 프리팹이 아니라 **코드로 생성**한다(`SystemPopup.Show/Close/IsShowing`).
씬·패널 로드 상태와 무관하게 어디서든 즉시 떠야 하므로 의도된 예외다.
