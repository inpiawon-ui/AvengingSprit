# 서버 코딩 규칙

서버 백엔드와 클라-서버 공용 코드에 적용되는 규칙이다.
서버팀(`wa-server-team-*`)과 `server-rule-compliance-reviewer`가 기준 문서로 참조한다.

> **스택 미확정**: 현재 서버 기술 스택은 미정이다. 본 문서는 스택 무관 규약(경로·레이어·계약·보안)만 명시하며,
> 언어별 상세 규약(네이밍·포맷·테스트 프레임워크 등)은 **스택 확정 시 보강(TBD)** 한다.

---

## 1. 코드 영역 구분 (3-영역)

서버 관련 코드는 3개 영역으로 분리한다.

| 영역 | 위치 | 책임 | 수정 권한 |
|------|------|------|-----------|
| **서버 백엔드 본체** | 별도 경로(미정, 스택 확정 후 지정) | 실제 서버 애플리케이션 코드 | 서버팀 |
| **클라-서버 공용 (범용)** | `Assets/GameFramework/Game/Module/Server/` | 게임 무관 범용 API·URL 클라이언트 | **프레임워크 오너만** (`protect_framework.ps1` 차단) |
| **클라-서버 공용 (프로젝트 전용)** | `Assets/Scripts/Module/Server/` | 범용 레이어를 참조하는 프로젝트 전용 서버 통신 | Claude 자유 작업 (클라팀 game) |

### 핵심 제약
- 서버팀은 `Assets/GameFramework/` 에 **직접 쓰지 않는다** (`protect_framework.ps1`이 전체 차단).
- 서버팀은 API 계약·URL·스키마·인증 흐름을 정의(`SRV_Design.md`)하고, 클라 측 구현은 클라팀에 핸드오프한다.
- 클라 측 범용 레이어(`GameFramework/Game/Module/Server`)는 클라팀 framework 에이전트(프레임워크 오너)가 계약 기반으로 구현한다.
- 클라 측 프로젝트 레이어(`Scripts/Module/Server`)는 범용 레이어를 참조하여 프로젝트 전용 호출·이벤트 발행을 구현한다.

---

## 2. 클라 측 폴더 역할

### `Assets/GameFramework/Game/Module/Server/` (범용)
- 어떤 게임에서도 재사용 가능한 **범용 API·URL 클라이언트**.
- 게임 내 범용적인 엔드포인트·기본 URL·공통 요청/응답 처리를 포함한다.
- 네임스페이스: `GameFramework.Game.Module.Server`
- 프레임워크 오너만 수정.

### `Assets/Scripts/Module/Server/` (프로젝트 전용)
- 위 범용 레이어를 **참조**하여 이 프로젝트에서만 쓰는 서버 통신을 작성한다.
- 프로젝트 고유 엔드포인트 호출, 응답 → IEvent 발행 흐름.
- 네임스페이스: `Game.Module.Server` (프로젝트 코드 네임스페이스 규칙 준수 — `Assets/Scripts/`는 `Game.*`)

---

## 3. 공용 계약(DTO) 레이어

클라-서버가 C#으로 DTO를 공유하는 경우:
- 계약 DTO 네임스페이스는 `Server.*` 를 사용한다 (백엔드도 C#일 때 양측 공유 가능).
- 계약 DTO는 `SRV_Design.md`의 스키마와 일치해야 한다 (계약 드리프트 금지).
- 공용 C# 코드의 네이밍·접근 제한자는 `.claude/rules/coding_conventions.md`를 따른다.

---

## 4. 보안 규약 (스택 무관·필수)

글로벌 `CLAUDE.md`의 Security Guidelines를 서버에 그대로 적용한다.

- **시크릿 외부화**: API 키·비밀번호·토큰·서명 키를 코드/이미지/로그에 하드코딩 금지. 환경변수/시크릿 매니저 사용.
- **서버 권위**: 재화·점수·인벤토리 등은 클라 입력을 신뢰하지 않고 서버에서 재계산·검증한다.
- **입력 검증**: 모든 외부 입력은 경계에서 검증한다 (인젝션·역직렬화 방어).
- **인증/인가**: 보호 엔드포인트는 토큰 검증·권한 체크를 거친다.
- **에러 정보 누출 금지**: 스택 트레이스·내부 경로를 응답에 노출하지 않는다.
- **레이트 리밋**: 남용 가능 엔드포인트에 적용한다.

---

## 5. 산출물·계약 문서

- 모든 서버 계약은 `Projects/[ProjCode]/[ProjCode]_SRV_Design.md`에 기록한다 (섹션 ID: SRV-API/AUTH/DATA/RT/INFRA/SEC).
- 인프라 값(백엔드 경로·배포 타겟·환경 URL)은 `.claude/project/environment.md` 서버 인프라 섹션에 기록한다.
- 게임 고유 서버 값(프로토콜 버전·게임별 엔드포인트)은 `.claude/project/constants.md` 서버 API 섹션에 기록한다.
