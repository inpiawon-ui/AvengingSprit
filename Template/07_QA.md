## QA-PLN-001: 테스트 계획

> 📌 **DoD(Definition of Done)**: 작업 완료 판정 기준. → 참조: 08_ProjectManagement.md

### 테스트 레벨 및 단계

| 레벨 | 책임자 | 시점 | 도구 |
|------|--------|------|------|
| Unit Test | 개발자 | 코드 커밋 시 자동 | Unity Test Framework |
| Integration Test | QA + 개발자 | 일일 빌드 | 자동 + 수동 |
| System Test | QA | 주간 빌드 | 수동 |
| Regression Test | QA | 버그 수정 후 | 수동 + 자동 |
| Performance Test | QA + CL | 마일스톤 빌드 | Unity Profiler, 기기 |
| Acceptance Test | PM + QA + PD | 마일스톤 | 수동 |

> 📌 **Regression Test(회귀 테스트)**: 버그 수정 후 기존 기능이 정상 동작하는지 재확인하는 테스트.
> 📌 **Smoke Test(스모크 테스트)**: 빌드 수령 직후 핵심 기능만 빠르게 검증하는 기초 테스트.

### 테스트 환경

| 환경 유형 | 용도 | 서버 환경 |
|---------|------|---------|
| Dev | 개발 중 개발자 자체 테스트 | Dev 서버 |
| Staging | QA 공식 테스트 | Staging 서버 |
| Production (Canary) | RC 빌드 최종 검증 | Production 일부 트래픽 |

### 테스트 디바이스 목록

|------|--------|-----|------|------|

| 중사양 iOS | iPhone 13 | iOS 16 | A15 | 목표 사양 기준 |
| 저사양 iOS | iPhone XR | iOS 15 | A12 | 최소 사양 기준 |

## QA-CAS-001: 테스트 케이스

### TC 작성 양식

파일명: `QA-TC-[콘텐츠ID]-[기능명].md` 또는 스프레드시트 관리

```markdown
## TC-[파트코드]-[번호]: [제목]

**TC ID**: TC-[파트]-[번호]
**테스트 대상**: [기능 / 시스템명]
**우선순위**: P0 (Critical) / P1 (High) / P2 (Medium) / P3 (Low)
**담당 파트**: [클라 / 서버 / 기획 등]

### 선행 조건
- [테스트 전 필요한 상태]
- [예: 레벨 10 캐릭터, 에너지 5 이상, 네트워크 정상 상태]

### 테스트 단계
1. [액션 1]
2. [액션 2]
3. [액션 3]

### 기대 결과
- [정상 동작 시 발생해야 하는 결과를 구체적으로 기술]

### 실제 결과
- [테스터 작성 공간]

### 판정
- [ ] Pass  [ ] Fail  [ ] Block  [ ] Skip

### 관련 버그 ID
- [BUG ID 목록 (Fail인 경우)]
```

### TC 우선순위 기준

| 우선순위 | 기준 |
|---------|------|
| **P0 (Critical)** | 핵심 게임 루프, 결제, 로그인 등 게임 진행 필수 기능 |
| **P1 (High)** | 주요 콘텐츠, 성장 시스템, 주요 UI |
| **P2 (Medium)** | 부가 기능, 시각적 피드백, 알림 |
| **P3 (Low)** | 텍스트 오탈자, 아이콘 위치 미세 조정 등 |

## QA-ACC-001: 접근성 검증

> ART-UI-001의 접근성 기준(WCAG 2.1 AA)을 QA 단계에서 검증한다.
> → 참조: 03_Art.md ART-UI-001 접근성 최소 기준 표

### 접근성 검증 체크리스트 (출시 전 전수 확인)

- [ ] **터치 타겟**: 모든 인터랙티브 요소가 44×44pt 이상인지 실기기에서 측정
- [ ] **색상 대비**: 텍스트와 배경 대비율 4.5:1 이상 — Colour Contrast Analyser 또는 Unity 접근성 도구로 확인
- [ ] **색맹 시뮬레이션**: 적록색맹(Deuteranopia) 모드에서 핵심 정보(HP 바, 미니맵 아이콘 등)가 아이콘/모양으로도 구분 가능한지 확인
- [ ] **폰트 크기**: 본문 14pt 이상, 중요 UI(버튼·제목) 16pt 이상
- [ ] **자막**: 핵심 VO가 있는 경우 자막 표시 정확성 확인
- [ ] **텍스트 크기 조절**: 지원 여부에 따라 최대 배율에서 UI 깨짐 없는지 확인

## QA-BUG-001: 버그 프로세스

### 버그 리포트 양식

```markdown
## BUG ID: BUG_[날짜]_[번호]

**요약**: [한 문장으로 버그 내용 설명]
**심각도**: Critical / High / Medium / Low
**재현 빈도**: 항상(100%) / 자주(70%) / 가끔(30%) / 드물게(10%)

### 재현 단계
1. [재현 방법 1]
2. [재현 방법 2]
3. [재현 방법 3]

### 기대 동작
- [정상 동작 설명]

### 실제 동작
- [오류 동작 설명]

### 환경
- 기기: [모델명]
- OS: [버전]
- 게임 버전: [버전]
- 계정: [테스트 계정 ID]
- 서버 환경: [Dev / Staging / Production]

### 첨부
- 스크린샷: [링크]
- 영상: [링크]
- 로그: [링크]

### 발견자 / 날짜
- [이름] / [날짜]

### 담당자
- [담당 개발자 또는 파트]
```

### 버그 심각도 기준 및 대응

| 심각도 | 정의 | 해결 목표 | 예시 |
|--------|------|---------|------|
| **Critical** | 게임 진행 불가, 크래시, 데이터 소실, 결제 오류 | 24시간 이내 | 전투 중 강제 종료, 결제 후 아이템 미지급 |
| **High** | 주요 기능 동작 불가 (우회 불가) | 3 영업일 이내 | 보상 미지급, 로그인 오류 |
| **Medium** | 기능 일부 오동작 (우회 가능) | 1주 이내 | UI 텍스트 오표시, 이펙트 미재생 |
| **Low** | 외관, 오타, 미미한 UI 오류 | 다음 마일스톤 | 아이콘 위치 미세 오류, 오탈자 |

### 버그 상태 흐름

```
[등록(Open)] → [담당자 확인(Assigned)] → [수정 중(In Progress)]
    → [수정 완료(Fixed)] → [QA 검증(In Verification)]
    → [완료(Closed)] 또는 [재오픈(Reopened)]
```

## QA-PER-001: 성능 테스트

### 성능 테스트 시나리오

| 시나리오 | 방법 | 측정 항목 | 기준 |
|---------|------|---------|------|
| 메인 로비 | 10분 체류 | FPS, 메모리 | 안정 60fps, 메모리 증가 ≤10MB |
| 전투 (일반) | 5분 연속 전투 | FPS, DrawCall, CPU | 목표 FPS 유지 |
| 전투 (보스) | 보스 전투 3회 | FPS, GPU 온도 | FPS 드롭 ≤5프레임 |
| 연속 씬 전환 | 로비↔전투 10회 | 메모리 누수 | 누적 메모리 증가 ≤50MB |
| 장시간 플레이 | 60분 연속 | 메모리, 배터리 | 메모리 증가 ≤100MB |
| 동접 부하 | 목표 DAU × 1.5 | 서버 응답 시간, TPS | P95 ≤300ms |

### 성능 테스트 도구

| 도구 | 용도 |
|------|------|
| Unity Profiler | CPU / GPU / 메모리 분석 |
| Memory Profiler | 메모리 누수 탐지 |
| Frame Debugger | DrawCall 분석 |
| Xcode Instruments | iOS 기기 성능 분석 |
| Android Profiler | Android 기기 성능 분석 |
| Apache JMeter | 서버 부하 테스트 |

| 장르 / 특성 | QA 추가 고려 항목 |

| 가챠/결제 | 드롭률 정확성 검증 TC(통계적 유의성 검증, 1만 회 샘플), 결제 실패/재시도/중복 결제 시나리오 P0 TC 필수 추가 |
| 오프라인 전용 | 서버 관련 TC 전부 생략. 오프라인 저장·로드 무결성 TC, 앱 강제 종료 후 데이터 보존 TC, 용량 초과 TC 추가 |
| 글로벌 출시 | 각국 등급 심의(GRAC KR/ESRB US/PEGI EU/CERO JP) 기준 검수 TC 추가. 언어별 텍스트 오버플로 TC(독일어 +30%, 중국어 줄바꿈) |
