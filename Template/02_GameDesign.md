## GD-COR-001: 코어 루프

### 코어 루프 정의

**Core Loop(코어 루프)**: 플레이어가 게임 내에서 반복적으로 수행하는 가장 기본적인 행동 사이클.
모든 콘텐츠와 시스템은 이 루프를 강화하거나 확장하는 방향으로 설계되어야 합니다.

```
[목표 제시] → [행동 수행] → [보상 획득] → [성장/투자] → [새로운 목표]
     ↑                                                         ↓
     └─────────────────────────────────────────────────────────┘
```

### 본 프로젝트의 코어 루프

| 단계 | 플레이어 행동 | 시스템 반응 | 목표 소요 시간 |
|------|-------------|-----------|--------------|
| 1 | `[예: 스테이지 선택]` | `[UI 전환, 정보 제공]` | `[N초]` |
| 2 | `[예: 전투 수행]` | `[적 AI 반응, 전투 처리]` | `[N분]` |
| 3 | `[예: 보상 획득]` | `[드롭 연출, 인벤토리 갱신]` | `[N초]` |
| 4 | `[예: 장비 강화]` | `[성장 피드백, 능력치 상승]` | `[N초]` |

- **1회 루프 타겟 시간**: `[N분]` [근거: 모바일 세션 평균 8~12분, Newzoo 2024]
- **세션당 평균 루프 횟수**: `[N회]` [근거: `[데이터 출처]`]

### 메타 루프 (Meta Loop)

**Meta Loop(메타 루프)**: 코어 루프를 여러 번 반복했을 때 달성하는 중·장기 목표 사이클. 장기 리텐션의 핵심.

| 메타 요소 | 진입 조건 | 주기 | 리텐션 효과 |
|----------|----------|------|-----------|
| `[예: 길드 시스템]` | `[레벨 N 달성]` | `[주간]` | `[근거: 길드 가입 유저 D30 리텐션 2.3배]` |
| `[예: 시즌 패스]` | `[무조건 진입]` | `[월간/시즌]` | `[구매 유저 이탈률 40% 감소]` |
| `[예: 컬렉션/도감]` | `[무조건 진입]` | `[상시]` | `[수집욕 동기 부여]` |

> [WARNING] 메타 루프 보상 강도가 코어 루프 동기를 압도할 경우 코어 루프 이탈 발생. 보상 비율 밸런스 시뮬레이션 필수.

- **급격한 난이도 상승 금지**: 2~3 스테이지 연속 실패 시 이탈률 `[N%]` 증가 [근거: 내부 테스트 T-`[날짜]`]

## GD-ECO-001: 경제 / 밸런스

> 📌 **TTK(Time To Kill)**: 대상을 처치하는 데 걸리는 시간. 전투 밸런스의 핵심 지표.

### 재화 체계

| 재화 | 분류 | 획득 경로 | 사용처 | 인플레이션 방지책 |
|------|------|----------|--------|----------------|
| `[소프트 재화명]` | Soft Currency | 전투 보상, 퀘스트, 일일 출석 | 소모품, 강화 | Sink 시스템 (수리비, 강화 실패 등) |
| `[하드 재화명]` | Hard Currency | 과금, 이벤트 | 가챠, 편의 기능 | 직접 획득 경로 없음 |
| `[프리미엄 재화명]` | Premium Resource | 월정액, 한정 이벤트 | 고급 강화 | 주간 획득 상한 `[N]개` |

> [WARNING] Hard Currency와 Soft Currency 획득/소모 비율이 불균형할 경우 경제 붕괴 위험. 주간 시뮬레이션 필수. → 참조: SV-DB-001 (서버 데이터 검증)

### 전투 밸런스 공식

```
최종 데미지 = (공격력 × 스킬 계수) × (1 - 방어력 / (방어력 + K)) × 치명타 배수

K값: [예: 100]  [근거: 방어력 100일 때 피해 감소율 50% 목표, 밸런스 시뮬레이션 S-[날짜]]
치명타 배수: [예: 1.5~2.5]  [근거: 기대값 1.X 기준]
```

> [WARNING] 밸런스 공식 변경 시 GD-ECO-001, SV-NET-001(서버 검증 로직), QA-CAS-001(TC) 동시 업데이트 필요.

### 캐릭터 스탯 성장 공식

| 스탯 | 공식 | 근거 |
|------|------|------|
| 기본 공격력 | `BaseATK = 레벨 × [계수] + [기본값]` | 레벨 `[N]` 기준 보스 TTK `[N]`초 목표 |
| 기본 체력 | `BaseHP = 레벨 × [계수] + [기본값]` | 레벨 `[N]` 기준 동급 몬스터 `[N]`회 피격 생존 |
| 레벨업 성장률 | `Stat = 기본값 × 1.05^(레벨-1)` | 등비수열, 상위 레벨 성장 체감 방지 |
| 등급 배율 | `Normal:1.0 / Rare:1.3 / Epic:1.7 / Legend:2.2` | 수집욕 자극, 과도한 격차 방지 |

### 에너지 시스템 (해당 시 작성)

| 항목 | 값 | 근거 |
|------|-----|------|
| 기본 회복량 | `1개 / [N]분` | 평균 세션 간격 `[N]분` 기준 |
| 최대 보유량 | `[N]개` | DAU 피크 타임 `[N]시간` 기준 |
| 유료 구매 가격 | `[N] Hard Currency / 1회` | 동종 게임 시장 조사 평균 |

## GD-PTT-001: 플레이테스트 프로토콜

> 플레이테스트는 기획 수치와 난이도 곡선의 유일한 실증 수단입니다. 내부 감각이 아닌 실측 데이터로 의사결정하세요.

### 단계별 목표

| 단계 | 시점 | 참가자 | 목표 | 핵심 질문 |
|------|------|--------|------|----------|
| 내부 알파 | Vertical Slice 직후 | 팀 내 비개발자 3~5명 | 코어 루프 재미 검증 | "한 번 더 하고 싶은가?" |
| 외부 클로즈드 | Alpha 이후 | 타겟 유저 10~20명 | 온보딩·난이도 검증 | "막히는 지점이 어디인가?" |
| 오픈 베타 | Beta 이후 | 제한 없음 | 밸런스·수익화 검증 | "KPI 목표 달성 가능한가?" |
| 소프트론치 | RC 이후 | 선행 출시 국가 실유저 | 글로벌 출시 가부 판단 | "D1/D7 리텐션 목표 달성?" |

### 진행 규칙

- **개입 금지 원칙**: 참가자가 막혀도 힌트 제공 금지 — 이탈 포인트를 있는 그대로 기록
- **Think-Aloud**: 참가자가 생각을 말하며 플레이하도록 요청 (UI 혼란, 목표 불명확 등 언어화)
- **세션 길이**: 1회 30~45분 초과 금지 (피로도 증가 시 데이터 왜곡)
- **관찰 기록 항목**: 막힌 지점, 표정/반응, 자발적 재시도 여부, 이탈 시점

### 결과 분석 템플릿

| 이슈 | 발생 빈도 | 심각도 | 원인 가설 | 대응 방안 | 우선순위 |

## 장르 확장 포인트 (GD)

> 기획 문서에서 장르·특성에 따라 추가 또는 변경이 필요한 섹션:

| 장르 / 특성 | GD 추가 섹션 및 고려 항목 |
|-----------|------------------------|
| 횡스크롤 2D 액션 | 이동/점프 물리 파라미터(중력 배율, 점프 높이, 코요테 타임, 착지 딜레이), 장애물 패턴 생성 규칙, 카메라 앞쪽 여유 거리 |
| RPG | 스킬 트리 구조 다이어그램, 파티 최대 인원 및 포지션 설계, 퀘스트 체인·분기 설계 |
| PvP 장르 | 매칭 ELO/MMR 공식, 시즌 리셋 주기, 랭킹 보상 설계 |
| 퍼즐 | 퍼즐 메카닉 상태 머신, 힌트 단계 설계(힌트 1→2→3), 콤보 보상 체계 |
| 방치형(Idle) | 오프라인 누적 보상 공식, 자동화 단계 설계, 오프라인 상한 시간 기준 |
| 가챠/컬렉션 | 드롭률 테이블 전체 (등급별 확률 합산 100% 검증 필수), 천장(Pity) 시스템 발동 조건, 픽업 기간 설계 |
| 타워 디펜스 | 웨이브 패턴 설계서, 타워 업그레이드 트리, 적 경로(Path) 다이어그램 |
